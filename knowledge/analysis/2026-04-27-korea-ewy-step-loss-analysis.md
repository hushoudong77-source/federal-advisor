# 韩国EWY踏空复盘 — 系统漏洞与废墟收割协议

**日期**: 2026-04-27
**审计类型**: 战役复盘 / 系统漏洞识别
**相关标的**: EWY（韩国KOSPI 200 ETF）
**事件**: 4/8关税恐慌低点$68.50→4/21高点$74.57（+8.86%），全程踏空

---

## 一、根因分析

### 根因1：核心池"占位符"陷阱
19大核心池中，EWY虽然有位置，但**缺乏开火条件**——没有明确的价格锚点、买入区间、乖离率阈值。核心池不等于弹药库，没有配"扳机"的标的只是观赏品。

### 根因2：恐慌日无"废墟收割"SOP
4/8 VIX>30，全市场恐慌抛售，EWY乖离率约-15%。但系统没有自动触发"全池乖离率扫描→超卖候选标记→分批建仓"的流程。注意力全部被占用在救火（A账户浮亏、黄金回调），没有带宽去发现废墟中的机会。

### 根因3：反弹确认后无"追认机制"
4/14-4/18 EWY放量突破20日线，经典开火信号。但锚定效应（还在用$68.50低点做参照）导致"已经涨了，等回调买"——而韩国市场没给深度回调，直接踏空。

## 二、三条永久固化经验

### 经验1：每个核心池标的必须有完整的"开火档案"

| 字段 | 说明 | EWY案例 |
|:-----|:-----|:--------|
| 买入区间 | 乖离率区间 + 价格区间 | 乖离率<-12% 或 $68-$72 |
| 开火信号 | 技术面/量能触发条件 | 放量突破20日线 或 VCP收缩末端 |
| 仓位上限 | 不超过组合% | 5% |
| 硬止损 | -8%统一标准 | -8% |
| 分批建仓SOP | 建仓→确认→加仓 | 恐慌先1/3→反弹确认加1/3→突破满仓 |

**执行规则**：核心池中的标的如果没有完整的开火档案，自动降级为"观察列表"，不在扫描报告中以可操作标的展示。

### 经验2：恐慌日自动触发"废墟收割协议"

恐慌检测 → 全池乖离率扫描 → 三重过滤 → 分批建仓

**阈值**：
- VIX > 28 或 全市场单日跌幅 > 5% → 自动触发
- 乖离率 < -12% → 标记为"废墟候选"
- 三重过滤：①排除基本面恶化标的 ②确认流动性正常 ③确认标的在核心池内

**执行**：
- T日（恐慌日）：建仓1/3仓位
- T+3日（反弹确认）：加仓至2/3
- 放量突破20日线：加仓至满仓
- 硬止损统一-8%

### 经验3：踏空补救——反弹确认后的"追认机制"

**核心原则**：踏空的最大敌人不是"买贵了"，而是"没买"。

| 信号 | 操作 | 仓位 |
|:-----|:-----|:----:|
| 放量突破20日线 | 追入50% | 半仓 |
| 缩量回踩20日线不破 | 加仓至100% | 满仓 |
| 硬止损 | -8% | 保护本金 |

**心理纠偏**：锚定效应是踏空后追入的最大障碍。参照系应该是**当前技术结构**（是否突破、量能是否确认），而不是**恐慌低点的价格**。
