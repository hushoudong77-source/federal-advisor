### 核心矛盾

```
CRB 超买 + 布伦特暴跌 = 商品通胀逻辑正在松动
├── 若布伦特持续下行 → 通胀恐惧减弱 → 黄金避险需求↓ → IAU/518880 承压
├── 但 DXY 走弱 → 美元计价资产受益 → 黄金获得汇率支撑
└── 两力对撞，净效应偏中性 → SGOV 地堡维持不变
```
