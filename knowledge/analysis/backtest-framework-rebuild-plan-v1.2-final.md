## 一、致命问题诊断（不变）

当前回测框架存在一条完整的错误因果链：

> **全量数据网格扫描 → 捕获噪声模式 → 简化框架放大幻觉 → 错误目标函数奖励低频噪声 → 样本不足无法验证 → 实战灾难**

具体表现：
- 513770 全量回测选出的 MA60×2.5ATR，在最近 250 天 19 连败 0% 胜率
- 159545 的 MA40×4.5ATR 命中率 42.3%，接近「闭眼持有」
- MUFG 6 年仅触发 12 次，所谓「最优参数」可能是 3 笔交易撑起的幻觉

**原子修复路径——不是修修补补，是从方法论根部重建。**

|--------|------|------|---------|---------|
| **BUG-1.1** | P0 | P2 | Calmar>0 门槛等于无门槛，任何随机策略都能通过 | 改为 **Calmar ≥ 0.5**；同时要求训练期 Top10 参数在验证期的**排名中位数 ≤ 15**（70组中的前21%） |

## 三、七步执行路线（硬标准以 **粗体** 标注）

### 3.1 P1 — 重建交易引擎（含状态机与熔断矩阵完整规格）

#### 3.1.1 宏观熔断矩阵（多维度）

| 维度 | 指标 | 阈值 | 权重 |
|------|------|------|------|
| 美股波动率 | VIX 收盘价 | > 35 | 1 |
| 美债利率 | US10Y 单日变化 | > 15bp | 1 |
| 美元指数 | DXY 日波动率 | > 1.5% | 1 |
| A 股本土 | 上证50ETF 期权 iVIX | > 25 | 1 |
| 流动性 | 雪球恐慌指数 / 交易所逆回购利率异动 | > 30 | 0.5 |

**熔断逻辑**：
- 任意 **2 项**同时触发 → 暂停新开仓
- 任意 **3 项**同时触发 → 强制减仓至 1/3
- VIX > 40 单独触发 → 全清
- P1 触发时禁止 B1/B2/B3，但已持仓标的仍需检查 SL2/SL3/SL4

#### 3.1.2 仓位状态机（四状态 + 六级优先级 + 单日单次转移）

**状态定义**：

| 状态 | 仓位 | 代码 |
|------|------|------|
| S0 | 空仓 (0%) | `EMPTY` |
| S1 | 轻仓 (33.3%) | `LIGHT` |
| S2 | 中仓 (66.7%) | `MEDIUM` |
| S3 | 满仓 (100%) | `FULL` |

**触发条件定义**：

| 代码 | 条件 | 数学定义 | 适用状态 |
|------|------|---------|---------|
| **B1** | 首次买入 | 收盘价 < MA − k×ATR | S0 only |
| **B2** | 二次加仓 | 收盘价 < MA − 1.5k×ATR | S1 only |
| **B3** | 三次满仓 | 收盘价 < MA − 2.0k×ATR | S2 only |
| **SL1** | 止盈减仓 | 收盘价 ≥ MA ± 0.5×ATR（回归均值区） | S1/S2/S3 |
| **SL2** | 止损清仓 | 亏损 ≥ 2.0×ATR **或** 亏损 ≥ −8% | S1/S2/S3 |
| **SL3** | 时间退出 | 持仓天数 ≥ 60 日 | S1/S2/S3 |
| **SL4** | 熔断清仓 | 多维熔断矩阵触发（≥3项） | S1/S2/S3 |

**优先级（高→低，互斥性来源）**：

```
P1: 宏观熔断（全局暂停新开仓）
P2: SL2 止损（无条件，任何状态→S0）
P3: SL3 时间退出（任何状态→S0）
P4: SL4 熔断清仓（任何状态→S0）
P5: SL1 止盈减仓（降一档：S3→S2, S2→S1, S1→S0）
P6: B1/B2/B3 买入（分级加仓）
```

**状态转移真值表**：

| 当前状态 | 触发条件 | 下一状态 | 约束 |
|---------|---------|---------|------|
| S0 | B1 | S1 | 单日最多一次转移；熔断期禁止 |
| S1 | B2 | S2 | 必须已持仓；熔断期禁止 |
| S2 | B3 | S3 | 必须已持仓；熔断期禁止 |
| S1/S2/S3 | SL2 | S0 | 一旦触发，当日跳过所有低优先级条件 |
| S1/S2/S3 | SL3 | S0 | 持仓满60日强制触发 |
| S1/S2/S3 | SL4 | S0 | 熔断≥3项触发 |
| S3 | SL1 | S2 | 价格回归均值区，减1/3 |
| S2 | SL1 | S1 | 同上 |
| S1 | SL1 | S0 | 同上，清仓 |
| 任意 | 无触发 | 保持 | — |

**互斥性硬化规则**：

1. **单日单次**：每个标的每个交易日，最多执行一次状态转移。若 S0 时价格直接跌破 B3 区间，当日仅执行 S0→S1，次日若仍满足 B3 再执行 S1→S2，以此类推。
2. **卖出优先**：若同一日同时触发买入和卖出条件（极端罕见），以**卖出条件优先**（风控优先原则）。
3. **熔断覆盖**：P1 触发时，禁止一切 B1/B2/B3，但已持仓标的仍需检查 SL2/SL3/SL4。
4. **无未定义状态**：任意状态下若未触发任何条件，保持当前状态（完备性保证）。

#### 3.1.3 其余交易规则

| 规则 | 来源 | 说明 |
|:---|:---|:---|
| ATR 动态止损 | 法典 4.2 | 入场价 − k×ATR_entry，只上移不下调 |
| 绝对止损 | 法典 4.2.2 | 逐标 abs_pct（-5% 或 -7%） |
| 动态止盈（跟踪线） | 法典 4.7 | 开仓以来最高收盘价 − sell_k×ATR，只上移 |
| 时间衰减退出 | 新增 | 持有超过 60 个交易日仍未触发止盈/止损 → 按当前价退出 |

**交易成本硬编码**：
- 滑点：买入 +0.1%，卖出 −0.1%
- 佣金：0.03%（美股）/ 0.05%（A 股）
- **冲击成本**：0.2%（境内）/ **0.5%（跨境 ETF）**

### 3.5 P4 — 置换检验（Stationary Bootstrap × 2000 + FDR 5%）

**硬规格**：
- 块长：**Stationary Bootstrap，平均块长 60 交易日**（几何分布，最小 20 日，最大 120 日）
- 次数：**2000 次**（保证 p 值精度 ±1.4%）
- 多重比较：**Benjamini-Hochberg FDR 控制在 5%**（非 Bonferroni，Q3 硬答案）

**FDR 执行程序**：
1. 70 组参数各自计算置换检验 p 值
2. 按 p 值升序排列：p(1) ≤ p(2) ≤ ... ≤ p(70)
3. 找到最大 k，使得 **p(k) ≤ (k/70) × 0.05**
4. 前 k 组参数通过 FDR 控制，进入候选池

**附加硬标准**：若 **k=0**（无一通过），该标的直接 🔴 红灯踢除。

**产出**：`permutation_test_results.csv`

### 8.2 宏观熔断五维矩阵（代码级）

```python
def circuit_breaker_trigger(vix, us10y_change, dxy_change, ivix, panic):
    """
    每日收盘后计算，次日开盘前生效
    返回 True 表示任意2项触发 → 熔断
    """
    triggers = 0
    if vix > 30: triggers += 1
    if abs(us10y_change) > 0.0015: triggers += 1  # 15bp = 0.15% = 0.0015
    if abs(dxy_change) > 0.015: triggers += 1      # 1.5%
    if ivix > 25: triggers += 1
    if panic > 30: triggers += 1
    return triggers >= 2
```

| 3 | DXY 日波动率 | > 1.5% | FRED (DTWEXBGS) |

### 8.3 VIX>30 熔断触发时点（代码级）

**规则：收盘确认，次日开盘执行。非盘中触发。**


### 8.4 年度再平衡偏离计算（代码级）

**规则：相对偏离，非绝对偏离。每年12月第一个交易日执行。**

```python
def rebalance_trigger(ticker, current_weight, target_weight, threshold=0.10):
    """相对偏离 = |当前权重 - 目标权重| / 目标权重"""
    if target_weight == 0:
        return False
    relative_deviation = abs(current_weight - target_weight) / target_weight
    return relative_deviation > threshold  # >10% 触发
```
