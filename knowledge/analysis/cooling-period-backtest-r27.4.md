## 边际分析 — 关键发现

被冷却期过滤掉的交易，均收始终为正：

```
0d→7d:  过滤4,662笔 → 被过滤笔均收 +247%
7d→14d: 过滤451笔   → 被过滤笔均收 +216%
14d→21d:过滤159笔   → 被过滤笔均收 +357%
21d→30d:过滤96笔    → 被过滤笔均收 +276%
30d→45d:过滤93笔    → 被过滤笔均收 +222%
45d→60d:过滤46笔    → 被过滤笔均收 +137%
60d→90d:过滤49笔    → 被过滤笔均收 +534%
```

**物理原因**：在C1∧C2（EMA多头排列）环境下，动量信号聚集。连续触发不是"过度交易"，而是趋势在延续。冷却期打断了趋势跟踪的连续性。

## 回测局限性

- **0天冷却期不可执行**：5,692笔交易=日均~3笔，实盘中t+1/t+2滑点和执行延迟会严重侵蚀收益
- **夏普无统计显著差异**：所有冷却期夏普在0.016-0.018之间，冷却期长度不是夏普驱动因子
- **回测低估高频摩擦成本**：回测按收盘价完美执行，实盘存在滑点/时差

## CEO裁决

**删除30天冷却期。** C1-C4条件在EMA多头排列环境下的触发稀疏性本身即为自然冷却机制。冷却期只过滤利润不过滤噪音。
