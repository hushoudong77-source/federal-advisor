## 一、测试设计

### 1.1 方法论

**核心思想**：参数不敏感性原则。不在全量回测中找"最优参数"（那是噪音拟合），而是测试当前参数周围的"走廊"——参数小幅扰动后，策略是否仍然存活？如果只在针尖上有效，那策略本身是脆弱的。

### 1.2 测试矩阵

对每个标的生成9组参数（MA周期 ±10 × k值 ±0.5）：

```
当前MA = 60 → 测试MA = {50, 60, 70}
当前k = 3.0 → 测试k = {2.5, 3.0, 3.5}
组合：3 × 3 = 9组
```

对MUFG（k=2.5）：测试k = {2.0, 2.5, 3.0}
对510500（k=5.0）：测试k = {4.5, 5.0, 5.5}

### 1.3 回测设置

| 参数 | 值 |
|:---|:---|
| 训练窗口 | 500日滚动 |
| 止损 | 2.0×ATR追踪 |
| 建仓 | 简化单批（非正金字塔） |
| 时间范围 | 2018-2026（按数据可用性） |

### 1.4 判定标准

| 裁决 | 条件 |
|:---|:---|
| 🟢 鲁棒 | Sharpe中位数 > 0 ∧ 标准差 < 0.3 |
| 🟡 边际 | Sharpe中位数 > 0 ∧ 标准差 0.3~0.5 |
| 🔴 脆弱 | Sharpe中位数 > 0 ∧ 标准差 > 0.5 |
| 🔴🔴 否决 | Sharpe中位数 < 0（全区间负期望） |

## 三、关键发现

### 3.1 🟢 唯一鲁棒：IAU（黄金）

9组参数全部正Sharpe（2.95~3.61），标准差仅0.24。黄金反击策略对参数扰动完全不敏感——不是针尖策略，是整块钢板。金盾总纲与反击参数形成双保险。

### 3.2 🔴🔴 三个否决标的

**EWY**（中位数−0.43）：9组中8组负Sharpe。韩国ETF在反击框架下是系统性陷阱——跌了还会跌，没有均值回归。走廊测试揭示了此前回测未暴露的问题：反弹率高（93.8%）但**胜率被盈亏比吃掉**——反弹率≠赚钱。

**SMIN**（中位数−1.39）：9组100%负Sharpe。印度小盘ETF的反击完全失效。此前已由Step 3回测裁决剥夺反击资格（PF=0.93），走廊测试独立确认了这一裁决。

**510500**（中位数−0.47，标准差1.86）：中证500，9组中5组负Sharpe。标准差1.86是极端不稳定信号——MA50/k=5.5的Sh=+4.17，但MA60/k=5.5的Sh=−1.34，差一个MA周期夏普从+4崩到−1。教科书级的针尖策略。

### 3.3 🔴 四个脆弱标的

QQQ（std=0.99）、VTI（std=0.71）、VNM（std=0.62）、IVV（std=0.57）。这些标的的反击参数存在"悬崖效应"——参数小幅偏移，Sharpe大幅跳变。QQQ的绝对值高（中位数5.59），脆弱但至少正期望；VNM中位数仅0.20，脆弱且接近零期望。

### 3.4 🟡 四个边际标的

FLIN、VEA、MUFG、BBJP——标准差在0.35-0.46之间，不满足"<0.3鲁棒"标准但也不算脆弱。策略在这些标的上可用，但需要接受一定程度的参数敏感。

## 四、黑帽审计

### 4.1 方法论缺陷

1. **回测引擎简化**：使用2.0×ATR固定追踪止损，未实现法典正金字塔两层建仓（30%+70%）。这会让回测结果偏向保守——实际策略因为分批建仓，在参数鲁棒性上可能优于本测试。

2. **500日训练窗口**：对2018年起的数据意味着前两年不产生信号。对SMIN/EWY这类新兴市场标的，可能漏掉了早期的有效信号。

3. **QQQ Sharpe中位数5.59**：不意外。QQQ 2018-2026年本身就是超级牛市，任何"跌到MA以下买入"的策略都会享受到巨大的Beta红利。走廊测试测量的是**策略+市场Beta的联合分布**，不是纯Alpha。

### 4.2 走廊测试的角色

走廊测试不是用来否定现有参数的——它的战术价值在于识别**结构性死亡**的标的。当9组参数中有8组负Sharpe时，不是参数问题，是策略×标的的匹配根本不存在。
