## §0 固定层宪法 (Permanent Base Layer)

### 0.1 宪法地位

**VEA（20%）+ VTI（10%）构成全局资产的固定底仓层，总权重 30%。**

固定层具有以下不可侵犯属性：

| 属性 | 内容 |
|:---|:---|
| **路由豁免** | 不进入第二段路由判断。永远不被分配到进攻/反击/闲置轨道 |
| **策略豁免** | 不适用 Spearhead/Counterpunch 的任何入场/离场规则 |
| **止损豁免** | 不设 ATR 止损、绝对底线止损、动态止盈——不设技术指标驱动的自动离场条件，仅保留 §0.1 极端尾部减仓这一宪法级人工触发例外 |
| **宏观熔断豁免** | US10Y≥5.00%、VIX≥35、涨跌比<30% 等宏观闸对固定层无效 |
| **战时满载豁免** | S1/S2 满载态不改变固定层权重 |
| **唯一操作** | 仅执行年度再平衡（恢复至 VEA 20% / VTI 10% 目标权重） |
| **卖出禁令** | **任何情况下不得清仓固定层**（年度/偏离再平衡中的卖出超配部分不属于「清仓」，属于「权重修正」，被豁免于本禁令） |
| **极端尾部减仓** | VEA或VTI自52周高点回撤 ≥ 30% → 启动年度再平衡前置，允许减仓至目标权重的50%（即VEA 10% / VTI 5%），保留15%底仓。回撤 < 20%后恢复至目标权重。减仓资金转入现金层 |

### 0.2 再平衡触发条件

| 触发类型 | 条件 | 操作 |
|:---|:---|:---|
| **年度再平衡** | 每年 12 月首个交易日 | VEA 恢复至 20%，VTI 恢复至 10% |
| **偏离触发** | 任一标的权重偏离目标 ±5pp（VEA<15% 或 >25%，VTI<5% 或 >15%） | 立即再平衡至目标权重 |
| **新增资金** | 全局总资产因外部注资增长 ≥20% | 按 20%/10% 比例增配 VEA/VTI |

**互斥条款**：年度再平衡日若偏离触发同时满足 → 仅执行年度再平衡一次，偏离触发顺延至下一交易日校验。避免同日双次再平衡产生重复交易。

### 0.3 再平衡执行规则

```
1. 计算当前 VEA/VTI 市值
2. 计算目标市值 = 全局总资产 × 目标权重（20%/10%）
3. 差额 = 目标市值 − 当前市值
4. 正差额 → 从现金账户划拨资金买入。若现金不足，暂停再平衡，标记「现金不足-待注资」，不卖出其他资产。**固定层再平衡为宪法义务，优先于§3.3现金主权率下限——再平衡可动用现金至 5% 硬底（即现金最低降至全局总资产×5%），此 5% 硬底不可突破。**
5. 负差额 → 卖出超配部分，资金回笼现金账户
6. 执行后固定层权重精确恢复至 20% + 10%
```

### 0.4 固定层与全局资产的关系

```
全局资产
├── 固定层 30%（VEA 20% + VTI 10%）← 本宪法管辖，永不离场
├── 竞争上岗池（进攻 + 反击，资金动态进出）← 双轨法典管辖
└── 现金（不在仓的所有资金，用户自行管理停放）
```

**固定层不计入竞争上岗池可用资金。**

```
现金层市值 = 全局总资产 − 固定层市值 − 已占用进攻仓位市值 − 已占用反击仓位市值
```
其中「已占用市值」= Σ(持仓股数 × 当前市价)，非成本。恒等式保证现金层永远非负（市值随市价波动，总资产同步波动）。

## 第二段：路由判断 (Routing Logic)

### 2.0 路由总则

- 🟢 **进攻策略**：顺势加仓，七条件全满足
- 🟡 **反击策略**：逆势接飞刀，MA200走平/向下 + 价格落入买入区间

**核心原则**：一标一轨 / 已持仓豁免路由重判 / 路由仅决定新资金去向 / 反击锚点前置 / 固定层（§0）不进入路由。

### 2.2 路由规则详解

#### A5 动态ADX

| ADX区间 | A5判定 | 原理 |
|:---|:---|:---|
| ADX > 30 | 禁用，不检查乖离 | 强趋势中乖离大≠过热 |
| 20 < ADX ≤ 30 | C − MA30 ≤ 5×ATR | 中等趋势，给更多空间 |
| ADX ≤ 20 | 无条件通过 | 低趋势环境，乖离检查无统计效力。**备用保护**：若 C−MA30 > 3×ATR（极度乖离），降级为 🟡「ADX低位+高乖离风险」，标注于指令备注栏，不阻断入场 |

#### A7 容差

0.5%容差（×0.995），消除ETF买卖盘摩擦/汇率噪声。**低价标的额外保护**：容差 = max(0.5%, 0.05元/入场价)。即：若0.5%对应的绝对金额 < 0.05元（如VNM 19.77×0.5%=0.099元 > 0.05元，正常通过；极端低价 <10元的标的才触发），取0.05元对应百分比。确保低价标的不会因买卖盘1-2分钱摩擦系统性触发A7失败。

#### 步骤0.5 极端乖离

\|C−MA200\|/MA200 > 50% → 🔴直接观望。双向拦截：向上过热（泡沫风险）+ 向下崩盘（接飞刀风险）。尾部风险对称保护。

阈值依据：全池19标历史乖离分布中，\|乖离\|>50%的样本占比<2%，且后续20日胜率<35%。50%为极端尾部截断线，目的不是精准择时，而是阻止在统计上几乎必然回归的场景中建仓。对高波动标的（EWY/VNM），50%阈值在回测中未出现系统性误杀（EWY当前乖离+79.7%属于极端场景，拦截合理）。

### 3.1 进攻策略 (Spearhead Protocol) — 全量内嵌

**核心哲学**：纯趋势跟随。不预判，只跟随。唯一防线 = 3×ATR trailing stop。

#### 3.1.1 入场信号（七项全满足）

| # | 条件 | 说明 | 路由条件 |
|:--|:---|:---|:---|
| ① | MA200 方向向上 | 中长期上升趋势确立 | A2 |
| ② | MA30 方向向上 | 中短期动能向上 | A4 |
| ③ | 收盘价 > MA200 | 价格在长期均线之上 | A1 |
| ④ | 收盘价 > MA30 | 价格在中短期均线之上 | A3 |
| ⑤ | 收盘价 ≥ 20日最高价（0.5%容差） | 突破确认，趋势加速信号 | A7 |
| ⑥ | ADX > 20 | 趋势强度足够 | A6 |
| ⑦ | ADX > 30 → 禁用乖离检查 / 20<ADX≤30 → C−MA30 ≤ 5×ATR / ADX≤20 → 无条件通过 | 动态乖离过滤 | A5 |

七项全满足 → 进攻开火。与路由层§2.1步骤1完全一致（A1-A7全部对应）。

**本层与路由层的关系**：路由层已判定进攻的标的，本层入场信号自动通过（两者条件等价）。本层存在的意义：(1) 提供仓位计算与建仓序列（路由层不涉及）；(2) 为直接 `/开火` 快捷指令提供独立执行入口，无需先经过完整路由扫描。

#### 3.1.2 仓位与建仓

**资金池**：独立子账户，全局总资产的 10%–15%。

**R 定义**（风险单位，全文档统一）：
```
R = 3 × ATR    ← 入场价与3×ATR止损价之间的最大亏损距离。1R亏损 = 每股亏损 3×ATR。
```

**首发仓位计算**：
```
若 ATR ≤ 0 → 中止，数据异常
若 3×ATR ≥ 入场价 → 中止，波动率过大不适合进攻建仓
N₁ = (全局总资产 × 1%) / (3 × ATR)
```
分母 = 3×ATR = 触发止损时的每股亏损。N₁ = 单次风险暴露 = 全局总资产 1%。

**单标上限截断**：
```
若 N₁ × 入场价 > 全局总资产 × 8% → N₁ = floor(全局总资产 × 8% / 入场价)
```

**加仓序列（反等价鞅 — 盈利加仓）**：

| 批次 | 触发条件 | 数量 |
|:---|:---|:---|
| 第一发 | 入场信号触发 | N₁ |
| 第二发 | 浮盈 ≥ 2×R（即股价−入场价 ≥ 2×3×ATR） | N₁ × 50%（递减） |
| 第三发 | 第二发建仓后浮盈再 ≥ 1×R（即从第二发实际建仓价起算，股价再涨 1×R=3×ATR） | N₁ × 25%（再递减） |

**单标上限 — 8% 硬顶**：

| 铁律 | 内容 |
|:---|:---|
| 一 | 总暴露（N₁+N₂+N₃）× 入场价 / 全局总资产 ≤ 8% |
| 二 | N₁ 占满 8% → 终生禁止加仓该标的 |
| 三 | N₁ + N₂ 达 8% → 永久取消第三发 |
| 四 | 严禁为凑三发主动压减 N₁ |

#### 3.1.3 离场机制 — 唯一防线

**3×ATR Trailing Stop**：
```
买入即挂载：建仓以来最高收盘价回撤 3×ATR 追踪止损
  → 最高收盘价定义：建仓日至今每日收盘价的最大值，不含盘中最高价
触线 → 市价全清，无例外
未触线 → 死咬利润，不设上限
```

**跳空缺口执行条款**：若开盘价 ≤ 止损线 − 0.5×ATR（隔夜跳空直接击穿止损线），触发后下一分钟执行 TWAP（时间加权均价）清仓。TWAP 每30秒采样一次，1分钟内完成。原因：跳空缺口下市价清仓成交价可能远低于理论止损价，TWAP可减少缺口滑点损耗。

**废除的冗余防线**（全部移除）：
- ❌ MA30 跌破离场（剧烈洗盘常击穿MA30）
- ❌ 时间止损（高位旗形震荡是主升前常态）
- ❌ MA200 转势离场（数学上永远比3×ATR晚触发）
- ❌ 固定止损等1R（推迟挂载=拉长风险暴露窗口）

#### 3.1.4 宏观过滤器

**不加。** 决策逻辑：
1. 子账户隔离已定价尾部风险：10%–15%资金池，最坏全损上限已知
2. 3×ATR双向滞后：跳空打穿多亏1-2R，但V型反弹时不关闸能吃到
3. 纯跟随哲学：不预判，只跟随

#### 3.1.5 与反击策略冲突解决

```
ATTACK_LOCKED：进攻持仓中
  → 反击策略对该标的：买入信号屏蔽 / 卖出信号屏蔽
  → 唯一离场：3×ATR trailing stop

ATTACK_UNLOCKED：进攻清仓后
  → 反击策略恢复对该标的的完整管辖权
```

| 场景 | 进攻状态 | 反击信号 | 裁决 |
|:---|:---|:---|:---|
| ① 双向暴露 | 持仓中 | 买入信号 | **禁止叠加**，ATTACK_LOCKED |
| ② 信号冲突 | 持仓中 | 卖出信号 | **反击卖出无效**，3×ATR是唯一离场 |
| ③ 无冲突 | 无持仓 | 买入信号 | 各自独立执行 |
| ④ 无冲突 | 无持仓 | 卖出信号 | 无仓可卖 |

#### 3.2.2 仓位与建仓

**仓位分档规则**：

| 分档 | 批次 | 单批比例 | 适用梯队 |
|:---|:---|:---|:---|
| **低风险** (T1) | 2批 | 50% + 50% | QQQ/IVV/510300/513910/159545 |
| **中风险** (T2/T3-A/T4) | 3批 | 50% + 30% + 20% | BBJP/MUFG/EWY/VNM/FLIN/510500/159302 |
| **高风险** (T3/T3-B) | 3批 | 33% + 33% + 34% | 159915/588000/513770/513180 |

**建仓执行**：
```
第一批（先锋）：价格首次落入买入区间 → 按分档比例建仓
第二批（加仓）：价格继续下探至买入区间下界附近 → 加仓
第三批（满仓）：价格触及下界或以下 → 满仓（仅中/高风险分档）
```

**单标上限**：MA200走平 ≤10% / MA200向下 ≤5%。与进攻策略合并不得突破单标总暴露 ≤20%。

**股数计算**：
```
若 ATR ≤ 0 → 中止，数据异常
若 3×ATR ≥ 入场价 → 中止，「极端波动禁止建仓」，N=0，指令终止输出
若 0.05 × 入场价 > 3 × ATR → 中止，「低波动异常禁止建仓」，N=0，指令终止输出
  → 原因：止损价被−5%硬线截断后，实际每股风险 (入场价×0.05) 远超 3×ATR 设计假设，
     此时N = (动态总资产 × 1%) / (3×ATR) 会严重低估实际风险暴露，突破1%风险单元上限
N = (动态总资产 × 1%) / (3 × ATR)     ← 反击统一用3×ATR作分母
```
其中**动态总资产** = 全局总资产 − 固定层市值（§0.1），即竞争上岗池+现金的总和。动态总资产仅在资金分配时计算一次，建仓执行期间不随市价波动重算。

**单标上限截断**：
```
若 N × 入场价 > 动态总资产 × 单标上限 → N = floor(动态总资产 × 单标上限 / 入场价)
```

**止损位计算**（互锁公式）：
```
止损价 = min(入场价 − 2.0×ATR, 入场价 × 0.95)
```
物理含义：两个下限取更紧者。**绝不取更宽者**——2.0×ATR止损线若低于−5%线，截断至−5%（本金保护优先）。黄金类(IAU/518880)绝对底线为0.93（−7%）。

| 标的分类 | ATR乘数 | 绝对底线 | 止损价公式 |
|:---|:---:|:---:|:---|
| 全池（除黄金） | 2.0×ATR | −5% | `min(入场价−2.0×ATR, 入场价×0.95)` |
| 黄金类 (IAU/518880) | 2.0×ATR | −7% | `min(入场价−2.0×ATR, 入场价×0.93)` |

#### 3.2.3 离场机制 — 卖出五源

任何持仓标的的减仓/清仓指令，必须且仅能由以下五源之一触发：

| 编号 | 卖出源 | 触发条件 | 动作 |
|:---:|:---|:---|:---|
| SRC-1 | **基础止损** | 价格 ≤ 止损价（§3.2.2互锁公式结果） | 市价全清 |
| SRC-2 | **绝对底线** | 价格 ≤ 入场价 × 0.95（黄金0.93） | 市价全清 |
| SRC-3 | **动态止盈** | 价格 ≤ 建仓以来最高收盘价 − sell_k×ATR | 市价全清 |
| SRC-4 | **锚线跌破** | 收盘价 < MA 锚线（逐标差异） | 收盘确认后清仓。**建仓冷却期豁免**：买入后5个交易日内不触发SRC-4 |
| SRC-5 | **宏观熔断** | 标的属地宏观闸触发（§2.1步骤0-A至0-D）且该标的正在持仓 | 市价全清 |

**SRC-1与SRC-2的关系**：互锁公式 `min(入场价−2.0×ATR, 入场价×0.95)` 取两个下限的更紧者。当 2.0×ATR < 5%×入场价 时，止损价=入场价−2.0×ATR（SRC-1更紧先触发），此时 SRC-2（0.95×入场价）更宽、尚未触发。当 ATR 极端缩小（2.0×ATR 极小）时，止损价=入场价×0.95（SRC-2更紧先触发）。实际执行取先触发的 SRC 编号，执行一次即可。SRC-2的实际作用是：当ATR极端缩小时，−5%硬线提供独立保护。

**SRC-5（宏观熔断）触发条件**：完全引用§2.1步骤0-A至0-D的宏观闸阈值（不新增独立标准）：
- 0-A 全局：US10Y ≥ 5.00% → 全池持仓清仓（固定层豁免）
- 0-B 国际：VIX ≥ 35 → 美股/港股持仓清仓
- 0-C 国内：涨跌比 < 30% → A股持仓清仓
- 0-D 港股：恒生20日跌幅 > 15% → 港股持仓清仓

宏观熔断触发后，已持仓标的立即市价清仓，不等待止损线触发。固定层（§0）豁免。此规则与§2.4「宏观熔断下的已持仓处理」完全一致，无歧义。
