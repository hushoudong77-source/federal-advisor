##### §6.4 状态切换信号优先级与自检熔断

```

P3: 高收益债利差（P4 AnySearch）
P4: 经济领先指标（PMI/消费者信心，P4 AnySearch）
```

**状态切换规则**：
- **进入STAGE_1**：VIX突破35 → 立即激活§4.4 CRISIS状态
- **STAGE_1→STAGE_2**：必须同时满足VIX从峰值回落>30% + 降息确认（两条件AND）→ 不可提前
- **STAGE_2→STAGE_3**：必须同时满足VIX<20 + 信贷利差<400bp（两条件AND）→ 不可提前
- **越级回退**：任何阶段VIX重新突破35 → 直接退回STAGE_1

**自检熔断**：
- 触发：VIX>35时输出中包含"进攻开火"/"反击开火"/"买入黄金"任一信号 → 危机状态机违规，立即中止

**默认状态**：所有涉及美股/全球资产的审计/扫描/路由判定前，必须先获取VIX数据并判定当前危机状态。本模块优先级与模块零（数据取数强制流程）同级。

#### §6.5 极端场景处置规则（2026-06-27 焊入 — K2.6审计 4-004）

**核心原则**：法典的止损/止盈/冷却期/开仓信号均基于「价格连续、流动性正常」假设。当标的遭遇涨跌停/停牌/流动性枯竭等极端场景时，上述假设破裂，必须走独立处置流程。

**触发条件（OR）**：
| 条件 | 定义 | 判定标准 |
|:---|:---|:---|
| **涨停板** | A股涨幅≥10%（创业板/科创板≥20%） | 当日无法以市场价买入 |
| **跌停板** | A股跌幅≥10%（创业板/科创板≥20%） | 当日无法以市场价卖出 |
| **停牌** | 交易所公告停牌 | 连续≥1个交易日无法交易 |
| **美股熔断** | 标的价格单日触发LULD暂停 | 5分钟内无法交易 |
| **流动性枯竭** | 标的日均成交量骤降>70%或买卖价差>5% | 连续3个交易日 |

**处置矩阵**：

| 场景 | 已持仓处置 | 新开仓 | 冷却期 | 恢复条件 |
|:---|:---|:---|:---|:---|
| **涨停板** | 持有不动，止损上移至成本价（保本） | ⛔禁止追板 | 涨停日不计入冷却期 | 次日开盘恢复 |
| **跌停板** | 次日开盘集合竞价挂跌停价卖出（无论是否触发止损） | ⛔禁止抄底 | 跌停日不计入冷却期 | 打开跌停后48h重新判定 |
| **停牌** | 仓位冻结，止损/止盈暂停累计 | ⛔禁止建仓 | 停牌期不计入冷却期 | 复牌后首个交易日恢复 |
| **美股熔断** | 持有不动，熔断解除后按当日收盘重新计算止损/止盈 | ⛔禁止建仓 | 熔断日不计入冷却期 | 下一交易日恢复 |
| **流动性枯竭** | 减仓50%（无论盈亏），剩余仓位止损收紧至ATR×1.5 | ⛔禁止建仓 | 冻结 | 日均量恢复至枯竭前70%以上+价差<2% |

**停牌复牌特别规则**：
```
停牌期间 → 持仓市值 = 停牌前最后收盘价 × 持仓量（用于账户总资产计算）
复牌首日 → 不触发任何买入信号（无论价格多诱人）
         → 若复牌首日大跌触发止损线 → 立即按开盘价卖出
         → 若复牌首日涨停 → 持有，次日恢复止损/止盈正常判定
复牌次日 → 恢复正常路由判定 + 冷却期重新计算
```

**A股跌停板次日强制卖出 SOP**：
```
Step 1: 跌停当日收盘后确认跌停 → 标记「次日强制卖出」
Step 2: 次日9:15前挂跌停价集合竞价卖出
        ├── 若集合竞价成交 → 执行完毕
        └── 若未成交 → 9:30开盘后以对手方最优价卖出
Step 3: 卖出后 → 记录决策日志 → 触发48h冷却期
Step 4: 48h后重新路由判定
```

**自检熔断**：
- 触发：标的处于跌停/停牌/流动性枯竭状态，但仍输出买入信号 → **极端场景违规**
- 触发：跌停标的未标注「次日强制卖出」→ **跌停处置遗漏违规**
- 触发：停牌标的的止损/止盈仍在累计计算 → **停牌规则违规**
- 触发：流动性枯竭标的未标注减仓50% → **流动性处置遗漏违规**
