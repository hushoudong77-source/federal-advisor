## §0 固定层宪法

> 定位：VEA（20%）+ VTI（10%）构成全局资产的固定底仓层，总权重 30%

### 0.0 术语定义

| 术语 | 定义 |
|:---|:---|
| **P0** | 人工决策层（统帅/守东胡总）。法典中唯一可覆盖自动化规则的权限主体。P0指令优先级高于所有自动化规则，但不可突破5%现金主权率硬底。 |
| **全局总资产** | 固定层市值 + 竞争上岗池市值 + 黄金独立层（IAU/518880）市值 + 现金层市值。含黄金层。 |
| **清仓** | 将持仓卖出至0。与"权重修正卖出"不同——后者仅卖出超配部分，保留目标权重持仓。 |
| **权重修正** | 卖出超配部分以恢复目标权重，不属于"清仓"，豁免于卖出禁令。 |
| **TWAP** | 时间加权平均价格算法，在指定窗口内分批执行。 |

### 0.1 宪法地位

固定层具有以下不可侵犯属性：

| 属性 | 内容 |
|:---|:---|
| **路由豁免** | 不进入第二段路由判断。永远不被分配到进攻/反击/闲置轨道。**空仓例外（V5.8.2r17修订）**：若持仓为零 → 临时进入「固定层建仓专用通道」（非进攻/反击轨道），建仓目标 = 目标权重（10%/20%），**不受Spearhead 7.5%上限约束**。建仓后自动转入§0管辖，恢复豁免。详见路由§2.0 |
| **策略豁免** | 不适用 Spearhead/Counterpunch 的任何入场/离场规则 |
| **止损豁免** | 不设 ATR 止损、绝对底线止损、动态止盈——不设任何技术指标驱动的**自动**离场条件。**策略全链路合龙条款（V5.8.2r17修订）**：VTI/VEA建仓后仍受策略层持仓监控扫描，但离场动作被限缩——SRC-5（US10Y≥5.00%）自动执行TWAP减仓，SRC-1~4/6仅告警需P0手动确认。详见0.1.2固定层与策略全链路接口协议 |
| **宏观熔断豁免** | US10Y≥5.00%时：**禁止清仓**（卖出至0），允许权重修正卖出（当前权重>目标权重时）+ SRC-5 TWAP减仓（仅当当前权重>目标权重50%时）。禁止再平衡买入。年度再平衡顺延至US10Y<5.00%后首个NYSE交易日。详见0.1.1三向死锁优先级矩阵 |
| **常规操作** | 年度再平衡（恢复至 VEA 20% / VTI 10% 目标权重）。例外操作：空仓建仓（路由§2.0专用通道）、偏离触发、新增资金、提取资金 |
| **卖出禁令** | **任何情况下不得清仓固定层**（权重修正卖出、SRC-5宏观减仓不属于「清仓」，属于「权重修正」，被豁免于本禁令） |

#### 0.1.1 三向死锁优先级矩阵（V5.8.2r17 — BUG-A修复）

当以下三层同时触发时，按优先级裁决：

```
优先级0（最高—不可逾越）：现金主权率 5% 硬底
  → 任何操作不得击穿。现金不足时所有买入（含固定层再平衡）一律暂停
优先级1：宏观闸 US10Y ≥ 5.00%
  → 固定层：禁止清仓和再平衡买入。允许：超配权重修正卖出 / SRC-5 TWAP减仓（仅当当前权重>目标权重50%时）
  → 策略层：按0-A规则执行（进攻TWAP减仓50%/反击市价全清）
优先级2：固定层再平衡义务（年度/偏离触发/新增资金）
  → 仅在优先级0和1均未锁死时执行
```

**裁决示例**：
- US10Y=5.1% + 现金主权率=6%（状态B）+ VEA偏离触发：固定层买入被优先级1冻结（禁止再平衡买入），非被优先级0禁止（现金还够）。年度再平衡顺延。
- US10Y=5.1% + 现金主权率=3%（击穿硬底）：优先级0锁死一切买入。超配卖出仍可执行（回笼现金恢复硬底）。年度再平衡顺延。
- US10Y=4.8% + 现金主权率=5.5%（状态B）+ VEA偏离触发需买入：优先级1未触发、优先级0未锁死 → 固定层买入可执行，买入金额=min(计算值, 可用现金−硬底)。

#### 0.1.2 固定层与策略全链路接口协议（V5.8.2r17 — BUG-B修复）

VTI/VEA 建仓后，同时受固定层宪法（§0）和策略全链路（§2+§3）管辖。以下为接口协议，消除两层级间的传参死锁：

```
VTI/VEA 建仓后：
├── §0 固定层宪法管辖：
│   ├── 年度再平衡 / 偏离触发卖出（权重修正）→ 自动执行，无需P0确认
│   ├── 卖出禁令 → 清仓=绝对禁止，超配卖出=权重修正=豁免
│   └── 三向死锁优先级矩阵（0.1.1）→ 适用
│
├── §2 策略全链路监控：
│   ├── 持仓监控扫描 → 永不豁免（r21保留条款）
│   ├── SRC-1~4 / SRC-6 扫描 → 仅告警，需P0手动确认执行，不自动离场
│   ├── SRC-5 宏观熔断（US10Y≥5.00%）→ 自动执行，无需P0确认
│   │   → TWAP减仓至目标权重50%（VEA 20%→10%, VTI 10%→5%）
│   │   → TWAP窗口：2个交易日（启动后继续执行完毕，US10Y回落<5%也不回撤）
│   │   → 此减仓为「宏观闸强制权重修正」，豁免于卖出禁令中的"清仓"定义
│   └── 告警阈值：浮亏≥8%（SRC-2等效）/ 双死叉（SRC-4等效）/ -15%（SRC-6等效）
│       → 触发时输出「固定层告警：标的/阈值/当前值」，等待P0确认
│
├── 再平衡卖出（权重修正/提取资金）：
│   → 自动执行，无需P0确认
│
└── 核心原则：
    ├── 固定层可被策略层监控，但不能被策略层单方面清仓
    ├── SRC-5为唯一策略层可自动执行的固定层离场动作
    ├── 再平衡卖出为宪法层自动执行的离场动作
    └── 技术指标离场（SRC-1~4/6）→ 仅告警 + 需P0手动确认
```

**离场确认分级汇总**：

| 离场类型 | 触发来源 | 执行方式 |
|:---|:---|:---|
| 再平衡卖出（权重修正/提取资金） | §0 固定层宪法 | 自动执行 |
| SRC-5 TWAP减仓（US10Y≥5.00%） | §2 策略全链路 | 自动执行 |
| SRC-1~4 / SRC-6 技术指标离场 | §2 策略全链路 | 仅告警，需P0手动确认 |
| 清仓（卖出至0） | 任何来源 | **绝对禁止** |

**与路由§2.0的对接**：路由§2.0中"VTI/VEA空仓→临时进入路由判定，建仓后仅禁新开仓，持仓监控永不豁免"——"持仓监控永不豁免"的具体行为按本协议执行（SRC-5自动执行，其余仅告警）。

### 0.2 再平衡触发条件

| 触发类型 | 条件 | 操作 |
|:---|:---|:---|
| **年度再平衡** | 每年 12 月首个可交易 NYSE 交易日（含因休市顺延） | VEA 恢复至 20%，VTI 恢复至 10%。若该日 A 股休市，顺延至下一 A 股交易日执行美股交易指令 |
| **偏离触发** | 任一标的全局权重偏离目标 ±5pp（VEA<15% 或 >25%，VTI<5% 或 >15%）。**基准（V5.8.2r16明确）**：目标全局权重 = §0.1定义的 VEA 20% / VTI 10%。偏离 = \|当前全局权重 − 目标全局权重\| ≥ 5pp。固定层内部权重（VEA:VTI=2:1）仅作参考，不独立触发 | 立即再平衡至目标权重。**偏离计数器重置（V5.8.2r18缺陷3）**：任何再平衡操作（年度/偏离/新增/提取）执行后，自动重置偏离触发状态。下次扫描重新计算权重独立判定，杜绝并发重复执行。 |
| **新增资金** | 外部净注入资金 ≥ 上次再平衡日全局总资产的 10%（V5.8.2r16修订：区分外部注资与资产增值。资产增值/贬值导致的总资产变化不计入。基准：上次再平衡日总资产，每次再平衡后自动重置基准） | 恢复至目标权重。缺口优先用新增资金填补。新增资金不足时，按§0.4资金池竞争仲裁从现金层划拨（服从§0.5.2三态裁决，可动用至5%硬底）。仍不足时标记「硬底锁死-买入暂停（待注资）」，暂停再平衡 |
| **提取资金** | 外部净提取资金 ≥ 上次再平衡日全局总资产的 10%（V5.8.2r16新增：对称触发。**V5.8.2r17强制化**：触发后**强制**恢复至目标权重，无论是否达到偏离阈值。原因：提取资金改变全局总资产基数，必须精确校准权重） | VEA/VTI 权重被动升高 → 卖出超配部分恢复至目标权重（权重修正，豁免于卖出禁令） |

**并发处理（V5.8.2r17 P2备忘J）**：年度再平衡日若偏离触发同时满足 → 合并为单次执行，按目标权重一次性调整到位，避免重复交易。偏离触发顺延取消（已被合并覆盖）。

**状态C时年度再平衡处理（V5.8.2r18缺陷2 — 方案A）**：
- 负差额（超配）→ 正常卖出，回笼现金恢复硬底
- 正差额（缺口）→ 买入冻结，本次年度再平衡标记「硬底锁死-年度再平衡未完成」
- 不自动顺延。等待下次触发条件（偏离/新增资金/次年年度）自然评估。年度再平衡为周期性校准，非紧急事件，硬底优先。

**偏离触发补充条款（V5.8.2r22黑帽终审第二轮）**：

**P2提醒A — 内部比例告警**：固定层内部权重 VEA:VTI=2:1 仅作参考，不独立触发再平衡。但当内部比例偏离 > 3:1（即 VEA>75% 或 VTI>75%，固定层内部）或 < 1:1 时，系统应输出**告警日志**（不触发再平衡，不进入偏离计数器），供P0年度再平衡时参考。告警阈值：内部比例 > 3:1 或 < 1:1，每季度自动扫描一次。

**P2提醒B — 执行容差**：§0.3步骤6"精确恢复至20%+10%"在物理上不可实现（执行期间市价变动）。补充容差条款：执行后 |实际权重 − 目标权重| ≤ 0.5pp 视为"已恢复"。超出容差 → 标记「再平衡残余-待下次触发修正」，不启动无限微调循环。

### 0.3 再平衡执行规则

> **V5.8.2r27.1 同步更新**：单标总暴露上限表述与主权指令对齐。宪法文本保留"≤20%"数值，备注栏明确"主权指令已覆盖，20%从硬顶降级为预警提醒"。实际执行以AGENT.md仓位主权条款为准。

```
1. 计算当前 VEA/VTI 市值
2. 计算目标市值 = 全局总资产 × 目标权重（20%/10%）
3. 差额 = 目标市值 − 当前市值
4. 正差额 → 买入缺口。
   买入金额 = min(正常计算值, 可用现金 − 总资产×5%硬底)
   ├── 若 min值 ≤ 0 → 标记「硬底锁死-买入暂停（待注资）」，本次再平衡终止
   ├── 若 0 < min值 < 正常计算值 → 标记「硬底约束-部分买入」，仅买入min值，权重未完全恢复
   └── 若 min值 = 正常计算值 → 全额买入，权重完全恢复
   再根据§0.5.2三态裁决微调：
   状态A（>8%）：全额买入（min值不额外受限）
   状态B（5-8%）：固定层再平衡正常执行，全额买入（服从§0.5.2三态裁决——固定层再平衡在状态B不受半速限制。非固定层半速消耗不受此影响）。原状态B半速条款已删除（r27.1 P1-5修复：与§0.5.2「固定层再平衡正常执行」矛盾）。
   状态C（≤5%）：禁止一切买入，标记「硬底锁死-买入暂停（待注资）」
   5% 硬底为终极防线，任何情况（含P0指令）不可突破。
   **空仓建仓例外（V5.8.2r17 P2备忘M）**：空仓VTI/VEA建仓为宪法义务（恢复目标权重），不受状态B半速约束。状态C仍禁止。
5. 负差额 → 卖出超配部分。
   卖出金额 = |当前权重 − 目标权重| × 总资产（卖出金额为金额，非股数）
   资金回笼现金账户
   （V5.8.2r17：删除冗余"/当前市价"，卖出金额=金额，执行时按市价换算为股数）
6. 执行后固定层权重精确恢复至 20% + 10%（若部分买入则标记未完全恢复）
```

**0.3与0.5.2统一（V5.8.2r16）**：本条不再独立定义"现金不足→暂停"逻辑，统一引用§0.5.2三态裁决。两者表述不一致的历史遗留已消除。

### 0.4 全局资产分层架构

```
全局资产
├── 固定层 30%（VEA 20% + VTI 10%）← 宪法管辖，永不离场
├── 竞争上岗池（进攻 + 反击，资金动态进出）← 双轨法典管辖
├── 黄金独立层（IAU + 518880）← 金盾总纲V1.2独立管辖，不参与路由，不参与竞争
└── 现金层（不在仓的所有资金，用户自行管理停放）
```

**固定层不计入竞争上岗池可用资金。黄金独立层独立核算，不计入竞争上岗池。**

**全局总资产定义（V5.8.2r17 P2备忘L明确）**：
```
全局总资产 = 固定层市值 + 竞争上岗池市值 + 黄金独立层市值 + 现金层市值
```
所有再平衡目标权重的计算基于此全局总资产（含黄金层）。

**跨币种市值转换（全局适用）**：
```
美元标的 CNY市值 = 持仓股数 × 当前市价(USD) × USDCNY
人民币标的 CNY市值 = 持仓股数 × 当前市价(CNY)
```

```
现金层市值 = 全局总资产 − 固定层市值 − 已占用进攻仓位市值 − 已占用反击仓位市值 − 黄金独立层市值
```

### 资金池竞争仲裁

当多个资金需求方同时申请资金时，按以下优先级排队：

```
P1：固定层再平衡（宪法义务，最高优先级）→ 服从§0.5.2三态裁决
P4：反击新开仓（需现金主权率>5%）→ 同优先级按路由时间戳先到先得
P5：进攻新开仓（需现金主权率>5%）
P6：黄金独立层买入（IAU/518880，金盾总纲V1.2管辖）→ 服从§0.5.2三态裁决：状态A全速/状态B半速/状态C禁止买入（仅允许卖出/止盈）。金盾总纲买入信号需通过三态裁决后方可执行。不单独设置现金主权率门槛（V5.8.2r17：明确金盾总纲与三态裁决优先级——三态裁决优先）
```

**止损回补说明**：SRC触发后持仓清仓，资金自动回笼现金层，提升P4/P5/P6可用额度。止损回补为资金释放事件，非资金需求方，不参与排队竞争。原P2/P3编号已废弃。

**P6与状态机统一规则（V5.8.2r16更新）**：P6=黄金独立层（IAU/518880），服从§0.5.2三态裁决。状态A正常执行，状态B半速消耗，状态C禁止一切买入。不单独设置现金主权率门槛。

### 0.5 现金主权率管理

#### 0.5.1 定义

```
现金主权率 = 现金层市值 / 全局总资产
硬底线 = 5%
```

#### 0.5.2 硬底线执行规则 【V5.8.2r17缺陷H修复】

```
状态 A：「正常」— 现金主权率 > 8%
  → 所有操作正常执行

状态 B：「警戒」— 5% < 现金主权率 ≤ 8%
  → 固定层再平衡正常执行。非固定层操作可执行但半速消耗。已有持仓止损/止盈正常
  → 半速消耗定义：非固定层单笔开仓金额 = 正常计算值 × 50%。若正常计算值 × 50% < 最小交易单位（A股100股/美股0.01股），则标记「半速消耗-资金不足」，暂停该笔开仓

状态 C：「硬底触及」— 现金主权率 ≤ 5%
  → 暂停一切非固定层操作
  → 已有持仓的止损/止盈仍可执行
  → 固定层再平衡：
    - 现金主权率 < 5%（硬底击穿）：仅允许卖出操作（含固定层超配卖出、非固定层止盈/止损），禁止一切买入。优先通过卖出恢复至5%硬底。若所有持仓已清仓仍未恢复→标记「硬底击穿-待注资」
    - 现金主权率 = 5% 时：仅允许执行「卖出超配」（负差额），资金回笼现金层。
      禁止执行「买入缺口」（正差额），标记「硬底触及-买入暂停」。
      执行逻辑：正差额买入必然消耗现金→现金主权率数学上<5%→击穿硬底。
    - 5% < 现金主权率 ≤ 8%：固定层再平衡可动用现金，但动用后不得低于 5% 硬底。
      买入金额 = min(正常计算值, 可用现金 − 总资产×5%硬底)（与0.3步骤4一致）
    - 5% 硬底本身为终极防线，任何情况（含 P0 指令）不可突破
  → 恢复至「警戒」需现金主权率回到 >5%；恢复至「正常」需 >8%

状态C恢复规则（V5.8.2r17缺陷H新增）：
  ├── 硬底恢复后（>5%）：不自动重启被暂停的再平衡
  ├── 仅解除买入禁令，等待下一次独立触发条件（偏离/年度/新增资金）
  └── 若偏离已持续存在，下次扫描时自然触发
```

**P0 指令覆盖边界**：P0 不可覆盖现金主权率 5% 硬底线。
