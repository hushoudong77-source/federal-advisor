## §3.2 反击策略 (Counterpunch Protocol)

> 核心哲学：均值回归。在趋势非多头时，于买入区间分批建仓，SRC多级离场。

### 3.2.0 参数冻结协议

**跨标参数统一性裁决**：均线锚线+ATR乘数全池逐标强制差异化，禁止任何分组统一。参数基于标的永久底层波动率属性（大盘宽基/科技主题/新兴小微），非回测窗口历史最优解拟合。参数表见 §2.6（路由判断）。

### 3.2.0b 基础冷却期（V5.8.2r23焊入 — P0-5修复）

```
反击入场冷却期 = 48小时（2个交易日）
→ 任一反击批次成交后，该标的48h内禁止再次触发反击入场（含R2a/R2b/核爆底）
→ 冷却期内该标的维持⚪闲置，仅监控已有持仓的SRC离场条件
→ 冷却期到期后，若R0+R1+R2(a或b)仍满足 → 允许重新入场
→ 例外：核爆底override可突破冷却期（全局恐慌信号优先级高于冷却期）
```

### 3.2.1.2 底部序列降级建仓（r33.77焊入 — 2026-07-28 守东确权）

> **根因**：五轮回测（原始R2→二维→三维→分层→放宽条件）最终结论：底部序列（恐慌日→止跌日）确实有效——有序列的R2胜率系统性高于无序列（510500 +41pp、512100 +33pp），但底部序列触发率极低（放宽条件后仅2.9%的R2有序列）。将97%的R2全拦截 = 策略废了。守东裁决：底部序列不拦截信号，只分层仓位——有序列全仓，无序列轻仓试探。

> **r33.76（已废止）**：拦截器方案——5标启用、无序列=⛔不建仓。废止原因：底部序列触发率2.9%，拦截97%的R2让反击策略名存实亡。

> **三维均线方案否决（保留记录）**：MA5不创新低+MA20跌幅放缓作为底部确认第三维→全池仅剩4笔交易（0.1%保留率），信号灭绝。否决。

**核心原则**：底部序列是仓位分层器，不是拦截器。有序列=全仓正金字塔，无序列=仅建首批30%试探，次批等止跌日出现后补足。

**底部序列定义（两条件AND，近20日内序列）**：

```
① 恐慌日: 单日跌幅 > 3% ∧ 成交量 > VOL_MA20 × 1.5
   → 物理含义：有人在割肉，有人在接货——恐慌出清

② 止跌日: 恐慌日之后出现 实体 < 0.3×ATR ∧ 成交量 < VOL_MA20 × 0.8
   → 物理含义：卖盘耗尽，没人愿意再割了
   → 止跌日必须在恐慌日之后1-10个交易日内出现
```

**降级建仓逻辑**：

```
R2触发
    │
    └── 近20日内有「恐慌日→止跌日」完整序列？
        ├── ✅ 有 → 🟢 正常正金字塔两层建仓（首批30% + 次批70%）
        │   └── 标注「底部序列确认，全仓建仓」
        │
        └── ❌ 无 → 🟡 降级建仓——仅建首批30%
            ├── 次批70%等待止跌日出现后补足（窗口=20个交易日）
            ├── 20个交易日内止跌日未出现 → 次批作废
            ├── 首批30%正常止损（逐标独立参数）
            └── 标注「底部序列缺失，降级仅建30%，次批等止跌确认」
```

**全池统一适用（不逐标区分）**：
- 五轮回测结论：底部序列不适用逐标启用——启用标上2.9%触发率让策略名存实亡，不启用标上底部序列同样有效。最优方案是全池统一降级建仓——有序列多买，无序列少买，不拦截任何R2。

**输出格式（/扫描 /开火 /反击 中R2触发时）**：

```
[R2触发标的] 底部序列:
├── 恐慌日: [有/无] — [日期] 跌幅−X.X% 量比X.XX
├── 止跌日: [有/无] — [日期] 实体X.XX/ATR 量比X.XX
├── 序列完整: [✅/❌]
└── 裁决:
    ├── ✅ → 🟢 正常建仓（首批30%+次批70%）
    └── ❌ → 🟡 降级建仓（仅首批30%，次批等止跌日补足，窗口20日）
```

**与§3.2.1.1辅助确认层的关系**：
- §3.2.1.1：管「没触发R2但接近触发+反转形态」→手动评估（不自动执行）
- §3.2.1.2：管「R2已触发」→仓位分层（自动执行）
- 两者互补——3.2.1.1是信号外的手动确认，3.2.1.2是信号内的仓位分层

**自检熔断**：
- 触发：R2触发但输出中未出现底部序列判定 → **底部序列遗漏违规**
- 触发：底部序列确认但输出降级建仓 → **方向错误（应全仓）**
- 触发：底部序列缺失但输出全仓建仓 → **降级跳过违规**

### 3.2.2 建仓批次分档 — 正金字塔分批建仓（r26全量重构）

> 原等分三批（1/3+1/3+1/3）已废弃。五标三年回测证实正金字塔（30%+70%）全维度碾压：胜率+4~6pp、均值+0.8~1.4pp、最大回撤−0.6~0.9pp。

**标准标的（非红利层，适用正金字塔）**：

```
第一层（浅废墟 — R2a触发）：
  单批金额 = 全局资产 × 仓位上限 × 30%
  单批股数 = floor(单批金额 / 入场价 / 股数单位) × 股数单位
  → 美元标的股数单位=0.01（保留2位小数），人民币标的股数单位=100（整手）

第二层（深废墟 — R2b触发）：
  单批金额 = 全局资产 × 仓位上限 × 70%
  单批股数 = floor(单批金额 / 入场价 / 股数单位) × 股数单位
  → 总仓位 = 第一层 + 第二层 = 100%目标仓位

跳层路径（R2b直接触发，未经过R2a）：
  单批金额 = 全局资产 × 仓位上限 × 70%
  → 跳过第一层30%，直接以70%仓位入场
  → 无后续补仓。若后续反弹至R2a区间 → 不再追加入场（已错过浅位窗口）
```

**红利层标的（513910/159302，豁免正金字塔）**：

```
一次性建仓（R2触发 → 100%目标仓位）：
  单批金额 = 全局资产 × 仓位上限 × 100%
  单批股数 = floor(单批金额 / 入场价 / 股数单位) × 股数单位
  → 胜率100%的标的无需分批保护，直接满仓
```

**建仓后价格监控**：

| 场景 | 第一层30%已入场 | 第二层70%已入场 |
|:---|:---|:---|
| 价格反弹出R2a区间 | 维持持仓，等待SRC离场 | — |
| 价格继续跌入R2b区间 | 触发第二层补仓70% | — |
| 价格跌破R2b区间下限 | — | 维持持仓，SRC-2均价止损保护 |
| 价格反弹回R2a区间以上 | 30%仓位获利了结（SRC-3止盈） | 全部仓位统一管理 |

**批次暂停与恢复**：
- 第一层成交后价格反弹出R2a区间 → 第二层暂停。再次回落至R2a区间 → 恢复第二层挂单（不重置第一层）
- 第二层成交后 → 批次完成，后续不追加

### 3.2.3 离场信号（六个卖出来源 + 步骤1.5）

> **全法典收盘价触发统一规则（V5.8.2r11焊入）**：所有SRC触发条件均以**收盘价**为基准。盘中触及仅作预警，不执行离场指令。

**SRC-1**：2.0×ATR 追踪止损
```
Trailing Stop = max(Highest_Since_Entry − 2.0 × ATR(14), 建仓日Trailing Stop初值)
→ C ≤ Trailing Stop → 市价全清
→ ATR = 当前ATR(14)，每日更新，与建仓日ATR不同（V5.8.2r2明确）
```

**SRC-2**：买入均价跌破止损（V5.8.2r21原子修复——解决buy_k>2标的买入区间与止损线重叠的数学真空）
```
C < 买入批次均价 − 2.0 × ATR(14) → 市价全清
→ 止损基准为实际买入成本，非锚线。与分批建仓逻辑自洽，消除「区间下半部买入即触发止损」的致命缺陷
→ 买入批次均价 = Σ(每批买入价 × 该批股数) / 总股数。仅建仓批次参与计算
```

**SRC-3**：盈利回吐止盈（首批建仓日起算）
```
浮盈 ≥ 5% 后回落至 浮盈 ≤ 2% → 市价全清
→ 从首批建仓日起算，后续批次不重置时钟（V5.7.1 P1-⑤定义）
→ 浮盈 =（当前总市值 − 首批建仓成本×首批股数）/（首批建仓成本×首批股数）
→ 后续批次成本不参与浮盈计算，仅首批成本为基准
```
