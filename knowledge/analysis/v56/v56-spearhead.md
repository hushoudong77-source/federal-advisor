**修订后 C4 公式**：

```
C4 = (C ≥ H20 × 0.98) ∧ { (V > MA20_V × 0.8) ∨ [ATR(14) < ATR(14)_MA20 × 1.1] }
```

**逻辑解读**：价格必须接近20日高（2%容差），且满足以下任一：
- 放量突破（标准路径）；或
- 波动率收缩状态下的突破（缩量但波动率压缩，趋势启动前兆）

#### C4.1 成交量确认补充规则（r28.8焊入 — 方案A：区分"跌入型C4"与"横盘型C4"）

**物理根因**：C4的H20是滚动窗口。C4可以通过两种方式触发——(a)价格跌到H20×0.98（真回调），(b)横盘20天等H20下移（假回调）。回测191笔进攻交易未区分这两种触发方式，存在"等出来的C4质量不如跌出来的C4"的已知盲区。

**补充规则**：

```
C4补充条件 = 当日成交量 ≥ 20日均量 × 0.8

完整C4判定 = C ≥ H20 × 0.98 
              ∧ (V > MA20_V × 0.8 ∨ ATR14 < ATR14_MA20 × 1.1)  ← 原有量能/波动率二选一
              ∧ V ≥ MA20_V × 0.8                                   ← 🆕 强制放量确认
```

**物理含义**：
| C4触发方式 | 典型量能 | 判定 | 说明 |
|:---|:---|:---|:---|
| 跌入型（价格回踩H20×0.98） | 放量（V≥0.8×均量） | ✅ 通过 | 恐慌性抛售=浮筹清洗，买入质量高 |
| 横盘型（H20随时间下移） | 缩量（V<0.8×均量） | ❌ 拦截 | 无清洗=筹码钝化，买入质量低 |

**注意**：此规则与原有量能条件 `V > MA20_V × 0.8` 使用同一阈值0.8，形成统一：**C4触发必须伴随至少80%的均量水平**。原有"波动率豁免"（ATR14<ATR14_MA20×1.1时的缩量豁免）**仍然生效**——波动率收缩+量能≥0.8×均量=合法突破；波动率收缩+量能<0.8×均量=拦截。即：波动率豁免只豁免"放量突破"要求，不豁免"最低量能确认"要求。

**回测待执行**：此规则为理论推导+方案A焊入。需下次全量回测重跑191笔进攻交易，验证新增0.8×量能门槛后胜率是否从68.1%进一步提升。

**跨境ETF特殊量能阈值**（BBJP/MUFG/EWY/VNM/FLIN）：V > MA20_V × **0.7**（五标的跨境属性导致常态化缩量，进一步放宽10%）。

**H20定义**：前20个交易日最高收盘价（不含当日）。成交量 = 当日成交股数（A股1手=100股统一换算为股数，美股直接取股数），20日均量同单位。

#### 攻击窗口机制（V5.8.2r18新增 — 解决时序错配）

| 要素 | 规则 |
|:---|:---|
| **触发** | C4首次满足当日（T日）**收盘确认** |
| **窗口期** | T+0 至 T+2 收盘（2个交易日有效） |
| **开火条件** | 窗口期内，C1∧C2∧C3 **持续满足** 即可执行进攻 |
| **窗口关闭** | ①已开火（单次窗口仅1次开火权）；②T+2收盘未开火；③C1或C2任一翻False（**立即关闭，不等T+2**）；④C3跌破（C<50EMA） |

**作用**：C4只需"点亮一次信号灯"，无需持续满足。避免"突破时C2还没金叉→金叉时突破已过"的死亡螺旋。

### 3.1.4 阶梯止盈（Tiered Profit Lock — r28.9焊入）

> **根因**：进攻策略§3.1.3只有SRC-1~6止损体系，没有利润保护机制。浮盈+30%后回吐至成本以下是物理真实风险。本规则补全利润锁定维度，与SRC止损体系形成「攻守闭环」。

**触发条件**：浮盈达到指定阈值 → 止损线上移至对应保护位。

```
阶梯止盈 = 单向上移，不下调

┌──────────────────────────────────────────────────────────────┐
│ 浮盈档位          │ 止损线调整              │ 锁仓效果        │
├──────────────────────────────────────────────────────────────┤
│ ≥ +10%            │ 止损线上移至成本价        │ 保本            │
│ ≥ +20%            │ 止损线上移至 +10% 位      │ 锁一半仓位（卖出50%仓位，锁定该部分利润）│
│ ≥ +30%            │ 止损线上移至 +20% 位      │ 锁三分之二仓位（卖出66%仓位）│
│ ≥ +50%            │ 止损线切换为 H20×0.95     │ 趋势跟踪        │
└──────────────────────────────────────────────────────────────┘
```

**关键规则**：

1. **单向上移**：止损线只上调不下调。如果浮盈从+25%回落到+15%，止损线仍保持在+10%位（不回退到成本价）。

2. **与SRC-1的关系**：阶梯止盈的止损线与SRC-1追踪止损线**取更高者**作为实际止损价。
   ```
   实际止损价 = max(阶梯止盈止损线, SRC-1追踪止损线)
   ```
   - 浮盈<10%：实际止损 = SRC-1追踪止损（无阶梯保护）
   - 浮盈≥10%：如果阶梯止损线 > SRC-1追踪止损 → 阶梯覆盖SRC-1
   - 浮盈≥50%后：H20×0.95趋势跟踪取代固定阶梯

3. **触发确认**：浮盈以**收盘价**计算（全法典统一规则）。盘中触及不触发阶梯调整——需收盘确认。

4. **浮盈基准**：以建仓均价为基准计算浮盈百分比。加仓后以加权均价为基准。

5. **阶梯不可逆**：一旦进入更高档位，即使浮盈回落也不会降档（仅回落到更低档位的止损线不会自动下调）。例：浮盈从+35%回落到+22%，止损线仍在+20%位（不降到+10%位）。

**与SRC体系的关系**：

| 浮盈状态 | 止损来源 | 保护对象 |
|:---|:---|:---|
| 浮亏 | SRC-1追踪止损（5.0×ATR） | 本金 |
| 浮盈<10% | SRC-1追踪止损 | 本金+微利 |
| 浮盈10-20% | max(成本价, SRC-1) | 保本 |
| 浮盈20-30% | max(入场价×1.10, SRC-1) | 锁10%利润 |
| 浮盈30-50% | max(入场价×1.20, SRC-1) | 锁20%利润 |
| 浮盈≥50% | max(H20×0.95, SRC-1) | 趋势跟踪 |

**SRC-2~6仍正常生效**：8%硬止损、EMA反转、跳空、宏观熔断、-15%底线在任何浮盈状态下均正常触发。

**示例 — QQQ当前持仓**：
```
成本 $711.71 → 当前价 $740.61（浮盈 +4.06%）
SRC-1追踪止损 $660.83（成本−5×ATR）
阶梯止盈止损线：未触发（浮盈<10%）
→ 实际止损 = $660.83（SRC-1）
→ 无利润保护，继续持有
```

**示例 — QQQ涨至$850（+19.4%）**：
```
阶梯触发：浮盈≥10% → 止损线上移至 $711.71（成本价）
→ 实际止损 = max($711.71, SRC-1) 
→ 保本锁定，最差结果是不赚不赔
```

**回测待执行**：本规则为理论推导焊入。需下次全量回测重跑191笔进攻交易，对比有/无阶梯止盈的绩效差异（胜率、均盈、最大回撤、利润归零率）。关键验证指标：浮盈>20%后归零的比例能否从当前X%降至阶梯锁仓后的Y%。
