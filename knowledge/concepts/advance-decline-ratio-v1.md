# A股涨跌比情绪指标 V1.0

**创建日期**：2026-05-06
**数据源**：乐咕乐股网 `akshare.stock_market_activity_legu()` → 东方财富底层数据
**更新频率**：交易日盘中实时（约每5-10分钟刷新）

---

## 计算公式

```
涨跌比 = 上涨家数 / (上涨家数 + 下跌家数) × 100%
```

平盘家数不计入分母，仅作参考。

---

## 情绪分级标准（V1.0）

| 涨跌比区间 | 信号灯 | 解读 | 操作含义 |
|:---|:---:|:---|:---|
| < 25% | 🔵 极寒 | 恐慌抛售 | 废墟收割扫描启动 |
| 25% ~ 40% | 🔵 偏冷 | 弱势调整 | 观望，关注废墟前哨 |
| 40% ~ 55% | ⚪ 中性 | 正常波动 | 正常操作区间 |
| 55% ~ 70% | 🟡 偏热 | 温和亢奋 | 正常，关注是否持续升温 |
| 70% ~ 80% | 🟠 过热 | 情绪高涨 | 谨慎追高，检查乖离率 |
| 80% ~ 90% | 🔴 狂热 | 一致性预期陷阱 | 严禁新开仓，减仓观察 |
| > 90% | 🔴 极端狂热 | 物极必反高危 | 强制减仓至50%以下 |

## 使用SOP

1. **每日开盘后** → 自动抓取涨跌比
2. **突破70%** → 触发偏热预警，检查核心池乖离率
3. **突破80%** → 触发减仓审计
4. **突破90%** → 强制减仓至50%以下
5. **跌破25%** → 启动废墟收割全池扫描

## 数据获取代码

```python
import akshare as ak
df = ak.stock_market_activity_legu()
data = dict(zip(df['item'], df['value']))
up = int(data['上涨'])
down = int(data['下跌'])
ratio = up / (up + down) * 100
```
