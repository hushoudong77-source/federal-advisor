# Black-Litterman模型与联邦投顾的融合潜力

> Source: Guo, X. et al. (2017) §2.4.2 — 联邦投顾知识库编译

## 学术核心

### 模型本质

Black-Litterman(1992)解决的是**资产配置中的"观点输入"问题**：

> 投资者有主观观点（"A股未来3个月跑赢美股"），但如何将这些观点量化地融入资产配置权重？

**标准MPT**：输入预期收益μ → 输出最优权重w
**BL模型**：输入市场均衡收益π + 主观观点Q → 输出后验预期收益μ_BL → 输出最优权重w_BL

### 数学结构

```
先验：μ ~ N(π, τΣ)          ← 市场均衡收益(CAPM隐含)
          ↓ 融合观点
后验：μ_BL = [(τΣ)⁻¹ + P'Ω⁻¹P]⁻¹[(τΣ)⁻¹π + P'Ω⁻¹Q]
          ↓
权重：w_BL = (λΣ)⁻¹ μ_BL
```

其中：
- π = 市场均衡收益（从市值加权组合反推）
- τ = 先验不确定性标量
- Σ = 协方差矩阵
- P = 观点矩阵（连接标的与观点）
- Ω = 观点不确定性（置信度越高Ω越小）
- Q = 观点向量
- λ = 风险厌恶系数

### 关键创新

| 问题 | 标准MPT | Black-Litterman |
|:---|:---|:---|
| 输入敏感性 | 微小μ变化→权重剧烈变化 | 通过先验(π)约束，输出更稳定 |
| 观点量化 | 无法处理主观判断 | 结构化观点输入(P,Q,Ω) |
| 不确定性 | 假设μ已知 | 明确建模观点不确定性 |

## 联邦投顾的融合潜力

### 当前状态

联邦投顾的资产配置框架：
- **固定层**（VEA 20% + VTI 10%）：永不离场，固定比例
- **竞争上岗池**：按实时信号动态分配进攻/反击
- **黄金**：金盾总纲独立驱动

**BL模型最自然的应用点：固定层的权重分配**。

### 应用场景矩阵

| 场景 | 输入 | 输出 | 实施难度 | 价值 |
|:---|:---|:---|:---:|:---:|
| 固定层VEA/VTI分配 | 守东"美元走弱"观点 | VEA/VTI权重偏移 | 🟡中 | 中等 |
| 进攻/反击权重分配 | 各标的技术信号 | 竞争上岗权重新分配 | 🔴高 | 低 |
| 黄金vs权益配置 | 通胀/利率观点 | 黄金仓位偏移 | 🟡中 | 中等 |

### 详细方案：固定层BL融合

**现状**：VEA 20%/VTI 10%，固定比例，永不离场

**BL改进方案**：
1. 市场均衡收益π：从VEA/VTI的市值比例反推（≈55%/45%）
2. 守东主观观点Q：
   - 场景A：看多非美发达市场 → "VEA未来3个月跑赢VTI 2%"
   - 场景B：看多美股 → "VTI未来3个月跑赢VEA 3%"
3. 观点置信度Ω：由守东设定（低/中/高对应Ω的大小）
4. 输出：μ_BL → 新的VEA/VTI权重

**示例**：
| 观点 | 原权重 | BL后权重 | 偏移 |
|:---|:---:|:---:|:---:|
| 无观点（纯市场均衡） | 20/10 | 16.5/13.5 | VEA↓ VTI↑ |
| VEA跑赢VTI 2%（高置信度） | 20/10 | 22/8 | VEA↑ VTI↓ |
| VTI跑赢VEA 3%（中置信度） | 20/10 | 14/16 | VEA↓ VTI↑ |

### 为什么不实施（当前判断）

1. **固定层的哲学矛盾**："永不离场"意味着不调整——BL的核心是"根据观点调整"
2. **30%的体量太小**：VEA/VTI合计仅占总资产30%，BL优化的边际收益有限
3. **守东的主战场在竞争上岗池**：固定层是"压舱石"，不是进攻方向
4. **BL的额外复杂度**：需要维护协方差矩阵Σ、观点矩阵P、不确定性参数τ——这些对于两只ETF的配置来说过度复杂

### 何时应该实施

```
触发条件（任一满足）：
├── 固定层仓位扩大到总资产50%+
├── 固定层标的扩展到3只以上（如加入IAU）
└── 守东明确要求固定层权重动态调整
```

## BL模型的核心洞见（不实施也值得记住）

**BL模型告诉我们的最重要的事**：当你的观点置信度低时，不要偏离市场均衡太远——因为市场均衡（市值加权）本身就是无数参与者博弈后的结果，比你的"直觉"更可靠。

这与联邦投顾的**物理锚定原则**完全一致。
