# 买卖交易系统：GEM自动化审计协议 (V2.0)

> 基于CAN SLIM选股系统 + 威廉·欧奈尔《笑傲股市》
> 核心目的：构建GEM的"Rule Engine"，实现选股-买入-持有-卖出全流程自动化

---

## 0. 核心审计原则 (Core Compliance)

| 原则 | 描述 |
|------|------|
| **右侧交易强制令** | 禁止任何形式抄底，GEM仅在Stage 2或向上突破关键阻力位时激活买入 |
| **8%绝对止损线** | 系统主权红线，触及即发FORCE_LIQUIDATE，无视任何基本面利好 |
| **大盘方向开关(M)** | 大盘未处于放量新高或MA30向上 → 自动锁定买入，进入WATCH_ONLY模式 |

---

## 1. CAN SLIM量化审计

**评分>80方可进入执行池：**

| 维度 | 变量 | 审计逻辑 | 触发阈值 |
|------|------|----------|---------|
| **C** (Current) | 季度EPS增长 | 同比增长率审计 | ≥25% (优选50%) |
| **A** (Annual) | 年度EPS增长 | 过去3年稳定性审计 | ≥25%且无年度亏损 |
| **N** (New) | 新变化/新高 | 股价相对52周高点物理位置 | 创历史新高或突破平台 |
| **S** (Supply) | 筹码供求 | 流通盘规模及机构回购 | 流通盘偏小，回购比例≥10% |
| **L** (Leader) | 领军股评级 | 股价相对强弱指数(RS) | RS评分≥80 (优选90+) |
| **I** (Institutional) | 机构认同度 | 优质机构持仓增减 | 至少1-3家优质机构进场 |

## 2. 价格形态进场协议 (Entry SOP)

**GEM仅识别以下四种物理形态：**

### 带柄茶杯形态

| 参数 | 数值 |
|------|------|
| 杯身回撤 | 12%-33% |
| 柄部回撤 | 8%-12% |
| 触发点 | 收盘价向上突破柄部高点 |
| 成交量验证 | 突破当日成交量 > 前5日均值40% |

### 双重底 (W底)

| 参数 | 数值 |
|------|------|
| 物理位 | 第二个底略低于第一个底（清洗浮筹） |
| 触发点 | 放量突破中间颈线 |

### 高而窄旗形

| 参数 | 数值 |
|------|------|
| 物理位 | 4-8周内暴涨≥100%，随后缩量盘整3-5周 |
| 触发点 | 向上突破旗形上沿 |

## 3. 仓位与执行管理 (Execution Protocol)

### 分批建仓法

| 批次 | 时机 | 仓位 |
|------|------|------|
| Initial Buy (50%) | 形态突破瞬间且成交量达标 | 50% |
| Pyramid Add (50%) | 价格回踩确认支撑有效且再次放量拉升 | 50% |

### Chandelier Exit (枝形吊灯离场)

| 条件 | GEM动作 |
|------|---------|
| 8周内涨幅>20% | 自动进入STRONG_HOLD模式，止损位移至10周均线 |
| 高位放量滞涨 / 收盘跌破10周均线 / RS背离 | 触发TAKE_PROFIT_ALL |

---

## 4. 风险控制与熔断 (Kill Switch)

### 单笔头寸限额

```
单一标的仓位不得超过总资产的20%
```

### 组合风险敞口

```
单次交易预期损失不得超过总资产的2%（基于8%止损位倒推仓位）
```

### 主权熔断三级体系

| 级别 | 触发条件 | GEM动作 |
|------|---------|---------|
| **一级蓝** | 总资产回撤5%-8% | 强行清理弱势品种(RS<70) |
| **二级黄** | 回撤10%-12% | 总仓位强执降至50%以下 |
| **三级红** | 回撤15%以上 | 主权熔断，90%资产转入现金/SGOV，系统进入7天审计期 |
