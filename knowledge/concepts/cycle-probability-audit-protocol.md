# 周期胜率审计协议：GEM市场位置与胜率审计 (V2.0)

> 基于霍华德·马克斯《周期》(Mastering the Market Cycle)
> 核心目的：从技术性"点位计算"升华为"风险胜率审计"，判定钟摆位置与概率分布倾斜

---

## 0. 系统哲学：马克斯准则

| 原则 | 描述 |
|------|------|
| **周期不可预测，但可定位** | 我们不知道要去哪里，但我们应该知道现在在哪里 |
| **均值回归的必然性** | 人类倾向于走极端，所有偏离中轴线的波动最终都会向相反方向修正 |
| **概率分布的倾斜** | 周期审计的目的不是确定未来，而是判定当前布局是否"赔率占优" |

---

## 1. 周期钟摆传感器：情绪与估值对账

### 三维度钟摆判定

| 维度 | 钟摆极端A (恐惧/低点) | 钟摆极端B (贪婪/高点) | GEM审计逻辑 |
|------|----------------------|----------------------|-------------|
| **信贷环境** | 融资困难、信贷紧缩 | 资本廉价、信贷极度宽松 | IF 连垃圾债都容易发行 → CREDIT_EASY_WARNING |
| **投资者心理** | 极度悲观、避险意识过强 | 盲目乐观、风险容忍度过高 | IF "为什么不买"成为主流 → DANGEROUS_OPTIMISM |
| **市场估值** | 远低于历史均值(低PE/PB) | 远高于历史均值(高PE/PB) | 衡量价格与内在价值的偏离度 |

### 信贷窗口状态

```
IF 银行放贷意愿极高 + 贷款协议保护性条款(Covenants)减少
→ 判定为周期末端的"轻率放贷"
→ 预警资产价格泡沫
```

### 不良债权机会

```
IF 信贷由于违约而突然关闭
→ 激活 DISTRESSED_ASSET_MODE
→ 寻找"低价买入好资产"的机会
```

## 2. 风险态度切换协议

### 防御模式 (Defensive Mode)

| 项目 | 内容 |
|------|------|
| **触发条件** | 钟摆处于上方（高估值、信贷宽松、普遍乐观） |
| **GEM指令** | 提高组合安全性/确定性，下调R风险额度 |
| **优先操作** | 执行 SELL_LIMIT |

### 进攻模式 (Aggressive Mode)

| 项目 | 内容 |
|------|------|
| **触发条件** | 钟摆处于下方（低估值、信贷枯竭、普遍恐慌） |
| **GEM指令** | 即便技术面尚未完全Stage 2，根据"价值/价格"差增加进场频率 |
| **优先操作** | 执行 BUY_LOW_CONFIDENCE_ATTEMPT |

## 3. 周期定位SOP (The Assessment SOP)

GEM在生成报告时，必须包含以下"自省式"审计：

| 审计维度 | GEM问题 | 输出 |
|---------|--------|------|
| **量化位置** | 目前价格是在历史均值之上还是之下？ | PE/PB分位数 |
| **行为对账** | 周围的人是在恐慌抛售还是贪婪追涨？ | 情绪指数 |
| **结果导向** | 在当前位置加仓，赢的概率大还是输的概率大？ | 赔率评估 |

| 预警信号 | 触发关键词 | GEM动作 |
|---------|----------|---------|
