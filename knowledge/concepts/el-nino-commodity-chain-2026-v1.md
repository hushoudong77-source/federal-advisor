# 2026年厄尔尼诺 → 商品资产传导全链路 V1.0

> 基于国盛证券徐文辉5/20报告+NOAA CPC/IRI预测+历史13次厄尔尼诺事件复盘。
> 入库：2026-05-26 | 来源：守东投喂

## 一、2026年厄尔尼诺气象预测

| 指标 | 数据 | 来源 |
|:---|:---|:---|
| 进入时间 | 2026年5月进入厄尔尼诺状态 | 国家气候中心4月 |
| 强度 | 中等及以上，超强概率>30%（11月） | NOAA 5月 |
| 持续至北半球冬季概率 | 96% | NOAA CPC+IRI |
| ONI达峰时间 | 北半球冬季（12-2月） | 历史规律（13次中9次） |

**定义标准**：NINO3.4指数3个月滑动平均绝对值≥0.5℃且持续≥5个月。
**强度分档**：弱0.5-1.3℃ / 中等1.3-2.0℃ / 强2.0-2.5℃ / 超强≥2.5℃。

**气候影响方向**：
- 东南亚/澳大利亚 → 高温干旱↑，森林火灾风险↑
- 中国 → 北旱南涝
- 南美/北美南部 → 雨涝
- 北美中西部/东部 → 高温

## 二、资产传导逻辑框架（三阶漏斗）

```
L1: 天气异常（ONI上升）
  ↓
L2: 主产区产量下修（供给冲击）
  ↓
L3: 库存/贸易流变化（价格反应滞后兑现）

⚠️ 不能直接外推历史最大涨幅。2023-24已证明：
    白糖/棉花可先于ONI见顶，棕榈油可因降雨正常+库存累积反应有限。
```

## 三、白糖（CANE关联 — ⭐已有仓位）

### 3.1 6年周期特征（当前处于周期底部）

| 周期 | 见底 | 上行至 | 下行至 |
|:---|:---:|:---:|:---:|
| 周期一 | 2008底 | 2011 | 2014 |
| 周期二 | 2014底 | 2017 | 2020 |
| 周期三 | 2020底 | 2023 | **2026（见底迹象）** |

### 3.2 厄尔尼诺共振历史涨幅

| 事件 | 区间最大涨幅 | 年份 | 备注 |
|:---|:---:|:---:|:---|
| 2009-2011 | ~78% | 中等厄尔尼诺 | 巴西潮湿+印度减产24%+泰国降雨减少+中国广西干旱 |
| 2014-2016 | ~55% | 超强厄尔尼诺 | 巴西降雨增加影响出糖率+印度减产9.18%至7年低位+泰国-13% |
| 2020-2023 | ~39% | 中等厄尔尼诺 | 涨幅最小的一轮 |
| **2026（当前）** | **待定** | **中等及以上** | **已见底迹象+厄尔尼诺共振** |

### 3.3 与CANE协议的对账

CANE跟踪协议 V1.0（2026-05-24签发）已基于以下逻辑建仓：
- 厄尔尼诺概率96%+ → 巴西雨季风险窗口6-8月
- 三种情景预估：保守+9~23% / 基准+23~50% / 乐观+50~90%
- 建仓方案：三批$75K，第一批$25K 5/26市价执行

**新补充信息**：
- ✅ 6年周期底部迹象（2008→2014→2020→2026，间隔约6年）
- ✅ 2009/2014/2020三次厄尔尼诺均与白糖上行周期共振
- ⚠️ 2023-24反例：巴西降水充沛抵消减产，糖价先于ONI见顶
- ⚠️ **巴西制糖比32.93%（2026开局）偏高——若2026降雨正常，巴西可能再次大幅增产对冲其他产区减产**

### 3.4 关键跟踪链

```
天气（巴西中南部降雨量/印度季风）→ UNICA双周报（制糖比/压榨量）
  → 印度ISMA产量预估 → 泰国减产确认
    → 全球库存去化 → 价格反应（滞后1-2个季度）
```

## 四、棕榈油

### 4.1 产区集中度
马来西亚+印度尼西亚≈全球产量80%。

### 4.2 滞后特征
**价格高点滞后ONI达峰约4个季度。** 当前（5月进入厄尔尼诺）→ 价格高点约在2027年Q1-Q2。

### 4.3 历史涨幅

| 事件 | 区间最大涨幅 | 关键驱动 |
|:---|:---:|:---|
| 2009-2010 | ~71% | 印尼产量预期2450→2196万吨(-10.4%)；马来2050→1699万吨(-17.1%) |
| 2014-2016 | ~48% | 超强厄尔尼诺但全球豆油供应宽松+需求下降→弹性弱于2009 |
| 2023-2024 | ~45% | 马来产量不降反增+库存攀升+降雨未明显偏低→天气冲击未充分兑现 |

### 4.4 2026年关键变量
- 马来/印尼降雨是否实质偏少（当前厄尔尼诺刚开始，5-6月降雨尚未反映）
- 全球豆类油脂供需格局（宽松→压制棕榈油弹性）
- 欧盟/印度/中国进口需求

## 五、天然橡胶

### 5.1 滞后特征
**价格高点滞后ONI达峰约4-5个季度**——所有农产品中滞后最长。

### 5.2 历史涨幅

| 事件 | 区间最大涨幅 | 关键驱动 |
|:---|:---:|:---|
| 1997-1998 | ~33% | 超强厄尔尼诺 |
| 2002-2003 | ~118% | 干旱致胶汁干涸+全球增长+远期超卖 |
| 2009-2010 | ~167% | ANRPC产量891.7万吨(-3.5%) |
| 2014-2016 | ~101% | ANRPC产量1077万吨(-2.5%) |
| 2023-2024 | ~54% | 胶树老龄化+割胶工人短缺+高温干旱开割不顺+下游轮胎需求稳定 |

### 5.3 2026年特征
- 供应端三重压力：厄尔尼诺干旱 + 胶树老龄化 + 割胶工人短缺
- 需求端：半钢胎出口较好
- 若2026干旱确认 → 弹性可能高于2023-2024轮

## 六、棉花

### 6.1 特殊性（需求+库存约束强于天气）

棉花与白糖不同——价格路径更复杂，受需求和库存双重约束。

### 6.2 历史涨幅

| 事件 | 区间最大涨幅 | 关键驱动 |
|:---|:---:|:---|
| 2009-2010 | ~149% | 供需共振：印度干旱+出口禁令+中国纺服触底+全球消费>产量15% |
| 2014-2016 | ~54% | 先库存压力（2014/15期末库存2353万吨创新高）→2016年3月见底后涨 |
| 2023-2024 | ~30.7% | 需求偏弱+储备棉投放+进口配额+巴西丰产弥补美棉减产 |

### 6.3 2026年判断
- 需求端：全球纺织服装需求是否回暖（当前不确定）
- 库存端：全球期末库存位置（需查最新USDA）
- 供给端：新疆/印度/澳大利亚/美国产区干旱确认度
- **三因素缺一不可**——仅天气不足以驱动棉花大幅上涨

## 七、煤炭/电力（另一条传导链）

### 7.1 逻辑链
```
厄尔尼诺→全球气温上升→中国北旱南涝+夏季高温
  → 用电量激增 → 火电出力增加 → 动力煤需求上升
```

### 7.2 历史验证（三次厄尔尼诺）
2009-2010 / 2014-2016 / 2023-2024：
- ONI上行至达峰阶段（通常6-8月）
- 全国火电发电量同比↑
- 动力煤需求同步↑

### 7.3 与农产品逻辑的区别
- 煤炭/电力**不是减产逻辑**，而是**高温→用电→火电→动力煤**的天气传导链
- 传导周期更短（季内兑现，非跨年滞后）
- 与CANE/棕榈油/橡胶不构成竞争关系，可独立配置

## 八、风险限制（反方审计）

| 风险 | 物理含义 | 影响程度 |
|:---|:---|:---:|
| **气象未兑现** | 厄尔尼诺强度弱于预期，降雨正常 | 🔴 CANE/棕榈油/橡胶均受影响 |
| **巴西增产对冲** | 巴西降水充沛→甘蔗/大豆大幅增产→抵消其他产区减产 | 🔴 白糖最敏感（2023年反例） |
| **库存高企** | 全球库存充裕→供给冲击无法传导至价格 | 🟡 棉花最敏感 |
| **美元流动性** | 美元走强/加息→压制所有商品名义价格 | 🟡 所有商品 |
| **需求疲软** | 全球经济放缓→商品需求不足 | 🟡 棉花/橡胶 |
| **市场结构变化** | 期货升贴水结构、投机资金持仓变化 | 🟡 所有商品 |
