# ETF动量轮动策略 — RPS排名 vs 法典对撞

> Source: 守东分享的"45位ETF老油条访谈"文章（2026-06-02），84%受访者最终只用动量排名作为唯一进出场信号

## 核心论点

ETF轮动交易者（非长期持有、非超短线）中，84%最终放弃所有技术指标，只用一个信号：**N日收益率排名（RPS，Relative Strength）**。

### 操作逻辑

1. 选定一篮子ETF（10-20只，宽基+行业+跨境）
2. 每周/每月按近N日（20日或60日）涨幅排序
3. 只买前20%（前3-5名），等权买入
4. 掉出前N名就卖，换新的进来
5. 整体市场下跌（前5名涨幅为负）→ 空仓或国债ETF

### 底层原理

- **强者恒强**：动量是唯一被大量实证研究证明有效的因子（Jegadeesh & Titman 1993）
- **不预测，只跟随**：放弃"判断顶部/底部"，只做趋势确认后的跟随
- **认错概率**：震荡市动量策略确实会左右打脸，但主升浪赚的钱远多于震荡亏的小钱

## 与法典的对撞审计

### 共识区 ✅

| 维度 | 文章 | 法典 |
|:---|:---|:---|
| 砍掉冗余指标 | 8个副图→只留1个动量排名 | MA方向+ATR乖离+阶段判定，明确拒绝指标堆砌 |
| 不预测只跟随 | "动量在哪我就在哪" | 物理锚定 > 趋势 > 价值 |
| 核心逻辑 | 强者恒强直到它不强 | 进攻策略C1-C4核心就是动量确认 |
| 震荡市认亏 | "亏的是震荡的小钱" | 反击策略专门处理震荡市，两种模式互补 |

### 分歧区 ❌

| 维度 | 文章（纯动量排名） | 法典 |
|:---|:---|:---|
| **时间尺度** | 20日/60日排名 | 150EMA+50EMA+30EMA三级均线，区分长期趋势与短期方向 |
| **入场机制** | 固定频次调仓（周/月） | 事件驱动（C1-C4触发才入场） |
| **止损机制** | 掉出前N名就卖 | ATR×乘数追踪止损 + 冷却期（物理边界，非相对排名） |
| **跨品种管理** | 全量平等轮动 | 分层管理（进攻/反击/固定层/黄金），不同层级不同规则 |
| **震荡市处理** | 要么空仓要么硬扛 | 反击策略独立补丁，正金字塔分批建仓+SMIN剥夺机制 |

### 关键发现

法典的 **C3条件（现价>MA60且MA60向上）** 本质上是60日动量过滤器的升级版本：

| 对比 | RPS前20% | C3: MA60向上 |
|:---|---:|:---|
| 时间窗口 | 20日（短期） | 60日（中期） |
| 信号类型 | **相对排名** | **绝对方向** |
| 震荡市稳定性 | ❌ 易反复翻转 | ✅ 更稳定 |
| 冷门标的灵敏度 | ✅ 早期捕获 | ⏳ 可能滞后 |

**最优解**：C3做趋势过滤 + RPS排名做标的选择，两者互补而非互斥。

## 对法典的强化启示

1. **RPS排名可以作为进攻候选池的补充排序维度**：在C1-C4全部触发的标的中，用RPS排名决定优先级
2. **固定频次调仓（周/月）vs 事件驱动**：文章的逻辑更适合震荡市/轮动市，法典的事件驱动更适合趋势市——两者各有所长
3. **纯动量排名的致命缺陷**：没有止损边界、没有分层管理、震荡市没有独立补丁——这正是法典比纯动量更抗揍的原因

### 关键发现

1. **RPS前5名全部是美股标的**（EWY/QQQ/MUFG/VEA/IVV），A股整体垫底（513910排#16、518880排#17）。纯动量排名会倾向全仓美股，忽略A股反击机会——法典的三层管理恰恰填补了这个缺口。

2. **EWY的RPS榜首≠可操作标的**：RPS(20)=+32.47%，断层领先，但EWY反击资格已永久剥夺（回测CAGR -2.79%，走廊测试全负），进攻C4也尚未触发。法典的资格剥夺机制过滤了"涨得最猛但已经涨过头"的陷阱。

3. **RPS(20)与RPS(60)排名差异揭示趋势阶段**：
   - EWY: #1/#1 → 单边主升，但已经涨过头
   - 588000: #9/#3 → RPS60强但RPS20弱 → 长期动量还在但短期回调，正是反击入场场景
   - 513910: #16/#15 → 双周期垫底 → 动量耗尽阶段，反击买入区间的"捡便宜"逻辑成立

4. **RPS排名对进攻冷却期标的的附加判断**：QQQ/IVV的RPS(20)=#2/#5，RPS(60)=#2/#4，双周期高位。如果6/20冷却期解禁时RPS依然维持前5 → 开火置信度大幅提升。

### 融入法典的规则

```
RPS在法典中的定位:
├── 非决策信号（不触发任何买入/卖出）
├── 辅助排序（同条件标的内按RPS优先级排序）
├── 覆盖范围: 进攻策略（C1-C4候选）+ 反击策略（已进入区间标的分级）
├── 不覆盖: 固定层（VTI/VEA永不离场）、黄金（金盾独立驱动）、
│           观望/剥夺标的（FLIN/SMIN/EWY反击）
└── 特殊规则: 冷却期标的即使RPS排名高也不提前解锁
```
