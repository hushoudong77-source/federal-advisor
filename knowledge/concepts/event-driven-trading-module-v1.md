# 产业事件驱动交易模块 V1.0

**地位**：法典 V20.55.3 的独立叠加层，不修改法典本体。
**设计日期**：2026-05-06
**触发背景**：5/6 科创50 +8.25%、半导体涨停潮，法典买入区间悬空无法捕捉 → 需补产业事件驱动维度

---

## 一、核心定位

| 维度 | 法典 V20.55.3 | 产业事件驱动模块 |
|:---|:---|:---|
| 驱动逻辑 | 均值回归（价格→MA120） | 产业景气（事件→EPS→价格） |
| 买入信号 | 价格进入 [MA120−2ATR, MA120] | 产业催化剂触发 + 价格站上 MA20 |
| 止盈 | 60日持有或加速离场 | 产业景气证伪或动量衰减 |
| 止损 | 2.7×ATR / 硬止损-8% | 3.0×ATR（买入价不在均线支撑区，从严） |
| 仓位上限 | 8%（S1/S2可扩容至10%/12%） | 3%（与法典仓位独立核算） |
| 标的选择 | 21只核心池全覆盖（含固定层VTI/VEA空仓临时路由） | 仅产业有事件驱动的标的 |

**关键原则**：事件驱动仓位和均值回归仓位完全隔离，互不侵占额度。

---

## 二、触发机制：三层漏斗

### 漏斗一：产业催化剂（必须满足至少一项）

| 催化剂等级 | 定义 | 示例 |
|:---|:---|:---|
| **核弹级** | 全球产业龙头发布超预期业绩/指引，或国家级产业政策突变 | AMD Q2 CPU收入+70%、三星SK海力士历史新高、东阳光签160亿算力合同 |
| **扩散级** | 海外同板块连续2日暴涨（单日>5%）传导至A股 | 韩国半导体+12%→A股半导体联动 |
| **周期级** | 产业景气周期数据连续2季度向上，且龙头CAPEX扩张 | 全球半导体设备订单连续3季增长 |

### 漏斗二：价格确认（必须满足全部）

| 条件 | 阈值 | 逻辑 |
|:---|:---|:---|
| 价格站上 MA20 | 收盘价 > MA20 | 确认产业事件已被价格吸收 |
| MA20 斜率向上 | MA20今 > MA20昨 | 防止事件一日游后回落 |
| 成交量确认 | 当日量 > 20日均量 × 1.5 | 机构资金确认参与 |

### 漏斗三：宏观环境过滤（否决项）

| 条件 | 动作 |
|:---|:---|
| US10Y ≥ 5.00%（法典唯一熔断触发） | 一票否决，禁止任何事件驱动开仓 |
| 涨跌比 > 85%（狂热） | 一票否决，禁止追高 |
| VIX > 35（恐慌） | 暂停事件驱动模块，等VIX回落 |
| 标的当日涨幅 > 15%（个股级别过热） | 禁止当日追入，等次日回调 |

## 四、仓位与风控参数

| 参数 | 值 | 说明 |
|:---|:---|:---|
| 单笔风险 | 1% 全局权益 | 与法典一致 |
| 单标事件仓位上限 | 3% 全局权益 | 独立于法典的8%仓位上限 |
| 止损 | max(3.0×ATR, -8%硬止损) | 因买入价不在均线支撑区，ATR乘数从严 |
| 止盈 | 产业催化剂证伪 或 价格跌破MA20 或 +20%利润后移动止盈至MA10 | 三重退出 |
| 最大并行事件仓位 | 6%（即最多同时持有2个标的的事件仓位） | 分散事件风险 |
| 事件冷却期 | 同一标的两次事件开仓间隔 ≥ 10个交易日 | 防止反复追高 |

## 五、与法典的互锁协议

### 互锁一：仓位隔离
- 事件驱动仓位和均值回归仓位**独立核算，独立风控**
- 同一标的可以同时有事件仓位（上限3%）和均值回归仓位（上限8%），但合计不超过 10%
- 如果均值回归仓位已满8%，事件仓位最多再+2%（合计10%硬顶）

### 互锁二：止损联动
- 无论仓位来源，同一标的跌破硬止损位时，**全部平仓**
- 均值回归的止损和事件驱动的止损分别计算，同时触发时执行最大亏损的那个

### 互锁三：宏观熔断优先
- 法典 US10Y ≥ 5.00% 熔断 → 事件模块全部冻结
- 法典废墟收割协议触发 → 事件模块暂停（废墟收割优先级更高）

### 互锁四：事件模块不修改法典
- 事件模块的输出标有 **[事件驱动]** 前缀
- 法典的买入区间公式、涨跌比、RSI等规则**不适用于事件驱动仓位**
- 但法典的风险底线（US10Y 5.00%、涨跌比>85%）仍然适用

## 六、执行 SOP

```
触发事件 → 
  ├─ 漏斗一：产业催化剂确认（至少1项）
  ├─ 漏斗二：价格确认（3项全部满足）
  ├─ 漏斗三：宏观过滤（0项否决触发）
  ├─ 计算 N 股数：全局权益 × 1% / (入场价 - 止损价)
  ├─ 检查：N × 入场价 ≤ 全局权益 × 3%
  ├─ 输出 [事件驱动] 交易指令
  └─ 写入事件交易日志
```
