# EWY 动量跟随策略 V1.1

> **定位**：独立策略，与FLIN/SMIN共用相同策略框架，参数统一（1.5ATR回撤止盈）。
> **核心逻辑**：MACD金叉确认动量恢复 + 现价<MA20确保不在追涨区 → 低成本入场捕捉反弹，两阶段退出机制（静态止损+动态回撤止盈）。
> **焊入日期**：2026-06-22 守东确权。

## EWY为什么入池

- EWY此前为⛔永久剥夺（反击策略全区间负Sharpe，2026-05-23裁决）
- 但反击失败≠动量跟随失败——两者盈亏来源完全不同
- 反击是均值回归逻辑，动量跟随是趋势反弹捕捉
- EWY V1.1 Sharpe 1.070（vs V1.0 0.701），改善+52.7%，六标中改善幅度最大
- EWY高波动（ATR/价格=1.53%）天然适合动态回撤止盈——经常先涨一波后回落

## 策略参数（与FLIN/SMIN统一）

| 参数 | 值 |
|:---|:---|
| **入场条件** | MACD金叉（BAR>0 ∧ 前日BAR≤0）AND 现价<MA20 |
| **入场时机** | 金叉次日开盘价（滞后1日确认） |
| **止损** | 入场价 − 2×ATR14（始终生效，不可上移） |
| **退出机制** | 两阶段动态退出 |
| **仓位** | 单笔5%，全仓进出，不分批 |
| **冷却期** | 30天 |
| **硬熔断** | VIX>35暂停 / FOMC+非农+CPI前72h暂停 / 浮亏严禁补仓 |

## 退出机制（两阶段 — V1.1动态回撤止盈）

```
入场
  │
  ├── 阶段一: 浮盈 < 1.5×ATR14
  │   ├── 止损（−2×ATR）始终生效
  │   └── 止盈：收盘价 ≥ MA60 → 离场
  │
  └── 阶段二: 浮盈 ≥ 1.5×ATR14 → 激活动态回撤止盈
      ├── 止损（−2×ATR）始终生效
      └── 回撤止盈：从建仓后最高收盘价回撤 ≥ 1.5×ATR14 → 离场
          ├── 收盘价确认（不盘中触发）
          ├── 峰值仅上移不下调
          └── MA60止盈在阶段二不再适用
```

## 核心改善机制

- EWY 2笔止损被动态回撤翻转为盈利
- 物理逻辑：EWY高波动环境下经常先涨一波（浮盈≥1.5×ATR激活回撤保护层），然后回落。V1.0的MA60固定止盈在回落中损失大量浮盈，V1.1在回落时锁定利润
- 新增的6笔交易（vs V1.0的18笔）含更多小额信号，拉低了均收益但累计收益更高

## 与全池策略的关系

- EWY路由从「⛔剥夺」升级为「⚪独立」（2026-06-22）
- 本策略为独立轨道，不经过法典C1-C4或R0-R2路由判定
- 信号触发时在/扫描报告中以「⚪独立」路由展示
- 与FLIN/SMIN共用同一策略框架，参数统一

## 关键特征

1. **信号极度稀疏**：EWY年均~2.7笔，在下跌市中可能整年无信号——天然自带空仓保护
2. **高波动天然适配动态回撤止盈**：ATR/价格=1.53%是六标中第二高，经常出现先涨后落的大幅波动
3. **止损快速**：−2×ATR，亏损有限
4. **2020年3月为策略最佳窗口**：暴跌后的V型反弹完美契合入场+动态回撤止盈逻辑
5. **全仓进出，简单有效**：不分批、不锁半仓
