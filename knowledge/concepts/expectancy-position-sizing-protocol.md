# 期望值与头寸审计协议 (GEM V2.0)

> 基于范·撒普《通向财务自由之路》
> 核心目的：将"买多少"和"是否有胜算"完全数学化

---

## 0. 系统哲学：撒普准则

| 原则 | 描述 |
|------|------|
| **R倍数思维** | 禁止以百分比/点数讨论盈亏，所有风险定义为R |
| **离场优于进场** | 进场点只占系统成功率10%，审计重点在退出和头寸 |
| **正期望值校验** | 不具备长期正期望值的策略必须强制拦截 |

---

## 1. R倍数分布审计 (Expectancy Matrix)

### 核心公式

| 变量 | 公式 | 说明 |
|------|------|------|
| **初始风险R** | R = 买入价 - 止损价 | 单位化风险基准 |
| **期望值E** | E = Σ(P_i × R_i) | P_i为概率，R_i为该类交易的R倍数 |
| **机会频率f** | 单位时间内交易次数 | GEM计算 E × f = 系统真实盈利能力 |

### 审计规则

```
✅ E > 0：系统具有正期望值，允许执行
❌ E ≤ 0：系统无正期望值，强制拦截
```

---

## 2. 头寸规模缩放协议

### 模型A：核心风险模型 (Percentage Risk Model)

**输入**: 总资产(Equity)、单笔风险率(Risk%)

```
数量 = (Equity × Risk%) / R
```

| 约束 | 限值 |
|------|------|
| Risk% 硬上限 | **严禁超过2%** |
| 建议常态 | 0.5% - 1% |

**触发条件**:
```
IF 止损位太近 → 计算数量超过流动性限制
THEN 自动触发 VOLUME_LIMIT_WARNING
```

---

### 模型B：波动率缩放模型 (Volatility Position Sizing)

**输入**: 标的10日平均真实波幅(ATR)

**止损位设定**:
```
止损点 = 买入价 - (N × ATR)
```

**执行规则**:
```
确保 1.0 × ATR 的波动导致的损失不超过总资产的 1%
```

## 3. 退出审计协议 (The Exit Protocol)

四种"退出传感器"：

| 退出类型 | 触发条件 | GEM动作 |
|---------|---------|---------|
| **灾难性止损** | 1R硬止损 | 应对黑天鹅，无条件执行 |
| **跟踪止损** | 3.0×ATR枝形吊灯 或 MA120向上平移 | 每日更新，只上移不下移 |
| **获利回吐** | 盈利达3R或5R **且** RSI顶背离 | 触发利润收割 |
| **逻辑失效** | 买入理由5日内未产生向上推力 | 强制离场 |

## 4. 心理与执行审计 (Self-Correction Protocol)

### 黑帽审计质问

| 审计类型 | 质问内容 |
|---------|---------|
| **偏好审计** | 本次操作是否因"连续盈利产生的贪婪"或"挽回损失的报复性交易"？ |
| **抽奖审计** | 本次进场是否符合正期望值分布？ |

### 强制休息触发条件

```
IF 账户30天内回撤 > 10%
THEN:
  1. 锁定买入权限
  2. 启动"交易心理对账"
  3. 要求强制休息
  4. 回测最近10笔失败交易
```
