# 开火信号与持仓状态无关性 V1.0

> 2026-08-13 守东纠错后固化。根因：联邦投顾在 `/开火 A股` 报告中错误归因「已持仓标的不再产生开火信号」。

## 物理真相

`fire_report.py` 的反击开火判定**不读取任何持仓状态**。判定逻辑唯一依赖：

```python
triggered = cp.get("triggered", False)   # 路由引擎判定：现价是否 ≤ 买入区间上沿
if triggered and not r05_blocked:
    fire = "🟢"
elif triggered and r05_blocked:
    fire = "⛔R0.5"
else:
    fire = "—"
```

**开火信号 = 现价是否回到买入区间内（差比转负），与「是否已持仓」无关。**

## 三条铁律

1. **开火口径 ≠ 持仓口径**：`fire_signals.triggered` 是「现价 ≤ 买入区间上沿」的物理判定，不区分新开仓 / 已持仓加仓。
2. **已持仓标的照样出开火信号**：价格重新跌回买入区间（差比转负），脚本照样输出 🟢，语义为「可加仓」。
3. **不触发的原因只能是价格**：若已持仓标的未出开火信号，唯一解释是「现价高于区间上沿」（差比为正），与持仓状态无关。

## 2026-08-13 案例

6 个已持仓反击标的（588000/510500/512100/159530/510300/159915）本轮全部 `triggered=false`，真实原因是**现价已反弹脱离超卖低位（差比 +0.70%~+6.96%）**，而非「因为已持仓所以不开火」。

| 标的 | 现价 | 区间上沿 | 差比 | 真实原因 |
|:---|:---:|:---:|:---:|:---|
| 159915 | ¥3.604 | ≤¥3.491 | +3.25% | 现价高于区间上沿 |
| 510300 | ¥4.729 | ≤¥4.637 | +1.98% | 同上 |
| 159530 | ¥1.397 | ≤¥1.387 | +0.70% | 同上 |

## 相关澄清

- 「加仓过热」（30天内≥3次暂停）是**独立于开火信号**的标的级约束，与 `triggered` 判定正交。
- 分批建仓冷却期豁免规则（同一信号内未完成仓位补足不触发冷却）也基于「价格仍在区间内」，同样与持仓状态不冲突。
- 唯一需要读持仓的场景是 `positions.json`（硬锁零.十）——但那用于输出持仓数量/成本，不用于开火判定。

## 自检熔断

- 触发：任何报告中把「未触发开火」归因到「已持仓」→ **归因错误，立即修正为「现价未回到买入区间」**。
- 触发：声称「脚本因持仓状态跳过某标的」→ **伪逻辑（脚本无此分支），立即撤回**。
