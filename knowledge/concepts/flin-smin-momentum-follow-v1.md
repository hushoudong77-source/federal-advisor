# FLIN/SMIN/EWY 动量跟随策略 V1.1

> **定位**：独立策略，不入全池进攻/反击/金盾体系。三标共用相同策略框架，参数一致。
> **核心逻辑**：MACD金叉确认动量恢复 + 现价<MA20确保不在追涨区 → 低成本入场捕捉反弹，两阶段退出机制（静态止损+动态回撤止盈）。
> **适用环境**：下跌趋势中的反弹波段捕捉。在全面下跌市中信号极度稀疏，天然自带空仓保护。

## 策略参数

| 参数 | 值 |
|:---|:---|
| **入场条件** | MACD金叉（BAR>0 ∧ 前日BAR≤0）AND 现价<MA20 |
| **入场时机** | 金叉次日开盘价（滞后1日确认） |
| **止损** | 入场价 − 2×ATR14（始终生效，不可上移） |
| **退出机制** | 两阶段动态退出 |
| **仓位** | 单笔5%，全仓进出，不分批 |
| **冷却期** | 30天 |
| **硬熔断** | VIX>35暂停 / FOMC+非农+CPI前72h暂停 / 浮亏严禁补仓 |

## 退出机制（两阶段 — V1.1动态回撤止盈）

```
入场
  │
  ├── 阶段一: 浮盈 < 1.5×ATR14
  │   ├── 止损（−2×ATR）始终生效
  │   └── 止盈：收盘价 ≥ MA60 → 离场
  │
  └── 阶段二: 浮盈 ≥ 1.5×ATR14 → 激活动态回撤止盈
      ├── 止损（−2×ATR）始终生效
      └── 回撤止盈：从建仓后最高收盘价回撤 ≥ 1.5×ATR14 → 离场
          ├── 收盘价确认（不盘中触发）
          ├── 峰值仅上移不下调
          └── MA60止盈在阶段二不再适用
```

**设计逻辑**：
- 止损−2×ATR14是硬底线，始终生效
- 阶段一用MA60止盈：浮盈不够厚时，MA60作为趋势方向锚点
- 阶段二切换到动态回撤：浮盈够厚后，不再等MA60，而是保护已实现的浮盈
- 1.5×ATR是阈值——在SMIN日均波动~$1.2（约2.5%）的环境下，1.5×ATR约3.7%的回撤容忍度，在噪音和趋势之间取中
- 不分批：回测证明全仓动态回撤止盈 > 分批止盈。分批提前截断前半仓，趋势市中必然跑输

## 分批止盈测试结论（已否决）

测试了两种分批方案：
- **分批A**（1.5ATR回撤止盈½ + 2.5ATR回撤止盈½）：FLIN +34.94%（Sharpe 0.376），SMIN +29.20%（Sharpe 0.174）
- **分批B**（1.5ATR回撤止盈½ + MA60止盈½）：FLIN +28.87%（Sharpe 0.293），SMIN +20.01%（Sharpe 0.123）

全仓动态回撤止盈在FLIN上全面优于两种分批方案。SMIN上分批A略微领先累计但Sharpe几乎持平（差异在噪音范围内）。

**结论：全仓动态回撤止盈，不分批。** 分批提前截断前半仓，在趋势市中必然跑输全仓一把走。动态回撤止盈本身已在方向逆转时离场，不需要分批来「保护」。

## 均线过滤测试结论（已否决）

在FLIN上测试了全部均线过滤组合（MA60↑方向、MA150↑方向、MA20>MA60金叉状态、MA20>MA150金叉状态、MA40>MA150金叉状态、MA60>MA150金叉状态等），**所有过滤均导致绩效恶化**——信号被砍到接近零且剩余信号胜率更低。原因是FLIN/SMIN的大部分时间均线在下行，偶尔上行的窗口里MACD金叉+价<MA20的信号几乎不发生。

**结论：不加均线过滤。MACD金叉+价<MA20两条件即足够。**

## 与全池策略的关系

- FLIN和SMIN为「⚪独立」路由（2026-06-22从⛔剥夺升级）
- 本策略为独立轨道，不经过法典C1-C4或R0-R2路由判定
- 信号触发时在/扫描报告中以「⚪独立」路由展示
- 仓位计入总权益仓位上限

## 关键特征

1. **信号极度稀疏**：FLIN年均~2.6笔，SMIN年均~3.4笔。在下跌市中可能整年无信号——天然自带空仓保护。
2. **动态回撤止盈在趋势市中能吃满主升浪**，震荡市中1.5×ATR快速锁定利润。
3. **止损快速**：−2×ATR，亏损有限。4笔（FLIN）+3笔（SMIN）止损被翻转为盈利——这是V1.1最大的绩效贡献。
4. **2020年3月为策略最佳窗口**：FLIN +13.77%、SMIN +17.55%——暴跌后的V型反弹完美契合入场+动态回撤止盈逻辑。
5. **全仓进出，简单有效**：不分批、不锁半仓。动态回撤止盈的「方向逆转时离场」逻辑已足够。
