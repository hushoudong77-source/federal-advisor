## 1. 宏观传导链审计协议（GEMINI 核心贡献）

### 1.1 传导链模型（GEMINI 框架）

```
【出口型经济体：越南案例】

① 外部冲击源（Input）：
   布伦特原油 +5.62% / 霍尔木兹双封锁确权

② 传导路径（Transmission）：
   原油 ↑ → 进口原材料成本 ↑ → 制造业利润 ↓ 
   → 企业盈利下调 → 越南盾汇率承压 
   → EPS 预期下调 → 股价下杀（滞后反应）

③ 财报时滞（Lag）：
   成本冲击通常在 **2-3个季度后** 才反映在财报中
   但聪明资金会 **提前 1-2 个季度** 预判并撤离

④ 当前状态（Current）：
   VNM $19.04 = "基于地缘扰动减弱的虚假共识"
   下一季报（Q2）才是物理证伪节点
```

### 1.2 出口导向型经济体的宏观脆弱性矩阵

| 经济体类型 | 典型标的 | 高度敏感因子 |
|:---|:---|:---|
| **原材料进口-成品出口** | 越南 (VNM)、印度、孟加拉 | 原油、海运费、汇率 |
| **资源出口型** | 巴西、印尼、俄罗斯 | 大宗商品价格、本币汇率 |
| **内需驱动型** | 美国、中国 | 消费数据、房地产 |
| **能源生产型** | 沙特、阿联酋 | 原油出口收入、OPEC政策 |

### 1.3 宏观传导链强制审计协议

> **任何新兴市场分析，必须在 30 秒内回答以下三个问题：**

```
【GEMINI 三问】

❓ Q1：原材料进口依赖度？
   → 查 贸易账差额 / 经常账差额
   → 越南：经常账逆差，外汇储备薄

❓ Q2：出口目的地集中度？
   → 过度依赖欧美/中国单一市场 = 订单风险集中
   → 越南：高度依赖美国（消费电子、纺织）

❓ Q3：能源运输通道是否经过高风险区？
   → 霍尔木兹 / 马六甲 / 曼德海峡
   → 越南：南海 + 马六甲航线均涉及地缘风险
```

## 2. 量能深度审计协议（GEMINI 第二贡献）

### 2.1 我的分析 vs GEMINI 的分析

| 我的分析 | GEMINI 的修正 | 教训 |
|:---|:---|:---|
| "成交量 97万股，较前期放大" | "对比历史脉冲量 **明显不足**，是缩量上涨" | ✅ **没有绝对基准的放量是无意义的** |
| "价升量增，健康上涨" | "缩量上涨 = 离岸资金 **最后撤离拉抬**" | ✅ **量价背离不一定是背离，而是资金性质问题** |

### 2.2 量能审计速查矩阵

| 成交量场景 | 物理含义 | 操作建议 |
|:---|:---|:---|
| **放量突破**（≥历史脉冲量的 60%） | 新资金入场，趋势确认 | 可执行趋势跟随 |
| **缩量上涨**（< 历史脉冲量的 40%） | 离岸资金拉抬 or 空头回补 | **严禁追高** |
| **放量下跌** | 主动性卖盘，主力撤离 | 立即减仓 |
| **缩量下跌** | 多头惜售 or 无人接盘 | 观望，区分场景 |
| **地量（< 均量 30%）** | 趋势枯竭，等待催化 | 等待方向确认 |

### 2.3 量能审计 SOP（必检项）

```
【GEMINI 量能审计 SOP】

Step 1：获取 20 日均量作为基准
Step 2：获取历史脉冲量（最大单日成交量）作为对标
Step 3：计算比值 = 今日量 / 历史脉冲量
Step 4：
  IF 比值 < 40% AND 价格上涨 → 缩量上涨 → 标记 ⚠️
  IF 比值 > 60% AND 价格上涨 → 放量上涨 → 确认 ✅
  IF 比值 > 60% AND 价格下跌 → 放量下跌 → 警惕 🔴
```

## 3. 阶段动态概率框架（GEMINI 第三贡献）

### 3.1 我 vs GEMINI 的阶段判定

| 框架 | 判定 | 问题 |
|:---|:---|:---|
| **我的判定** | "Stage 2 初期" | ❌ 静态标签，无法指导动态决策 |
| **GEMINI 判定** | "Stage 2 vs Stage 3B 的概率博弈" | ✅ 动态概率，触发条件明确 |

### 3.2 Stage 2 / Stage 3B 动态概率矩阵

```
【VNM 案例分析】

GEMINI 给出的条件：

IF VNM 突破 $19.85 (前期高点) with 放量确认
  THEN 判定：Stage 2 确认 → 可执行买入
  
IF VNM 在 $19.85 前止步，且原油继续上涨
  THEN 判定：Stage 3B (派发末期) 概率 > 60%
  → 离场 or 禁止买入
```

### 3.3 阶段概率审计 SOP

```
【阶段概率审计 SOP】

每个标的在任何时点，必须同时评估：

  状态A：当前阶段是什么？（静态）
  状态B：对立阶段概率是多少？（动态）
  
  例：VNM 处于 Stage 2 
      BUT Stage 3B 概率 ≥ 40% → 禁止重仓
      BUT Stage 3B 概率 ≥ 70% → 强制减仓
```
