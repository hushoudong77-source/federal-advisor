# 黄金分析记忆关联协议 V2.0

## 协议概述

本协议规定了黄金相关分析时必须关联的记忆数据源和执行流程，确保分析结论基于完整的物理数据。

## 一、强制关联数据源（五维黄金对撞体系）

### 1. 全球黄金数据（必须）
- **数据源**：`1.csv`全球重力数据（用户提供）
- **关键标的**：IAU（黄金信托ETF）、XAU（黄金现货）
- **存储位置**：`memory/2026-04-22.md` (01:02)
- **使用要求**：所有黄金分析必须关联此数据源

### 2. 国内黄金数据（必须）
- **数据源**：AU9999（上海黄金交易所现货）
- **获取方式**：实时网络搜索
- **使用要求**：所有国内黄金ETF分析必须关联此数据

### 3. 汇率数据（必须）
- **数据源**：USD/CNY汇率
- **获取方式**：实时网络搜索
- **使用要求**：所有跨境黄金分析必须关联此数据

### 4. 持仓数据（必须）
- **数据源**：用户提供的持仓信息
- **使用要求**：所有持仓分析必须基于用户提供的准确数据

### 5. GVZ 黄金波动率指数（必须）
- **数据源**：CBOE Gold Volatility Index (GVZ)
- **获取方式**：Barchart.com / 实时网络搜索
- **最新值**：25.90（2026-04-27）
- **使用要求**：所有黄金分析必须关联GVZ作为波动率锚点
- **判读规则**：
  - GVZ < 20 → 低波动，黄金市场极度平静
  - GVZ 20-30 → 正常波动区间（当前25.90在此范围）
  - GVZ 30-40 → 中高波动，警惕风险
  - GVZ > 40 → 极端恐慌，类似2026年1月峰值48.68

## 二、五维对撞执行流程

```
1. 接收黄金分析指令
2. 检索记忆：1.csv全球重力数据（IAU, XAU等）
3. 检索记忆：美股收盘数据（SPX, NDX, IEF等）
4. 实时搜索：AU9999国内现货价格
5. 实时搜索：USD/CNY汇率
6. 实时搜索：GVZ黄金波动率指数（Barchart）
7. 接收：用户持仓数据
8. 执行：联邦四线程对撞分析（GVZ纳入波动率审计）
9. 输出：V20.31.6极简决策版报告
```

### GVZ 在审计中的应用规则

| 场景 | GVZ信号 | 审计动作 |
|:----|:--------|:---------|
| IAU下跌但GVZ低位 | 有序回调 | 正常持有，技术性回调 |
| IAU下跌且GVZ飙升 | 恐慌踩踏 | 强制减仓审计 |
| IAU横盘GVZ持续走低 | 波动率压缩 | 等待突破，警惕Gamma挤压 |
| IAU上涨GVZ同步走高 | 趋势动能 | 持有但设紧止损 |

## 三、记忆断层熔断机制

### 触发条件
- 未关联1.csv全球重力数据
- 未关联AU9999国内现货数据
- 未关联USD/CNY汇率数据
- **未关联GVZ黄金波动率数据**

### 熔断动作
1. **立即暂停**当前分析
2. **检索记忆**缺失数据源
3. **重新执行**完整分析流程
4. **记录教训**到知识库
