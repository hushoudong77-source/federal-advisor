## 核心差异

**518880是人民币计价的黄金+汇率双期权，IAU是美元计价的黄金裸敞口。** 前者看中美利差剪刀差，后者看美元实际利率单刀直入。

## §0 固定层定义（V1.3新增）

### §0.1 MA方向精确定义

所有条款中「MA60方向向上/向下」的判定标准统一为：

```
MA60方向向上 = 当日MA60数值 > 前一交易日MA60数值
MA60方向向下 = 当日MA60数值 < 前一交易日MA60数值
```

**定义澄清**：这是均线值本身的日际变化方向，**非**「收盘价是否在MA60上方」。价格围绕均线上下穿越而均线值仍在上升时，判定为MA60方向向上。

### §0.2 DXY MA20日际变化定义

```
DXY MA20日际变化 = DXY_MA20(t) - DXY_MA20(t-1)
```

其中DXY_MA20为美元指数20日简单移动平均。

### S0 纪律细则

**触发条件**：
- S0-单侧逆风：C1满足但仅有一侧向下，即 `(US10Y↓ ∧ DXY↑) ∨ (US10Y↑ ∧ DXY↓)`
- S0-双逆风：C1不满足（US10Y↑ ∧ DXY↑）但S3未触发

**动作**：
- 禁止开新仓（加仓）
- 禁止反击轨道（回撤≥4%不触发反击买入）
- 仅允许S1（MA60↓）/ S2（假突破）/ S6（追踪止盈）被动离场
- S0-双逆风态额外启动S3监测

**设计意图**：防止在信号混乱期主动加仓被双面打脸。S0不是「清仓信号」，而是「冻结主动操作信号」——持仓可以继续持有等待S6止盈或S1趋势止损，但不能再往同一个方向加码。

### S3 术语修正与物理注释（V1.3）

**术语修正**：删除「单日跳升」，统一使用「**MA20日际变化**」。

**物理含义**：

```
US10Y MA20日际变化 = [US10Y(t) - US10Y(t-20)] / 20
```

- **2bp阈值** = 20个交易日内US10Y累积变化需≥40bp
- 这是**加速上行**信号，非日内事件。温和双逆风（每日0.1-0.5bp）不会触发S3，由S1（MA60↓）承担趋势级别的保护
- 基于2018-2026年1996个交易日全量回测：触发率5.1%，10日胜率55.9%

**DXY侧不对称注释**：DXY MA20日际变化>0在DXY上升趋势中几乎恒真。当前阈值（>0）仅作为方向确认，不设幅度阈值——因为DXY端的作用是确认「双逆风」中的右侧风向，而非独立触发条件。

**S3与S0关系**：
- S0-双逆风态（US10Y↑ ∧ DXY↑）启动S3监测
- S3触发 → P0清仓，覆盖S0的所有冻结纪律
- S3未触发 → 继续S0持仓，等待S1/S2/S6被动离场

### S4 确定性动作（V1.3）

**删除「或」**，改为确定性分流：

```
首次触及S4：
├── 浮盈 > 5% → 清仓（锁定利润，波动率异常往往预示趋势末端）
└── 浮盈 ≤ 5% → 减仓50%（保留半仓观察，剩余仓位按S6/ATR止损兜底）

次日仍触及S4 或 伴随C1恶化 → 清仓剩余仓位
```

### S5 数据源与防死锁（V1.3 → V1.4.1 标记死锁）

**FRA-OIS利差**：
- 首选：彭博/路透终端（⚠️ 2026-06-03审计确认：从未验证可用性，标记为「数据源不可获取」）
- 备选：若不可获取，改用 `VIX > 40` 或 `黄金ETF溢价率 > 1.5%` 作为流动性恐慌代理指标（⚠️ 两个阈值极高，历史上极少触发）
- **V1.4.1裁决（2026-06-03自审）**：S5当前为事实死锁条款——首选不可用，备选阈值极少触发。S5降级为**预警因子**：不触发强制清仓，仅当备选指标触及阈值时发出预警。未来若接入彭博/路透或替代数据源，重新激活S5强制清仓功能

### 卖点逻辑说明

- **S2 假突破止损**：以突破日最低价而非固定百分比作为铁底，贴合实际入场成本。
- **S4 波动率异常**：V1.4三段划分回测确认——黄金波动率异常放大后5日/10日均价反而上涨（趋势加速非均值回归），S4在所有常用阈值(2.0%-4.0%)下均为反向指标。训练集(2018-2022)上S4≥3.5%触发后跌率78.6%有效，但测试集(2023-2026)完全失效。**升阈至3.5%减少误触发，但逻辑方向标注为「反向风险」——高波动未必是离场信号，可能是趋势加速。** 与ATR止损不冲突——S4先发制人减仓，ATR止损兜底剩余仓位。
- **S5 IAU独有**：美元流动性危机（如2020年3月）中，IAU会与黄金现货同步暴跌，518880因汇率对冲反而可能抗跌。阈值硬编码：FRA-OIS利差>50bp（对应流动性恐慌）或单日跳涨≥15bp（急剧恶化信号）。正常情况下FRA-OIS在10-25bp区间浮动。
- **S6 追踪止盈**：以**自入场以来的滚动最高收盘价**为基准（非静态H15，非动态H15），减去3×14日ATR作为移动止盈线。价格创新高后止盈线上移，锁定更多利润；价格未创新高则止盈线维持不动。黄金无可替代的独立止盈条件。法典进攻策略无独立止盈，此条款作为黄金豁免模块写入。^V1.4回测：3.0×维持（全量夏普0.25 vs 2.5×夏普0.05，3.0×更稳健。训练集最优2.5×在测试集同样亏损——不是参数问题，是2023年后黄金C1-C4入场信号本身在失效）。

### COT数据源与防死锁条款（V1.3）

COT（Commitment of Traders）报告用于IAU反击轨道的非商业净多头分位判定。数据源为CFTC每周五发布的持仓报告。

**获取优先级**：
1. P0：守东手动投喂（最高优先级）
2. P4：自动拉取CFTC官网（备选）

**防死锁条款**：
- COT数据超过**7个自然日**未更新 → 跳过COT条件，仅评估前三项（C1满足+回撤≥4%+未破MA60）
- 跳过COT时标注：「COT数据逾期，反击轨道简化判定」
- 此条款防止反击轨道因单一数据源空缺而完全死锁

**分位定义**：`<30%分位` = 当前非商业净多头持仓在2018年以来历史数据中处于最低30%区间。`<<30%分位`（原V1.2表述）中的`<<`已删除，统一为`<30%分位`。

## 五、关键纪律

1. **汇率剪刀差纪律**：当USDCNH MA20向上（人民币贬值），同等进攻信号下，**仓位向518880倾斜**，IAU仅作卫星配置。

2. **不可互套MA60**：518880的MA60与IAU的MA60必须独立计算，人民币升值期两者可能一多一空。

3. **黄金无废墟抄底**：不同于股票的"核爆底反击"，黄金不存在价值废墟，只有**趋势回调**。跌破MA60即意味着宏观逻辑可能已变，不可补仓摊低成本。

4. **S3优先于一切**：S3宏观双逆风是P0级清仓信号，优先级高于任何技术指标和浮盈状态。S3触发 → 立即清仓，不等待反弹。

5. **汇率剥离分析**（V1.3新增）：当518880与IAU的MA60方向背离时，优先以IAU（美元裸敞口）信号为准，518880信号需降级验证。背离场景通常反映的是人民币汇率变动而非黄金本身趋势——例如人民币升值期518880 MA60可能向上（价格涨），但IAU MA60向下（美元金价跌），此时买入518880买入的是汇率β而非黄金α。

### 核心发现

**2023年后黄金C1-C4入场信号系统性失效。** 训练集(2018-2022)上金盾四条件产生了5笔正收益交易(+12.73%)，但测试集(2023-2026)上仅2笔全亏损(−8.96%)。根因：2023年后「美元逆风+DXY强势」环境下，C1∧C2∧C3∧C4从未真正同时满足过有利的入场窗口。这不是参数问题——当前参数已是最优配置，调整空间极小。金盾策略的边际效用已触及天花板。

**失效的深层根因链（2026-05-25联邦审计补充）：**
```
2023-2026油价持续高位 → 整体CPI被能源推高（如2026年4月3.8%）
    → 整体CPI与核心CPI（2.4%）的1.4pp鸿沟 → 市场误读为"通胀顽固"
    → 加息预期升温 → US10Y持续高位 → 实际利率上升
    → 黄金持有成本（不生息 vs 有息资产）攀升 → 入场信号被宏观逆风压制
```
简言之：不是C1-C4信号本身出错了，而是信号触发的时机恰好处于「利率持续高企压制黄金估值」的环境下。**停火若落地，将从源头斩断这条链**——油价回落→CPI降温→加息预期退潮→实际利率下行→C1-C4可能重新获得有效性。详见[黄金逻辑链穿透审计：停火→油价→CPI→加息预期→金价](../analysis/gold-logic-chain-stopfire-cpi-2026-05.md)。

**S4逻辑方向是比参数更根本的问题。** 黄金波动率异常放大后价格反而上涨——波动率飙升反映的是地缘脉冲/宏观冲击，推动趋势延续而非均值回归。S4作为「波动率异常→减仓」的逻辑在黄金上不成立。升阈至3.5%是折中方案（减少误触发），未来可能考虑废除S4或重构为「趋势加速确认信号」。
