## 一、K线形态识别体系

### 1.1 识别范围（12 种经典形态）

| 形态 | 类型 | 信号强度 | 判定逻辑 |
|:---|:---|:---:|:---|
| **十字星** (Doji) | 反转/犹豫 | 🟡 | `abs(open-close)/open < 0.1%`，实体极小 |
| **蜻蜓十字星** (Dragonfly Doji) | 看涨反转 | 🟢 | 十字星 + 下影线长度 > 实体 × 3 |
| **墓碑十字星** (Gravestone Doji) | 看跌反转 | 🔴 | 十字星 + 上影线长度 > 实体 × 3 |
| **锤子线** (Hammer) | 看涨反转 | 🟢 | 下影线 > 实体 × 2，上影线 < 实体 × 0.3 |
| **上吊线** (Hanging Man) | 看跌反转 | 🔴 | 同锤子线，但发生在上升趋势中 |
| **吞没形态** (Engulfing) | 反转 | 🟢🟢/🔴🔴 | 当日实体完全吞没前日实体（看涨：阳吞阴 / 看跌：阴吞阳） |
| **孕线** (Harami) | 反转 | 🟡 | 当日实体被前日实体完全包含（看涨：阴中阳 / 看跌：阳中阴） |
| **晨星** (Morning Star) | 强底反转 | 🟢🟢 | 阴→小实体→阳，第三根阳线吞回第一根阴线 50%+ |
| **黄昏星** (Evening Star) | 强顶反转 | 🔴🔴 | 阳→小实体→阴，第三根阴线吞回第一根阳线 50%+ |
| **三白兵** (Three White Soldiers) | 强延续 | 🟢🟢🟢 | 连续三根阳线，每根开盘在前一根实体内，收盘接近最高 |
| **三乌鸦** (Three Black Crows) | 强延续 | 🔴🔴🔴 | 连续三根阴线，每根开盘在前一根实体内，收盘接近最低 |
| **光头光脚** (Marubozu) | 强势 | 🟢/🔴 | 实体占比 > 90%，几乎没有影线 |

### 1.2 信号叠加规则

形态信号**不单独产生交易指令**，仅作为现有决策维度的**叠加层**：

| 形态 + 价格位置 | 叠加效果 |
|:---|:---|
| 🟢🟢 晨星 + 买入区间内 | 优先级+1，仓位可满额（若无其他拦截） |
| 🟢🟢 晨星 + 价格悬空 | 仅作参考，不追 |
| 🟢 锤子线/蜻蜓十字 + 买入区间内 | 确认信号，不改变原有裁决 |
| 🔴🔴 黄昏星/三乌鸦 + 持仓中 | 触发强制止盈审计 |
| 🟢🟢🟢 三白兵 + 价格悬空 | 过热警告，严禁追涨 |
| 🔴 上吊线 + 持仓浮盈 | 强制止盈审计，建议减仓 50% |
| 🟡 十字星 | 无独立信号，等待次日确认 |

## 二、MACD 动能审计体系

### 2.1 计算参数

- **标准参数**：EMA(12) - EMA(26) = DIF，DEA = EMA(DIF, 9)，MACD柱 = 2 × (DIF - DEA)
- **数据门槛**：≥ 26 日 OHLCV（当前全池 563~587 日，远超门槛）
- **执行频率**：每次 `/扫描` 自动输出

### 2.2 信号灯规则

| MACD 状态 | 信号灯 | 含义 |
|:---|:---:|:---|
| 零轴上 + DIF↑ + 红柱↑ | 🟢🟢 | 多头增强 — 最强状态 |
| 零轴上 + DIF↑ + 红柱↓ | 🟢 | 多头减速 — 关注是否转空 |
| 零轴上 + DIF↓ + 绿柱 | 🟡 | 多头回调 — 正常调整 |
| 零轴附近 + 金叉（DIF上穿DEA） | 🟢🟢 | 转折信号 — 关键开火确认 |
| 零轴下 + DIF↑ + 绿柱缩小 | 🟡 | 空头收敛 — 筑底中 |
| 零轴下 + DIF↓ + 绿柱↑ | 🔴 | 空头增强 — 均值回归陷阱 |
| 零轴下 + 死叉（DIF下穿DEA） | 🔴🔴 | 加速下行 — 强制禁买 |

### 2.3 与买入区间的联动规则（核心）

```
价格在买入区间 + MACD 零轴上多头增强  = 🟢 满分开火（无其他拦截时）
价格在买入区间 + MACD 零轴上多头减速  = 🟢 可开火，仓位不减
价格在买入区间 + MACD 零轴附近金叉    = 🟢🟢 优先级最高，可满额
价格在买入区间 + MACD 零轴下空头收敛  = 🟡 筑底，仓位减半（50%）
价格在买入区间 + MACD 零轴下空头增强  = 🔴 均值回归陷阱，红牌拦截
价格悬空 + MACD 零轴上金叉           = 🟡 关注回踩MA20，不可追
```

### 2.4 特殊信号：金叉/死叉

- **金叉（DIF上穿DEA）**：若同时发生在零轴附近或零轴上，视为强开火确认信号
- **死叉（DIF下穿DEA）**：持仓标的触发死叉 → 强制止盈审计，考虑减仓
- **顶背离**（价格新高 + MACD红柱面积缩小）：触发强制止盈审计
- **底背离**（价格新低 + MACD绿柱面积缩小）：叠加买入区间 = 强废墟收割信号

### 6.2 优先级排序（宪法级）

```
第一梯队：一票否决（任一触发 → 直接终止裁决，输出最终指令）
  ├── 🛑 宏观熔断 (US10Y≥5.00% / SHIBOR≥1.70% / DXY异常)
  ├── 🛑 绝对止损 (−7%硬线，持仓标的专属)
  └── 🛑 动态止盈 (跟踪线触及，持仓标的专属)

第二梯队：物理锚定（必须通过才能继续）
  ├── 📐 买入区间 (价格是否在[MA20−m×ATR, MA20]内)
  ├── 📐 Stage判定 (≠Stage4)
  └── 🟢 废墟豁免 (反向解锁，可绕过第二梯队部分拦截)

第三梯队：真金白银（权重×2.0）
  └── 💰 主力/北向资金

第四梯队：技术确认（权重×1.0，多空对撞）
  ├── 📊 MACD动能
  ├── 📊 RSI
  └── 📊 K线形态

第五梯队：辅助调节（不改变方向，仅调仓位）
  ├── 📏 ATR波动率 → 调节N股数
  └── 🌡 涨跌比情绪 → 调节建仓节奏
```

### 6.3 三色决议台（开仓方向）

对任一标的，12个维度信号汇聚后，按以下规则输出最终裁决：

#### 🔴 红牌拦截（以下任一触发 → 禁止开仓）

| SHIBOR 3M ≥ 1.70%（A股买入压减） | 宏观熔断 |
| 价格不在买入区间内（悬空） | 买入区间 |
| Stage = 4（破位下行） | Stage判定 |
| MACD零轴下 + 空头增强（均值回归陷阱） | MACD动能 |
| RSI > 70 + Stage≠2（超买禁追） | RSI |

### 6.4 信号灯合成算法（可量化版）

当多个第四梯队信号同时存在时，按以下公式合成综合技术评分：

```
综合技术分 = MACD得分(35%) + RSI得分(25%) + K线形态得分(25%) + Stage得分(15%)
```

**各维度打分标准**：

| 维度 | +2 (强多) | +1 (偏多) | 0 (中性) | −1 (偏空) | −2 (强空) |
|:---|:---|:---|:---|:---|:---|
| MACD | 零轴上金叉/多头增强 | 零轴上多头减速 | 零轴附近震荡 | 零轴下空头收敛 | 零轴下空头增强/死叉 |
| RSI | 25-35 超卖区 | 35-45 偏弱 | 45-55 中性 | 55-65 偏强 | >70 超买 |
| K线 | 晨星/三白兵 | 锤子线/蜻蜓十字 | 十字星/无形态 | 上吊线/墓碑十字 | 黄昏星/三乌鸦 |
| Stage | Stage2 主升 | Stage1 筑底 | 无法判定 | Stage3 顶部 | Stage4 破位 |

**综合分裁决**：

| 综合分 | 裁决 | 仓位系数（若无红牌） |
|:---:|:---|:---:|
| ≥ +1.2 | 🟢🟢 强多共振 | 100% |
| +0.6 ~ +1.2 | 🟢 偏多 | 100% |
| 0 ~ +0.6 | 🟡 弱多 | 50% |
| −0.6 ~ 0 | 🟡 弱空 | 25%（仅侦察） |
| < −0.6 | 🔴 偏空 | 0%（红牌拦截） |

### 6.5 卖出方向裁决树（持仓标的专属）

卖出方向仅由以下触发条件产生，**其他任何维度信号不得产生卖出指令**（参见法典 1.1.5.1 叙事驱动交易禁令）：

```
卖出触发条件（OR逻辑，任一触发即执行）
├── 🛑 绝对止损 −7% → 无条件全清
├── 🛑 动态止盈跟踪线触及 → 全清或减至跟踪线
├── 📐 MA锚线跌破（收盘确认）→ 全清
│   ├── 518880: MA120
│   ├── 159302: MA60
│   └── 其他: MA20
├── 📊 MACD死叉 + 价格跌破MA20（双确认）→ 减仓50%
├── 📊 K线黄昏星/三乌鸦 + MACD零轴上转空 → 触发止盈审计
├── 🛑 宏观熔断升级 → 全池无条件压舱
└── 🛑 US10Y单日跳升>8bps（重力加速）→ 新兴市场/日元标的减仓50%
```

### 6.7 与法典现有模块的关系

本协议**不替代**法典任何现有条款，仅作为**信号汇聚层的统一裁决框架**：

- **第一梯队** = 法典 2.1 分层重力熔断协议 + 4.3 绝对止损 + P6 动态止盈
