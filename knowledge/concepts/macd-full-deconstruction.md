## 一、底层计算原理

### 1.1 三组件公式

```
EMA12 = 过去12日收盘价的指数加权移动平均
EMA26 = 过去26日收盘价的指数加权移动平均

DIFF = EMA12 − EMA26        ← 快慢线差值（核心动量）
DEA  = EMA9(DIFF)            ← DIFF的9日指数平滑（信号线）
BAR  = 2 × (DIFF − DEA)      ← 柱状图（DIFF与DEA的差距×2）
```

**EMA vs SMA的区别**：
- SMA（简单均线）：每天权重相等，`SMA_N = (C₁+C₂+...+C_N) / N`
- EMA（指数均线）：越近的日期权重越大，`EMA_today = C_today × α + EMA_yesterday × (1−α)`，其中 `α = 2/(N+1)`

**为什么是12/26/9？**
Gerald Appel在1979年设计的原始参数。12和26分别代表约2周和1个月的交易周期，9是信号线的平滑周期。至今仍是全球默认标准，联邦法典全部沿用此参数。

### 1.2 三组件的物理含义

| 组件 | 物理含义 | 正值含义 | 负值含义 |
|:---|:---|:---|:---|
| **DIFF** | 快线与慢线的差距 = 短期趋势与中期趋势的方向差 | 短期强于中期，上升动量 | 短期弱于中期，下降动量 |
| **DEA** | DIFF的平滑版本 = 动量的趋势 | 动量趋势向上 | 动量趋势向下 |
| **BAR** | DIFF与DEA的差距×2 = 动量加速度 | 动量在加速（DIFF远离DEA） | 动量在减速（DIFF接近或低于DEA） |

**关键洞察**：
- DIFF > 0 ≠ 买入。只说明短期均线在长期均线之上——趋势方向
- BAR > 0 ≠ 买入。只说明DIFF在DEA之上——动量还在加速
- **金叉（DIFF上穿DEA）** = 动量从减速转为加速，这才是交易信号

## 三、BAR柱状图的深度用法

### 3.1 BAR的物理含义

BAR = 2 × (DIFF − DEA)，放大两倍是为了肉眼可见。

```
BAR > 0 且增大 → 动量在加速，趋势在强化
BAR > 0 但缩小 → 动量在减速，趋势可能转折（顶背离前兆）
BAR < 0 且缩小（负值变大）→ 下跌动量在加速
BAR < 0 但增大（负值变小）→ 下跌动量在减速（底背离前兆）
```

### 3.2 BAR收缩 = 金叉/死叉的早期预警

BAR从负值向零收缩（绿柱缩短）= DIFF正在靠近DEA = 金叉可能即将发生。这是比金叉**更早的信号**，但假信号率更高。

**联邦实战应用**：
- `/开火` 机会排序中，动量池的「MACD BAR强度」占30%权重——BAR越大说明动量越强，排序越靠前
- 但BAR强度**不是入场条件**——只有金叉确认后才入场。BAR强度只影响同策略池内「先做哪个」

## 四、MACD的三大经典陷阱

### 4.1 滞后性（最致命）

MACD基于EMA12/EMA26——EMA26是过去约一个月数据的加权平均。金叉发生时，价格可能已经涨了一段。

**联邦对策**：动量跟随策略的金叉确认滞后1日——金叉当日收盘后判定，次日开盘价执行。这是**主动接受滞后**，换取信号可靠性。

### 4.2 震荡市假信号

横盘震荡时DIFF和DEA反复交叉，金叉→死叉→金叉连续触发。每次都是假信号。

**联邦对策**：独立动量策略要求价<MA20——震荡市中价格大概率在MA20附近反复穿越，但至少排除了追涨的假信号。ADX>30的多空绞杀态也天然过滤了震荡市。

### 4.3 顶/底背离的误用

价格创新高但MACD DIFF未创新高 = 顶背离。这是经典用法，但回测数据不支持其预测能力——顶背离后价格可以继续涨几个月。

**联邦立场**：背离不作为独立交易信号。只在 `/技术` 分析中作为辅助观察标注，不触发任何仓位调整。
