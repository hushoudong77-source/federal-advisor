# 宏观周期审计协议：GEM多空市场交易 (V2.0)

> 核心目的：将经济周期转化为可配置的资产轮动模板，实现宏观择时的机械化操作

---

## 0. 系统初始化：核心运行法则

| 原则 | 描述 |
|------|------|
| **不预测、只跟随** | 放弃对价格的预测，仅根据领先/同步/滞后指标的物理信号操作 |
| **美联储总开关** | 所有投资决策的首要因子是美联储的流动性注入或撤回 |
| **12个月变化率(ROC)** | 统一计算同比变化百分比，消除季节性，捕捉趋势拐点 |

## 2. 经济周期四阶段：资产轮动协议

### 【阶段1】衰退末期 -> 复苏初期 (Recovery)

| 项目 | 内容 |
|------|------|
| **传感器状态** | 领先指标(如M2)开始上行，滞后指标(利率/通胀)仍在下降或见底 |
| **CORE配置** | 股票(成长股)、长期债券 |
| **SELL** | 现金或空头仓位 |
| **禁止** | 触碰商品或资源股 |

### 【阶段2】复苏中期 (Expansion)

| 项目 | 内容 |
|------|------|
| **传感器状态** | 同步指标超过长期增长率(>3%)，领先指标继续冲高 |
| **CORE配置** | 股票(行业龙头、周期股) |
| **ADD** | 开始关注商品类资产的底部信号 |
| **风险预警** | 利率若底部反弹，提示债券仓位减仓 |

### 【阶段3】经济过热期 (Overheating)

| 项目 | 内容 |
|------|------|
| **传感器状态** | 滞后指标大幅攀升，领先指标出现背离或见顶 |
| **CORE配置** | 商品(原油、黄金、能源股)、资源股 |
| **LIQUIDATE** | 清理非周期性股票，全面清仓债券 |
| **防护** | 进入防御模式，强制调高现金比例 |

### 【阶段4】滞胀 -> 衰退初期 (Contraction)

| 项目 | 内容 |
|------|------|
| **传感器状态** | 所有领先/同步指标均大幅下行，滞后指标在顶点形成压力 |
| **CORE配置** | 现金、超短期国债(SGOV)、防御型医疗股 |
| **SELL** | 清空所有商品仓位 |
| **等待条件** | 只有当滞后指标确认拐头向下，才能激活阶段1的小额试错 |

## 3. 风险监控：负反馈熔断 (Kill Switch)

### 盈利修正报警

```
IF 单位劳动力成本增速 > 生产率增速
THEN GEM必须下调该标的/板块盈利预期
触发 SELL_SIGNAL
```

### 流动性虹吸对账

```
IF 短期利率(13周国债)在2个月内上涨>200个基点
THEN 强制股票仓位降至50%以下
```

### 负反馈审计

```
IF 库存/销售比连续三个月上升
THEN GEM判定"生产过剩"
应降低工业与制造业板块权重
```

### 7.1 霍尔木兹地缘锚点（2026.4.21-4.22）

| 时间节点 | 事件性质 | 物理背景 |
|----------|----------|----------|

| **4.22 奇点** | 停火协议到期日 | 为期两周的临时停火协议（Ceasefire）官方失效日 |

### 7.2 核心矛盾解析

| 矛盾点 | 内容 |
|--------|------|
| **4.21 通牒** | 美方要求伊朗在 4 月 21 日前就核燃料外运及霍尔木兹海峡永久通行权达成协议，否则将武力清除海峡内布雷区及岸舰导弹威胁 |
| **4.22 奇点** | 停火协议到期后，路径 A（续约）→ 地缘溢价回落；路径 B（开火）→ 全球 20% 石油运力停摆 |

### 7.3 金融含义映射

|------|---------------------|---------------------|---------------------|

| **US10Y 美债收益率** | 触发流动性虹吸拦截 | 温和回落 | 波动加剧 |
