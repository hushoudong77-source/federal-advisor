# 宏观周期与利率对账协议：GEM多空市场交易 (V2.0)

> 基于乔治·达尼诺《多空市场交易》(Profiting in Bull or Bear Markets)
> 核心目的：商业周期与投资组合深度解耦，建立宏观数据"早鸟"预警系统

---

## 0. 系统哲学：GEM核心元逻辑

| 原则 | 描述 |
|------|------|
| **利率是万物重力** | 所有资产价格的波动，本质是利率环境（折现率）变化引起的重新定价 |
| **周期领先性** | 金融市场（债券、股票）总是领先于实体经济（工业生产、就业）见顶或见底 |
| **跨市场联动** | 通过"债券-股票-大宗商品"的相对强弱来判定周期位置 |

---

## 1. 商业周期传感器：数据对账矩阵

### 三大传感器

| 传感器 | 输入变量 | 审计逻辑 |
|--------|---------|---------|
| **流动性传感器** | M2供应量、短期联邦基金利率 | IF M2增速放缓 + 加息 → 预判流动性收紧，压制估值 |
| **通胀传感器** | PPI(生产者价格指数)、单位劳动力成本 | IF PPI持续上涨 → 预判利润率受蚀，警惕制造业利润 |
| **收益率曲线** | 10Y-2Y美债利差 | IF 曲线倒挂 → 触发RECESSION_WIND_DOWN（衰退清场信号） |

---

## 2. 四阶段资产配置指令 (Asset Allocation SOP)

### 【阶段1】衰退/早期复苏 (Recession to Early Recovery)

| 项目 | 内容 |
|------|------|
| **特征** | 利率大幅下降，通胀消失，经济数据极差 |
| **核心配置** | 长期政府债券(TLT)、利率敏感型成长股 |
| **逻辑** | 债券价格首先反映利率下行，是周期中最先启动的资产 |

### 【阶段2】强劲扩张期 (Strong Expansion)

| 项目 | 内容 |
|------|------|
| **特征** | 工业生产创新高，企业利润激增，通胀温和 |
| **核心配置** | 周期性股票、科技股、中小型股 |
| **逻辑** | 此阶段股票表现超过债券 |

### 【阶段3】过热/滞胀期 (Late Expansion to Stagflation)

| 项目 | 内容 |
|------|------|
| **特征** | 资源短缺，PPI飙升，美联储激进加息 |
| **核心配置** | 大宗商品(黄金、原油)、能源/资源股 |
| **LIQUIDATE** | 清空所有长期债券 |
| **逻辑** | 商品是该阶段唯一的避险/盈利池 |

### 【阶段4】衰退初期 (Onset of Recession)

| 项目 | 内容 |
|------|------|
| **特征** | 所有经济指标掉头向下，股市开始恐慌 |
| **核心配置** | 现金(SGOV)、短期国债、公用事业/医药(防御股) |
| **逻辑** | 保持最高流动性，等待阶段1的债券买入信号 |

## 3. 风险管理：财务健康与利润率审计

### 成本挤压审计

```
公式：对比PPI变化率与CPI变化率
指令：IF PPI增速 > CPI增速
→ GEM判定企业无法转嫁成本
→ 自动调低制造业标的的投资权重
```

### 利息支出审计

```
监控10年期美债收益率对高杠杆公司现金流的侵蚀
IF 利率大幅上升 + 高杠杆公司
→ 预警现金流恶化风险
```

## 4. GEM操作指令集

| 指令类型 | 触发方式 |
|---------|---------|
| **周期定位审计** | "根据美债收益率曲线和M2数据，计算当前处于哪个阶段？配置权重如何调整？" |
| **跨市场背离审计** | "标普500上涨但10Y美债价格下跌，是否预示进入阶段3？" |
| **利润率预警** | "分析PPI与单位劳动力成本趋势，成本压力>3%则输出减仓名单" |

## 7. 核心预警信号

| 信号 | 触发条件 | GEM动作 |
|------|---------|---------|
| **流动性收紧** | M2放缓 + 加息 | 压制估值，减仓高PE股 |
| **成本侵蚀** | PPI > CPI | 减制造业权重 |
| **曲线倒挂** | 10Y-2Y利差<0 | RECESSION_WIND_DOWN，全面防守 |
| **债券见顶** | 债券指数转跌 | 预警股票同步风险 |
