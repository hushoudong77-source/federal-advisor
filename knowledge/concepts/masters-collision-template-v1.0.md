# 大师对撞模板 V1.0

## 触发指令
`/大师对撞 [标的代码]`

## 模板结构（四章制）

### 一、Sentinel-01 物理层：冻结事实
- 使用 Markdown 表格展示标的全部物理数据（现价、持仓、成本、均线、DXY/CRB/IEF/VIX）
- 物理位阶判定（均线夹缝状态描述）

### 二、大师战术知识库对撞
依次从《大师战术精华》中提取四个核心框架进行多维度对撞：

#### 🥊 第一维度：Weinstein 阶段判定
- 表格：判定指标 | 当前状态 | 阶段判定
- 四大指标：MA30周线方向、价格vs MA30周、短期MA21、成交量特征
- 结论：阶段判定 + 一句话本质描述

#### 🥊 第二维度：CAN SLIM 适配
- 表格：CAN SLIM 七大要素 | 标的适配 | 评分
- 总分计算（/100）
- 主要扣分项分析
- 结论：中长期逻辑 + 短期限制

#### 🥊 第三维度：撒普 R 倍数框架
- 表格：R 维度 | 计算 | 审计
- 四大维度：浮盈、入场R值、当前有效R、效率红线对撞
- R_tier 判定（L1-L5）
- 审计官判定

#### 🥊 第四维度：达利奥全天候适配
- 表格：经济环境 | 当前状态 | 适配度
- 三大场景：增长/通胀/紧缩
- 撕裂状态识别
- 结论

### 三、大师对撞综合裁决
- 汇总表格：大师框架 | 核心判定 | 信号灯
- 四大师共识一句话

## 格式规范
1. 全表使用 Markdown 表格
2. 信号灯：🟢 Stage 2 / 🟡 Stage 1/3 / 🔴 Stage 4
3. 核心指令章节强制使用 `>` 引用块 + **加粗**
4. 四大师框架编号：🥊 第一/二/三/四维度
5. 物理数据优先读取记忆固化值，缺失标注"数据真空"
