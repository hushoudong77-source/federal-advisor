## mx-data — 金融数据查询

### 覆盖能力

| 数据类型 | ETF覆盖 | 参数精度 | 评价 |
|:---|:---:|:---|:---|
| 收盘价/最新价 | ✅ 9/9 | 精确到厘 | 核心可用 |
| 涨跌幅 | ✅ 9/9 | 精确 | 核心可用 |
| 成交量 | ✅ 9/9 | 股/亿元 | 核心可用 |
| 换手率 | ✅ 5/9 | 百分比 | 部分标的缺失 |
| 量比 | ✅ 5/9 | 精确 | 部分标的缺失 |
| MA简单移动平均 | ⚠️ | 周期不可控 | **受限** |
| RSI相对强弱指标 | ⚠️ | 周期不可控 | **受限** |

### 关键限制

1. **MA 周期不可指定**：查询 `MA60`、`MA120`、`60日均线` 均返回同一默认 MA 值（疑似 MA3/MA5，数学上无法与任何简单周期精确对账）。**法典要求的 MA120 灵魂溯源和 MA60 趋势判定无法通过 mx-data 直接获取。**

2. **ETF 归类为「开放式基金」**：东方财富底层将 ETF 归为基金而非股票，导致「今日收盘价」等查询可能返回区间净值数据。有效查询词为：`最新价 涨跌幅 成交量 换手率 量比`（一次批量查询）。

3. **RSI 周期不可指定**：返回的 RSI 值疑似默认 RSI6 或 RSI14，但无法确认。

### 推荐使用模式

```
# 行情快照（核心）
python3 mx_data.py "510300 510500 159545 513910 159915 588000 513180 513770 518880 最新价 涨跌幅 成交量 换手率 量比"

# 技术指标（辅助参考，不能替代精确MA60/MA120）
python3 mx_data.py "510300 510500 159545 513910 159915 MA简单移动平均 RSI相对强弱指标"
```

### 与现有数据源的配合

- mx-data 替代「用户投喂收盘价/成交量/换手率」
- **MA60/MA120 仍需用户投喂或通过 Yahoo Finance 获取**
- mx-data 的 MA/RSI 作为交叉参考，不作为决策锚点

## mx-search — 金融资讯搜索

### 覆盖能力

| 搜索类型 | 覆盖 | 评价 |
|:---|:---:|:---|
| 个股/ETF研报 | ✅ | 权威机构研报，时效性高 |
| 宏观资金流向 | ✅ | 北向/南向/融资数据 |
| 板块行业新闻 | ✅ | 较全面 |
| 公告/事件 | ✅ | 分红、解禁等 |

### 推荐使用模式

```
# 标的研报搜索
python3 mx_search.py "513910港股央企红利ETF最新研报或机构观点"

# 资金流向搜索
python3 mx_search.py "北向资金最新流向 南向资金 2026年4月"

# 黄金相关
python3 mx_search.py "518880黄金ETF 黄金价格 最新分析"
```

### 价值评估

- 替代通用搜索引擎（百度/Google）进行金融资讯搜索
- 信源权威性优于通用搜索（东方财富数据库筛选）
- 时效性：可获取当日新闻和最新研报
