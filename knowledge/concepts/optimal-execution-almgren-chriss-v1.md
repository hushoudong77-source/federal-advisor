# 最优执行：Almgren-Chriss框架（第六章）

> Source: Guo, X. et al. (2017) §6.1-6.3 — 联邦投顾知识库编译

## 核心问题

**要在T时间内买入/卖出N股，怎么拆单让总成本最小？**

总成本 = 冲击成本（滑点）+ 市场风险（持仓期间的不利波动）

## 三种价格影响

| 类型 | 含义 | 模型处理 |
|:---|:---|:---|
| **永久性影响** | 每笔交易改变标的"公允价值" | g(Nₖ/δ)，影响未来所有价格 |
| **暂时性影响** | 交易发生时瞬间的滑点，立即恢复 | h(Nₖ/δ)，只影响当前价格 |
| **短暂性影响**（LOB模型） | 价格影响随时间指数衰减 | Alfonsi模型，ρ为衰减速率 |

## 三种执行策略

### 1. TWAP — Bertsimas和Lo(1998)

**规则**：每期等量交易，N₁=N₂=...=N_T

**最优条件**：无风险厌恶(λ=0)，线性价格影响

**适用**：流动性极好、波动率极低的标的

### 2. Almgren-Chriss（波动率调整）— 行业标准

**核心公式**：
```
η · Y''ₜ - λσ² · Yₜ = 0
```
**解析解**：
```
Yₜ* = Ñ · sinh(A(T-t)) / sinh(AT)
其中 A = √(λσ²/η)
```
Yₜ = 时刻t的剩余待交易股数

**物理含义**：
- 早期交易更多——因为市场风险随持有时间累积，越快完成越好
- λ越大/σ越大/η越小 → 交易越快（更怕波动而非冲击）
- λ越小/σ越小/η越大 → 越接近TWAP均匀交易

### 3. LOB形状模型 — Alfonsi等(2010)

**规则**：考虑LOB的具体形状——不同价位上的挂单量分布

**关键参数**：弹性回复速率ρ——LOB被吃掉后的恢复速度

**适用**：LOB形状已知且稳定的标的（极低流动性标的）

## 对不同量级的执行建议

| 单量占比日均量 | 推荐策略 | 说明 |
|:---:|:---|:---|
| **<1%** | 市价单一次性 | 冲击成本<1bp，不值得拆单 |
| **1-5%** | 分2-3次，间隔几分钟 | 心理安抚为主，数学差异可忽略 |
| **5-10%** | TWAP/VWAP算法 | 冲击成本开始显著 |
| **10-20%** | 多日分批执行 | 冲击成本主导 |
| **>20%** | 多日+隐蔽执行 | 暗池+冰山订单 |

## 联邦投顾的应用

### 直接应用：CANE建仓

**参数**：
- 金额：$25,000
- 股数：~2,525股
- CANE日均量：50-100万股
- 占比：0.25-0.5%

**判定**：< 1%阈值 → 市价单一次性执行，不需要拆单

**如果金额扩大**：
- $100,000（~1%日均量）→ 分2批
- $250,000（~2.5%）→ 分3批，间隔15分钟
- $500,000（~5%）→ TWAP算法执行

### 潜在应用：固定层调仓

VTI/VEA的再平衡：
- 假设每次调仓规模$5,000-20,000
- VTI日均量~2000万股，占比<0.01%
- **冲击成本永远不是问题**——固定层调仓不需要考虑执行优化

### 潜在应用：大额离场

- 进攻/反击清仓时单个标的最大仓位7.5-10%
- A股ETF（如588000日均量~5亿份）：占比仍然<0.5%
- 美股ETF（如QQQ日均量~3000万股）：占比更小
- **当前组合规模下，冲击成本对所有标的都不可见**

## 学术限制

1. **η（冲击系数）的估计**：模型假设η已知，实际中η难以精确估计
2. **线性价格影响假设**：实际价格影响可能是非线性的
3. **单资产模型**：多资产同时执行时的cross-impact更复杂（§6.4）
4. **不考虑信息泄露**：大单拆分会暴露策略意图
