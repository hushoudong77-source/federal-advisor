# 限价指令簿与高频交易模型（第五章+第七章）

> Source: Guo, X. et al. (2017) 第5章（LOB数据分析）+ 第7章（做市与智能订单路径）— 联邦投顾知识库编译

## 第五章：限价指令簿（LOB）

### LOB数据结构

| 层级 | 价格 | 挂单量 | 累计 |
|:---|:---|:---:|:---:|
| 卖5 | 最高 | 小 | — |
| 卖4 | ↑ | 中 | — |
| 卖3 | 中间 | 大 | — |
| 卖2 | ↓ | 小 | — |
| **卖1** | **卖一价** | **最小** | **最先成交** |
| **买1** | **买一价** | **最小** | **最先成交** |
| 买2 | ↑ | 小 | — |
| 买3 | 中间 | 大 | — |
| 买4 | ↓ | 中 | — |
| 买5 | 最低 | 小 | — |

**物理含义**：LOB是市场微观结构的"快照"，反映当前时刻所有市场参与者的供需分布。

### 关键LOB特征量

| 指标 | 定义 | 交易含义 |
|:---|:---|:---|
| 最优买卖价差 | 卖一-买一 | 流动性最直接度量，价差宽=流动性差 |
| 中间价 | (买一+卖一)/2 | LOB的"公允价格"参考 |
| 交易量不平衡 | (买方量-卖方量)/(买方量+卖方量) | 正=买方主导，短期看涨信号 |
| 概率权重累积交易量之差 | 加权到各价位的堆积量差 | 比简单不平衡更精确的供需度量 |
| 斜率 | LOB在最优价位附近的陡峭度 | 陡峭=吃单成本高，平坦=薄市场 |

### Hawkes过程（自激发点过程）

**物理含义**：订单到达是"聚集"的——一个大买单后面会跟着更多买单（羊群效应/拆单行为）。

**数学形式**：
```
λ(t) = μ + ∫₀ᵗ φ(t-s) dN(s)
```
- λ(t) = 当前t时刻的订单到达强度
- μ = 基准强度（自发到达）
- φ(t-s) = 自激发核函数（之前的订单对当前的影响，随时间衰减）
- dN(s) = 之前的订单事件

**对联邦投顾的意义**：
- 当前我们交易的都是ETF，流动性极好，LOB建模的必要性低
- 但在CANE这类低流动性ETP上，Hawkes过程可以解释**为什么突破时价格会快速跳空**——订单的聚集效应
- **实战含义**：低流动性标的出现大单时，不要等回调——后续订单会接踵而来，价格不回

### 排队论建模

LOB的每个价位可以视为一个排队系统：
- 限价单到达 → 队列增加（顾客到达）
- 市价单吃掉 → 队列减少（顾客离开）
- 撤单 → 队列减少（顾客离开）

**扩散极限**：当订单到达/离开频率很高时，LOB的离散变化可以用连续扩散过程近似——这是连接LOB与第六章最优执行的数学桥梁。

## 第七章：做市与智能订单路径

### Ho-Stoll模型（经典做市商定价）

**问题**：做市商在最优买/卖价上挂单，应该设置多宽的价差？

**核心权衡**：
```
价差收入 vs 存货风险
   ↑            ↑
  赚更多        库存方向不利波动
```

**平衡解**：价差 = 存货风险的补偿 + 订单处理成本

### Avellaneda-Stoikov决策模型

**核心思想**：做市商的最优报价是**随时间变化的**——接近收盘时要缩小价差（存货风险时间窗口缩小），存货偏离目标时要调整报价以吸引反向订单。

**HJB方程解**：
```
最优卖价 = 中间价 + 价差/2 + γσ²(T-t) × (q - q_target)
最优买价 = 中间价 - 价差/2 + γσ²(T-t) × (q - q_target)
```
- γ = 风险厌恶系数
- σ = 波动率
- T-t = 剩余时间
- q = 当前库存

**物理含义**：
- 库存多(q>q_target) → 降低卖价、提高买价（吸引买入、抑制卖出）
- 剩余时间少(T-t小) → 价差缩小（存货风险窗口缩短）
- 波动大(σ大) → 价差扩大（存货风险溢价升高）

### 智能订单路径（SOR）

**问题**：多个交易所/暗池同时提供了同一标的的流动性，如何分配订单？

| 场景 | 策略 | 适用 |
|:---|:---|:---|
| 单个交易所 | 按LOB深度下单 | 大部分ETF |
| 多个明池 | 按价差+流动性加权分配 | 美股多交易所交易 |
| 暗池 | 试探性小单（鲨鱼探测） | 大单避光场景 |

**暗池的特殊性**：删失学习问题（Censored Exploration & Exploitation）
- 你看不到暗池里的挂单
- 你只能通过小额试探来"探测"暗池深度
- 但探测本身会暴露你的意图

## 对联邦投顾的实战意义

### 当前适用度

| 模型 | 联邦适用度 | 理由 |
|:---|:---:|:---|
| LOB分析 | ⚪低 | ETF流动性极好，LOB分析的必要性极低 |
| Hawkes过程 | 🟡中 | 解释CANE/低流动性标的的价格跳空行为 |
| 排队论扩散极限 | ⚪低 | 纯理论，与第六章最优执行连接 |
| Ho-Stoll做市 | ⚪低 | 联邦不做市 |
| Avellaneda-Stoikov | 🟡中 | 可用于低流动性标的的订单时序安排（CANE分批建仓） |
| SOR多交易所 | ⚪低 | 联邦只交易ETF，单交易所执行 |

### 唯一有价值的应用

**Avellaneda-Stoikov的时间依赖逻辑**——可以用在CANE分批建仓的时序安排上：
- 剩余时间短(建仓deadline临近) → 缩小价差容忍度，加速执行
- 剩余时间长 → 可以等待更好的价格窗口
- 当前$25,000一把梭结论不变（量级太小），但如果未来加仓金额扩大（$50,000+），该框架可以给出分拆时间表
