# 参数不确定性下的动态投资组合选择

> Source: Guo, X. et al. (2017) §3.3.6. 基于教科书框架的联邦投顾实践对撞

## 学术核心逻辑

### 问题本质

经典Merton/Samuelson模型假定**已知**资产收益率的漂移项µ和波动率σ。实际中只能**估计**——这就引入了"参数不确定性"这个额外的风险维度。

### 三个核心结论

| 作者 | 年份 | 模型设定 | 核心发现 |
|:---|:---:|:---|:---|
| **Brennan** | 1998 | 1个风险资产+1个无风险资产，µ未知σ已知 | 参数不确定性→降低风险资产比例；但随着数据积累"学习"→比例回升 |
| **Xia** | 2001 | µ可预测且时变(多因子模型) | 参数不确定性产生**与状态相关的对冲需求**，随时间非单调变化 |
| **Cvitanić et al.** | 2006 | m个风险资产+市场组合，µ未知σ已知 | 给出指数/对数效用函数下的**解析解**，证明滤波方法有效 |

### 方法论核心：Kalman-Bucy滤波

核心数学结构——当µ未知时，将其作为**状态变量**，用滤波方法序贯更新后验分布：

```
先验: µ ~ N(m₀, v₀)
         ↓ 观测到价格Pt
后验: µ|Pₜ ~ N(mₜ, vₜ)
         ↓
dmₜ = (vₜ/σ²)(dPₜ/Pₜ - mₜdt)   ← Kalman-Bucy滤波方程
vₜ  = v₀σ²/(v₀t + σ²)            ← 方差随时间递减
```

**物理含义**：初始时不确定性大(v₀大) → 风险资产配置比例降低 → 随着时间推移，观测数据增多，vₜ变小 → "学习效应"使比例回升。

### 关键洞见

1. **预测风险(Prediction Risk)**：参数不确定性本身就是一个风险源，需要额外对冲
2. **学习(Learning)**：随着时间推移，参数估计越来越精确，可以逐步增加风险暴露
3. **波动率不确定性被低估**：大部分研究只处理了µ的未知，σ的未知更难（需要非线性滤波）
4. **对冲需求是时变的**：不是固定减仓多少，而是随时间/状态发生变化

## 与联邦投顾实践的对撞

### 我们目前在做的 vs 学术框架

| 维度 | 联邦投顾当前实践 | 学术框架 §3.3.6 |
|:---|:---|:---|
| 参数来源 | 回测历史数据→固定参数 | 贝叶斯后验更新→时变参数 |
| 不确定性处理 | 走廊测试+敏感性分析 | Kalman滤波+动态规划 |
| 参数更新 | 手动审计后冻结 | 自动序贯学习 |
| 波动率处理 | ATR14分位状态机(A/B/C) | σ已知假设(最弱环节) |
| 多标的相关性 | 独立回测每标 | Cvitanić m+1资产解析解 |

### 直接可应用的洞见

**洞见1：回测参数的最优置信度权重**

走廊测试发现IAU"唯一鲁棒"——因为别的标的Sharpe在走廊测试中剧烈波动。学术解释：**参数不确定性对低信噪比标的冲击更大**。IAU的σ小(约12%)，而EWY的σ大(约25%)——σ越大，vₜ衰减越慢，学习越慢，参数不确定性持续更久。

→ **推论**：高波动标的(SMIN/EWY/510500)的回测参数天生不可靠，走廊测试全面负Sharpe不是巧合，是参数不确定性在数学上的必然结果。

**洞见2："冷却期"的学术基础**

法典中30天冷却期的设计（进攻清仓后30天内不可再开仓）——学术框架里没有直接对应，但可以用"学习"的概念解释：
- 清仓事件本身提供了关于当前市场 regime 的信息
- 需要足够的新观测数据(30天约22个交易日)来更新µ的后验估计
- 冷却期 = 强制等待后验方差vₜ收敛到可接受水平

**洞见3：正金字塔分批建仓的理论支撑**

反击策略的两层建仓(30%+70%)可以理解为：
- 第一批30% = 在参数不确定性最大时的保守暴露
- 等待信号确认+更多数据点 → vₜ缩小 → 第二批70%加码
- 这与Brennan(1998)的"先小后大"序贯学习策略一致

**洞见4：波动率状态机(A/B/C)的改进方向**

当前ATR14波动率状态机是**非参数方法**（基于分位数硬切），学术框架建议**参数化方法**（滤波+动态规划）。但参数化方法的计算成本高，且需要非线性滤波处理σ的不确定性——当前非参数方法在工程上更合理。

### 局限性

1. **学术假设过于理想**：µ未知但σ已知——现实中σ不确定性更大
2. **计算成本高**：Kalman滤波+动态规划需要大量实时计算
3. **多资产扩展困难**：Cvitanić的解析解只适用于特定效用函数
4. **未考虑制度转换**：µ和σ在牛市/熊市中截然不同——单一滤波模型不够

## 结论

参数不确定性的学术框架并未否定我们的**走廊测试方法论**，反而为其提供了理论支撑——走廊测试本质上是一种**非参数敏感性分析**，用于探测参数不确定性带来的策略绩效波动。两者的关系是：

```
学术（演绎）：参数不确定性 → 降低风险暴露 → 序贯学习恢复
                            ↓
实践（归纳）：走廊测试探测参数脆弱性 → 参数冻结/否决 → 冷却期机制
```

最直接的实践改进：**可以给每个标的的回测参数打一个"置信度分数"**，基于其σ大小和历史走廊测试的Sharpe波动率——σ越大、走廊越宽，置信度越低，策略执行时应更保守。
