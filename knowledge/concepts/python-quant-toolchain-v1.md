### 2.2 策略开发（五大经典策略）

| 策略 | 核心逻辑 | 联邦对应 |
|:---|:---|:---|
| **均线策略** | SMA/EMA交叉信号：短期上穿长期→买入 | 法典 EMA50>EMA150 趋势过滤 |
| **MACD策略** | DIF/DEA交叉+柱状图变化 | 金盾V1.4 MACD金叉为入场条件之一 |
| **RSI策略** | >70超买卖出，<30超卖买入 | 金盾RSI<70为入场条件之一 |
| **趋势跟踪** | 跟随主要趋势，移动均线/布林带判断 | 法典进攻策略=趋势跟踪 |
| **均值回归** | 价格偏离均值→回归，偏离过大时反向交易 | 法典反击策略=均值回归 |

## 🆕 P0高级回测引擎（2026-06-14 落地）

基于现有 `hitrate_backtest.py` V2.0，新建 `scripts/backtest_advanced.py`，叠加三个P0级指标：

| 指标 | 功能 | 触发阈值 |
|:---|:---|:---|
| P0-1 滚动窗口漂移率 | 36/24/12/6/3月五个窗口HR vs 全周期HR | 近6月HR < 全周期HR×0.7 → 🔴告警 |
| P0-2 参数敏感度 | k参数9邻域扫描（±0.05~±0.50），检测过拟合 | 邻域HR降幅>15pp且偏移≤0.10 → 🔴过拟合 |
| P0-3 最大连续亏损时间标记 | 所有连续亏损段的时间、累计亏损、平均亏损 | ≥8笔 → 🟡执行心理风险 |

**运行方式**：`python3 scripts/backtest_advanced.py`（全池）/ `--ticker 513910`（单标）/ `--sensitivity-only`（仅敏感度）/ `--export report.md`（导出）

- 2个异常告警：159302近12月HR恶化-11.5pp（🔴）、FLIN近12月HR恶化-19.8pp（🔴）
- 全池参数整体稳健，无过拟合信号
- 510500最大连续亏损6笔（2024-05~2024-08，累计-22.48%）为全池最高
