# 已实现波动率（Realized Volatility）

> Source: Guo, X. et al. (2017) §4.3 — 联邦投顾知识库编译

## 学术定义

**已实现波动率（RV）**是日内高频收益的平方和，是**积分波动率（Integrated Volatility）**的无偏一致估计量。

### 数学形式

**完整表达式**：
```
RVₜ = Σᵢ₌₁ⁿ r²ₜ,ᵢ
```
其中 rₜ,ᵢ = log(Pₜ,ᵢ/Pₜ,ᵢ₋₁) 为第t天第i个时间段的对数收益

**对积分波动率的收敛性**：
```
RVₜ —→ ∫ₜ₋₁ᵗ σ²(s)ds   (当 n→∞)
```
即——抽样频率n足够高时，RV收敛到真实积分波动率。

### 为什么RV比GARCH好

| 维度 | GARCH | 已实现波动率(RV) |
|:---|:---|:---|
| 数据需求 | 日线就够了 | 需要日内高频数据 |
| 估计方式 | 参数化（假设分布） | 非参数化（直接计算） |
| 收敛性 | 渐进有效 | 无偏一致估计 |
| 时效性 | 用历史估未来 | 用今天数据估今天 |
| 实现难度 | 简单 | 数据获取难 |

**一句话**：GARCH是用昨天参数猜今天波动率；RV是用今天前几个小时的数据算今天到现在为止的波动率。

## 教科书方法论

### 抽样频率选择

| 频率 | 优点 | 缺点 |
|:---|:---|:---|
| 1分钟 | 信息量最大 | 微结构噪音严重（买卖价差反弹） |
| **5分钟** | **经验最优折中** | 教科书推荐，标准实践 |
| 15分钟 | 噪音少 | 信息损失大 |
| 30分钟 | 最干净 | 信息损失严重 |

**教科书的经验法则**：5分钟抽样是"噪信比"最优折中点。

### 微结构噪音问题

高频数据中的噪音来源：

| 噪音源 | 来源 | 影响 |
|:---|:---|:---|
| 买卖价差反弹 | 价格在买一/卖一间来回跳 | 人为增加波动率估计 |
| 交易异步性 | 不同标的成交时间不同 | Epps效应——相关性低估 |
| 离散价格 | 最小报价单位(1分/1厘) | 微小波动被截断 |

**解决方案**：

| 方法 | 原理 | 适用场景 |
|:---|:---|:---|
| 稀疏抽样 | 用5分钟而不是1分钟 | 简单有效，教科书基础推荐 |
| TSRV（双时间尺度） | 高频估计+低频偏差校正 | 理论最优，但实现复杂 |
| 已实现核估计 | 核函数加权平滑 | 稳健性好 |
| 预平均方法 | 对高频收益先做局部平均 | 渐进有效 |
| QMLE | 准最大似然估计 | 统计性质最优 |

### 多资产协方差估计

**Epps效应**：当两个资产不同步交易时，它们的高频相关性被系统性低估。

**同步技术（Refresh Time）**：
1. 当两个资产都有新交易时，记录一个"同步时间点"
2. 只用这些时间点计算协方差
3. 缺点是会丢失数据点

## 对联邦投顾的实战意义

### 当前应用

联邦投顾已实现波动率的使用：

| 应用 | 当前实现 | 教科书方法对比 |
|:---|:---|:---|
| 波动率状态机 | ATR14的252日分位（非参数） | RV的直接估计是替代方案 |
| 金盾S4阈值 | 乖离率3.5% | 可用RV校准 |
| 进攻ATR止损 | 5.0×ATR（日线14日） | 可用RV提高灵敏度 |
| 反击买入区间 | MA60±k×ATR14 | 可用RV替代ATR14 |

### 改进方向

**场景1：CANE波动率监控**
- 教科书方法：获取CANE的15分钟高频数据 → 计算每日RV → 监控RV的突变
- 联邦方法：用日线ATR14近似
- 差距：日线ATR14对日内波动不敏感，厄尔尼诺事件确认当天RV可能暴涨但ATR14只缓慢变化
- **改进**：如果未来能获取CANE的高频数据，RV可以作为ATR14的领先预警

**场景2：金盾S4阈值校准**
- S4是乖离率阈值(3.5%)——本质上是一个"波动率倍数"
- 用RV替代σ估计：S4 = k × σ_RV × √252
- 当RV放大时，k可以相应调整，而非固定阈值

**场景3：波动率状态机优化**
- 当前：ATR14的252日分位(P70/P30三分区)
- 替代方案：日度RV → RV的252日分位
- RV比分位ATR14更灵敏（ATR14是14日平滑，RV是单日估计）
- **但灵敏不一定是好事**——更灵敏意味着更多误报

### RV陷阱（教科书没说的）

1. **跳跃项分离**：RV = 连续波动 + 跳跃项。重大事件（如厄尔尼诺确认）的跳空会"污染"RV，需要BNS跳跃分离检验（§4.4）
2. **过夜波动**：CANE是期货ETP，过夜跳空占相当比重。RV只覆盖交易时段
3. **数据获取成本**：RV需要高频数据（Tick/分钟级），对当前数据基础设施是额外负担

## 关键结论

**RV vs ATR14不是替代关系，而是互补关系**：
- RV：单日波动率的**水平**，灵敏但易受噪音干扰
- ATR14：滚动波动率的**趋势**，平滑但滞后

```
RV暴涨 → 预警信号
         ↓
ATR14开始上升 → 确认信号
         ↓
波动率状态机切换 → 策略调整
```
