# 准备金余额监控协议 V1.0

> 创建：2026-06-19 | 触发：YouTube视频《2026下半年定价权从美联储交给财政部》联邦审计 → 发现联邦框架缺少财政抽血管道监控

## 物理公式

```
准备金余额 = 美联储总资产 − TGA（财政部账户）− ON RRP（隔夜逆回购）
```

或直接使用FRED WRBWFRBL序列（Reserve Balances with Federal Reserve Banks）。

## 数据源

| 指标 | 数据源 | 频率 | 滞后 | 获取方式 |
|:---|:---|:---|:---|:---|
| **WRBWFRBL** (准备金余额) | FRED St. Louis Fed | 每周三 | ~7天 | AnySearch CLI extract |
| WALCL (美联储总资产) | FRED | 每周三 | ~7天 | AnySearch CLI extract |
| TGA (财政部账户) | FRED WTREGEN / ycharts | 每日 | ~1天 | AnySearch CLI search |
| ON RRP (隔夜逆回购) | FRED RRPONTSYD | 每日 | ~1天 | AnySearch CLI search |

## 阈值体系

| 准备金余额 | 状态 | 行动 |
|:---|:---|:---|
| >$2.5万亿 | 🟢 充裕 | 正常执行，无额外限制 |
| $2.0-2.5万亿 | 🟡 收敛 | 进攻仓位减半（与VIX ALERT叠加）；反击正常 |
| $1.5-2.0万亿 | 🔴 稀缺 | 暂停所有进攻开火；现有进攻仓位止损收紧至3×ATR |
| <$1.5万亿 | 🔴🔴 危机 | 全局熔断（与VIX>50 MELTDOWN同级） |

## 历史参照

| 事件 | 准备金余额 | 后果 |
|:---|:---|:---|
| 2019年9月回购危机 | ~$1.4万亿 | 隔夜回购利率飙升至10%，美联储被迫重启扩表 |
| 2020年3月COVID | ~$1.6万亿（扩表前） | 流动性危机，美联储紧急降息+无限QE |
| 2022年峰值 | ~$4.2万亿 | QT启动前 |
| 2026年6月10日 | **$3.111万亿** | 距稀缺区间（$2.0万亿）仍有$1.1万亿缓冲 |

## 与联邦框架的关系

- 准备金余额监控是**宏观危机状态机（模块十二）的前置补充**——在VIX飙升之前，准备金余额下降是更早期的流动性预警
- 与US10Y双熔断（≥5.00%）、VIX危机阈值（>35）互补——三者在不同维度测量流动性压力：利率价格（US10Y）、恐慌烈度（VIX）、管道存量（准备金）
- **优先级**：VIX > US10Y > 准备金余额。准备金余额是慢变量，不替代VIX/US10Y的瞬时熔断，但提供更早的预警窗口

## 取数SOP

1. **每周一次**（与债市杠杆率同频，周一执行）
2. AnySearch CLI: `search "WRBWFRBL reserve balances June 2026"` 或直接提取FRED页面
3. 记录最新值到当日memory
4. 若准备金余额周环比下降>$500亿 → 标注「准备金加速消耗」
5. 若准备金余额<$2.5万亿 → 标注「准备金进入收敛区间」
