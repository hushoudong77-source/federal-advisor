# SEPA策略与VCP审计协议 (GEM V2.0)

> 基于马克·米勒维尼《超级绩效》(Trade Like a Stock Market Wizard)
> 核心目的：从基本面筛选到技术面精准卡位的全流程自动化审计

---

## 0. 系统哲学：超级绩效前置条件

| 原则 | 描述 |
|------|------|
| **寻找领导股** | 只交易行业中盈余和股价表现最强的龙头 |
| **风险前置** | 先确定止损位，再决定买入 |
| **特定进场点(SEPA)** | 只在波动极度收缩、阻力最小的路径上(VCP)出手 |

---

## 1. 趋势模板：GEM准入审计矩阵 (Trend Template)

**任何标的在进入SEPA筛选前，必须100%满足以下硬准则：**

| 审计项 | 物理特征 | 执行逻辑 |
|--------|---------|---------|
| **均线排列** | 价格 > MA50 > MA150 > MA200 | 确保标的处于Stage 2(主升段) |
| **均线斜率** | MA200至少上行1个月以上 | 确认长期趋势已扭转向上 |
| **价格位置** | 价格高于52周低点至少25%-30% | 确认已经从底部启动 |
| **相对强度** | RS评级(对比大盘) ≥ 70 | 必须优于市场平均水平(优选90+) |

**GEM自动拦截**: 任一条件不满足 → 拒绝买入

## 2. VCP形态审计协议 (Volatility Contraction Pattern)

### 收缩次数 (Ts)

```
识别2到4次的价格回撤收缩
例如: 25% -> 12% -> 5%
```

### 紧凑性审计 (Tightness)

| 特征 | GEM判定 |
|------|---------|
| 日波动幅度极小 | 波动末端信号 |
| 成交量严重萎缩 | VCP底部确认 |
| 波幅仍>10% | NOT_READY，判定为未进入收敛区 |

### 阻力最小路径 (Pivot Point)

| 条件 | GEM动作 |
|------|---------|
| 价格突破收缩区最高点 | 确认为Pivot触发点 |
| 突破时成交量 > 前10日均值40%-50% | 确认有效突破 |

---

## 3. SEPA五大核心要素对账 (Five Key Ingredients)

**总分 >80 方可执行买入：**

| 要素 | 审计内容 | 最低要求 |
|------|---------|---------|
| **Trend (趋势)** | 符合趋势模板 | 100%满足 |
| **Fundamentals (基本面)** | EPS同比增长≥25%，有盈余意外(Surprise) | 核心条件 |
| **Catalyst (催化剂)** | 新产品/新管理层/行业环境巨变 | 至少一项 |
| **Relative Strength** | 在指数调整时横盘或逆势上涨 | RS评级≥70 |
| **Institutional Support** | 机构建仓信号(放量上涨，缩量回调) | 必须有 |

---

## 4. 风险管理与执行指令 (Position Sizing & Stop-loss)

### 绝对止损线

| 类型 | 限值 |
|------|------|
| 最大止损 | 严禁超过7%-8% |
| 平均止损 | 应控制在3%-5% |

### 盈亏比审计

```
预期获利必须是风险的2倍以上
IF 为了博取10%利润而冒8%风险 -> 执行 VOID_TRADE
```

### 强制离场信号

| 信号 | 描述 |
|------|------|
| Stage 3异常波动 | 趋势破坏，立即离场 |
| Climax Top (高潮顶部) | 涨幅过大过快且成交量异常巨量 |

## 5. GEM操作指令集

| 指令类型 | 触发方式 | GEM执行 |
|---------|---------|---------|
| **趋势模板审计** | "检查[标的]是否满足Stage 2均线排列" | 输出趋势模板评分 |
| **VCP形态分析** | "识别最近3个月VCP收缩次数，是否处于Pivot区" | 输出紧凑度报告 |
| **基本面对账** | "提取最近两季度EPS及分析师修正方向" | 输出盈利加速分析 |
| **动态止损计算** | "在当前Pivot买入，计算3:1盈亏比止损位" | 输出基于ATR的科学止损位 |
