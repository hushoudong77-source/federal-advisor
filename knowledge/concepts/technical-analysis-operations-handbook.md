# 股市技术分析操作手册：GEM自动化审计协议 (V2.0)

> 核心目的：将技术分析形态转化为可执行的GEM指令，消除歧义，引入权重

---

## 0. 预设环境 (Pre-sets)

| 参数 | 描述 |
|------|------|
| **收盘价优先权** | 仅以收盘价作为逻辑判定锚点，忽略盘中最高/最低点 |
| **3%过滤器** | 所有突破必须偏离关键位>3%且持续2个交易日才判定为有效 |
| **相互印证** | 单一指数信号无效，必须双指数同步验证 |

## 1. 核心形态：逻辑触发矩阵 (Logic Matrix)

### 【头肩形态】—— 趋势终结判定

| 审计项 | GEM输入 | 权重 | 执行逻辑 |
|--------|---------|------|---------|
| **成交量递减** | 左肩/头部/右肩的成交量序列 | 0.4 | 右肩上涨时成交量必须显著低于左肩和头部 |
| **颈线刺透** | 收盘价跌破颈线3% | 0.6 | 确认趋势破坏 |

**执行指令**:
```
IF 逻辑1 & 逻辑2 同时满足
THEN 发出 CRITICAL_SELL 指令
目标跌幅 H = |Head - Neckline|
```

### 【对称三角形】—— 能量爆发判定

| 审计项 | GEM输入 | 权重 | 执行逻辑 |
|--------|---------|------|---------|
| **时间窗口** | 突破点占形态全长的比例 | 0.7 | 突破点处于形态长度的50%-75%区间 |
| **成交量对撞** | 向上突破时成交量 | - | 必须激增>前5日均值50% |

**执行指令**:
```
IF 突破发生在75%之后
THEN 标记为 LOW_CONFIDENCE，视为震荡，禁止入场
```

**向下突破**：无需成交量验证

## 2. 趋势线审计协议 (Trendline Audit)

### 有效性评分

| 连接点数 | 评级 | GEM处理 |
|---------|------|---------|
| 2点 | 临时线 | 不可作为止损依据 |
| 3点 | 确立线 | GEM止损锚点 |
| 4点+ | 强主权线 | 破位即清仓 |

### 加速度预警

```
IF 趋势线斜率连续两周增加且偏离原始趋势线>30度
THEN GEM触发"乖离率过高"警报
强制将止损位提升至最近的波段低点
```

## 3. 支撑/阻力：物理位转换审计

### 极性反转原则

```
关键位被3%过滤器突破后 → 极性反转
前高阻力 → 回踩时变成支撑
前低支撑 → 反弹时变成阻力
```

### GEM审计逻辑

| 条件 | GEM判定 |
|------|---------|
| 缩量回踩 + 出现反转K线 | STRONG_SUPPORT (Stage 2加仓点) |
| 放量跌破前高阻力 | 支撑失败，清仓 |

## 4. 风险控制：机械化执行指令

| 规则 | 描述 |
|------|------|
| **止损物理锚点** | 固定设在颈线或支撑位下方1.5%-2%缓冲区 |
| **测算限度** | 价格达到形态测算目标位(H距离)90%时，发出TAKE_PROFIT_ALERT，收紧移动止损 |
| **多空平衡** | 道氏理论未确认长线反转前，逆势形态权重降低50% |

## 5. GEM操作指令集

| 指令类型 | 触发方式 |
|---------|---------|
| **三角形审计** | "审计[标的]日线，检查是否处于对称三角形有效时间窗口，计算突破目标位" |
| **头肩形态** | "检查[标的]是否形成头肩顶，计算颈线跌破后的目标跌幅H" |
| **趋势线** | "连接[标的]最近波段高/低点，输出有效性评分" |

|------|---------|-----------|---------|
