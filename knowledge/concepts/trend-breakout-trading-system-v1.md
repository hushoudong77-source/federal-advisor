# 趋势突破交易系统 V1.0

> **来源**：守东口述选股/开仓/持股/离场全链路规则
> **审计硬化**：联邦投顾（联邦四线程对撞 + 参数量化 + 假突破防御 + 仓位约束）
> **状态**：V1.0 冻结，可回测
> **入库日期**：2026-06-04

---

## 一、系统概览

**核心逻辑**：在已确认的上升趋势中，等待价格突破关键压力线并放量确认后入场，用均线角度分治进行动态止损跟踪。

**与联邦法典关系**：独立系统，与法典进攻策略（Spearhead C1-C4）逻辑共振但不互斥。可并行使用。

**适用市场**：A股个股（非ST），日线级别。

---

## 二、选股条件（4条件AND）

### 条件S1：趋势向上（道氏定义）

**量化标准**：
```
窗口：最近13个月（回溯至去年5月）
判定：
├── 低点序列：取每月最低价，低点逐月抬高（允许单月回撤≤前月低点×1.02，即2%容差）
└── 高点序列：取每月最高价，高点逐月抬高（允许单月回落≤前月高点×0.98，即2%容差）
```

**通过标准**：低点序列和高点序列同时满足"逐月抬高"趋势（各允许不超过1次容差内违反）。

**禁止行为**：主观看图判定。必须用OHLCV数据计算月线高低点序列。

---

### 条件S2：压力线突破

**压力线画法（硬化版）**：

```
Step 1: 在最近6个月（≥1个月）日线数据中，识别最近3个明显波段高点
        ├── 波段高点定义：当日最高价 > 前5日和后5日的最高价
        └── 取最近3个满足条件的波段高点（按时序标记为 H1/H2/H3，H3为最近）

Step 2: 取最近2个高点（H2和H3）画压力线
        ├── 压力线 = H2与H3的连线，向右延伸
        └── 备选：若H2和H3时间间隔<20个交易日，改用H1和H3（确保压力线有足够的统计意义）

Step 3: 逐日计算压力线值（线性插值）

Step 4: 突破判定
        ├── 当日收盘价 > 当日压力线值 × 1.03（即突破幅度>3%）
        └── 突破日距今≤5个交易日
```

**突破幅度 = 3%（百分比，非绝对价格）**。统一标准，解决高价股与低价股不可比问题。

**压力线拟合备选方案**（用于回测自动化）：
- 取最近3个波段高点，用线性回归拟合趋势线
- 突破判定：收盘价 > 回归线预测值 × 1.03

---

### 条件S3：放量确认

**量化标准**：
```
基准量 = 突破日前5个交易日的日均成交量
判定：
├── 突破日成交量 ≥ 基准量 × 1.5 → ✅ 放量（标准）
├── 突破日成交量 ≥ 基准量 × 2.0 → ✅✅ 倍量（优先）
└── 突破日成交量 < 基准量 × 1.5 → ❌ 不放量，条件S3不满足
```

**优先含义**：倍量突破 > 普通放量突破。在多个标的同时满足条件时，倍量者优先。

---

### 条件S4：排除ST

**量化标准**：
- 股票简称不含 "ST" 或 "*ST"
- 或：最近一期年报净利润 > 0 且 净资产 > 0（排除连续亏损风险，即使未戴帽）

---

## 三、开仓条件

### 主入口

**入口A — 突破当日/次日开仓**：
- 触发：S1∧S2∧S3∧S4 全部满足的当日或次日
- 仓位：初始仓位 = 总资金 × 5%（单票初始上限）
- 止损：以压力线为初始止损位（收盘价跌破压力线 = 止损）

**入口B — 回调不破开仓**：
- 触发：突破后股价回调，但回调期间每日收盘价 > 压力线，且出现企稳信号
- 仓位：同入口A
- 止损：同入口A
- 优势：盈亏比更好（入场价更接近止损位）

---

### 加仓条件（三层，累计≤3次含初始建仓）

**加仓A — 回调企稳**：
```
触发条件（AND）：
├── 突破后股价下跌（回调）
├── 回调期间每日收盘价 > 压力线（未跌破）
├── 回调后出现企稳信号：当日收阳线 且 收盘价 > 前日收盘价
└── 加仓量 = 总资金 × 3%
```

**加仓B — 连续小涨**：
```
触发条件（AND）：
├── 突破后连续3个交易日上涨
├── 3日累计涨幅 ≤ 5%
├── 每日开盘价 > 突破日收盘价
├── 优先：3日均为阳线
└── 加仓量 = 总资金 × 3%
```

**加仓C — 均线支撑**：
```
触发条件（AND）：
├── 上涨途中出现回调
├── 回调触及5日线或10日线（收盘价距均线≤1%）
├── 收盘价 > 均线（获得支撑）
└── 加仓量 = 总资金 × 2%
```

**加仓硬约束**：
- 单票总仓位 ≤ 总资金 × 20%
- 累计加仓次数 ≤ 3次（含初始建仓）
- 任一加仓触发后，同一回调波段内不再触发同类加仓（防重复计数）

## 四、持股与动态止损

### 角度分治（量化硬化版）

> **核心逻辑**：趋势越陡 → 越脆弱 → 需要更紧的止损。
> **硬化方式**：用乖离率替代视觉角度测量。

**角度判定**（每日收盘后执行）：

```
计算：乖离率 = (收盘价 - MA10) / MA10 × 100%

判定：
├── 低角度（<45°）：乖离率 < 3%
│   └── 止损线 = MA10（收盘价跌破MA10 → 清仓/大幅减仓）
│
├── 高角度（>45°）：乖离率 ≥ 3%
│   └── 止损线 = MA5（收盘价跌破MA5 → 清仓）
│
└── 角度切换：
    ├── 低→高：当乖离率从<3%升至≥3%时，止损线从MA10切换至MA5
    └── 高→低：当乖离率从≥3%降至<3%时，止损线从MA5切换回MA10
```

**MA5/MA10取值来源**：Tushare日线数据，收盘后重新计算。不接受视觉估算或AI推断值（联邦规则L）。

## 五、离场条件

### 5.1 止损离场（OR触发，非AND）

以下任一条件满足 → **清仓**：

| # | 条件 | 量化标准 |
|:---:|:---|:---|
| L1 | 放量跌破压力线 | 成交量 ≥ 前5日均量 × 1.5 **且** 收盘价 < 压力线 |
| L2 | 大跌破线 | 当日跌幅 > 5% **且** 收盘价 < 压力线（无论量能） |
| L3 | 均线止损 | 按第四章角度分治规则，收盘价跌破对应止损线 |
| L4 | 放量跌破压力线（缩量例外） | 成交量 < 前5日均量 × 0.7 **且** 收盘价 < 压力线 **但** 跌幅 < 3% → **不触发**（缩量小跌=洗盘可能性大） |

### 5.2 缩量持有例外

```
条件（AND全部满足 → 持有，不清仓）：
├── 成交量 < 前5日均量 × 0.7（缩量）
├── 收盘价 ≥ 压力线（未跌破）
└── 当日跌幅 < 5%

逻辑：缩量未破线 = 主力未出逃，趋势结构完整 → 忍受波动
```

### 5.3 假突破止损

```
场景：入口A或B开仓后，股价回调跌破压力线

处理：
├── 开仓后收盘价首次跌破压力线 → 立即止损，不等放量条件
└── 止损后重新突破压力线（满足S2+S3）→ 可重新入场（视为新交易，独立计算仓位）
```

**逻辑**：入场后跌破压力线=突破失败，保护本金优先于等待确认。

## 六、仓位管理总纲

| 层级 | 仓位上限 | 触发条件 |
|:---|:---:|:---|
| 初始建仓 | 5% | 入口A/B首次开仓 |
| 加仓A（回调企稳） | +3% | 回调不破+企稳阳线 |
| 加仓B（连续小涨） | +3% | 3日小涨<5% |
| 加仓C（均线支撑） | +2% | 5/10日线支撑 |
| **单票硬顶** | **20%** | 任何情况下不得超过 |
| 加仓总次数 | ≤3次 | 含初始建仓 |

## 七、回测参数定义

### 7.1 选股池

- 全A股（沪深两市）
- 排除：ST / *ST / 上市不满13个月（条件S1需要13个月数据）

### 7.2 信号识别

| 参数 | 值 | 说明 |
|:---|:---|:---|
| 趋势窗口 | 13个月 | S1 |
| 月线容差 | 2% | S1高低点序列允许的单月违反幅度 |
| 压力线高点数 | 最近3个 | S2 |
| 压力线取点 | 最近2个（H2+H3），间隔<20日改用H1+H3 | S2 |
| 突破幅度 | 3%（百分比） | S2 |
| 突破时效 | ≤5个交易日 | S2 |
| 放量基准 | 前5日均量 | S3 |
| 放量阈值 | ≥1.5×（标准）/ ≥2.0×（倍量优先） | S3 |

### 7.3 交易参数

| 参数 | 值 | 说明 |
|:---|:---|:---|
| 初始仓位 | 5% | 入口A/B |
| 单票硬顶 | 20% | 仓位约束 |
| 加仓上限 | 3次 | 含初始建仓 |
| 低角度乖离率阈值 | <3% | <45°等效，用MA10止损 |
| 高角度乖离率阈值 | ≥3% | >45°等效，用MA5止损 |
| 缩量阈值 | <0.7×前5日均量 | 缩量持有例外 |
| L1放量阈值 | ≥1.5×前5日均量 | 放量跌破压力线 |
| L2跌幅阈值 | >5% | 大跌破线 |
| L4缩量豁免跌幅 | <3% | 缩量小跌不触发止损 |

## 八、与联邦法典的关系

| 维度 | 趋势突破系统 | 联邦法典进攻策略 |
|:---|:---|:---|
| 标的范围 | A股个股 | 全球ETF（17标） |
| 趋势定义 | 道氏高低点 | 均线多头排列（EMA50>EMA150） |
| 入场信号 | 压力线突破+放量 | C1-C4 AND（均线+MACD+RSI+回调深度） |
| 止损方式 | 角度分治（MA5/MA10） | 5.0×ATR追踪止损 |
| 仓位管理 | 5%初始+三次加仓 | 单笔10%+单标20%硬顶 |
| 关系 | **独立系统，并行使用** | 不互斥，不同标的池 |

**冲突解决**：无冲突。趋势突破系统用于A股个股选股，法典用于ETF池。资金池独立管理。

## 九、待验证项（回测前标记）

1. **压力线自动识别算法**：波段高点的定义（前5后5）是否产生过多/过少候选点
2. **假突破率**：突破3%后回踩跌破压力线的比例（需要历史数据统计）
3. **加仓ABC重叠频率**：同一波段内ABC同时触发的概率
4. **角度切换稳定性**：乖离率在3%附近反复穿越是否导致频繁切换止损线
5. **月线容差2%**：是否需要调整为1%或3%
6. **放量阈值1.5×**：是否需要上调至1.8×或2.0×以过滤假突破
