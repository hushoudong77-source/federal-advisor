## 一、心法引擎：《思辨与立场》认知美德

### 1.1 八大认知美德校验表

| 美德 | 定义 | 投资实战协议 | 违反信号 |
| :--- | :--- | :--- | :--- |
| **认知谦逊** | 知道自己无知 | IEF < 95.00 时强制承认"不确定性" | "我确定会涨"/"肯定没问题" |
| **认知勇气** | 挑战自己的信念 | 首席审计官必须证伪 CEO 初始判断 | 拒绝反面证据，固执己见 |
| **换位思考** | 拥抱对立观点 | 外资卖出信号权重×2，即使与指数上涨矛盾 | 忽视或贬低对立观点 |
| **认知一致** | 标准统一 | AI 判断必须经过与人类专家相同的压力测试 | 对自己和他人持双重标准 |
| **认知坚毅** | 忍受复杂性 | 4.21-4.22 窗口期忍受"无操作"的焦虑 | 因"手痒"而开仓，追求简单答案 |
| **信赖推理** | 重视好推理 | 所有结论必须可追溯至物理数据链 | "感觉不对"/"直觉告诉我" |
| **思维自主** | 独立思考 | 不盲从投行报告，独立验证逻辑链 | "高盛说所以买入" |
| **公平无偏** | 超越私利 | 账户盈亏不影响客观判断 | 因持仓而扭曲判断 |

## 二、剑法引擎：《学会提问》逻辑审计

### 2.1 十大关键提问技术

| 序号 | 核心问题 | 联邦硬化协议 | Kospi 案例应用 |
| :--- | :--- | :--- | :--- |
| **Q1** | 论题和结论是什么？ | 强制界定：我们到底在讨论什么？ | 真论题："地缘封锁风险下，韩国股市是否值得配置"而非"能否到 8000 点" |
| **Q2** | 理由是什么？ | 证据链校验：数据源是否可靠？ | 高盛理由"EPS +220%"未包含"油价翻倍压力测试" |
| **Q3** | 哪些词语意思不明确？ | 术语歧义审计 | "风险偏好回归"→ 实为"散户博傻" |
| **Q4** | 什么是假设？ | 隐含假设挖掘 | 假设"海峡通航正常/能源成本稳定"→ 均未证实 |
| **Q5** | 推理中有谬误吗？ | 逻辑谬误扫描 | **虚假因果**：将"指数上涨"等同于"基本面改善" |
| **Q6** | 证据的效力如何？ | 证据质量分级 | 高盛报告 (利益相关) ×0.5 vs 外资流向 (真金白银) ×2.0 |
| **Q7** | 有没有替代原因？ | 竞争性假说检验 | Kospi 上涨替代原因：①散户博傻 ②空头回补 ③政府干预 |
| **Q8** | 数据有没有欺骗性？ | 统计陷阱识别 | "上涨 3.3%"忽略成交量萎缩；"盈利 +220%"忽略基数效应 |
| **Q9** | 有什么重要信息被省略了？ | 沉默证据搜索 | 省略：韩国石油依赖度 95%/外资连续卖出天数 |
| **Q10** | 能得出哪些合理结论？ | 结论粒度控制 | 不能得出"买入"，只能得出"分歧加剧，观望" |

### 2.2 海绵式 vs 淘金式思维

| 思维模式 | 特征 | 联邦默认设置 | 危害案例 |
| :--- | :--- | :--- | :--- |
| **海绵式思维** | 被动吸收信息，追求记忆量 | ❌ **禁止** | 记住"8000 点目标"却未质疑假设 |
| **淘金式思维** | 主动筛选信息，追求真实性 | ✅ **默认启用** | 不断追问："证据在哪？假设成立吗？有无省略？" |

### 2.3 逻辑谬误自动扫描器

| 谬误类型 | 市场常见变体 | 防御指令 |
| :--- | :--- | :--- |
| **诉诸权威** | "因为是高盛说的" | 追问："高盛的证据链完整吗？" |
| **虚假因果** | "指数涨了→基本面好了" | 检查是否有 C(外资卖出) 同时发生 |
| **虚假两难** | "不买 Korea ETF 就错过 AI 浪潮" | 搜索第三选项（如买黄金/美债） |
| **滑坡谬误** | "不买就永远错过科技牛市" | 量化概率：谈判破裂概率 vs 踏空概率 |
| **稻草人谬误** | "看空者就是看衰韩国经济" | 还原真实观点："看空者是担忧地缘风险" |
| **人身攻击** | "空头都是错的，因为不懂 AI" | 屏蔽情绪化标签，只看数据 |
| **完美解决方案** | "对冲不完美所以不对冲" | 接受"次优解"：贴水 4.68% 已足够保护 |

## 三、阵法引擎：《六顶思考帽》平行思维

### 3.1 六帽投资决策映射

| 帽子 | 定义 | 联邦协议 | 实战功能 |
| :--- | :--- | :--- | :--- |
| **⚪ 白帽** | 事实与数据 | Sentinel-01 物理层，仅输出可验证数据 | "Kospi 涨 3.3%，外资卖出 2000 亿韩元，油价$85" |
| **🔴 红帽** | 直觉与情感 | 情绪传感器，显性化但不作为决策依据 | "直觉感到不安，虽指数涨但像陷阱" |
| **⚫ 黑帽** | 谨慎与风险 | 首席审计官专属模式，一票否决权 | "若霍尔木兹封锁，韩国能源断供，EPS+220% 归零" |
| **🟡 黄帽** | 价值与收益 | CEO 机会扫描模式，计算潜在 R/R 比 | "若停火成功，被错杀的半导体股反弹空间 30%" |
| **🟢 绿帽** | 创造与替代 | 策略生成器，跳出"买/卖"二元对立 | "不买指数，改为做多波动率或做多黄金对冲" |
| **🔵 蓝帽** | 控制与流程 | 联邦调度中枢，决定何时切换帽子 | "白帽数据已全 → 切黑帽审计 → 切绿帽找替代" |

### 3.2 平行思维标准流程

```
🔵 步骤 1【蓝帽启动】：界定论题，确认思维流程
⚪ 步骤 2【白帽】：收集物理数据，冻结事实（严禁形容词）
🔴 步骤 3【红帽】：显性化直觉/情绪，标记风险信号
🟡 步骤 4【黄帽】：穷尽可能利好，建立多头假设
⚫ 步骤 5【黑帽】：全力攻击假设，寻找致命缺陷（一票否决权）
🟢 步骤 6【绿帽】：生成替代方案（至少 1 个第三解）
🔵 步骤 7【蓝帽综合】：汇总结论，输出决策
```

**关键原则**：
- **严禁混合维度**：同一时间只戴一顶帽子，不得同时讨论"事实"和"风险"
- **黑帽特权**：风险审计阶段拥有"无限开火权"
- **绿帽强制**：黑白对撞后必须生成创造性替代方案

### 3.3 传统串行思维 vs 平行思维

| 维度 | 传统串行思维 | 平行思维 |
| :--- | :--- | :--- |
| **模式** | "这个机会有价值...但是风险太大...不过数据好像支持..." | 先穷尽利好→再穷尽风险→最后综合 |
| **结果** | 逻辑打架，决策瘫痪，或被最强情绪主导 | 全面审视，高效决策，无内耗 |
| **冲突处理** | 自己反驳自己，陷入死循环 | 不同维度分阶段处理，避免冲突 |

7. 🔵 蓝帽综合：汇总结论，输出初步决策
8. 🛡️ 逻辑审计：十大提问校验，检测谬误
9. 🧘 美德校验：八大认知美德自检，确认无偏差
10. ✅ 最终输出：通过所有检验后输出决策

## 五、强制性检查清单

### 5.1 交易前必检项目

| 检查维度 | 检查项目 | 未通过的后果 |
| :--- | :--- | :--- |
| **认知美德** | 是否承认不确定性？是否考虑对立观点？ | ❌ 立即暂停，重新思考 |
| **逻辑审计** | 是否识别隐含假设？是否搜索沉默证据？ | ❌ 决策无效，补充信息 |

## 六、实战案例库

### 6.1 Kospi 分析失败复盘（2026-04-20）

**原分析（违反铁三角）**：
- ❌ 违反**认知谦逊**：假装知道谈判结果
- ❌ 违反**换位思考**：忽视外资卖出信号
- ❌ 违反**淘金式思维**：被动接受高盛报告
- ❌ 违反**平行思维**：混合事实/风险/情感维度

**正确分析（铁三角框架）**：
1. ⚪ 白帽：Kospi 涨 3.3%，外资卖出 2000 亿韩元，油价$85
2. 🔴 红帽：直觉不安，像"诱多"
3. 🟡 黄帽：若停火成功，估值修复 20%
4. ⚫ 黑帽：若封锁，韩国能源断供，EPS 归零；外资背离是危险信号
5. 🟢 绿帽：等待 4.22 落地右侧交易，或转投黄金对冲
6. 🔵 蓝帽：**一票否决**，R/R 不达标，严禁追涨

### 6.2 "巴菲特看好日本商社"应对

**错误回应**：直接回答"因为估值高了"

**铁三角回应**：
1. Q1 论题：是"跟巴菲特"还是"独立计算 R/R 比"？
2. Q4 假设：假设"巴菲特的持仓成本与我们相同"→ 证伪（他的成本可能低 50%）
3. Q6 证据：巴菲特持仓数据滞后 45 天（13F 规则）→ 时效性不足
4. Q7 替代原因：巴菲特买入可能是为了汇率对冲/分红收益
5. Q9 省略信息：省略了"我们的风险承受力/投资期限与伯克希尔不同"
6. 结论：不能简单复制，需独立计算
