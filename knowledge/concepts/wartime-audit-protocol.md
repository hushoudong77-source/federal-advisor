# 战时审计协议

## 概述
基于GEMINI黄金投资处角色的战时审计模式，总结危机环境下的投资决策框架。

## 一、战时模式触发条件

### 1. 地缘风险触发
- 霍尔木兹海峡封锁或类似重大地缘事件
- 战争爆发或谈判破裂
- 能源生命线实质性阻断

### 2. 市场风险触发
- 恐慌指数VIX > 40
- 主要指数单日跌幅 > 5%
- 流动性危机迹象出现

### 3. 政策风险触发
- 美联储紧急政策调整
- 主要经济体实施资本管制
- 系统性风险预警发布

## 二、战时身份定位

### 首席执行官角色
- **权威性**: 强调决策的绝对性和权威性
- **紧迫性**: 时间锚定到分钟级，强调"决战时刻"
- **责任性**: 明确资产管理的最终责任

### 语言风格特征
- 军事化术语: "战场"、"阵地"、"防线"
- 物理化表达: "重力"、"压强"、"利差"
- 权威性签署: "首席执行官最后签署"

## 三、战时分析框架

### 1. 物理对账审计
**核心公式**: 国际金价 → 人民币公允价 → ETF折价率

**计算步骤**:
1. 获取国际现货金价 (XAU/USD)
2. 计算人民币公允价: `公允价 = XAU / 31.1035 × USD/CNY`
3. 获取国内ETF价格 (如518880)
4. 计算折价率: `折价率 = (公允价 - ETF价) / 公允价 × 100%`

**审计标准**:
- 折价率 > 5%: 绝对锁死，禁止减仓
- 折价率 3%-5%: 谨慎持有，观察变化
- 折价率 < 3%: 考虑减仓，锁定利润

### 2. 地缘风险评估
**风险等级划分**:
- **一级风险**: 实际军事冲突，能源生命线阻断
- **二级风险**: 谈判破裂，制裁升级
- **三级风险**: 外交紧张，市场预期恶化

**应对策略**:
- 一级风险: 黄金绝对锁死，现金待命
- 二级风险: 黄金持仓为主，少量现金机动
- 三级风险: 平衡配置，关注机会成本

### 3. 情绪管理协议
**恐慌识别指标**:
- 媒体恐慌性报道密度
- 社交媒体情绪指数
- 期权市场恐慌溢价

**情绪控制技术**:
1. **物理锚定**: 强调物理利差的保护作用
2. **时间锚定**: 明确危机的时间边界
3. **成本锚定**: 对比持仓成本与市场恐慌

## 四、战时决策机制

### 1. 资产分类处理
**避险资产 (黄金等)**:
- 绝对锁死持仓
- 禁止恐慌性减仓
- 利用物理利差作为缓冲

**现金储备**:
- 一级封锁状态
- 禁止追高买入
- 等待极端机会出现

**风险资产**:
- 暂停新建仓位
- 现有仓位严格止损
- 关注错杀机会

### 2. 决策优先级
**第一优先级**: 物理对账结果
- 折价率 > 5% → 绝对锁死
- 折价率 < 3% → 考虑减仓

**第二优先级**: 地缘风险评估
- 风险升级 → 增加避险仓位
- 风险缓解 → 逐步恢复正常

**第三优先级**: 情绪管理
- 市场恐慌 → 逆向思维
- 市场狂热 → 警惕风险

### 3. 执行纪律
**绝对禁止行为**:
- 恐慌性清仓
- 追高买入
- 无视物理对账结果

**强制要求行为**:
- 每日物理对账
- 情绪状态自检
- 决策记录留存

## 五、战时沟通协议

### 1. 报告结构
**标准格式**:
```
【身份声明】→【物理审计】→【地缘评估】→【执行指令】→【情绪管理】
```

**关键要素**:
- 精确的时间锚定
- 清晰的物理对账数据
- 明确的地缘风险等级
- 具体的执行指令
- 有效的情绪安抚

### 2. 语言工具箱
**军事化术语**:
- 阵地、防线、突破口
- 决战、审判日、最后通牒
- 锁死、待命、出击

**物理化表达**:
- 重力、压强、利差
- 折价、溢价、断层
- 缓冲、保护、防御

**权威性签署**:
- 首席执行官最后签署
- 最终审计结论
- 明确执行指令

## 六、战时退出机制

### 1. 危机缓解信号
- 地缘谈判取得实质性进展
- 能源生命线恢复通畅
- 市场恐慌指数回落至正常水平

### 2. 退出策略
**渐进式退出**:
1. 降低避险资产仓位至正常水平
2. 逐步释放现金储备
3. 恢复正常投资框架

**机会捕捉**:
- 关注危机后的错杀机会
- 布局复苏预期资产
- 优化资产配置结构

### 3. 战后复盘

**系统升级**:

- 提升危机应对能力

## 七、实战案例

### 案例: 2026-04-16 伊斯兰堡谈判
**战时状态**:
- 地缘风险: 一级风险 (海峡封锁)
- 市场状态: 高波动，高恐慌
- 资产状态: 黄金持仓锁死，现金待命

**审计过程**:
1. 物理对账: 折价率5.46% → 绝对锁死
2. 地缘评估: 谈判破裂风险高 → 保持警惕
3. 情绪管理: 强调物理利差保护 → 控制恐慌
4. 执行指令: 黄金锁死，现金待命 → 明确动作

**结果评估**:
- 成功避免恐慌性操作
- 利用物理利差获得保护
- 为后续机会保留现金
