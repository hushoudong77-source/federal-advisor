## 1. 四阶段审计矩阵 (Stage Analysis)

| 阶段 | 名称 | 物理特征 | GEM指令 |
|------|------|---------|---------|
| **Stage 1** | 打底区 | 价格横向波动，MA30走平，成交量萎缩 | WATCH_ONLY，不买入，等待放量突破 |
| **Stage 2** | 上升段 | 价格 > MA30，且MA30向上 | STRONG_BUY/HOLD，回踩均线是加仓点 |
| **Stage 3** | 头部区 | 价格反复穿刺MA30，波动加剧，MA30走平 | REDUCE_POSITION，强制减仓，准备撤离 |
| **Stage 4** | 下降段 | 价格 < MA30，且MA30掉头向下 | FORCE_LIQUIDATE，全自动熔断，严禁抄底 |

## 2. 进场审计协议：突破三合一 (The Breakthrough SOP)

**GEM仅在满足以下三个条件时发出买入信号：**

| 条件 | 描述 | GEM判定 |
|------|------|---------|
| **静态位移** | 价格从Stage 1底部放量向上突破阻力线 | 确认突破有效性 |
| **均线确认** | 突破时MA30已停止下跌，转为平整或向上 | 趋势转折确认 |
| **RS验证** | RS曲线处于上升趋势或由负转正 | 确保标的优于大盘 |

**相对强度计算**:
```
RS = 股价 / 指数
RS上升 → 标的强于大盘
RS下降 → 标的弱于大盘
```

## 3. 退出与放空执行指令 (Exit & Short Protocol)

### 【卖出：多头了结】

| 情景 | GEM动作 |
|------|---------|
| 初始止损 | 设在Stage 2突破点下方的近期支撑位 |
| 动态位移 | 随股价上涨，将止损位提升至MA30处 |
| HARD_SELL触发 | 收盘价跌破MA30且3日内无法收回 |

### 【放空：Stage 4执行】

| 条件 | GEM动作 |
|------|---------|
| 触发条件 | Stage 3顶部 + 跌破MA30 + MA30趋势转下 |
| 绝对禁令 | 禁止因PE高而放空 |
| 执行时机 | 跌破支撑位或反弹回抽均线无力时 |

## 4. GEM风险过滤器 (Filter Protocol)

### 阻力审计

```
IF 目标获利空间与上方阻力位距离 < 2R
THEN 判定为 LOW_REWARD_RATIO，拦截交易
```

### 成交量验证

```
IF 突破时成交量未达前4周均值的2倍
THEN 判定为"疑似假突破"，标记为 WARNING
```

### 板块效应审计

```
IF 该股票所属行业指数未处于Stage 2
THEN 降低该标的仓位权重50%
```
