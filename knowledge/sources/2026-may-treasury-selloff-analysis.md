## 三大驱动共振

1. **中东地缘冲突**：军事行动在伊朗铺开，霍尔木兹海峡畅通性忧虑 → WTI $104.39/Brent $108.30
2. **再通胀数据**：4月CPI 3.8%（2023年5月以来最快），PPI 6.0%（2022年底以来新高），进口价格+4.2%
3. **美国经济韧性**：工业产值+0.7%（预期0.2%），产能利用率76.1%（8月来最高），制造业+0.6%

## 核心冲击链条

```
地缘冲突+能源暴涨 → 高通胀+经济韧性 →
├─ 1. EM资产抛售：EM主权债收益率飙升，EM ETF -4.2%
├─ 2. 非美主权恶化：英国30Y 5.85%（国债/GDP 150%），本世纪最高
└─ 3. 非美货币失锚：日元158-160 → 日本动用~10万亿日元干预
    → 抛售美债筹美元 → 推高美债收益率 → 息差更大 → 恶性循环
```

## 关键结构转变

1. **"股债双杀"常态化**：高利率→贴现率高企→估值承压，配置向防御性行业（能源/原材料/高股息）集中
2. **"现金为王"回归**：短期国债4.0%-5.5%确定性收益，现金从过渡防御升格为核心配置
3. **黄金避险角色倒转**：2023年10月US10Y 5.0%时黄金+6%，2026年5月黄金-4%。实际利率与黄金负相关（-0.82）压倒地缘避险。美元成唯一巨型避险池
4. **传统对冲失效**：「股债对冲」「债金对冲」双双失灵
