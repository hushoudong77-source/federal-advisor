# 巴西降雨与甘蔗压榨 — 2026年5月研究数据汇编

> 研究时间: 2026-05-24 | 数据截至: 2026-05-24 | 来源: UNICA/INMET/NOAA/USDA/CTC

## 一、核心发现摘要

### 1.1 2026/27榨季开局（4月上半月）
- **甘蔗压榨量**: 1,956万吨，同比+19.67%（UNICA 4月15日数据）
- **糖产量**: 64.72万吨，同比**-11.94%**（制糖比仅32.93%，去年同期~50%）
- **乙醇产量**: 12.3亿升，同比+33.32%
- **ATR**: 103.36 kg/t，同比-0.10%（基本持平）
- **因降雨停榨天数**: 仅1天——**4月上半月降雨对压榨影响极小**

### 1.2 INMET 5-7月预测
- **圣保罗州（甘蔗核心产区）**: 5-7月降雨**低于历史均值**，偏差可达-50mm
- **巴拉那州（南部边缘产区）**: 同样降雨偏少
- **温度**: 圣保罗+1°C以上偏高
- **土壤湿度**: 5月仍维持>70%，但6月起快速下降至<40%

### 1.3 ENSO状态
- **当前（2026年5月）**: ENSO中性（Niño 3.4 SST +0.5°C）
- **5-7月**: El Niño概率**82-88%**
- **6-8月**: El Niño概率**92%**
- **9月-2027年2月**: El Niño概率**96-98%**
- **2027年Q1**: 仍维持El Niño概率**96-98%**
- **衰退时间**: 最早2027年4-6月（DJF 96%→之后才开始下降）

### 1.4 USDA/FAS 巴西糖年报（2026年4月20日发布）
- 2026/27榨季甘蔗产量: **6.75亿吨**（全国）
- 中南部甘蔗预测: 约6.35亿吨
- UNICA/业界预估: **3,900万吨糖**（较2025/26的4,043万吨减~3.6%）
- Datagro预测: 中南部压榨6.422亿吨，产糖4,098万吨
- Conab预测: 全国甘蔗7.091亿吨（+5.3%），乙醇创纪录408.6亿升

### 1.5 厄尔尼诺对巴西降雨的季节性影响模式
| 季节 | 巴西南部（SP/PR/MS） | 巴西中北部 |
|:---|:---|:---|
| **6-8月（压榨高峰）** | 显著偏多（+30-50%） | 正常或略少 |
| **9-11月（压榨尾声）** | 偏多（+15-30%） | 偏少 |
| **12-2月（生长期）** | 正常或略多 | 偏少 |
| **3-5月** | 正常 | 正常 |

### 1.6 当前矛盾点
1. **INMET预测偏干 vs 厄尔尼诺气候模式偏湿**: INMET 5-7月预报圣保罗降雨偏少，但厄尔尼诺通常在6-8月给巴西南部带来偏多降雨。这意味着**6月可能成为转折点**——5月偏干，但6-8月厄尔尼诺充分建立后降雨可能转为偏多
2. **4月上半月仅1天降雨停榨**: 当前压榨进度并未受降雨阻碍，与"巴西降雨持续是风险"的说法相矛盾
3. **甘蔗压榨量同比+19.67%**: 表明当前田间条件良好，甘蔗供应充裕

## 三、对CANE的影响传导链

```
厄尔尼诺建立（5-7月，概率88%）
├── 6-8月 → 巴西南部降雨偏多（厄尔尼诺气候模式）
│   ├── 阻碍压榨进度 → 短期利多糖价
│   ├── 降低ATR（甘蔗糖分） → 糖产量下降
│   └── 制糖比可能维持低位（乙醇竞争力偏强）
│
├── 9-11月 → 降雨仍偏多（压榨尾声）
│   └── 糖厂可能提前收榨 → 加剧供给收紧
│
├── 10-12月 → 印度/泰国干旱减产（厄尔尼诺对北半球）
│   └── 叠加巴西减产 → 全球供给收紧确认
│
└── 2027Q1 → 厄尔尼诺衰退
    └── 巴西2027/28丰产预期开始定价 → 远期顶部
```

## 四、当前评估（2026-05-24）

**短期（1-3个月）**: 5月偏干对压榨有利，压榨进度同比+19.67%是短期利空。但厄尔尼诺的雨季效应可能在6-8月显现，届时压榨延迟+ATR下降将形成利多催化剂。

**中期（4-6个月）**: 厄尔尼诺对印度/泰国的干旱影响 + 巴西制糖比低位 = 全球供给收紧，核心基本面利多。

**远期（7-12个月）**: 厄尔尼诺衰退后巴西2027/28丰产预期，约2027年1-2月开始定价。

**核心风险**: 厄尔尼诺若未如期在6-8月建立（概率仍有8-18%），则巴西压榨顺畅+印度泰国未受干旱=糖价承压下行。
