**核心逻辑**：6年完整周期底部 + 厄尔尼诺减产共振 + LNG危机能源溢价（新增双重驱动）。

```
旧框架（单一天气驱动）：
厄尔尼诺→巴西降雨→压榨延迟→产糖量↓→糖价↑

新框架（天气+能源双驱动）—— V3.0：
┌─────────────────────────────────────────────┐
│ 链条A（天气）：厄尔尼诺→巴西降雨↑→压榨↑→产糖↓ │
│ 链条B（能源）：霍尔木兹→LNG危机→原油↑→乙醇    │
│     竞争力↑→制糖比维持低位→产糖↓              │
│                                              │
│ → 双重供给收缩 + 时间窗口高度重叠              │
│ → 2026年白糖叙事从"单一天气"升级为              │

└─────────────────────────────────────────────┘
```

### 🆕 V3.0关键结构变量：巴西制糖比32.93%

> 2026/27榨季开局制糖比仅**32.93%**（去年同期~50%）。这是有数据以来的极低水平。

**含义**：
- 糖厂已主动选择大量产乙醇而非产糖
- 进一步压缩空间约2-3个百分点（不可能低于30%）
- **但低起点维持低位的利多效应同样很强**
- LNG危机→原油高位→乙醇竞争力↑→糖厂维持甚至进一步压低制糖比

**V2.0未覆盖此变量，这是对撞审计中最重要的补充修正。**

### 周期底部迹象

过去三个完整周期：2008见底→2011顶→2014底 | 2014底→2017顶→2020底 | 2020底→2023顶→2026底（当前）

### 历史三次厄尔尼诺区间涨幅（ICE#11期货实际值）

| 事件 | 文章口径 | **ICE#11实际涨幅** | 核心驱动 |
|:---|:---:|:---:|:---|
| 2009-2011 | ~78% | **~230%**（10→33.50美分） | 巴西潮湿+印度减产24%+泰国降雨减少+广西干旱 |
| 2014-2016 | ~55% | **~133%**（10.13→23.65美分） | 超强厄尔尼诺，巴西降雨影响收榨出糖率+印度减产9.18% |
| 2023-2024 | ~39% | **~56%**（18→28.14美分） | 巴西增产对冲部分减产 → 反例警示 |

> **口径差异说明**：V2.0引用来源文章口径（78%/55%/39%）可能基于白糖现货价格指数或纽约白糖价格，联邦对撞审计拉取ICE#11原糖期货实际涨幅更高（230%/133%/56%）。方向完全一致，幅度被低估。

### 2026年跟踪要点
- 巴西压榨期降雨 → 影响收榨和出糖率（6-8月窗口）
- ⭐ **LNG危机→原油高位→乙醇竞争力→制糖比维持低位**（V3.0新增）
- 印度/泰国/广西干旱 → 单产下滑
- **反例警示**：2023-2024年巴西增产可抵消其他产区减产 → 需看主产区之间的产量对冲关系
- **跟踪顺序**：天气异常→产量预期下修→库存/贸易流变化→价格滞后上行

### CANE对账
- ICE#11当前约$13.5-14.0区间，6年周期底部区域 → **但CANE现价$9.45已逼近2年低位**，与ICE#11现货价差隐含市场已定价大量负面预期

## 四、棕榈油（马来西亚/印尼）— 滞后4Q

**主产区**：马来西亚+印尼=全球产量~80%
**价格滞后**：高点通常滞后ONI达峰约4个季度

### 区间涨幅
| 事件 | 区间最大涨幅 | 弹性因素 |
|:---|:---:|:---|
| 2009-2010 | ~71% | 降雨锐减，印尼产量2450→2196万吨，马来2050→1699万吨 |
| 2014-2016 | ~48% | 超强厄尔尼诺但豆油供应宽松+需求下滑，弹性减弱 |
| 2023-2024 | ~45% | 马来产量不降反增，降雨未明显偏低，天气冲击未兑现 |

### 2026年跟踪要点
- 东南亚干旱烈度 → 产量是否实质受损
- 豆类油脂供应格局（替代品效应）
- 需求端（中国/印度/欧盟进口量变化）
- 滞后窗口：ONI达峰后约4个季度 → 2027年Q1-Q2是高点窗口
- **当前ONI刚起步，未到进场窗口** ⚠️

## 五、天然橡胶 — 滞后5Q，弹性最强

**主产区**：亚太（ANRPC成员国）
**价格滞后**：高点滞后ONI达峰4-5个季度

### 区间涨幅
| 事件 | 区间最大涨幅 | 核心驱动 |
|:---|:---:|:---|
| 1997-1998 | ~33% | |
| 2002-2003 | ~118% | 干旱胶汁干涸+全球经济增长+远期订单超卖 |
| 2009-2010 | ~167% | ANRPC减产3.5% |
| 2014-2016 | ~101% | ANRPC减产2.5% |
| 2023-2024 | ~54% | 厄尔尼诺+胶树老龄化+割胶工短缺+需求端轮胎稳定 |

### 2026年跟踪要点
- 东南亚干旱→胶树生长受阻→胶汁干涸
- 胶树老龄化+割胶工短缺（结构性供给约束，非周期性）
- 下游轮胎需求（半钢胎出口）
- 滞后窗口最长，当前处于ONI爬坡早期 → **2027年H2才是高点窗口** ⚠️

## 六、棉花 — 需求库存约束，最复杂

**主产区**：中国/印度/巴基斯坦/澳大利亚/美国/巴西

### 区间涨幅
| 事件 | 区间最大涨幅 | 核心驱动 |
|:---|:---:|:---|
| 2009-2010 | ~149% | 供需共振：干旱+印度出口禁令+中国纺织回暖+消费超产量15% |
| 2014-2016 | ~54% | 先跌后涨：2014/15库存创1960年新高2353万吨→减产去库存+厄尔尼诺冲击新疆/印度/澳棉 |
| 2023-2024 | ~30.7% | 需求偏弱+储备棉投放+进口配额+巴西增产对冲美棉减产 → 先于ONI见顶 |

### 2026年跟踪要点
- **不只看天气** — 需求和库存是否配合才是关键
- 全球棉花期末库存方向（累库 vs 去库）
- 中国纺服出口景气度
- 巴西丰产 vs 美棉/印度减产的对冲关系
- 反例警示：2023-2024年先于ONI见顶

## 七、煤炭/电力 — 中性偏多（V3.0评级下调）

**逻辑**：厄尔尼诺→全球气温↑→中国夏季北旱南涝→平均气温↑→用电量↑→火电出力↑→动力煤需求↑

### V3.0修正：「最确定赛道」→「中性偏多」

| 支撑（利多） | 压制（利空） |
|:---|:---|
| 高温→用电↑→火电出力↑ | 中国保供政策（长协煤占比高，有政府"心理顶"¥900-950/吨） |
| 厄尔尼诺→北旱南涝→水电偏弱 | 进口煤（印尼/澳洲）价格优势 |
| 历史验证：三次厄尔尼诺火电同比均增 | 电厂库存充足（发改委要求20天以上） |

**结论**：煤炭会涨，弹性有限。A股相关标的（515220）可作为夏季博弈工具，但不适合重仓。

| 资产 | 联邦状态 | 资金约束 |
|:---|:---|:---|

**正确顺序**：先集中白糖，等厄尔尼诺确认+价格启动后，再考虑棕榈油/橡胶的滞后窗口。太早进场=时间成本（展期损耗+机会成本）。

### DXY尾部风险（V3.0新增）

| 情景 | DXY方向 | 对商品影响 | 触发条件 |
|:---|:---:|:---:|:---|
| 基准情景 | 99下方偏弱 🟢 | 商品整体偏友好 | 无新地缘冲突 |
| 尾部风险 | 反抽至101+ 🔴 | 商品溢价压缩 | 霍尔木兹局势失控→全球避险 |
| 观察位 | MA150~100.50 | 突破此位则确认反抽 | 需周度监控 |

### 跟踪顺序（物理传导链）

```
天气异常（NOAA/国家气候中心月度更新）
  → 主产区产量预期下修（USDA/UNICA/ANRPC月度报告）
    → 库存/贸易流变化（各品种库存数据）
      → ⚡ LNG/原油价格方向（V3.0新增—能源溢价链监控）
        → 价格滞后上行（ONI达峰后不同滞后窗口兑现）
```

### 风险清单

1. **气象本身有不确定性** — 预测≠兑现，2023-2024年棕榈油就是反例
2. **美元流动性变化** — DXY走强压制所有商品价格
3. **市场结构变化** — 历史样本有限，13次事件中只有9次中等及以上
4. **单产区对冲** — 巴西增产可抵消亚太减产（2023-2024白糖已验证）
5. **需求端下行** — 全球经济放缓压制商品需求弹性
6. **LNG危机缓解**（V3.0新增）— 若霍尔木兹局势解除→原油回落→乙醇溢价消失→糖价失去能源逻辑支撑
