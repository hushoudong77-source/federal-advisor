## 第六章核心：最优执行（Almgren-Chriss框架）

### 框架本质

Almgren和Chriss(2001)回答了这个问题：**要在T时间内买入/卖出N股，怎么拆单让"冲击成本+市场风险"最小？**

### 核心公式

连续时间下，最优执行策略的Euler-Lagrange方程：

```
η · d²Yₜ/dt² - λσ² · Yₜ = 0
```

其中：
- Yₜ = 时刻t剩余待交易股数
- η = 暂时性价格影响系数（滑点/流动性参数）
- σ = 波动率
- λ = 风险厌恶系数

**解析解**：

```
Yₜ* = Ñ · sinh(A(T-t)) / sinh(AT)，其中 A = √(λσ²/η)
```

### 三种价格影响

| 类型 | 含义 | 模型处理 |
|:---|:---|:---|
| 永久性影响 | 每笔交易改变标的"公允价值" | g(Nₖ/δ)，影响未来所有价格 |
| 暂时性影响 | 交易发生时瞬间的滑点，立即恢复 | h(Nₖ/δ)，只影响当前交易价格 |
| 短暂性影响（LOB模型） | 价格影响随时间指数衰减 | Alfonsi模型，ρ为衰减速率 |

### 三种策略的直观对比

**1. TWAP（时间加权平均价格）** — Bertsimas和Lo(1998)
- 每期等量交易：N₁=N₂=...=N_T = Ñ/T
- 最优条件：无风险厌恶(λ=0)，线性价格影响
- 适用：流动性极好、波动率极低

**2. Almgren-Chriss（波动率调整）** — 当前标准
- 早期交易更多（波动率风险随时间累积，越快完成越好）
- Yₜ* = Ñ·sinh(A(T-t))/sinh(AT) — 双曲正弦递减，**前期快后期慢**
- λ越大/σ越大/η越小 → 交易速度越快（更怕波动而非冲击）
- λ越小/σ越小/η越大 → 越接近TWAP均匀交易

**3. LOB形状模型** — Alfonsi等(2010)
- 考虑LOB具体形状f(x)dx（不同价位上的挂单量）
- 弹性回复速率ρ：LOB被吃掉后的恢复速度
- 块状LOB（常数形状）→ 解析解；一般形状→数值解

### 对CANE建仓的启示

#### 执行参数估算

CANE日均成交量约**50-100万股**（ETP流动性较低），$25,000约2,525股，占比仅**0.25%-0.5%**日均量。

| 参数 | 估值 | 说明 |
|:---|:---|:---|
| η（暂时性影响） | 极低 | 仅占日均量的0.25-0.5%，冲击成本可忽略 |
| σ（波动率） | ~20%年化 | 商品ETP的波动率水平 |
| λ（风险厌恶） | 由用户设定 | 建议λ取中等值，CANE非核心仓位 |

#### 关键结论

**对$25,000（~2,525股）的CANE建仓，Almgren-Chriss框架的实际判断是：**

1. **冲击成本接近零** — 2,525股占日均量不到0.5%，市价单直接吃掉的冲击成本可以忽略（远低于1bp）
2. **TWAP≈Almgren-Chriss** — 因为冲击成本η极小，A≈0，Yₜ*≈Ñ(1-t/T)，几乎等于均匀交易
3. **最优执行策略**：**一次性市价买入就够了**，不需要拆单
4. **如果非要拆单**（心理上舒服）：分2-3次，每次间隔5-10分钟即可

#### 真正需要拆单的场景

Almgren-Chriss框架的实用价值体现在**大单**场景：
- 持仓占比>5%日均量 → 需要拆单
- >10%日均量 → 需要VWAP/TWAP算法
- >20%日均量 → 需要多日执行

CANE $25,000属于**小单**范畴，学术框架的结论是：**别折腾，一把梭**。
