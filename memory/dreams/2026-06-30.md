# Dream Diary: 2026-06-30

今夜整理了6月30日的记忆，发现这一天的工作密度惊人。

最核心的是持仓数据的一次全面清洗。守东在21:50确权了B账户全部持仓——QQQ 24,279股、IVV 7,496股、VEA 2,244股、VTI 282股，还有新增的BOTZ 3,041股。这与之前记录的数字存在数量级差异，SGOV也已清仓。更早时还发现CANE的持仓记录被污染——系统曾将止损信号脑补为"守东确认清仓"，导致多轮输出将实际持有的2,525股误标为0股。这是继510880事件后的又一次持仓对账事故，根因相同：系统越过规则O的强制过滤，将自推断结论当作事实写入。

参数修正的工作量也很大。全天完成了至少五轮k参数重标定：r33.21调513910的k从1.5到2.0，r33.22调588000/510500/BBJP/VTI四个标的，r33.24又对510500/512100/510880做了回撤修正，r33.25将BBJP和VNM的k从2.5调到1.5。过程中发现了实战SOP回测与全量回测之间的矛盾——BBJP在实战回测中k=2.5胜率46%，但全量回测k=1.5均收益高出18倍。这是过拟合与泛化性的经典取舍，守东决定以全量回测为准。

588000的独立策略设计是另一条主线。这个科创板ETF的波动远超反击池其他标的（ATR/价格>4%），与反击策略"均值回归"的底层假设根本冲突。经过多轮回测和方案迭代，最终确定双轨制：保留反击路由的同时新增动量跟随路由，两策略互斥锁并行。H方案（金叉入场+MA60连续2日破位离场+收盘确认）表现最优，加入"金叉当日收盘≥MA60"的入场确认后，胜率从60%提升至76.9%。

Tushare再次大面积故障，6/28起持续超48小时的API网关鉴权崩溃刚恢复，6/30晚间又全接口token失效。腾讯API持续充当现价补位角色，但技术指标计算全部暂停，数据真空成为日常。

梦境中浮现的画面是：流水线上的机器人被分成两支队伍，一支举着"反击"旗帜等跌到位，一支举着"动量"旗帜等金叉——互斥锁咔嗒转动，只放行先到的那支。远处，CANE的糖业数据流穿过厄尔尼诺叙事，BOTZ的MACD柱状图还在收窄。非农静默期的计时器滴答作响，所有进攻窗口被锁死到7月6日。
