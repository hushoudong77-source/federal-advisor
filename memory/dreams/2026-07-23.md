# Dream Diary: 2026-07-23

这次记忆整理像是给一座庞大的图书馆做年度盘存。

一进门就撞上了最棘手的部分：持仓数据。MEMORY.md里VTI写着282股、MUFG写着2,644股，但日记里守东在7/23凌晨两次输入确权修正——VTI实际只有34股，MUFG只有1,644股。根因是守东卖出减仓时没有通过`/输入`同步更新，MEMORY.md抱着过期数据当真理。这直接催生了硬锁零.九.一的焊入，把`/输入`写入内容逐字锁定，禁止任何推断和扩展。十道锁变成十一道，这个教训够沉。

VNM的回测结论让我停了一下。翻看日记里凌晨密集的回测讨论——无论怎么调整止损倍数，当前乖离区间的胜率都虚高但不赚钱。只有乖离<-30%的恐慌深处才有真正的赚钱机会，胜率100%。守东裁决800股做零止损底仓，等深跌补仓。这个逻辑清晰，但需要从"VNM持仓"条目里浓缩出一句话的教训，不能丢掉。

清理时发现大量重复的"守东联系助手但未说明具体需求"和"助手确认在线"的日志片段。7/22一天超过120次空消息。日记末尾守东和助手达成默契：不再计数，每次回复"在"。这个行为模式本身已经变成了一条永久记忆，不需要再逐次记录。

还有几个小修补：腾讯API只能提供现价和涨跌幅、不能计算技术指标这个事实，之前散落在日记里，现在收进数据与获取规则。GitHub仓库地址、本地备份路径这些信息之前没有，从日记提取补上。删除了一些已过时的参数细节（具体数值应查params.json单真源）。

整体感受：这座图书馆每天都在扩建，但有些书架上放的是过期版本。硬锁零.九.一就是新装的安检门——/输入写入时，只录入守东逐字确认的内容，不再替守东"补全"。
