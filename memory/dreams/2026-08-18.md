# Dream Diary: 2026-08-18

深夜整理记忆，像在战场废墟里清点弹药。今天的主线是一场纠错——588000的幽灵持仓终于现形。positions.json里躺着5,900股，成本、浮盈、加仓建议全都长在这片幻影上，直到守东一句「588000没有持仓」把它连根拔起。移入never_held，同步修正MEMORY，才明白之前所有围绕它的浮盈判断都是空中楼阁。这是记忆污染自愈的又一次实战，也再次印证硬锁零.十一的价值。

同一片战场还藏着CANE峰值的暗雷。$11.11被确认为系统脑补错误值，真实8/13盘中最高是$10.86，而8/17收盘$10.93刷新峰值，最终滚动峰值定为$10.93、触发线下修到$10.3835，peak_basis标记为close。一次参数修正，牵动整个厄尔尼诺左侧分批框架的触发线。

更深的裂痕在均线方向判定。守东一句「已经发现多次MA60判定斜率不准了」引爆r33.96修复——固定0.3%死区对高波动标的太敏感，EWY的走平被误判为down。改造成波动率自适应死区ε=max(0.3%地板, ATR14)，三态判定up/flat/down，全池25标验证无回归。EWY的MA60从down归正flat，而MA40真下行−8%依然down，真相终于对齐。

C1锚线的回测像一场小型地震。真跑4标×2000条数据，取消C1累计收益从+228%跳到+360%，止损8%下从+258%跳到+516%，而被拦掉的83笔信号大部分能盈利且无风险对冲价值。MA60把「美股进攻」锁成了「深跌抄底」模式，白白损失约1/3收益。守东拍板选1：MA60→MA20，非彻底取消。三处代码+法典同步，r33.96闭环。

EWY的镜像对照最令人不安——8/17缩量急拉+5.03%、8/18缩量崩塌−7.13%，两次量比都是0.28。涨时无人追、跌时无人接，这是流动性真空的典型症状。阴跌磨底比急跌见底更危险，因为没有恐慌盘出清就没有反转燃料。裁决只有一条：持有观察，反弹是离场窗口而非加仓机会。

整场整理像在给记忆做外科手术：摘除幽灵持仓、修正峰值锚点、升级均线死区、松绑C1锚线。每一条修正都贴着真实命令和返回，没有一处凭记忆硬编。感受是清醒而沉重的——系统在进化，但每一次进化都源于一次失误的暴露。
