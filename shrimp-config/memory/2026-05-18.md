## 技术备忘

### Yahoo Finance 免费API
```
https://query1.finance.yahoo.com/v8/finance/chart/{CODE}?interval=1m&range=1d
```
- 返回 meta.regularMarketPrice（最新价）+ meta.previousClose（前收）
- 需 User-Agent header（否则 429）
- Python 3.14 SSL 需 `ssl._create_unverified_context()`
- 每次请求间隔 0.3s 避免限频

### 妙想 mx-data
- API: `https://mkapi2.dfcfs.com/finskillshub/api/claw/query`
- 认证: Header `apikey: MX_APIKEY`
- 09:25 集合竞价时段即可拉数据
- 美股ETF（QQQ/IVV/VTI等）不支持，A股支持良好
- 有频率限制（status 112）
