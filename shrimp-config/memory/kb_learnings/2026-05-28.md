### 课程框架（十个模块）

#### 模块一：销售场景认知
- 产品公司定位：帮省公司"打粮食"，不是来抢生意
- 省公司购买逻辑：产品好不好卖、支撑到不到位、结算划不划算
- 省公司三大偏见：强推、一线推不动、结算不划算
- 省公司决策流程：一线/产品主管→部门经理→分管副总→执行层
- 分角色沟通要点：副总看KPI价值与风险，部门经理看兼容性，产品主管看绩效，客户经理看售卖难度

#### 模块二：客情五级模型
1. **认识**（让省公司知道你和你的产品）→ 切入方式：弹药思维
2. **熟悉**（让省公司觉得你是自己人）→ 2-3周拜访一次，每带新信息增量
3. **认可**（用试点建立信任）→ 试点三标准：有意愿+有人手+有场景
4. **信任**（从单产品到多产品）→ 产品落地→标杆→故事→会议→文件
5. **合作**（省公司把你当自己人）→ 持续信息增量+保障不出问题+帮省公司"长脸"

#### 模块三：新人进省·30天开局法
- **第一周**：信息摸底（组织架构/存量产品/关键人态度）
- **第二周**：破冰（先见支持者→中立者→抵触者）
- **第三四周**：信任奠基（解决一个实际问题+3页价值报告）

#### 模块四：撬动内部支撑资源
- 建内部资源通讯录（产品经理/技术支撑/售前方案/售后服务）
- 产品主管的KPI是最好的切入点
- 让一线客户经理"爽"：帮签单拿提成

#### 模块五：外部生态·ISV合作
- ISV选择标准：本地化、有政企经验、响应快
- 省公司不养开发团队，ISV是解决方案

#### 模块六：帮省公司算三本账
- **收入账**：产品直接带来的政企收入增量
- **效率账**：帮省公司节省的成本（运维、培训、认证）
- **战略账**：政企服务、政务关系、合规，难量化却最关键

#### 模块七：产品引入流程
- 六步走：需求→评估→试点→采购→合同→上线
- 常见卡点及应对

#### 模块八：七大典型拒绝场景
1. "我们不缺这个" → 强调"更好"而非"缺少"
2. "一线推不动" → 驻场兜底承诺
3. "结算不划算" → 算三本账
4. "等明年再说" → 制造紧迫感+小试点退一步
5. "领导没表态" → 帮准备材料，让中层5分钟汇报
6. "集团强推的不要" → 强调他省实践+内部争取资源
7. "我们有自己的产品在用" → 非替代而是补充

#### 模块九：内部谈判与持续管理
- 谈判三要素：试点数据、他省对标、总部政策
- 分角色沟通：高层谈战略、中层谈KPI、一线谈提成
- 签约后前3个月是"危险期"

#### 模块十：六大核心产品·一句话卖点
1. **公众号平台**：政企客户经营轻量化入口
2. **移动办公**：运营商级安全协作，信创合规
3. **量子安全**：量子加密通话，高层对高层路线
4. **5G消息**：短信升级为智能服务入口
5. **移动认证**：手机号一键免密登录
6. **大数据**：9亿+用户行为数据洞察

#### 模块十一：场景翻转演练
- 演练一：首次拜访政企部副总（30秒自我介绍）
- 演练二：3分钟产品推荐
- 演练三："这个产品我们不需要"应对

### 核心方法论关键词
- 弹药思维（不是推销，是送弹药）
- 客情积分（产品落地越多，信任越高）
- 他省对标（最有说服力的武器）
- 驻场兜底（解决"一线推不动"的核心手段）
- 三本账算账法（收入+效率+战略）
- 信息增量法则（每次拜访带新东西）
