## 2026-05-26 Token Unicode 破坏 + CORS 全链路复盘

### 问题链
1. **Token 被破坏**：`read` 工具/终端渲染把 `...`（三个ASCII点）显示成 `…`（Unicode U+2026），写回配置文件时这个非法字符被写死了
2. **HTTP Header 不能含非 ASCII**：Python `urllib.request`、Node.js `http.request` 都拒绝在 header 里发非 latin-1 字符，导致认证全挂
3. **`auth.token` 需硬重启**：`reloadKind: "restart"`，SIGUSR1 不生效
4. **CORS 跨域**：linkai-chat 页面（8899）发 POST 到网关（18789），端口不同算跨域，浏览器 OPTIONS 预检被网关拒绝

### 修复方案
- 代理服务器 `server.py` 从配置文件直接读 token，后端转发时自动加 `Bearer` 前辍，前端不需要填 token
- 所有 API 路由通过同端口代理（8899），消除 CORS
- Token 必须纯 ASCII，不用 Unicode 字符

### 规则更新
- ⚠️ 写配置文件时，注意不要通过 `read` → 复制 → `write`，中间字符编码可能被破坏
- ⚠️ 配置文件中有 `…` 等 Unicode 字符的 token，一定要检查实际字节
- ⚠️ `gateway.auth.token` 改完后要硬重启（kill -9 + launchd 自动重启）

## 2026-06-01 VLOG 能力边界澄清

守东问虾米能否自动剪辑 VLOG（拼接多段素材+口播稿）。
**答案：不能做时间线拼接。** 虾米只做单视频的口播处理（去口误/静音）和字幕生成。多片段拼接、转场、多轨编排需要在剪映里手动完成。
**分工模式：** 虾米 = 预处理（去口误+字幕+配音+高清导出），剪映 = 组装（拼接B-roll+配乐+转场+特效）。
