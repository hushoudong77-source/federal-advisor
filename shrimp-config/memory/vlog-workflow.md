# VLOG 制作工作流（全链路）

## 已安装技能一览

| 名称 | 用途 | 触发词 |
|------|------|--------|
| `videocut:剪口播` | 转录+去口误+静音剪辑 | 剪口播、处理视频 |
| `videocut:导入字幕` | 字幕生成+剪映草稿（带花字） | 导入字幕、生成剪映草稿 |
| `videocut:配音` | 文稿→配音音频 | 配音、语音合成 |
| `videocut:高清化` | 2-pass 高清导出 | 高清化、导出高清 |

## 完整 VLOG 流程

```
┌─────────────────────────────────────────────┐
│ 1️⃣  录好视频 (.mp4)                         │
│     口播/实拍/混合                           │
└──────────────────────┬──────────────────────┘
                       ↓
┌─────────────────────────────────────────────┐
│ 2️⃣ 🦐 剪口播                                 │
│     → 提取音频 → 火山引擎转录                  │
│     → AI 识别口误/重复/卡顿                    │
│     → 网页审核确认 → 帧级精确剪辑                │
│     输出: *_cut.mp4                           │
└──────────────────────┬──────────────────────┘
                       ↓
┌─────────────────────────────────────────────┐
│ 3️⃣ 🦐 导入字幕                                │
│     → 基于剪辑后视频转录                        │
│     → AI 校对（对照原稿/术语字典）               │
│     → 生成剪映草稿（花字+入场动画）               │
│     输出: 剪映草稿 + video.srt                 │
└──────────────────────┬──────────────────────┘
                       ↓
┌─────────────────────────────────────────────┐
│ 4️⃣ 🦐 配音（可选）                             │
│     → 从字幕 SRT 逐句配                        │
│     → macOS TTS（Tingting 中文女声）           │
│     → 输出全片配音 + 逐句配音                   │
│     输出: 配音_全片.mp3                        │
└──────────────────────┬──────────────────────┘
                       ↓
┌─────────────────────────────────────────────┐
│ 5️⃣  你 → 剪映专业版                            │
│     → 打开字幕草稿                             │
│     → 配 BGM（剪映内置曲库超强）                │
│     → 转场/特效/调色/关键帧                     │
│     → 检查字幕对齐 + 微调                      │
│     → 配音音轨拖入时间线                        │
└──────────────────────┬──────────────────────┘
                       ↓
┌─────────────────────────────────────────────┐
│ 6️⃣ 🦐 高清化（可选）                           │
│     → 2-pass 编码 + 锐化                      │
│     → 码率 1.2x 原片                          │
│     输出: *_hd.mp4                            │
└─────────────────────────────────────────────┘
```

## 快速命令速查

```bash
# 剪口播（视频 → 去口误剪辑）
→ 用户说: "帮我处理这个视频"

# 导入字幕（剪辑后视频 → 字幕草稿）
→ 用户说: "导入字幕"

# 配音（字幕 → 配音音频）
bash skills/videocut-配音/scripts/srt_voiceover.sh output/*/字幕/3_输出/video.srt Tingting
# 或快速单句配音
bash skills/videocut-配音/scripts/tts.sh "你的台词文本" 输出.mp3

# 高清化
bash skills/videocut-高清化/scripts/hd_export.sh input.mp4 output_hd.mp4
```

## 关于配乐

虾米现在没有专门的 AI 音乐生成能力。推荐方案：

| 方案 | 说明 | 成本 |
|------|------|------|
| **剪映内置曲库** | 海量版权音乐，直接拖进时间线 | 免费 |
| **网易云/QQ音乐** | 下载无版权音乐或原创配乐 | 按需 |
| **Uppbeat/Epidemic Sound** | 国外无版权 VLOG 音乐网站 | 免费/订阅 |

需要的话可以让我帮你搜 VLOG 背景音乐推荐。
