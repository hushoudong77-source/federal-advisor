## 一、集团商企中小课程课件（12个文件）

### 概括

本套课件聚焦中国联通商企客户经理的能力建设，涵盖市场营销组织架构、场景化营销、实战销售训练营、百天效能攀登等项目。核心围绕**四大聚类市场**（商务楼宇、专业市场、商业综合体、厂园区）展开，提出"行业应用带动中小企业销售"的创新思路，强调**顾问营销+价值营销**的销售方法转型。从心态塑造到实战演练形成完整闭环。

### 核心知识点

1. **四大聚类市场的场景化营销**：按商务楼宇、专业市场、商业综合体、厂园区四类，逐一拆解物业管理部门和企业业主两个维度的需求清单与产品匹配话术，实现精准场景切入。

2. **"1+1+N"培训模式**：2天课堂授课 + 1天实战辅导（或2+2、2+3），配合PBL教学法（以问题为导向）、情景模拟、行动学习等教学手段，强调实战转化而非纯理论。

3. **中小商企销售8大技巧体系**：需求挖掘激发、陌生约见、产品价值呈现、异议处理、双赢谈判、快速成交、关系锁定、现场促销，构成完整销售技能树。

4. **百天效能攀登的微信管理机制**：清晨唤醒→晨会→日常拜访晒照→夕会复盘→成交晒单→业绩通报，配合晨会标准流程（问好→切刀动作→口号叠加），形成标准化日管理节奏。

5. **销售跟进行动辅导（集中辅导+现场辅导+实战验证）**：从初选目标→匹配团队→摸排市场→需求分析→关系分析→方案制定→签约实施→总结表彰，全流程使用工具表格（聚类市场客户档案卡、移情图、客户概况展板等）。

## 二、杭州联通专精特新企业项目（15个文件）

### 概括

本项目围绕杭州市"专精特新"企业市场，结合政府政策红利（最高100万元小巨人奖励、"专精特新贷"40亿元等），形成**"政策驱动+产品方案+实战技巧"三位一体**的商企铁军攻坚战体系。核心思路是将"专精特新"梯度培育路径与企业数字化转型需求深度绑定，以"三查两画"作为客户需求诊断工具，以云犀卡、云联至简、云智眼等标准产品为销售抓手，帮助客户经理从"卖产品"转型为"做企业数字化顾问"。

### 核心知识点

1. **专精特新企业梯度培育路径与政策红利**：科技型/创新型中小企业→专精特新中小企业→小巨人企业三级培育体系；"三查两画"（查账单、查服务报告、查客户背景；画组织架构、画拓扑架构）+ BEBT模型（Bill账单、Business业务、Environment环境、Topology拓扑）做客户诊断。

2. **"一企一表"需求解读法**：从机房、信息化系统、IT运维、存储灾备、大数据、物联网、5G、信息安全等19个维度建立需求清单，每个维度对应联通的标准产品与方案，形成"现状→痛点→方案"的闭环对接。

3. **云犀卡+云联至简双产品核心**：云犀卡是工作手机方案（云录音、云转写、云质检、云定位、云名片），切入销售管理场景；云联至简是自研协同办公产品（联通版钉钉），切入数字化管理场景。两大产品覆盖人员管理和流程效率两大核心需求。

4. **专属活动日销售六步穿越法**：专属活动日组织要点→"人货场"关键匹配→"六定"准备（定目标、定产品、定话术、定激励、定分工、定工具）→现场拜访销售七步法（检测切入→破冰准备→现状了解→问题发现→业务导入→促进成交→后续跟进）。

5. **中小企业数字化水平评测（2024年版）**：从数字化基础（50%权重，网络建设、设备数字化）、经营、管理、成效四维度评测，二级（规范级）需≥40分+6个应用场景，三级（集成级）需≥60分+8个应用场景。将此评测标准作为需求诊断量规。

## 三、巴中联通标准化产品培训（4个文件）

### 概括

本项目以**巴中本地商企市场**为场景，聚焦中小酒店、便利零售超市、聚类市场三大目标客户群体，将产品体系（商务光专线、全企通、云守店、云犀）与场景化销售话术深度融合。课程设计强调"信心提升→话术优化→转化提效"，从FABE价值传递到异议处理、成交促成的全流程实战演练，是一套**"产品培训+销售方法论+实战演练"高度整合**的标准化课程。

### 核心知识点

1. **商务光专线产品矩阵与销售政策**：159/299/399元三档套餐，上行200M下行1000M，含移网成员共享、固话0-5部、TV、看店等可选包；严格的客户市场区隔（商企市场全力发展，要客/公众禁止）；6-7月积分佣金1.1倍激励。

2. **云守店降本增收销售逻辑**：以"帮客户降本增收"替代"同质化产品竞争"——24小时云值守解决夜间经济缺口（全年闭店超4000小时，凌晨营收占比5%-20%），AI监控+远程客服+盗损先行赔付，四川全省66万家批发零售商户的市场规模数据为证。

3. **FABE精准话术体系**：
   - 特征(Feature)：159元档上行200M下行1000M
   - 优势(Advantage)：上下行对称，满足多设备同时联网
   - 利益(Benefit)：监控无卡顿、网络无投诉、成本可控
   - 证据(Evidence)：某超市夜间监控传输流畅，盗损事件减少80%
   按酒店、超市、聚类市场分别设计FABE模板。

4. **四类异议标准化应对话术**：
   - 资费异议→对比长期成本，强调组合优惠
   - 效果异议→AI监控+赔付承诺，用数据说话
   - 售后异议→24小时支撑，1小时响应+4小时上门
   - 竞争异议→"免设备费+含保险"的成本优势
   异议处理四步法：认同→解释→证据→引导

## 四、广东营服认证项目（5个文件）

### 概括

本培训项目是**广东联通全业务营服中心人才培养体系**的顶层设计，覆盖全省约460个营服中心、2700多名营服人员。核心是建立"五级认证"人才发展梯队，对营服总经理和销售经理两个序列分别设置初中高三级培训认证标准，配合薪酬激励的"底薪+绩效+增量提成"模式，以及"百强营服中心龙虎榜"排名激励。培训课程包括团队建设、客户心理学、沟通谈判、网点拓展、促销组织、终端销售等12门课程，总投入146万元。

### 核心知识点

1. **五级认证人才培养体系**：营服总经理岗位五→一级、销售经理岗位四→一级的阶梯式培训认证，实现人员能力层级"纺锤型"分布，打通"培训-认证-薪酬"闭环。

2. **"倒三角"组织架构转型**：从员工听命于领导的层级结构，转变为员工、管理者、职能部门共同指向为客户创造价值的倒三角结构，核心是提升市场末梢的快速响应能力。

3. **"底薪+绩效+增量提成"薪酬激励模型**：
   - 营服总经理：岗位工资+业绩薪酬+营服中心增量提成
   - 营服团队人员：基本底薪+绩效奖金+业绩提成（上不封顶）
   - 底薪等级与业绩挂钩，动态调整

4. **网格化营销策略**：将市场末梢细分为网格，责任到人，核心四要素——网格结构设计、团队结构设计、渠道结构设计、营销沟通设计。目标客户模型五步法：摸底市场元素→摸清元素属性→摸清客户属性→判断市场价值→锁定潜在市场。

## 五、杭州联通行业经理基础能力培训（4个文件）

### 概括

本套培训以**行业客户经理的基础能力塑造**为核心，涵盖影响力塑造、销售技巧、物联网产品营销等主题。课程从"AKS模型"（态度Attitude、知识Knowledge、技能Skill）切入，帮助客户经理建立从传统的通信产品推销到客户价值顾问的角色转变。重点包括：商务客户四类市场特点分析、陌生拜访技巧（内在准备+外在准备）、以及产品营销架构模型（价值主张→客户细分→核心资源→收入成本）。

### 核心知识点

1. **商务客户经理三种角色定位**：
   - 业绩创造者、服务经理、分析专家、信息管理者（对内）
   - 勤奋工作者、自我管理者、乐观主义者、现实主义者（对己）
   - 大使、服务者、业务顾问、问题解决专家（对外）
   核心是成为"资源的整合者"，联通内部与客户、竞争对手之间的桥梁。

2. **AKS能力模型与习惯养成法**：态度（自信、积极、热忱）占成功要素首位，其次是知识（丰富的专业知识）和技能（沟通、人际关系、销售技能）。习惯养成三部曲：僵化→优化→固化（3周重复形成习惯，3个月形成稳定习惯）。

3. **产品营销架构模型（商业模式画布简化版）**：
   价值主张→我们给客户提供的价值是什么？
   客户细分→哪些客户需要这些价值？
   关键业务→我们如何创造这些价值？
   收入来源→我们得到多少收入？
   成本结构→我们需要支出多少成本？
   帮助客户经理从产品思维向商业思维转型。

4. **陌生拜访内外准备标准化**：
   - 内在准备：收集客户资料，了解客户情况
   - 外在准备：服装仪容自然、销售工具齐全（资料、名片、演示设备、笔记本）
   - 时间把控：提前10分钟到达
   - 要求形成职业习惯
