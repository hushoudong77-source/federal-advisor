## 一、【体验式营销】（约40个文件）

**概括**：以"先体验、后销售"为核心方法论，通过让客户亲手操作智能终端、体验3G/4G应用（手机电视、微博、沃商店、手机音乐、体感游戏等），在体验过程中挖掘需求、引导成交。课程包括体验式销售四步法、SPIN需求挖掘模型、FAB销售法，配合大量情景话术脚本和场景演练。配套考卷、评分标准、音乐包、破冰步骤、动员会流程等完整的培训交付包。

**核心知识点**：
- 体验销售四步法：吸引→体验→讲解→成交
- SPIN模型：Situation（现状问题）→ Problem（难点问题）→ Implication（暗示问题）→ Need-payoff（需求效益问题）
- FAB销售法：Feature（特点）→ Advantage（优势）→ Benefit（利益）
- 智能手机五大操作系统认知（Android/iOS/Symbian/Windows Mobile/BlackBerry）
- "沃"品牌四重释义：精彩在WO / 精彩在"握" / 精彩在"我" / 精彩在WO
- 时尚链细分：时尚创造者→时尚推动者→时尚跟随者→时尚不敏感人群

## 二、【顾问式营销】（约12个文件）

**概括**：以"站在客户利益角度提供专业意见和解决方案"为核心逻辑，区别于传统推销"客户是上帝、好商品=性能好+价格低"的思维，提出顾问式营销四步法：需求挖掘与商机管理→方案制定与呈现技巧→谈判策略与技巧→项目实施与客户价值提升。核心方法论来自胡守东（讲师），包含大量客户心理学（九型人格）与差异化竞争策略。

**核心知识点**：
- 顾问式营销定义：站在专业角度和客户利益角度提供专业意见、解决方案和增值服务
- 与传统销售的区别：客户是"朋友"而非"上帝"，"好商品"是客户真正需要的产品，"服务"本身就是商品
- 顾问式营销四步法：需求挖掘→方案呈现→谈判→实施与价值提升
- 客户商机来源：烦恼→需求→不满→痛点
- 商机管理：商机定义→商机来源→商机评估→商机推进
- "听、知、开、问"四字诀
- 银行版顾问营销：中国银行客户经理培训资料扩展

## 三、【集团客户铁三角攻坚训练营】（约20个文件）

**概括**：借鉴华为"铁三角"销售运营模式，构建联通集团大客户销售的团队作战架构。由团队经理、销售服务经理、支撑经理三个角色组成作战单元，强调基于流程的职责界定和"获取分享制"的考核激励机制。课程涵盖项目化销售流程（商机挖掘→方案提出→招标签约→交付开通→售后管理），配套售前顾问十项技能、技术解决方案撰写、演讲训练、谈判心理学等内容。

**核心知识点**：
- 铁三角三角色：团队经理（市场规划/过程管理/客户开发）、服务经理/销售服务经理（客户服务/关系维系/投诉处理）、支撑经理（方案制作/成本核算/技术实现）
- 铁三角成功三要素：团队运营模式（基础）+ 基于流程的职责界定（前提）+ 基于"获取分享制"的考核激励（保障）
- 项目化销售五环节：商机挖掘→提出解决方案→参加招标并签订合同→产品交付→售后管理
- 售前顾问十项技能：售前分析能力→拜访前准备→结构化知识→公司介绍→售前调研→解决方案→产品演示→现场答疑→客户考察→典型客户参观
- "别做四拍型销售"：一拍脑袋（拍脑袋决定）、二拍胸脯（承诺）、三拍大腿（后悔）、四拍屁股（推卸）
- 大项目关键影响要素：品牌资质、利润价值、技术实力、关系影响、社会关系
- 制胜核心：行业口碑 + 顾问能力 + 把握需求

## 四、【中小企业/网格经理培训】（约200个文件，含大量实战案例）

**概括**：联通网格化营销体系的完整培训包。核心课程包括《中小企业客户经理培训课程》（讲师版+学员版）、《中小企业客户营销技能》、《全国中小企业经理销售TTT课程包》等。包含大量来自全国各省市分公司的实战销售案例（覆盖商务楼宇、工业园区、专业市场、沿街商铺、聚类市场等场景），以及九型人格与销售、SPIN销售法、FAB呈现法的实操训练。TTT课程包含完整的讲师评级认证体系。

**核心知识点**：
- 网格化营销四大行业聚类：商务楼宇 / 工业园区 / 专业市场（汽配、家居、建材等）/ 沿街商铺
- 行业客户 vs 中小企业客户差异：行业客户（客户群有限、个性需求、理性消费、关系复杂、对价格不敏感）vs 中小企业（客户群大、基础通讯需求、冲动消费、老板即决策者、对价格极其敏感）
- 中小企业客户销售核心要素：把握一个客户核心需求→掌握一个销售契机→以一个优势业务有效突破竞争对手防御→促成成交
- 销售失败六大误区（略）
- 销售人员"三位一体"角色能力要求：市场管理能力 + 销售管理能力 + 关系管理能力
- 九型人格：脑区（5号/6号/7号）- 理性分析；心区（2号/3号/4号）- 情感认同；腹区（8号/9号/1号）- 权威务实
- SPIN案例教学实践
- TTT课程包含12个独立模块：案例教学（难道我的诚意不够、一次难忘的销售回忆、徐总到底想怎么样等）+ 工具教学（需求匹配表格、SPIN案例、场景演练）+ 讲师认证评估+ 考试题库
- 案例集精华（选录）：
  - "卖3G不如教客户用3G"：体验式营销带动销售
  - "痛点成就卖点"：挖掘客户真正痛点
  - "微小商机牵出大需求"：不忽视任何线索
  - "知此知彼是反争夺成功的关键"：竞争分析
  - "保姆关怀式服务"：让用户无法相信别人
  - "多产品捆绑是维系用户的最好方式"

## 六、【存量客户维系】（约4个文件）

**概括**：以VIP客户生命周期管理为核心，覆盖客户从入网→成长→成熟→衰退→离网的全过程管理。核心教材《VIP客户全生命周期管理手册》（五章三十二节），包含峰终理论在VIP服务中的运用、不同套餐类型客户（存费送机、购机送费、存费送费、单卡）的差异化维系策略。另有《关于宽带用户维系的对策建议》从目标客户细分、政策匹配、酬金激励、管控支撑四个维度构建宽带维系体系。

**核心知识点**：
- 客户全生命周期管理五阶段：入网→成长→成熟→衰退→离网
- 峰终理论（Peak-End Rule）：客户体验评价取决于"高峰时刻"和"结束时刻"的感受
- 四类客户差异化维系：存费送机型 / 购机送费型 / 存费送费型 / 单卡型
- 宽带维系四维体系：细分目标客户（速率/套餐/消费行为/在网年限）→ 匹配维系政策（优先融合、年付提速等）→ 确定维系酬金 → 销售管控支撑
- "钱包份额"和"心理份额"两个核心指标
- 离网预警：高危用户识别（欠费、单宽沉默、宽带沉默+手机活跃、宽带沉默+手机沉默）

## 客户常见痛点总结

1. **中小企业老板**：每一分钱都是自己赚的血汗钱，对价格极其敏感；没时间听暗示性语言；决策链简单（老板或老板娘）；冲动消费
2. **行业大客户**：决策理性、周期长；关系复杂（信息口/财务/使用部门/领导）；关注方案价值而非单一价格；领导重视起决定性作用
3. **宽带用户**：资费贵（单宽用户最易流失）；网络质量（不稳定）；套餐融合度越高越不易流失；沉默用户是离网预警信号
4. **聚类市场客户**：缺乏固定的服务网点；以"单打独斗"为主；需要策略性整体开发
5. **集团客户**：需要顾问式服务；关注信息化解决方案；行业竞争压力下的差异化需求
