## 一、总体概览

本次学习的培训材料覆盖中国联通面向政企客户的创新业务全体系销售课程，由西安集优咨询等机构为中国联通定制开发。课程以"云、大、物、智、ICT"五大创新业务为主线，贯穿客户经理从思维转型→产品知识→销售技巧→全流程演练→实战案例的完整培养链路。

## 二、五大核心产品知识体系

### （一）云计算业务（沃云体系）

**沃云产品线三层架构：**
- **IaaS层**：弹性云主机（13档规格，从1核0.5G到8核32G）、弹性块存储（0.4元/G/月）、对象存储（兼容S3协议）、虚拟私有云VPC
- **PaaS层**：云数据库RDS、中间件、Hadoop大数据服务
- **Saas层**：云桌面、云总机、云呼叫中心、云安全

**多云战略（混改产物）：**
- 联通与阿里云（沃云A）、腾讯云（沃云T）深度合作，客户经理面向中小企业可直接销售阿里云/腾讯云标准产品，打8折报价
- 沃云自营+合作云双轨制，沃云A使用阿里云技术栈，沃云T使用腾讯云技术栈
- 云专线/云快线组合产品：沃云+双创云快线（5折）、沃云+互联网专线（5折）

**三大差异化卖点：**
1. **云网一体**：沃云资源池既有互联网出口又有专线出口，客户不通过互联网也可直接访问
2. **本地化维护**：省分产业互联网公司有专门云维护团队
3. **大客户专业服务**：一对一客户经理+技术支撑

### （二）物联网业务

**平台架构：**
- 采用"专用网元+双平台"方式建设，全国一张网
- 南京交换区（覆盖13省）、广州交换区（覆盖10省）
- 平台提供连接管理、自动化规则、API集成、成本管理、诊断工具五大能力

**五大能力布局：**
1. M2M平台能力
2. 应用服务资源聚合能力
3. 终端模组定制能力（M2M专用SIM卡，支持高温/低温/抗震/防尘）
4. 端到端方案集成能力
5. 全球化能力

**六大行业客户：**
车辆服务（车厂/OBD/UBI/共享单车）、智能抄表（电水气热）、移动支付（POS/ATM/售货机）、智能可穿戴（手表/手环/笔记本）、生产及环境监测（传感器/工业设备/视频监控）、移动传媒

**资费模型（核心知识点）：**
- 月付单连接/月付灵活共享/预付单连接/预付灵活共享/月付固定共享/预付固定共享六种基础资费
- 补充套包：事件（单个连接临时升级）、追加（流量池叠加）、堆叠（预付灵活共享叠加）
- 折扣体系：省内系数（最低0.6）、地市行业总监（最低0.7）、省分行业总监（最低0.65）、省分集客总经理（最低0.6）、省分管集客副总（最低0.55）

### （三）大数据业务

**联通大数据核心优势：**
1. **数据一点集中**：31省BSS数据一点采集、一点处理、一点服务
2. **信息真实**：实名制全网用户数据，覆盖13亿手机用户
3. **数据全面**：通信、位置、互联网行为、消费、终端五维度数据
4. **平台能力强**：4500+节点，90PB存储能力，1300节点Hadoop集群

**八大产品体系：**
- **基础产品**：9大类3700+客户标签体系、能力开放平台
- **标准产品**：风控平台（金融征信）、数字营销（Wo营销平台）、沃指数（行业指数/交通/旅游/金融/终端/APP指数）、智慧足迹（位置服务）
- **平台级解决方案**：旅游大数据平台、政务大数据平台

**安全合规四原则（销售话术必提）：** 数据不出门、敏感数据不可见、数据标签化、用户授权

### （四）ICT业务

**六大业务链：**
1. **系统集成**：视频监控、视频会议、网络集成、综合布线
2. **软件开发**：呼叫中心、OA、税务软件、工程管理
3. **运维服务**：IT维保、代维，成本低利润高，增强客户粘性
4. **咨询服务**：IT规划、项目管理咨询、行业解决方案
5. **第三方销售**：服务器、网络设备等硬件转售
6. **租赁服务**：网络设备、应用系统租赁

**联通做ICT的六大资源优势：** 客户资源、网络资源、人力资源、信息资源、资金资源、品牌资源

### （五）智慧城市

**三层架构：**
- **大管理**：优化流程、提高管理效率
- **大服务**：服务企业和社会公众
- **大数据**：以云计算+大数据为基础

**目标客户群体：** 政府客户重在引导和帮助、参与顶层架构设计、做顾问和参谋；企业客户重在诊断问题、给出产品和运作模式

## 三、销售方法论与全流程

### （一）创新业务销售的客户经理六项基本能力

1. **懂技术、懂产品** — 五大类产品的架构、优势、卖点、目标客户
2. **懂行业、懂客户** — 客户调研五维模型、政府类/企业类客户切入点
3. **懂人情、懂世故** — 情理利三个维度、利他主义、换位思考、双赢共惠

### （二）创新业务销售八步法

1. **梳理客户名单** — 按产品匹配行业，利用行业协会/政府部门/网络搜索
2. **推广与商机发现** — 专项推广会、线上传播、行业展示厅、与政府联合推广
3. **发现商机** — 关系人脉、日常走访、政策文件、社会事件四个渠道
4. **需求探寻** — 拜访预调研、移情图分析、换位思考可能的痛点
5. **项目推动** — 把握客户预算/规划/紧迫性/决策链四个关键
6. **项目支撑** — 选合作商三要点（不打破利益格局/客户认知基础上/以能力为主）
7. **项目运营** — 从卖产品到卖运营、引导用户升级
8. **招标技巧** — 三种招标形式分析、控标方法、讲标技巧

### （三）大客户销售十二条黄金法则

双赢法则、人性法则、大数法则、大王法则、卧底法则、谨慎法则、人情法则、连环套法则、寻根法则、沟通法则、坚持法则、权威法则

### （四）客户成交公式

**价值总和 > 成本总和**（客户决定购买的核心）
- 价值不限于产品价值，包含品牌、服务、关系等多维价值
- 成本不限于购买成本，包含转换成本、维护成本、风险成本等

## 四、客户痛点 & 营销话术

### 六大客户场景痛点对应话术

| 场景 | 痛点 | 话术要点 |
|------|------|---------|
| 初创企业刚起步 | 一次性硬件投资大 | "只需投入很少一部分就可在云端搭建——避免倒闭后浪费硬件投资" |
| 设备老旧需升级 | 升级成本高 | "把老旧设备上的应用直接迁移到云端，节省投资，利旧设备" |
| 运维人力不足 | 专业人员成本高 | "分阶段迁移到云端，瘦身运维团队，节省人工成本" |
| 机房环境差 | 断电/宕机风险 | "联通云计算机房按国际最高标准——7×24小时专业团队监控" |
| 数据无备份 | 数据丢失风险 | "阿里巴巴说'我们是一家数据公司'——建议重要数据备份云端" |
| 系统不安全 | 网络攻击风险 | "云平台提供高等级安全防护——能抵御已知所有病毒及网络攻击" |

### 上云客户分类

- **困扰型**：硬件老旧、运维压力大、掉电宕机、无备份、安全等级低
- **创新型**：数字化转型、新业务上线、快速迭代验证

## 五、实战案例精华

### 65+案例汇总的核心经验

**高频切入场景（云业务）：**
1. 客户搬迁 / 机房升级 — 魏县公安局、邯郸规划设计院
2. 客户网站访问慢 / 服务器老化 — 山东淄博健身器材、湖南嘉裕环保
3. 客户有软件/APP需部署 — e代驾、小i机器人
4. 客户设备维护难 / 无专业人员 — 内蒙古广告公司、教育机构
5. 微信小程序为切入点 — 石家庄经验（餐厅老板一听小程序减少人工成本就来了兴趣）

**营销策略精华：**
- **"云+网+X"公式** — 以云带网，以网促云，再加物联网/应用/号卡等
- **"ping命令找云客户"** — 北京公司经验：ping客户域名得到IP，查是否已用阿里云/腾讯云，精准锁定目标
- **"甩单抢单机制"** — 客户经理用钉钉甩单，支撑经理抢单，解决客户经理云知识不足的问题
- **"云快线/云专线"** — 云+专线打包5折，1元云带动近3元网收入
- **"省政务云切入"** — 政府客户以此获得信任，再推介沃云（技术架构一致）
- **"B2B模式"** — 给软件开发公司提供云服务，让其向自己客户群推荐联通云

**关键数字：**
- 云专线套餐：套餐一 1600元/月（4核4G+300G+8M+专线20M），套餐二 2600元/月
- 云快线套餐：套餐一 1200元/月（2核4G+200G+6M+云快线50M）
- 沃云A/T产品在官网价基础上可打8折

## 六、陌生拜访与客情关系

### 中国特色客户关系三基石
- **亲情文化**：找到老乡、同学等近距离身份链接
- **属地文化**：利用本地化服务优势
- **熟人文化**：通过熟人介绍引荐

### 拜访准备四大能力
1. **卖自己**：先做人后做事，让客户认可为人处事
2. **识性格**：九型人格分为脑区/心区/腹区，不同性格不同沟通要点
3. **懂行业**：教育/金融/制造/政府/医疗/连锁六大行业需求特点与匹配清单
4. **预分析**：移情图分析、角色互换模拟

### 拜访核心四步
1. 约客户（电话/直接上门/熟人引荐）
2. 关系破冰（坐位选择、共同话题、技术权威展示、不刻意赞美）
3. 获取五个关键信息（信息化现状、年度工作安排、痛点问题、期望方向、部门职责）
4. 商机评估（C139项目评估模型）

## 七、三大实景模拟演练框架

### 企业版（复兴制药案例）
- 9幕全流程模拟：从初次拜访→信息收集→方案制定→高层沟通→投标→成交
- 关键角色：信息部主任（中性偏对手）、办事员小王（内线）、销售公司郑总（信息化不懂但有想法）、分管张总
- 训练重点：提问深度与广度、方案制定能力、竞争应对（李主任亲戚在电信）

### 政府版（东方市智慧旅游案例）
- 9幕全流程：从经信委→邹处长→旅游局朱局长→打探内线→联手其他公司→方案汇报
- 关键角色：经信委王科长（同学关系）、邹处长（技术型干部、摄影爱好、备选干部）、旅游局朱局长（儿子在西软上班，有倾向性）
- 训练重点：政府决策链分析（需求单位→财政→招标中心）、竞争策略（西软有内定优势，需合作投标）

### 核心销售沙盘工具
- 项目C139模型评估项目有效性
- 梅花分配法确定客户决策链进攻顺序
- 客户移情图分析
