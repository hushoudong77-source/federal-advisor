## 守东培训方法论（从知识库学到的）

### 核心教学基因
- **话术导向**：每套产品方案必须产出「一句话卖点」和「分角色话术」（对老板/对信息部负责人/对一线），学员不是学参数而是学怎么说
- **场景化教学**：所有知识点绑定到具体客户场景（互联网专线融云、酒店1+1+N、沿街商铺上云……），从不脱离场景讲产品
- **工具化交付**：每模块输出可带走的纸面工具——话术卡、需求调研表、选型速查表、TCO计算模板
- **属地化定制**：每省课程必引用该省本地案例、本地政策、本地客户画像
- **拒绝纯理论**：90%学员更接受案例拆解+情景模拟

### 标准课件结构
1. 客户痛点→2. 产品/方案能力→3. 应用场景（配本地案例）→4. 话术脚本→5. 营销组合与政策→6. 常见异议回答

### 善用的"一指禅"工具
- 一个产品一页纸：场景描述 + 目标客户画像 + 一句话卖点 + 访前准备清单 + 开口话术 + 异议处理 + 促成技巧 + 结算/利润说明

### 三大核心课程方向（高频交付）
1. **云产品训战**（IaaS/PaaS/SaaS 融云营销，移动云场景化营销）
2. **前沿科技课**（AI+行业应用、大模型落地、低空经济、算力网络、5G-A通感一体）
3. **政企销售技能**（客情经营、需求挖掘、方案编写、招投标、商机管理）

### 培训对象
- 主力：政企/商客客户经理（运营商省/市级）
- 辅助：产品支撑人员、县市网络口工程师
- 管理层：三级经理（地市中层）、四级经理（县级管理者）

### 验收标准模板
- 显性：培训满意度≥90%
- 隐性：学员能独立完成3件事（如：解读一个政策、对接一类客户、输出一份诊断表）

### 常见培训项目形式
- 训战（2-3天理论+1-2天实战演练+复盘）
- 行销会战示范班
- 三级经理专题培训
- 知识萃取/标准方案开发
- 流程穿越咨询项目

### 高频使用销售方法论
- 八步矩阵（客户营销八步法）
- 客情五级模型（认识→熟悉→认可→信任→合作）
- 三本账算账法（收入账+效率账+战略账）
- 一指禅话术卡（一产品一页纸）
- 七大异议场景突破（"不缺这个""一线推不动""结算不划算"……）

### 擅长的行业赛道
- 党政（数字政府、等保/信创合规）
- 工业能源（智慧工厂、设备上云）
- 教育（智慧校园、云桌面）
- 医疗（PACS影像上云、灾备）
- 农商文旅（数字乡村、智慧景区）
- 金融（云灾备、安全合规）
- 交通（智慧公交、车路协同）
- 楼园市场（商务楼宇/产业园区攻坚）

### 浙江联通商企训战方法论（2026年5月新学）
- **赛道聚焦**：跨境电商、商业综合体、直播电商三大赛道，每个赛道有独立攻坚手册+产品组合+话术
- **楼园三清管理**：楼宇信息清（地址/物业/入驻率/资源）、客户清单清（名称/行业/在用网络/到期日）、业务机会清（专线/算力/AI/SaaS/ICT）
- **一楼一策**：每栋楼有独立的攻坚方案（楼情+客情+竞品+产品组合+攻坚路径）
- **楼园准入五维度评分**：入驻质量20分+业务渗透空间25分+物业合作可行性25分+资源覆盖20分+业态匹配10分
- **短中长期物业借力**：短期（强势物业/低配合）→中期（有客情/想增收）→长期（客情好/愿投入资源）
- **创新商业模式**：联通集约化信息化服务品牌——派驻正式编制工程师驻园，以物业身份对外服务，服务为先/转化在后
- **训战一体化**：12天周期（1天理论+11天实战陪访+晨夕会+晒单+复盘+楼王争霸赛）
- **过程管控**：日拜访量、商机量、签单量三线并行，积分制排名，红包即时激励
- **陪访日志制度**：每次走访记录客户痛点→合作方案→双方共识→后续安排四段式
- **训后90天跟踪机制**：每个商机明确跟进人+目标转化时间+关键里程碑
