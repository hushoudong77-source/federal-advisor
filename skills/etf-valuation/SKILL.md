## 取数流程

### Step 1: 判断标的归属
- A股ETF（588000/513180/512100/510500/510880/513910）→ 进入Step 2
- 黄金（518880/IAU）→ 跳过
- 美股ETF → 返回「PE/PB数据不可用」

### Step 2: AnySearch批量查询
```
python3 /home/agent/cow/skills/anysearch/scripts/anysearch_cli.py batch_search \
  --query "<指数名称> <指数代码> PE PB 估值分位" \
  --query "<指数名称> <指数代码> PE PB 估值分位" \
  ...
```

### Step 3: 数据提取优先级
1. **理杏仁** (lixinger.com) — PE/PB + 3年分位，最可靠
2. **百分位网** (baifenwei.com) — PE/PB + 10年分位
3. **雪球基金** (danjuanfunds.com) — PE/PB + PE百分位 + PB百分位
4. **亿牛网** (eniu.com) — PE + 3/5/10年分位
5. **ETF.run** — PE + PB

### Step 4: 输出格式
```
| 标的 | 底层指数 | PE | PE分位 | PB | PB分位 | 数据源 | 更新时间 |
|:---|:---|:---:|:---:|:---:|:---:|:---|:---:|
```

## 注意事项

1. **分位口径不统一**：不同数据源分位区间不同（3年/5年/10年/成立以来），输出时必须标注分位口径
2. **PE为负处理**：科创50等指数PE极高或为负时，PE分位参考价值有限，以PB分位为主
3. **数据时效**：估值数据通常T+1更新（最新交易日收盘后），盘中不变
4. **不焊入法典**：估值数据仅作人工辅助参考，不纳入进攻/反击策略的C1-C4/R0-R2判定

## 适用指令

- `/估值` — 查询全池A股标的PE/PB估值矩阵
- `/估值 <标的代码>` — 查询单个标的底层指数估值
- 守东问询某标的"贵不贵"/"估值如何"时自动触发
