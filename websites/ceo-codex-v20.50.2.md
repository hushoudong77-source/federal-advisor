3.1 阶梯化宏观抗压风险公式 2.0
```
N = (R_tier × 动态总资产) / ((买入价 - 止损价) × γ_ER)
```

10.2 真实购买力回报强制计算公式  

每次新兴市场标的审计，必须输出以下三项：  

```
账面回报 (Nominal Return) = (现价 - 成本价) / 成本价 × 100%

汇率变动 (FX Change) = (当期汇率 - 建仓期汇率) / 建仓期汇率 × 100%
  → 本币贬值 = 负值（侵蚀美元回报）
  → 本币升值 = 正值（增厚美元回报）

真实购买力回报 (Real USD Return) ≈ 账面回报 + 汇率变动
  精确公式：Real Return = (1 + Nominal) × (1 + FX) - 1
```

**简化规则**：当账面回报与汇率变动均 < 5% 时，使用近似公式（账面+汇率），偏差 < 0.25%。  

**审计示例**：  
- EWY 账面回报 +3.0%，同期 KRW 对美元贬值 -4.0%  
- 真实购买力回报 ≈ +3.0% + (-4.0%) = **-1.0%**  
- 结论：「赢了账面输了购买力」，实际美元价值缩水。
