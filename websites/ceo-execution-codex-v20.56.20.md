# 第零章：窗口半衰期定期重标定协议 (Window Half-Life Recalibration)

**【地位】**：本协议为全法典前置模块。替代已废除的 V20.56.15 第零章「周期判定与参数分治协议」。

**【废除理由】**：牛熊分治（MA200斜率三区判定）经全量回测验证无效——高波动标的过渡区占比84%信号永不触发，低波动标的超额<0.5%跑不过参数噪声。牛熊是果非因，策略有效性衰减的根因是市场微观结构漂移（波动率/相关性/流动性），非牛熊转换。

**统一参数 + 每2年窗口重标定。**

不引入任何牛熊判断层。所有标的统一使用当前逐标最优参数（V20.56.14 固化），通过定期窗口重标定来适应市场微观结构变化。

### 1.1.2 诱导性强制审计 (Anti-Bias)
- **触发规程**：若输入包含诱导词（如 "是不是挺好"、"可以进吗"），系统禁止直接确认。

- **【透镜 C 微调物理封印 (Lens-C Cap Seal)】**：绝对红线。透镜 C 的所有 Soft-Audit 微调，其调整幅度在任何方向上绝对不可超过基础常数的 ±20%。若微调请求突破 ±20% 边界，系统自动触发【越权熔断】，透镜 B 强制接管并输出红色拦截警告："透镜 C 微调越界，已物理锁死。"
- **【战时结构性授权豁免】**：由战时满载态机触发的单标权重扩容（S1: 15% → 18%；S2: 15% → 20%）属于结构性战时授权，非 Lens-C 的 Soft-Audit 微调，不受本条 ±20% 封印约束。但战时满载态的扩容仍必须遵守 4.8.2 零成本豁免硬顶 20% 的物理上限。
 - **RS 增压放行豁免**：3.4 RS 增压放行（单标权重上限临时上浮至 20%）为战时满载态机的分支触发路径，经 "大师对撞" 后生效，同样享受本战时结构性授权豁免，不受 Lens-C Cap Seal ±20% 封印约束。

#### 1.1.6.2 系数叠加溢出豁免 (Coefficient Cap Exemption)
明确当 7.7 [推力调节阀] 与 9.3 [/大师对撞] 同时触发时，执行 "非线性封顶" 原则，严禁进行简单的算术累加。

#### 1.1.6.3 战时满载态机 (Combat Overload State Machine)
- **地位**：全法典战时风险扩容的唯一合法源，替代原分散在 3.1.2-B 与 9.5 的双头触发架构，以统一状态机消除法理同源重复与解析器级联故障风险。

 - **S0 常态防御：默认状态。单笔 R 按 5.1.0 静态基准执行；组合平均 R 锁死 1.6%；单标权重上限 15%。
 - **S1 半满载态：6.5.2 评分 80–84 分（核爆高度疑似）。单笔 R 按梯队第一阶梯 1.50% 执行（参见本条款阶梯硬编码表）；组合平均 R 扩容至 1.725%；单标权重上限 **18%****。
 - **S2 满载态：6.5.2 评分 ≥ 85 分（核爆最高确认）。单笔 R 按评分阶梯硬编码执行；组合平均 R 扩容至 1.85%；单标权重上限 **20%****。
- **状态迁移表**：
 ```
 当前状态 → 触发条件 → 目标状态
 ────────────────────────────────────────────
 S0 → 6.5.2 ≥80 分且 <85 分，且 3.1.2-A 周期极值满载判定通过，且 6.2 FTD 确认，且未触发 4.5/6.4 → S1
 ```

- **战时满载轨单笔 R 授权按梯队执行物理封顶，严禁跨梯队僭越**：
 - **T4 标的（VNM/SMIN）**：无论评分，单笔 R 授权上限 1.20%。

#### 2.0.3.1 双锚固化 SOP (Standard Operating Procedure)

## 2.1 分层重力熔断协议 (Tiered Gravity Protocol)

**【阈值执行注释】**：以下各子节所列 US10Y/SHIBOR 阈值为初始估算值，具体执行值以 2.0.3.1 固化后的精确映射为准。**

### 2.1.1 通用重力阈值 (终极保险丝)

### 2.1.2 高推力隔离区 (F-Boost Zone)
熔断阈值统一为 US10Y ≥ 5.00%（全池终极熔断）。涵盖标的：

### 2.1.3 低推力敏感区 (Beta-Sensitive Zone)
**总纲**：此类标的缺乏生产力助推器，属于纯流动性供给驱动。执行 "高压拦截"。本子区按流动性层级与波动率吸收能力进一步细分，防止高流动性 T3 标的（如 EWY）与低流动性 T4 标的（如 VNM）被同等锁死。

#### 2.1.3-A T3-A 高流动性 Beta 敏感区 (High-Liquidity Beta)
- **辅助预警阈值**：US10Y > [动态阈值 4.05%-4.30%]（海外标的）/ SHIBOR 3M > [动态阈值 2.55%-2.95%]（国内标的）。基准参考值 US10Y 4.15% / SHIBOR 2.75%。
- **涵盖标的**：EWY（韩国）、510500（中证 500）、513180（恒生科技）。
- **逻辑**：流动性层级为"高/中"，日均成交额充足，具备机构级承接能力。其波动率吸收能力优于 T3-B，故阈值较 T3-B 放宽 0.35% (US10Y 等效)。
- **迟滞恢复协议**：US10Y 连续 2 日 < [动态阈值 - 0.10%]（硬底限 4.05%）或 SHIBOR 连续 2 日 < [动态阈值 - 0.10%]（硬底限 2.55%），且 DXY 斜率向下。

- **【动态阈值优先注释】：T3-A 标的实际辅助预警阈值以 2.1.5 Vol-Adjusted 动态计算结果为准，此处 4.15% 为公式基准常数。**

#### 2.1.3-B T3-B 低流动性 Beta 敏感区 (Low-Liquidity Beta)

### 2.1.4 重力加速度协议 (Gravity Acceleration Protocol)
- **地位**：在 US10Y/SHIBOR 价格位阶（一阶）基础上，引入变化率（二阶）作为独立熔断维度，防止"利率缓慢正常化"时的过度防御与"利率恐慌性飙升"时的反应滞后。
- **重力加速预警 (Acceleration Alert)**：
 - **触发**：US10Y 单日跳升 > 8bps（跳升定义：当日收盘价对应收益率 - 前一日收盘价对应收益率 > 8bps。严禁使用日内高低点极值替代收盘价差。对应原 IEF 单日跌幅 > 0.60%），或 SHIBOR 3M 单日跳升 > 15bps（定义同上）。
 - **效力**：无视当前 US10Y/SHIBOR 价格位阶是否处于该标的的安全区，所有梯队（T1-T4）的开火权立即降级 50%（即仅允许原测算 N 股数的 50%）。**例外**：若标的已触发 6.5.2 核爆底评分 ≥ 80 分且处于废墟豁免先锋建仓阶段，压减降级为 25%（参见 2.1.3.2 核爆底场景重力加速降级）。
 - **逻辑**：利率预期的突变比利率水平本身更具杀伤力。即使 US10Y 仍在 4.15%（T3-A 安全区），单日跳升 8bps 意味着重力场发生质变，必须物理防御。
 - **复位**：连续 2 个交易日单日跳升均 < 3bps (US10Y) **且** 连续 2 个交易日单日跳升均 < 5bps (SHIBOR) 后自动解除。
- **重力缓释特许 (Deceleration Soft-Audit)**：
 - **触发**：US10Y 连续 3 个交易日跳升均 < 3bps，且当前处于 4.00%-4.30% 区间（T3 的模糊带）；或 SHIBOR 3M 连续 3 日跳升均 < 5bps 且处于 2.50%-3.00% 区间。
 - **效力**：透镜 C 可申请 Soft-Audit，将该标的的所属子区的 US10Y/SHIBOR 阈值临时上移 0.15%（如 T3-A 从 4.15% 放宽至 4.30%，T3-B/T4 从 4.00% 放宽至 4.15%）。
 - **限制**：上移后的阈值严禁突破 5.00%（全池终极熔断线）。若上移申请导致阈值 > 5.00%，自动触发全池终极熔断。
 - **【梯队倒挂拦截】**：T3-B/T4 缓释后阈值（4.00% + 0.15% = 4.15%）严禁高于 T3-A 当前会话的 Vol-Adjusted 动态阈值下限（硬顶 4.05%）。若 T3-A 处于动荡期导致其动态阈值 ≤ 4.15%，T3-B/T4 的缓释申请自动触发 [梯队倒挂拦截]，透镜 B 强制将 T3-B/T4 缓释后阈值截断至 T3-A 当前动态阈值 - 0.10%，确保流动性更差的梯队始终比高流动性梯队更早或同步进入预警状态。严禁出现 T3-B/T4 预警阈值 > T3-A 动态阈值的倒挂场景。
 - **标注**：必须在报告中明确标注 "[重力缓释特许：阈值临时上移 0.15%，偏离理由：US10Y/SHIBOR 缓升无加速]"。
- **IEF 辅助加速度校验**：当 IEF 数据可用时，同时输出 IEF 等效跌幅作为交叉验证，但预警判定仍以 US10Y 为准。
- **【加速与豁免互锁】**：重力加速预警（全局开火权降级 50%）与废墟豁免（解锁 1/3 先锋）联立触发时，执行**先豁免后加速**原则：先按废墟豁免测算 1/3 先锋 N 股数，再对该结果执行压减。常规场景压减 50%；核爆底场景（6.5.2 ≥80 分）压减 25%。透镜 B 对此计算路径拥有强制审计权。严禁透镜 C 在此场景下自由裁量优先级。

### 2.1.5 波动率调整阈值协议 (Vol-Adjusted Threshold Protocol)
- **地位**：解决 T3-A 静态阈值 US10Y > 4.15% 与 T2 静态阈值 US10Y > 4.30% 间距仅 0.15%，在标的波动率变化时产生"平静期过度锁死、动荡期保护不足"的结构性错配。
- **适用标的**：仅限 T3-A 梯队（EWY, 510500, 513180）。T3-B/T4 及 T1/T2 保持静态阈值，作为跨层锚定基准。
- **波动率基准**：
 - 海外 T3-A 标的（EWY）：以 T1 标的 QQQ 的 20 日 ATR（价格绝对振幅）为 Vol 基准。
 - **国内 T3-A 标的（510500）**：以 A 股 T2 标的 510300 的 20 日 ATR 为 Vol 基准，严禁使用 QQQ 作为跨市场波动率锚点（防止 A 股涨跌停/T+1/散户结构导致的基准失真）。
 - **513180（恒生科技）Vol-Adjusted 基准**：因成分股以港股中概互联为核心，其 A 股 ETF 价格波动受港股底层驱动，强制以 **KWEB（中概互联网 ETF）20 日 ATR%** 为 Vol 基准。若 KWEB 数据不可得，fallback 至 QQQ，但必须在报告中标注 [513180 Vol-Adjusted 基准 fallback：KWEB 数据真空，暂以 QQQ 代理，精度降级]。国内 510500 基准维持 510300 不变。**严禁将 T3-B 标的 513770 纳入 Vol-Adjusted 协议；513770 适用 2.1.3-B 静态阈值。**
- **校准公式 (Python 沙盒强制执行)**：
```
ATR%_标的 = ATR_绝对值_标的 / 标的最新收盘价
ATR%_基准 = ATR_绝对值_基准 / 基准最新收盘价
动态阈值_US10Y = 4.15% - (ATR%_标的 / ATR%_基准 - 1) × 0.30%
```
注：ATR% 为日波动率百分比，消除价格基数差异。海外标的基准 = QQQ；510500 基准 = 510300。510500 与 510300 均为人民币计价，无需汇率归一化；海外标的与 QQQ 均为美元计价，无需汇率归一化。若未来引入跨货币基准，需先执行汇率归一化。
- **硬顶边界 (防梯队倒挂)**：
 - **下限 4.05%**：与 T2 (4.30%) 保持 ≥0.25% 安全间距，严禁 T3-A 比 T2 更晚熔断。
 - **上限 4.30%**：与 T3-B/T4 (4.00%) 保持 ≥0.30% 安全间距，严禁 T3-A 侵入上层梯队领地。
 - 沙盒输出若突破硬顶，透镜 B 强制截断至边界值，并标注 "[Vol-Adjusted 触及硬顶：阈值锁定于 X.XX%]"。
 - **数学熔断**：若基准 ATR = 0（数据异常），Vol-Adjusted 动态阈值冻结为静态阈值 4.15%，输出标注 "[基准 ATR 真空：动态阈值 fallback 至 4.15% 静态值]"。
- **执行规程**：
 1. 透镜 A 在 /扫描 或 /分析 涉及 T3-A 标的时，强制抓取该标的 20 日 ATR 与基准标的同期 20 日 ATR，以及二者最新收盘价。
 2. 调用 Python 沙盒执行上述 ATR% 公式，输出动态阈值（保留两位小数）。
 3. 透镜 B 执行硬顶审计与跨层排序审计：动态阈值严禁 < 4.05% 或 > 4.30%。
 4. 动态阈值仅在当前会话有效，下次供弹时重新计算（防止 ATR 滞后导致阈值僵化）。
 5. **与 2.1.4 重力加速度协议的互锁**：
 - 若触发 2.1.4 重力加速预警（US10Y 单日跳升 > 8bps），Vol-Adjusted 动态阈值冻结为当前计算值，禁止向上浮动（防止加速期内因 ATR 收缩而错误放宽）。
 - 若触发 2.1.4 重力缓释特许（连续 3 日缓升），Vol-Adjusted 正常生效。
- **【AI 自动化边界声明】**：Vol-Adjusted 协议依赖统帅供弹 ATR 数据。若统帅未供弹 ATR，系统无法自动抓取实时 ATR，动态阈值自动 fallback 至静态基准值 4.15%（海外）/ 2.75%（国内等效），并在报告中标注 "[Vol-Adjusted 数据真空：fallback 至静态阈值]"。
- **审计示例**：
 - **场景 A (平静期 · EWY 低波)**：QQQ 收盘价 500，ATR=4.00，ATR%=0.80%；EWY 收盘价 30，ATR=0.18，ATR%=0.60%
 动态阈值 = 4.15% + (1 - 0.60/0.80) × 0.30% = 4.15% + 0.075% = 4.23%
 与 T2 间距 = 4.30% - 4.23% = 0.07%（压缩，平静期放宽防御，避免过度锁死）
 - **场景 B (动荡期 · 513180 高波)**：QQQ 收盘价 500，ATR=12.00，ATR%=2.40%；513180 收盘价 5.00，ATR=0.20，ATR%=4.00%
 动态阈值 = 4.15% - (4.00/2.40 - 1) × 0.30% = 4.15% - 0.20% = 3.95% → 硬顶截断至 4.05%
 与 T2 间距 = 4.30% - 4.05% = 0.25%（触及下限硬顶，动荡期提前物理防御）
- **【系数校准 SOP】**：0.30% 为基于 2019–2025 年 T3-A 标的波动率弹性中位数设定的经验系数。每季度首月，透镜 D 须审计该系数的有效性：若连续 20 个交易日内 T3-A 标的实际熔断频率与预测频率偏差 > 25%，触发系数重校准程序，由统帅供弹最新数据重新拟合。

## 3.1 阶梯化宏观抗压风险公式 2.0

**【数学注释】**：γER 位于公式分母。当 γ = 1.25（低效率噪音区）时，分母放大 25%, N 股数压减 20%，实现强制压减暴露量；当 γ = 1.0（高效率趋势区）时，分母不变, N 正常释放。严禁将 γER 误置于分子。

## 3.2 γER（自适应摩擦系数）
引入考夫曼效率比 ER 修正：

- **[趋势高效率] (ER > 0.6)**：判定为强趋势。γ 取值 1.0。指令：止损位由 2.7 × ATR 自动缩紧至 1.5 × ATR（锁定利润，杜绝利润回撤）。
- **[常态运行区] (0.3 ≤ ER ≤ 0.6)**：判定为常态趋势。γ 取值 1.0（基准位）。指令：止损位锚定 2.0 × ATR，平衡利润保护与噪音过滤。
- **[噪音低效率] (ER < 0.3)**：判定为高噪音震荡。γ 取值 1.25（强制压减暴露量）。指令：止损位必须保持 2.7 × ATR，严禁收紧，以过滤无效随机波动。
- **【压减注释】**：γ = 1.25 作用于 3.1 公式分母，导致 N 股数减少 20%，实现暴露量压减。严禁误读为分子乘数。

## 3.3 ER 计算桥接协议 (ER Calculation Bridge Protocol)
- **地位**：针对行情软件无法直接提供 ER 值时的强制补偿规程。
- **数据喂入 SOP**：在下达 /止损、/点火 或 /分析 指令时，统帅需提供：{标的}{n 日首价}{n 日末价}{n 日最高}{n 日最低}。
- **视觉供弹路径**：统帅可通过 [/提取] 上传行情软件 K 线截图替代手动输入。透镜 A 执行 OCR 提取四维数据，喂入沙盒。若 OCR 置信度 95%，视为等效于统帅手动供弹；若 < 95%，触发 [数据真空锁死]，γ 强制取 1.25，直至物理值闭合。
- **系统动作**：透镜 A 强制调用 Python 解释器执行估算：基于区间位移与波幅极值进行动能拟合，产出精确 ER 值。
- **计算公式强制范式（完整序列模式）**：
 ER = |n 日价格位移 (末价 – 首价)| / Σ(|n 日逐日收盘价绝对差|)
 - 分母严禁使用日内 High-Low 波幅替代。{n 日最高}{n 日最低} 仅用于计算 "区间波幅极值" 作为辅助验证指标，不混入 ER 分母。
 - **拦截准则**：若统帅提供的数据无法支持 ER 估算（如缺失区间起始价），系统自动触发 [数据真空锁死]，γ 强制取 1.25（极端防御位），直至物理值闭合。
- **【降级估算模式】**：若统帅仅提供四价（首/末/高/低）而无法提供逐日收盘价序列，系统承认此条件下无法产出精确 ER 值。强制切换为降级估算：
 - **周期默认**：若统帅未明确提供 n 日周期，系统默认 n = 20（与 ATR 20 日周期对齐）。若统帅对 n 有特定要求（如 10 日、60 日），必须在供弹时明确标注，否则一律按 n=20 强制执行。
 - 估算公式：ER ≈ |末价 – 首价| / (n × ATR_标的)，其中 ATR_标的 为统帅同步供弹或系统抓取的该标的 n 日平均真实波幅。若 ATR 亦不可得，使用 `|末价 - 首价| / n` 作为终极 fallback（严禁使用 (最高 – 最低) / n）。
 - **强制标注**：所有基于四价的降级估算必须在输出首行置顶标注："ER 降级估算模式：仅基于四价供弹，精确度下降，误差区间 ±15%，待完整逐日序列供弹后必须重新校准。"
 - **误差锁**：降级估算结果触发 3.1.1-A 战时算力降级协议，N 股数默认仅作为侦察参考。
 - **【四价降级估算上限封顶】**：若四价公式输出 ER > 0.5，系统强制截断至 0.5，并标注 "[四价降级估算触及上限：ER 锁定于 0.5，真实效率可能低于估算]"。防止无回调行情下的系统性高估。**【降级模式 γ 旁路协议 V20.56.20】**：降级估算模式下的 ER（无论截断前或截断后）**不参与 3.2 三区制 γ 映射**。降级模式 γ 取值独立规则：(a) 降级 ER 落入 [0.35, 0.50] → γ = 1.0（降级模式下的高效率区，等效于精确模式 ER>0.6）；(b) 降级 ER 落入 [0.25, 0.35) → γ = 1.25（模糊带保守）；(c) 降级 ER < 0.25 → γ = 1.25（噪音区）。此规则消除原 ER ≤ 0.5 截断与 3.2 ER > 0.6 强趋势区之间的结构断裂——降级模式下 ER 永远不会等于精确 ER，不能使用同一套 γ 映射。
 - **【降级估算模糊带 γ 保守取值】**：降级估算 ER 落入 [0.25, 0.35] 模糊带时，γ 强制保守取 1.25（噪音低效率区），严禁取 1.0。只有降级估算 ER > 0.35 时方可取 γ = 1.0；ER < 0.25 时 γ = 1.25。
 - **零波幅熔断**：零波幅熔断检查为降级估算的**第一顺位**。若末价 = 首价（n 日总波幅 = 0），直接输出 ER = 0.01（极低效率区），**跳过 ATR fallback 及分母计算**，严禁进入除零路径。γ 取 1.25，输出标注 "零波幅异常，ER 降级估算触发极端防御"。
- **【fallback 终极路径修正】**：若 ATR 亦不可得，取 ATR_fallback = `|末价 - 首价| / n`，分母 = `n × ATR_fallback = |末价 - 首价|`，此时 ER ≈ 1.0（当末价 ≠ 首价时）。**严禁将分母误写为 `|末价 - 首价| / n`（量纲错误，将导致 ER = n 的数学自杀）**。若末价 = 首价，直接触发零波幅熔断（ER = 0.01），严禁进入本 fallback 路径。若首价/末价缺失，触发 [ER 全真空]，γ 强制取 1.25，N 股数标记为 [不可测 算]，仅允许侦察参考，严禁作为开火依据。

### 3.3.1 数据真空默认防线 (ER-Vacuum Default Stop-Line)
- **触发条件**：统帅未提供 ER 值且原始数据无法支持估算（触发 [数据真空锁死]，γ 强制取 1.25），且统帅未在 /点火 指令中手动提供明确动态止损位时。
- **强制动作**：当 ER 处于真空状态，动态止损锚点强制默认取 2.7 × ATR 极端防御位，但须受 4.2.2 逐标绝对底线截断：若 2.7 × ATR < 买入价 × |abs_pct|，遵从 2.7 × ATR；若 2.7 × ATR > 买入价 × |abs_pct|，强制截断至逐标 abs_pct 硬线（QQQ=−5%、IAU=−7% 等，参见 4.2.2 逐标绝对底线表）。确保分母不为 Null，火控雷达不黑屏。

- **【统帅手动止损位与逐标硬线互锁】**：
 - 若统帅手动供弹止损位 **窄于 abs_pct**（如 −3% < |−5%|），遵从统帅输入，4.2.2 逐标底线不覆盖。

- **成本价止损**：浮盈后止损自动上移至成本价（GEMINI 零风险博弈协议）。
- **ATR 动态重算**：持仓期间 ATR 每 20 个交易日重算一次，止损乘数 k 不变，仅 ATR_entry 更新为最新值。

### 4.2.4 迈吉跟进止损 (Runaway Trailing Stop)
针对触发 [逃逸缺口] 的标的，止损锚定为：每日收盘价 - 1.5 * ATR。该线只升不降，严禁中途下移止损。

## 4.3 绝对止损线（生命线 · V20.56.1 逐标差异化）

### 4.9.1 连续止损簇休眠机制（V20.56.14 强化 · 从趋势追踪扩展至均值回归）

**背景**：V20.56.3 在 10.5.4 为趋势追踪模块（L1/L2）设立了「连续 3 次止损 → 休眠 60 日」机制。但三标回测暴露：均值回归体系的止损率在 0.5×ATR 参数下高达 73-89%，若不设休眠，震荡市一个月可触发 5-6 次止损，累计磨损 5-8%。V20.56.14 已将止损参数修正为 2.0×ATR + −5%，止损率预估降至 ~40-45%，但仍需休眠机制兜底。

**本条款将 10.5.4 的休眠机制扩展至均值回归体系**：

- **触发条件**：同一标的的均值回归体系（V20.56.0 MA20 区间买入）连续触发 **4 次止损**（基础止损 k×ATR 或绝对底线 −5% 触发均计入）。
- **熔断动作**：该标的的均值回归模块**自动休眠 60 个交易日**。休眠期间不产生任何买入信号，已持仓仓位仅执行止损/止盈，禁止加仓。
- **休眠解除**：60 日届满后自动解除，模块恢复待机状态。
- **审计理由**：即使止损率降至 40%，连续 4 次止损概率约 (0.40)⁴ ≈ 2.6%——已是小概率事件，说明标的处于持续下跌/高波动状态，不适合均值回归策略。60 日覆盖大部分中期趋势周期。
- **与 10.5.4 的关系**：两条休眠条款独立运行，互不干扰。趋势追踪模块的休眠不影响均值回归模块，反之亦然。
- **计数规则**：止损计数跨 60 日窗口滚动的，只计算最近 60 日内的止损次数。60 日前的止损自动过期清零。

# 第十章：趋势追踪模块 (Trend-Following Module) — V20.56.3 独立叠加层

## 10.1 设计哲学

V20.56.0 均值回归体系的核心 Trade-off：**用踏空换确定性**。QQQ 回测显示，均值回归在 $558→$588 区间连续 7 天发出买入信号，但从 $588→$682（+16%）全程悬空。趋势追踪模块的设计目标不是「抓住每一段涨幅」——而是**在均值回归体系完成底部建仓后，为标的脱离买入区间的趋势主升段提供有限仓位暴露**。

核心约束：
- 趋势追踪天然胜率低于均值回归（QQQ L1 回测胜率 50-60% vs 均值回归 86.1%），仓位必须更保守。

### 10.2.1 L1 触发细则

- **「连续 1 日收于 MA20 上方」**：以日线收盘价为准，盘中突破不计数。N=1 而非 N=2——全池 14 只逐标回测确认：N=2 不提高胜率，只减少信号（QQQ N=1 信号 58 次 vs N=2 信号 57 次，60d 均值 +1.4% vs +1.1%），多等一天只错过早期涨幅。
- **「量比 > 0.8」**：量比 = 当日成交量 / MA20 日均成交量。从 1.0 降至 0.8 的审计理由：全池回测显示量比从 1.0 降至 0.8 信号增加（QQQ 57→58 / MUFG 47→53）而收益无退化。量比条件因标的差异过大（MUFG/588000 量比显著有利，VNM/159545 量比有害），不可作为统一硬门槛——0.8 是「宽松过滤」，仅排除极端缩量突破。
- **L1 仓位 = 1.5%**（独立核算，不占用 V20.56.0 仓位额度）。

### 10.2.2 L2 触发细则

- **MA20 斜率 > 0.3%**：斜率 = (MA20_today − MA20_yesterday) / MA20_yesterday × 100%。
- **价格创新 5 日高**：当日最高价 > 前 4 个交易日最高价。
- **RSI(6) 50~75**：RSI < 50 说明趋势尚未形成，不触发；RSI > 75 说明已进入加速末端，性价比低——放过 QQQ 4/14~4/17 加速段（RSI 85-92）的代价是值得的，因为 RSI > 80 意味着进即接盘的概率大幅上升。
- **L2 仓位 = 3.0%（含 L1 试探仓）**，即 L1→L2 加仓 1.5%。

### 10.2.3 L3 离场触发

- **动能衰竭**：RSI(6) > 85 **且** 量比 < 0.6。两者必须同时满足——高 RSI 但有量能支撑说明趋势仍在加速，不触发。
- **强制离场**：跌破 MA20（收盘价为准）。这是趋势追踪的刚性止损线，不可协商。
- **L3 动能衰竭减仓 50% 后**，若后续触发强制离场，剩余 50% 全平。

## 10.5 风险控制

### 10.5.1 仓位隔离
- 趋势追踪仓位与 V20.56.0 均值回归仓位**独立核算**。

- L1 止损：跌破 MA20（日线收盘价为准）。
- L2 止损：MA20 − 1×ATR（较 L1 更紧，因为 L2 在趋势加速后入场，成本更高）。

### 10.5.4 连续止损心理熔断（V20.56.3 新增）

**触发条件**：同一标的的趋势追踪模块连续触发 3 次止损（L1 或 L2 止损，不含 L3 动能衰竭主动减仓）。

**熔断动作**：该标的的趋势追踪模块**自动休眠 60 个交易日**。休眠期间不产生任何 L1/L2/L3 信号。

**审计理由**：L1 胜率 30-43%。在随机游走市场中，连续 3 次止损的概率约为 (1−0.35)³ ≈ 27%——不是小概率事件。若不设熔断，震荡市可能一个月触发 5-6 次止损，累计磨损 5-8%。60 日休眠期覆盖大部分中期震荡周期，休眠结束后标的大概率已进入新的趋势或均值回归区间。

**休眠解除**：60 日届满后自动解除，模块恢复待机状态。休眠期间若标的触发 V20.56.0 均值回归买入信号，趋势追踪模块保持禁用（共存协议优先）。
