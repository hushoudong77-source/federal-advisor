## 一、设计原则

国内锚点不复制全球重力场（DXY/IEF/CRB），只填补「人民币资产池压强」的感知空白。

锚点准入三条件：
1. 物理可验证（有公开实时数据源）
2. 有区域传导力（能影响 A股/港股核心池标的）
3. 与核心池标的直接因果链路（非间接宏观叙事）

### §1.4.1 511260地位重构 + CN10Y替代锚点（V1.0r1焊入 — 修复P1-4流动性枯竭标的价格失真）

| 维度 | V1.0旧版 | V1.0r1 |

| 核心利率锚点 | 511260价格 | **CN10Y（中国10年期国债收益率）** |

**CN10Y替代规格**：

| 参数 | 值 | 说明 |
|---|---|---|
| 指标名 | 中国10年期国债到期收益率（中债估值） | 中债登 chinabond.com.cn 每日18:00发布 |
| 对撞矩阵列名 | CN10Y（替代原「511260」列） | 对撞矩阵中所有「511260」引用替换为「CN10Y」 |
| 触发条件 | **CN10Y单周跳升 > 15bp**（非绝对阈值）🟡 预标定（统计推断，未回测 — V1.0r2标记P1-4） | 基于2019-2024 CN10Y周度变动的95%分位数≈14bp，取15bp。回测Deadline: 2026-06-15。执行层日志强制标注「CN10Y 15bp阈值待回测验证」 |
| 方向判定 | CN10Y↑ = 跌（利率上行=债市下跌）<br>CN10Y↓ = 涨（利率下行=债市上涨） | 与511260价格方向一致 |
| 数据源 | P0: 中债登API / P1: Wind/Choice / P2: web_search「中国10年期国债收益率」 | 三级降级链 |

**CN10Y阈值设计原理**：

```
CN10Y 2019-2026历史区间：
  2019-2020: 2.5%-3.4%（常态）
  2021-2022: 2.6%-3.3%（窄幅）
  2023-2024: 2.1%-3.0%（下行通道）
  2025-2026: 1.55%-1.9%（超低利率新常态，2026年5月新发国债票面1.72%）

❌ 绝对阈值（如CN10Y>2.80%）不可用：
  → 2025年后CN10Y从未超过2.0%，2.80%阈值在可预见未来永不触发=死条件
  → 中国进入超低利率时代，绝对阈值随时代漂移

✅ 跳升阈值（单周>15bp）：
  → 捕捉「流动性突然收紧」的信号，不受绝对水平影响
  → 2024年9月政策转向周CN10Y跳升+22bp（2.1%→2.32%）→ 此信号被捕获
  → 2025年以来CN10Y周度波动中位数=5bp，15bp=3倍中位数=显著异常
```

**对撞矩阵列名替换**：

原矩阵中所有 `511260` 列替换为 `CN10Y`，方向映射：
- 511260 涨（价格↑）= CN10Y↓（利率↓）
- 511260 跌（价格↓）= CN10Y↑（利率↑）

**V1.0旧版5组合已废弃**（缺少组合⑥/⑧，SHIBOR触发过度敏感，CNH未量化，511260无有效性过滤，无CN10Y替代）

### §1.1.1 SHIBOR流动性红绿灯（V1.0r1焊入 — 修复P0-4过度敏感）

| 灯色 | 条件 | 动作 |
|---|---|---|
| 🟢 绿灯 | 跳升≤10bp AND 绝对值≤1.70%（V1.0r2修正：删除表格与公式冲突的第二条件） | 正常速度 |
| 🟡 黄灯 | 跳升>10bp AND 绝对值≤1.50% | 预警，不降速，日志记录 |
| 🟠 橙灯 | 跳升>10bp AND 绝对值1.50%-1.70% | 进攻降速25%，反击不变 |
| 🔴 红灯 | 跳升>10bp AND 绝对值>1.70%  OR  连续两周跳升>10bp  OR  绝对值>1.70%（跳升≤10bp时） | 进攻降速50%，反击上限锁死 |

**V1.0r2修正说明（修复P0-3公式表格互斥）**：
- 原表格🟡第二条件「绝对值1.50%-1.70%」与公式输出矛盾：跳升≤10bp且绝对值1.60%时，公式→🟢，表格→🟡
- 修正：表格以公式为准。🟡仅「跳升>10bp AND 绝对值≤1.50%」。绝对值1.50%-1.70%且跳升≤10bp→🟢（跳升不足，非趋势性收紧）

```
SHIBOR_ALERT = 
  IF (ABS(本周SHIBOR - 上周SHIBOR) > 0.10%) THEN
    IF (本周SHIBOR > 1.50%) THEN
      IF (本周SHIBOR > 1.70%) → 🔴
      ELSE → 🟠
    ELSE → 🟡
  ELSE
    IF (本周SHIBOR > 1.70%) → 🔴
    ELSE → 🟢
```

参数硬编码：10bp（2019-2024季节性波动95%分位=9bp）/ 1.50%（75%分位） / 1.70%（2020年疫情后最高值1.75%的近似阈值）

V1.0旧版「单周跳升>10bp OR >1.70%」→ 当前1.417%跳至1.517%即触发但绝对值仍极低，过度敏感
