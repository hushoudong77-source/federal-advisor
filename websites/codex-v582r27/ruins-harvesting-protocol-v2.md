## 一、协议定位

**废墟收割协议**是联邦投顾系统的极端行情捕捉模块，与常规进攻/反击策略并行运行，互不干扰。

- **触发条件**: 市场恐慌性暴跌（Z_atr极端偏离）
- **核心逻辑**: 利用市场情绪极端偏离进行逆向布局
- **适用标的**: 高波动港股ETF（Channel A）
- **资金隔离**: 与进攻/反击资金物理隔离，独立止损

## 二、M3 双参数体系（核心固化条款）

### 2.1 参数矩阵（不可谈判）

| 参数 | 代码 | 数值 | 说明 |
|:---|:---|---:|:---|
| Z_atr解锁阈值 | cond④a | **-2.50** | 市场恐慌确认线，跌破即解锁观察 |
| 买入触发阈值 | cond⑤a | **-1.25** | 反弹买入触发线，从④a区间反弹至此执行建仓 |
| Z_atr计算窗口 | — | 252日 | 与波动率状态机保持一致 |
| ATR计算周期 | — | 14日 | 法典全局统一标准 |
| 量能确认阈值 | cond④b | MA20_V × 1.0 | 恐慌需伴随放量 |

### 2.2 触发逻辑（双条件串联）

```
条件④: 市场恐慌确认（解锁观察）
├── ④a: Z_atr < -2.50
├── ④b: 当日成交量 > MA20_V × 1.0
└── 逻辑: ④a AND ④b → 解锁废墟收割观察模式

条件⑤: 买入触发（执行建仓）
├── ⑤a: Z_atr 从④a区间反弹至 -1.25（当日收盘价≥-1.25且前日<-2.50）
├── ⑤b: 当日未触发止损条件
└── 逻辑: ⑤a AND ⑤b → 执行第一批次建仓（30%目标仓位）
```

### 2.3 建仓与止损

| 阶段 | 动作 | 仓位 | 触发条件 |
|:---|:---|---:|:---|
| 第一批次 | 买入 | 30% | 条件⑤触发 |
| 第二批次 | 买入 | 70% | 第一批次持仓收益≥+3%或持仓≥5日 |
| 止损 | 卖出 | 100% | SRC-6 -15% 或 Z_atr 重新跌破 -2.50 |

**正金字塔建仓**: 第一批次30%试探，确认反弹后第二批次70%加满。禁止倒金字塔。

```

假废墟率 = 假废墟笔数 / 总触发笔数

目标: <15%
实际: 14.4% ✅
```

## 五、执行规则

### 5.1 与反击策略的隔离

| 维度 | 废墟收割 | 反击策略 |
|:---|:---|:---|
| 触发逻辑 | Z_atr极端偏离 | 价格触及MA60买入区间 |
| 适用标的 | Channel A四标 | 全池17标（含红利层） |
| 资金池 | 独立，¥32,000上限 | 独立，与进攻/固定层隔离 |
| 止损线 | SRC-6 -15% 或 Z_atr<-2.50 | 统一2.0×ATR+SRC-6 -15% |
| 并行规则 | 可与反击同时持仓同一标的 | 同上，仓位独立计算 |

### 5.2 日内执行流程

```
Step 1: 11:30 盘中检查
├── 计算四标的当前Z_atr
├── 检查是否跌破-2.50（解锁观察）
└── 标注状态: 🔒锁定 / 👁️观察 / 🎯待触发

Step 2: 14:55 收盘前确认
├── 若Z_atr从<-2.50反弹至≥-1.25
├── 检查量能条件（成交量>MA20_V）
└── 确认无止损触发 → 执行第一批次买入

Step 3: 持仓管理
├── 每日计算Z_atr位置
├── 监控SRC-6止损线
└── 第一批次达标后执行第二批次
```

### 5.3 熔断条件

| 条件 | 动作 |
|:---|:---|
| Z_atr重新跌破-2.50 | 无条件止损，全仓离场 |
| SRC-6触发-15% | 无条件止损，全仓离场 |
| 单标持仓超¥8,000 | 禁止新开仓 |
| 总持仓超¥32,000 | 禁止新开仓 |
| 与反击同标持仓 | 允许，仓位独立计算 |
