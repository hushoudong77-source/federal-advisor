## §1 数据输入层 (Data Input)

> 功能：17 只标的每日收盘价、EMA、ATR、成交量等标准化数据包的接收与计算

### 1.1 自主计算层

系统基于 Tushare 日线数据自主计算以下技术指标：

| 指标 | 计算方法 | 数据源 |
|:---|:---|:---|
| 50EMA/150EMA/30EMA | 递归EMA公式 | Tushare pro.us_daily / pro.fund_daily / pro.index_daily |
| ATR(14) | Wilder平滑法 | Tushare |
| H20（20日最高价） | max(Close[-20:])，不含当日 | Tushare |
| 20日均量 | mean(Volume[-20:]) | Tushare |
| RSI(6) | Wilder方法 | Tushare |
| RSI(14) | Wilder方法 | Tushare |
| MACD Hist | 12-26-9 | Tushare |
| 乖离率 | (C−150EMA)/150EMA | Tushare |
| 800005/000922等宏观锚定指数 | 日线OHLCV | Tushare指数接口，每日更新 |

### 1.1.1 扫描前数据完整性强制校验（V5.8.2r6焊入）

**规则一：拉取即填表**
Tushare数据拉取成功后，必须在30秒内将OHLCV/EMA/ATR/H20/20日均量填入标的分析表格对应列。禁止数据已在内存但表格列为"—"。

**规则二：MA锚线自算义务**
各标的锚线方向（如MA20方向、MA60方向）必须基于拉取的OHLCV数据自行计算。禁止输出"⏳需P0"占位符。唯一例外：当日收盘价尚未被Tushare收录时标注"Tushare最新:YYYY-MM-DD"。

**规则三：表格输出前自检清单**
```
□ 所有EMA列均无"—"占位符
□ 所有MA锚线方向无"⏳需P0"占位符
□ 所有ATR列已填充数值
□ 所有H20/20日均量列已填充数值
□ 数据缺口标注格式统一（"EMA基值日期: YYYY-MM-DD (T-1)"）
□ Tushare最新日期已统一标注
```

**规则四：违规熔断与数据降级**
表格输出中出现"—"/"⏳需P0"/"待算"占位符 → 立即中止输出，重新计算填表后重新输出。累计违规≥3次 → 当日剩余报告禁止输出，标记「数据完整性违规-暂停报告」。

**规则四-降级：数据不可用场景豁免【V5.8.2r22新增】**
以下场景不触发违规熔断：
- 标的停牌：该标的数据包标记「停牌-跳过」，路由层输出「🔴停牌-维持上日状态」
- 节假日无数据：该标的数据包标记「节假日-跳过」，路由层输出「🔴节假日-维持上日状态」
- Tushare接口故障：该标的数据包标记「接口故障-跳过」，路由层输出「🔴数据缺失-维持上日状态」
- 次日数据恢复后自动恢复正常扫描
- 违规熔断仅针对：数据已拉取成功但计算/填表失败（系统内部错误）

## §4 宏观闸：波动率状态机（r24全量重构）

> **r24 重构说明**：原§4固定阈值体系（US10Y≥4.50%预警/US10Y>8bp禁A股科技/VIX>3点禁创业板）全部废除。固定阈值存在三处物理缺陷：(1) US10Y≥4.50%预警——63笔样本，高利率期=牛市期，预警无预测力；(2) US10Y>8bp禁A股科技——348笔样本显示>8bp后反而好，标的针对性无数据；(3) VIX>3点禁创业板——VIX数据硬编码不可执行。替代方案：ATR14波动率分位状态机——不是禁止开火，而是在ATR窄时减少暴露（窄ATR→被震出概率更高）。

> **事件标签时效规则**：详见路由§2.1 步骤0-E（🚨地缘48h/📋政策24h/⚡黑天鹅72h/📊宏观24h仅标注/💬叙事当日清除）。

### 4.1 波动率状态机核心逻辑

**设计哲学**：不是"禁止开火"，而是"根据波动率环境调整仓位和止损带宽"。窄ATR意味着被震出的物理概率更高——收紧止损+减半仓位是对账户的物理保护。

### 4.2 状态定义与参数

| 状态 | ATR14分位 | 仓位系数 | 止损带宽 | 逻辑 |
|:---|:---|:---|:---|:---|
| **A（高波动）** | > P70 | 1.0×（正常） | 1.0× | ATR已膨胀，无需再放宽 |
| **B（中波动）** | P30 ~ P70 | 1.0×（正常） | 1.0× | 标准执行 |
| **C（低波动）** | < P30 | **0.5×（减半）** | **0.8×** | 窄ATR易被震出，减少暴露+收紧止损 |

### 4.3 分位窗口与计算

```
分位窗口: 252天（约174个交易日）
分位计算: 滚动窗口，每日更新
例外条款: |当前ATR − 窗口ATR均值| > 2σ → 强制状态A（波动率突变保护）
```

**例外条款设计逻辑**：252天窗口在波动率regime切换时可能出现滞后（如2022年Q2俄乌冲突后，窗口仍用低波动历史判断当前中波动）。2σ例外条款确保波动率突变时立即切换到高波动保护模式。

### 5.6 回测诚实化条款（r24焊入）

#### 5.6.1 摩擦成本

```
所有回测必须计入摩擦成本 = 0.15%/笔（买卖各0.15%，合计0.30%往返）
→ 覆盖：佣金 + 滑点 + 冲击成本
→ 计算方式：每笔交易净利润 = 原始净利润 − 交易金额 × 0.15%
→ 此前未计入摩擦成本的回测结果需重新计算后方可作为参数依据
```

#### 5.6.2 极端值排除

```
极端值定义：单笔收益率超过全样本均值 + 5σ
→ 排除条件：该笔交易收益率 > mean(全部交易收益率) + 5 × std(全部交易收益率)
→ 排除后重新计算PF/胜率/总收益
→ 排除的交易需记录：标的/日期/收益率/排除原因
→ 排除不是删除——保留在交易日志中，仅从统计指标计算中剔除
```

#### 5.6.3 反击系统物理死亡判定（跨文件引用：counterpunch §3.2.4）

```
反击触发笔数门槛：全池回测（2018-2026）中反击触发笔数 < 50笔
→ 后果：该版本反击规则无效，恢复至上一触发≥50笔的版本
→ 例外：守东P0指令可强制激活（主权覆写）
```

### 5.7 利润集中度硬顶（r24焊入）

**设计意图**：利润过度集中于单一标的/资产类别时，一旦该标的/类别转势，账户利润将被大量抹去。硬顶是对账户的物理保护，非对标的的否定。

#### 5.7.1 建议阈值规则（r27.1主权指令覆盖：原硬顶降级为建议阈值）

| 层级 | 建议阈值 | 计算口径 |
|:---|:---|:---|
| **单标** | 利润贡献 ≤ 20% | max(浮盈占比, 已实现占比) |
| **黄金合并** | IAU + 518880 利润贡献 ≤ 25% | max(IAU浮盈+518880浮盈, IAU已实现+518880已实现) |

**计算口径说明**：取浮盈和已实现中较大者——最保守口径。触发后输出预警，最终减仓决策权归守东。

#### 5.7.2 触发机制

```
方案C（r24原版）→ r27.1主权指令覆盖：
  ├── 触发后立即预警（输出超限标的/当前占比/建议阈值/超限金额）
  ├── 最终减仓决策权归守东（主权指令覆盖）
  ├── 联邦投顾角色：输出基于法典参数的建议 + 风险陈述
  └── 频闪保护：48h冷却期内不重复触发预警
```

#### 5.7.3 减仓算法

```
单标硬顶：
  超限部分 = max(0, 当前利润贡献 − 20%) × 总账户权益
  减仓金额 = 超限部分
  减仓股数 = floor(减仓金额 / 现价)

黄金合并硬顶：
  黄金敞口利润 = IAU利润 + 518880利润
  超限部分 = max(0, 黄金利润贡献 − 25%) × 总账户权益
  减仓标的 = 利润贡献更大的那一个（IAU或518880）
  减仓金额 = 超限部分
```
