## 零、固定层宪法（§0 — V5.8.2r24）

> 详参 `v56-constitution.md`

**VEA 20% + VTI 10% = 固定底仓30%，永不离场。**

### 核心属性

| 属性 | 内容 |
|:---|:---|
| 路由豁免 | 不进入进攻/反击路由 |
| 止损豁免 | 不设任何技术指标自动离场 |
| 宏观熔断 | US10Y≥5%→禁止清仓，允许权重修正卖出+SRC-5 TWAP减仓 |
| 卖出禁令 | 任何情况下不得清仓固定层（权重修正≠清仓） |

### 三向死锁优先级矩阵

```
优先级0（最高）：现金主权率5%硬底 → 不可突破
优先级1：US10Y≥5.00% → 禁止再平衡买入，允许超配卖出+SRC-5减仓
优先级2：固定层再平衡义务 → 仅0和1均未锁死时执行
```

### 现金主权率三态

| 状态 | 现金主权率 | 规则 |
|:---|:---|:---|
| A 正常 | >8% | 所有操作正常 |
| B 警戒 | 5%~8% | 非固定层开仓半速消耗 |
| C 硬底 | ≤5% | 禁止一切买入，仅允许卖出/止损 |

### 固定层与策略层接口

```
VTI/VEA建仓后：
├── SRC-5（US10Y≥5%）→ 自动TWAP减仓至目标权重50%
├── SRC-1~4/6 → 仅告警，需P0手动确认
└── 再平衡卖出 → 自动执行
```
