**注意**：IAU 不在趋势池中。若守东要求美股黄金敞口，需单独讨论。

### 3.2 入场条件（四维共振，缺一不可）

| 维度 | 条件 |
|:---|:---|
| **均线** | 价格 > MA（IVV/QQQ/518880=MA200，510300=MA120） |
| **站稳** | 连续3个交易日收盘 > 均线 |
| **动量** | ADX(14) > 25 |
| **成交量** | T0量 > 20日均量×1.2 **且** T+1量 ≥ 20日均量 **且** T+2量 ≥ 20日均量 |

### 3.3 仓位公式（双重约束，取更保守者）

```python
# 第一步：计算初始止损价
initial_stop = max(ma, entry_price - 2.5 * atr_14)
# ma = 该标的锚定均线（MA200或MA120）

# 第二步：1%风险法则 → 股数
risk_per_share = entry_price - initial_stop
shares_risk = int( total_asset * 0.01 / risk_per_share )

# 第三步：7.5%上限 → 股数
shares_cap = int( total_asset * 0.075 / entry_price )

# 第四步：取更保守者
shares = min(shares_risk, shares_cap)
```

### 3.4 调仓频率

- **入场信号检查**：每月第一个交易日
- **盘中监控**：仅监控离场信号，不监控入场信号

### 3.5 离场条件（优先级自上而下）

| 优先级 | 信号 | 动作 |
|:---:|:---|:---|
| **P0** | 当前价 < 入场价 × 0.92 | 立即全清（-8%绝对止损，从成本价计算） |
| **P1** | 当前价 < 入场后最高价 − 2.5×ATR(14) | 清仓（追踪止损，与P0先到者执行） |
| **P2** | 价格下破均线（IVV/QQQ/518880=MA200，510300=MA120） | 月末确认后清仓 |
| **P3** | ADX(14) < 20 | 月末确认后清仓 |

**P0说明**：-8%从成本价计算（`entry_price × 0.92`），不是从最高点回撤。确保安全气囊功能（保本），同时让利润奔跑。

### 3.6 建仓节奏

- 趋势跟踪仓位在总仓位建仓期（第1-4周）逐步建立
- 第1周若月频信号满足 → 买入该标的总趋势仓位的1/4
- 第2周 → 再买1/4（若信号仍满足，或前月已确认的持仓补满）
- …以此类推
- 第13周加仓期：趋势跟踪从10%加至20%，各标的趋势仓位按上限比例放大

## 第四章：法典卫星（20%，休眠层）

### 4.1 激活条件

- ADX(14) < 20 **持续60个交易日**（约3个月） → 激活
- 激活后适用法典 V20.56.27a 全部规则
- 激活前：20%资金存放于货币基金/SGOV

### 4.2 冲突解决

- 标的一旦被趋势跟踪持有 → 打上 **TREND_LOCKED** 标签
- TREND_LOCKED 期间，法典对该标的的一切买卖信号 **物理屏蔽**
- 趋势清仓后 → TREND_LOCKED 解除 → 标的重新进入法典扫描池

### 4.3 休眠状态

- 不执行日频扫描，不产生交易
- 资金年化约5%（货币基金/SGOV）

## 第五章：冲突解决协议（附则）

### 5.1 战术互斥：趋势 vs 法典

- 任何标的一旦满足趋势跟踪入场条件并建仓，即刻触发 **TREND_LOCKED** 状态标签
- TREND_LOCKED 存续期间（趋势仓位未触发离场信号前），系统**物理屏蔽**该标的在日频扫描中产生的一切法典均值回归买卖信号
- **严禁**同一标的在趋势侧和法典侧同时持有
- 若法典卫星池激活时，某标的已被趋势跟踪持有，该标的对法典信号免疫，对应资金自动分配至法典池其他标的；若法典池无其他可用标的，该部分资金**暂存货币基金**，不强制开仓

### 5.2 底仓并行：国运 vs 趋势

- 国运底仓与趋势战术仓允许在同一标的上叠加持有（如518880既在国运底仓5%，又在趋势池中）
- 系统内部划分为两个**独立虚拟子账户**：
  - **Sub-A（国运底仓）**：长期持有，年度再平衡，仅因主权级风险一次性清仓
  - **Sub-B（趋势战术仓）**：上限7.5%，月频进出，按第三章规则独立核算
- 趋势出场信号**仅清空 Sub-B 战术仓位**
- 国运底仓不受趋势信号影响，**严禁连带抛售**

### 5.3 状态机优先级（自上而下执行）

```
P0: 宏观熔断（全局暂停新开仓，但不影响国运底仓）
P1: 国运底仓（仅受年度再平衡/主权红线管辖，永不动）
P2: 趋势跟踪（TREND_LOCKED期间主导该标的，法典信号屏蔽）
P3: 法典均值回归（仅在标的未被TREND_LOCKED时生效）
P4: 现金/货币基金（默认状态）
```
