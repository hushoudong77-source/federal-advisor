## §0 固定层宪法 (Permanent Base Layer)

### 0.1 宪法地位

**VEA（20%）+ VTI（10%）构成全局资产的固定底仓层，总权重 30%。**

固定层具有以下不可侵犯属性：

| 属性 | 内容 |
|:---|:---|
| **路由豁免** | 不进入第二段路由判断。永远不被分配到进攻/反击/闲置轨道 |
| **策略豁免** | 不适用 Spearhead/Counterpunch 的任何入场/离场规则 |
| **止损豁免** | 不设 ATR 止损、绝对底线止损、动态止盈——没有离场条件 |
| **宏观熔断豁免** | US10Y≥5.00%、VIX≥35、涨跌比<30% 等宏观闸对固定层无效 |
| **战时满载豁免** | S1/S2 满载态不改变固定层权重 |
| **唯一操作** | 仅执行年度再平衡（恢复至 VEA 20% / VTI 10% 目标权重） |
| **卖出禁令** | 除年度再平衡卖出超配部分外，**任何情况下不得清仓固定层** |

### 0.2 再平衡触发条件

| 触发类型 | 条件 | 操作 |
|:---|:---|:---|
| **年度再平衡** | 每年 12 月首个交易日 | VEA 恢复至 20%，VTI 恢复至 10% |
| **偏离触发** | 任一标的权重偏离目标 ±5pp（VEA<15% 或 >25%，VTI<5% 或 >15%） | 立即再平衡至目标权重 |
| **新增资金** | 全局总资产因外部注资增长 ≥20% | 按 20%/10% 比例增配 VEA/VTI |

### 0.3 再平衡执行规则

```
1. 计算当前 VEA/VTI 市值
2. 计算目标市值 = 全局总资产 × 目标权重（20%/10%）
3. 差额 = 目标市值 − 当前市值
4. 正差额 → 从现金账户划拨资金买入
5. 负差额 → 卖出超配部分，资金回笼现金账户
6. 执行后固定层权重精确恢复至 20% + 10%
```

### 0.4 固定层与全局资产的关系

```
全局资产
├── 固定层 30%（VEA 20% + VTI 10%）← 本宪法管辖，永不离场
├── 竞争上岗池（进攻 + 反击，资金动态进出）← 双轨法典管辖
└── 现金（不在仓的所有资金，用户自行管理停放）
```

**固定层不计入竞争上岗池可用资金。** 现金层 = 全局总资产 − 固定层市值 − 已占用进攻/反击仓位市值。

## 第二段：路由判断 (Routing Logic)

### 2.0 路由总则

全池19只标的携带标准化10字段数据包进入路由层，分配到三个轨道之一：
- 🟢 **进攻策略**：顺势加仓，七条件全满足
- 🟡 **反击策略**：逆势接飞刀，MA200走平/向下 + 价格落入买入区间
- ⚪ **闲置**：不满足任何条件，资金留在现金层

**核心原则**：一标一轨 / 已持仓豁免路由重判 / 路由仅决定新资金去向 / 反击锚点前置 / 固定层（§0）不进入路由。

```

    0-B 国际：VIX ≥ 35 → 🔴美股/港股关闭 / VIX ≥ 25 → 反击关闭

  步骤0-E：事件预警标签（非阻断，仅标记，四分类+疲劳机制）
  步骤0.5：极端乖离拦截 → (C−MA200)/MA200 > 50% → 🔴观望
```

### 3.1 进攻策略 (Spearhead Protocol) — 全量内嵌

**核心哲学**：纯趋势跟随。不预判，只跟随。唯一防线 = 3×ATR trailing stop。

#### 3.1.1 入场信号（四项全满足）

| # | 条件 | 说明 |
|:--|:---|:---|
| ① | MA200 方向向上 | 中长期上升趋势确立（与路由层A2一致） |
| ② | MA30 方向向上 | 中短期动能向上（与路由层A4一致） |
| ③ | 收盘价 > MA200 | 价格在长期均线之上（与路由层A1一致） |
| ④ | 收盘价 ≥ 20日最高价 | 突破确认，趋势加速信号（与路由层A7一致） |

**判定频率**：每日收盘后，基于日线数据判定。
**不设宏观过滤器**：子账户隔离 + 3×ATR trailing stop 即为最终防线。

#### 3.1.2 仓位与建仓

**资金池**：独立子账户，全局总资产的 10%–15%。

**首发仓位计算**：
```
N₁ = (全局总资产 × 1%) / (入场价 − 3×ATR)
```
分母 = 入场价 − 3×ATR = 若触发止损的最大单股亏损。N₁ = 单次风险暴露 = 全局总资产1%。

**加仓序列（反等价鞅 — 盈利加仓）**：

| 批次 | 触发条件 | 数量 |
|:---|:---|:---|
| 第一发 | 入场信号触发 | N₁ |
| 第二发 | 浮盈 ≥ 2R | N₁ × 50%（递减） |
| 第三发 | 第二发后浮盈再 ≥ 1R | N₁ × 25%（再递减） |

**单标上限 — 8% 硬顶**：

| 铁律 | 内容 |
|:---|:---|
| 一 | N₁ 占满 8% → 终生禁止加仓该标的 |
| 二 | N₁ + N₂ 达 8% → 永久取消第三发 |
| 三 | 严禁为凑三发主动压减 N₁ |

#### 3.1.3 离场机制 — 唯一防线

**3×ATR Trailing Stop**：
```
买入即挂载：最高价回撤 3×ATR 追踪止损
触线 → 市价全清，无例外
未触线 → 死咬利润，不设上限
```

**废除的冗余防线**（全部移除）：
- ❌ MA30 跌破离场（剧烈洗盘常击穿MA30）
- ❌ 时间止损（高位旗形震荡是主升前常态）
- ❌ MA200 转势离场（数学上永远比3×ATR晚触发）
- ❌ 固定止损等1R（推迟挂载=拉长风险暴露窗口）

#### 3.1.4 宏观过滤器

**不加。** 决策逻辑：
1. 子账户隔离已定价尾部风险：10%–15%资金池，最坏全损上限已知
2. 3×ATR双向滞后：跳空打穿多亏1-2R，但V型反弹时不关闸能吃到
3. 纯跟随哲学：不预判，只跟随

#### 3.1.5 与反击策略冲突解决

```
ATTACK_LOCKED：进攻持仓中
  → 反击策略对该标的：买入信号屏蔽 / 卖出信号屏蔽
  → 唯一离场：3×ATR trailing stop

ATTACK_UNLOCKED：进攻清仓后
  → 反击策略恢复对该标的的完整管辖权
```

| 场景 | 进攻状态 | 反击信号 | 裁决 |
|:---|:---|:---|:---|
| ① 双向暴露 | 持仓中 | 买入信号 | **禁止叠加**，ATTACK_LOCKED |
| ② 信号冲突 | 持仓中 | 卖出信号 | **反击卖出无效**，3×ATR是唯一离场 |
| ③ 无冲突 | 无持仓 | 买入信号 | 各自独立执行 |

### 3.2 反击策略 (Counterpunch Protocol) — 全量内嵌

**核心哲学**：逆势接飞刀——在价格跌到锚线−k×ATR的恐慌区间分批建仓，在价格弹回卖出区间或触发止损时离场。

#### 3.2.2 仓位与建仓

**仓位分档规则**：

| 分档 | 批次 | 单批比例 | 适用梯队 |
|:---|:---|:---|:---|
| **低风险** (T1) | 2批 | 50% + 50% | QQQ/IVV/510300/513910/159545 |
| **中风险** (T2/T3-A/T4) | 3批 | 50% + 30% + 20% | BBJP/MUFG/EWY/VNM/FLIN/510500/159302 |
| **高风险** (T3/T3-B) | 3批 | 33% + 33% + 34% | 159915/588000/513770/513180 |

**建仓执行**：
```
第一批（先锋）：价格首次落入买入区间 → 按分档比例建仓
第二批（加仓）：价格继续下探至买入区间下界附近 → 加仓
第三批（满仓）：价格触及下界或以下 → 满仓（仅中/高风险分档）
```

**单标上限**：MA200走平 ≤10% / MA200向下 ≤5%。与进攻策略合并不得突破单标总暴露 ≤20%。

**股数计算**：
```
N = (动态总资产 × 1%) / (入场价 − 止损位)
止损位取 max(入场价 × |−5%|, 入场价 − 2.0×ATR) 即取两者中较宽者
黄金类标的绝对底线为 −7%
```

#### 3.2.3 离场机制 — 卖出六源

任何持仓标的的减仓/清仓指令，必须且仅能由以下六源之一触发：

| 编号 | 卖出源 | 触发条件 | 动作 |
|:---:|:---|:---|:---|
| SRC-1 | **基础止损** | 价格 ≤ 成本 − 2.0×ATR(14) | 市价全清 |
| SRC-2 | **绝对底线** | 价格 ≤ 成本 × (1 − abs_pct) | 市价全清，物理下限 |
| SRC-3 | **动态止盈** | 价格 ≤ 建仓以来最高收盘价 − sell_k×ATR | 市价全清 |
| SRC-4 | **锚线跌破** | 收盘价 < MA 锚线（逐标差异） | 收盘确认后清仓 |
| SRC-5 | **趋势追踪 L3** | 趋势追踪 L3 信号触发 | 按趋势追踪规则减仓 |
| SRC-6 | **宏观熔断** | DXY/CRB/IEF/US10Y/SHIBOR/VIX 熔断触发且明确指向该标的 | 按熔断规则执行 |

**止损统一公式**：
```
止损位 = max(成本 − 2.0×ATR, 成本 × |−abs_pct|)
```

| 标的分类 | k（ATR乘数） | abs_pct（绝对底线） |
|:---|:---:|:---:|
| 全池（除黄金） | 2.0×ATR | −5% |
| 黄金类 (IAU/518880) | 2.0×ATR | −7% |

**硬下限互锁**：若2.0×ATR推算止损位 < 成本×|−5%| → 以2.0×ATR为准（更宽松）/ 若 > → 强制截断至−5%硬线（物理下限）。

**动态止盈公式**：
```
止盈跟踪线 = 建仓以来最高收盘价 − sell_k × ATR(14)
价格触及跟踪线 → 市价全清
```
