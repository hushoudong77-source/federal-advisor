### 1.2 标准化数据包（输出到路由层）

每个标的经过数据输入段后，输出以下标准化数据包：

```json
{
  "ticker": "QQQ",
  "C": 694.94,           // 现价（交易日=收盘价，休市日=最近交易日收盘价）
  "MA30": 680.50,        // 30日简单移动均线
  "MA200": 640.20,       // 200日简单移动均线
  "ATR14": 15.30,        // 14日平均真实波幅
  "ADX14": 28.5,         // 14日平均趋向指数
  "MA200_direction": "up", // MA200方向：up/down/flat
  "MA30_ATR乖离": 0.94,  // (C − MA30) / ATR14
  "VIX": 17.23,          // CBOE波动率指数（统帅供弹）
  "US10Y": 4.38,         // 10年期美债收益率（Tushare）
  "DXY": 97.91           // 美元指数（统帅供弹）
}
```

**休市日规则**：非交易日（周末/节假日）使用最近一个交易日的收盘价，不额外标记。
**字段说明**：`C`=路由层判定基准线 / `MA30`=反击策略入场区间下界基准 / `MA200`=进攻策略方向判定+趋势过滤器 / `ATR14`=反击策略买入区间宽度计算 / `ADX14`=进攻策略趋势强度确认（A5动态修正依赖） / `MA200_direction`=进攻准入硬条件 / `MA30_ATR乖离`=反击策略入场精度

---

### 1.3 数据获取优先级（强制执行）

```
P0: 用户当前消息中直接提供的数据 → 最高权威
P1: 当日+前日记忆文件 → 准P0
P2: 长期记忆 MEMORY.md → 持仓/参数等固化数据
P3: Tushare 付费数据源 → OHLCV + US10Y
P4: 知识库 → 开火档案/法典条款
P5: 免费数据源 (mx-data / Yahoo / web_search)
```

**冲突裁决**：P0 > P1 > P2 > P3 > P4 > P5。Tushare与免费源冲突时以Tushare为准。

## 第二段：路由判断 (Routing Logic) — V4.2 修正版

### 2.0 路由总则

**入口**：全池19只标的，每个标携带标准化10字段数据包进入路由层。

**分岔**：每个标的被分配到以下三个轨道之一：
- 🟢 **进攻策略 (Trend Following)**：顺势加仓，趋势确认+创20日新高
- 🟡 **反击策略 (Mean Reversion)**：逆势接飞刀，MA200走平/向下+价格落入买入区间
- ⚪ **闲置**：不满足任何条件，对应资金留在现金层，用户自行决定停放 511880/SGOV 或等待

**核心原则**：
- 一个标的在同一时刻只能属于一个轨道
- 已持仓标的豁免路由重判——不会因为路由变化被强制卖出
- 路由判断仅决定「新资金可以往哪配」，不决定「现有持仓要不要卖」
- **反击锚点前置**：买入区间判定在路由层完成，策略层只接收可执行的标的

### 2.2 路由规则解释 — V4.2 修正详情

#### 2.2.1 进攻轨道（步骤1）— A5 动态ADX修正

**V4.1的A5缺陷**：一刀切 ≤3×ATR 的乖离过滤，在强趋势环境中拦截了QQQ、IVV、510500等主力标的。QQQ在ADX=68.8时乖离5×ATR是趋势延续的正常状态，不是事件驱动末端的狂热信号。

**V4.2修正逻辑**：

| ADX区间 | A5判定 | 原理 |
|:---|:---|:---|
| ADX > 30 | **禁用**，不检查乖离 | 强趋势中价格沿布林带上轨运行是常态，乖离大≠过热 |
| ADX ≤ 30 | ≤ 5×ATR | 中等/弱趋势，给予更多空间（ADX≤20时A6失败→不进进攻，第三档为死代码已删除） |

**释放标的**（基于5/8收盘）：QQQ(ADX=68.8)、IVV(ADX=46.0)、VNM(ADX=61.4)、510500(ADX=64.6)、510300(ADX=72.4)、159915(ADX=63.5)、588000(ADX=75.2)、159545(ADX=33.2) 全部从A5拦截中释放。

#### 2.2.2 进攻轨道（步骤1）— A7 0.5%容差修正

**V4.1的A7缺陷**：0.1%容差 (×0.999) 无法处理ETF收盘前的买卖盘摩擦、尾市集合竞价、汇率波动（港股通标的）。510500差0.22%、159545差0.4%被拦截，是纯噪声假阴性。

**V4.2修正**：容差从0.1%放宽至0.5% (×0.995)。

**释放标的**：510500（差0.22%）→ 通过。159545（差0.4%）→ 通过但MA200走平→仍闲置。513910（差1.1%）→ 超出0.5%容差→继续等待。

#### 2.2.3 步骤0.5 — EWY 极端乖离拦截（V4.2新增）

**背景**：EWY在修正后A5（ADX=50.6>30→禁用）下被释放，加上A7容差修正（差0.11%→通过），会直接进入进攻轨道。但EWY乖离MA200高达+79.7%，处于地缘事件（朝鲜半岛/中美关税）驱动的极端区。

**拦截规则**（可推广至所有标的）：
```
若 (C − MA200) / MA200 > 50%：
    → 🔴 直接观望，不进任何轨道
    → 不进入步骤1的任何讨论（含A1-A7）
```

**原理**：价格脱离长期趋势均值50%以上时，趋势跟踪策略的3×ATR止损无法有效保护。尾部风险不对称——向上空间有限，向下回撤可能单日−15%。

#### 2.2.4 反击轨道（步骤2）— R2 删除

**V4.1的R2缺陷**：C ≤ MA30 是多余的条件。反击策略的本质是「价格落入买入区间时介入」，MA200走平/向下已经给出了方向判定。加C ≤ MA30只会拦截价格在MA30上方但仍在买入区间内的标的——这种拦截没有逻辑依据。

**V4.2修正**：反击只看 R1(MA200走平/向下) ∧ R3(落入买入区间)。C与MA30的位置关系不参与判定。

#### 2.2.5 宏观闸属地分治（步骤0）— V4.2修正

**V4.1 缺陷**：所有锚点混在一起，未区分属地。VIX飙到40会把A股标的一起关闭，涨跌比崩到20%会把美股标的一起关闭——跨属地传播是逻辑错误。

**V4.2 修正**：四层闸，按标的属地独立判定，不跨属地传播。

| 闸层 | 适用范围 | 全关闭条件 | 仅反击关闭条件 | 不适用于 |
|:---|:---|:---|:---|:---|
| 0-A 全局硬闸 | 全池19标 | US10Y≥5.00% | — | — |
| 0-B 国际锚点 | 仅美股(7)+港股(2) | VIX≥35 | VIX≥25 | A股 |
| 0-C 国内锚点 | 仅A股(8) | 涨跌比<30% | 待接入50ETF IV | 美股/港股 |
| 0-D 港股专有 | 仅港股(2) | 恒生20日跌幅>15% | USDCNH单日>0.5% | 美股/A股 |

**属地判定逻辑**：
```
标的.市场 = 从19标池查表（美股: QQQ/IVV/IAU/BBJP/MUFG/EWY/VNM/FLIN/SMIN，
                          A股: 518880/510300/510500/159915/588000/513910/159545/159302，
                          港股: 513180/513770）

IF 标的.市场 == "美股":
    检查 0-B (VIX)
ELIF 标的.市场 == "A股":
    检查 0-C (涨跌比/SHIBOR)
ELIF 标的.市场 == "港股":
    检查 0-B (VIX) + 0-D (恒生/CNH)
```

**跨属地隔离示例**：
- VIX=40 → QQQ/IVV/IAU等美股标的🔴关闭，但510300/513910等A股标的照常按步骤1-2判定
- 涨跌比=20% → A股标的🔴关闭，但QQQ/IVV等美股标的照常按步骤1-2判定
- US10Y=5.20% → 全池关闭，不分属地（利率是万物重力）

#### 2.2.6 闲置标的标注

进攻和反击都不满足时，标的标记为⚪闲置。所有闲置标的必须标注具体失败条件：

| 闲置原因 | 语义 |
|:---|:---|
| 步骤0全局闸触发 | 宏观环境不允许任何仓位 |
| 步骤0.5极端拦截 | (C−MA200)/MA200 > 50% |
| A1-A7任一失败 | 进攻条件不满足（具体哪个A失败会标注） |
| R1/R3任一失败 | 反击条件不满足（具体哪个R失败会标注） |
| 🔴永久禁购 | SMIN类硬豁免 |

**闲置资金去向**：不强制指定。资金留在现金账户，用户自行决定停放 511880/SGOV 或暂时留在账户上等待。卖出后的资金同样回到现金账户。

**全局资产三层架构**：

```
全局资产
├── 长期底仓 30%（VEA+VTI，固定层，永不离场）
├── 竞争上岗池（进攻+反击，资金动态进出）
└── 现金（不在仓的所有资金，用户自行管理停放）
```

- 卖出 → 资金回到现金
- 路由判定通过 → 从现金划拨到进攻/反击
- 无信号 → 现金留在账户，用户决定是否买入货币基金
