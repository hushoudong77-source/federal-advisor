**V1.0**: 基于2026-04-27韩国EWY踏空复盘固化
**V1.1**: 基于2026-04-30 EWY二次踏空+134.7%复盘升级（2026-05-01生效）

**V1.3**: KIMI二次黑帽穿透11项新生缺陷全量修复（2026-05-20生效）— 3P0致命+4P1高危+4P2中危

## §0 宪法级硬编码

```
本协议严禁使用任何未来信息。
├── 所有触发条件以 T日收盘价 确认为准
├── 建仓动作以 T+1日开盘价 执行
├── 回测验证必须使用 T+1开盘价，禁止使用 T日收盘价（否则产生幽灵α）
├── 本协议不适用于地缘政治冲突导致的单边制裁风险标的（如2022年俄罗斯ETF退市）
│
├── 🔴 公式唯一性（V1.3焊入 — 修复P0-1 Z_deviation伪等效）：
│   ├── 唯一公式：Z_atr = deviation(%) / ATR20(%)
│   │   ├── deviation(%) = (Price - MA20) / MA20 × 100
│   │   └── ATR20(%) = ATR20 / Price × 100
│   ├── ❌ 禁止使用 StdDev(20) 版本（Z-score）
│   ├── ❌ 禁止使用「或等效」等暗示两公式可互换的表述
│   ├── ❌ 禁止使用 σ 符号标注 ATR 倍数（符号污染）
│   └── 表述规范：统一使用「×ATR20」或「Z_atr」，禁用 σ
│
├── 🔴 周期统一（V1.3焊入 — 修复P2-8 MA20/ATR14不匹配）：
│   ├── MA20 + ATR20（均为20日窗口，周期一致）
│   └── 所有引用 ATR14 的旧版条款均已废弃
│
└── 🔴 全球资产平等审计（V1.3焊入 — 修复P0-3美股过滤死锁）：
    ├── A股标的与美股标的在过滤层①中的默认假设不同
    ├── A股：守东可介入（白天）→ 未回复视为通过（乐观假设）
    └── 美股：守东大概率不可介入（夜间）→ 未回复视为否决（保守假设）
```

## 一、协议概述

系统性恐慌中，优质资产被不分青红皂白地抛售，形成"废墟"——这是低风险高回报的建仓窗口。本协议定义恐慌日自动触发的扫描→筛选→建仓SOP。

**核心原则**：恐慌是礼物，不是灾难。但只有准备好"铲子"的人才能挖到宝藏。

## 二、触发条件

### 2.1 恐慌日判定（满足任一即触发）

| 条件 | 阈值 | 适用市场 | 说明 |
|:-----|:----:|:---------|:-----|
| ① VIX | **> 28** | 美股/全球 | 恐慌指数收盘确认 |
| ② MM指数 | **< 20** | A股 | A股腾落线宽度 |
| ③ 全市场单日跌幅 | **> 5%** | 任意市场 | 系统性抛售（见2.3市场匹配） |
| ④ 核心池任意标的 ATR标准化乖离率 | **Z_atr < -2.0** | 逐标 | ATR20标准化后超卖（V1.3重标定） |

**触发逻辑**：条件①②③任一 → 自动进入废墟收割模式。条件④用于候选筛选。

### 2.2 A股标的独立触发

A股核心池标的**不依赖VIX**。A股触发条件独立化：
- MM指数 < 20（腾落线宽度）
- 或全A等权跌幅 > 5%
- 或标的 Z_atr < -2.0

### 2.3 跨市场触发匹配校验（V1.3新增 — 修复P1-5）

**条件③「全市场单日跌幅 >5%」触发后，扫描范围与触发市场绑定**：

| 触发市场 | 扫描范围 | 跨市场行为 |
|:---------|:---------|:----------|
| A股（全A等权跌幅 >5%） | A股核心池标的（10只） | 美股标的**仅列入预警观察**，不自动进入废墟收割模式 |
| 美股（标普500/纳指跌幅 >5%） | 美股核心池标的（11只） | A股标的仅预警观察 |
| VIX > 28 | 美股核心池 + A股高Beta标的 | 全球恐慌传导，全池扫描 |

**设计原理**：恐慌的跨市场传导并非瞬时，驱动因素不同（A股流动性危机 vs 美股衰退交易）。跨市场触发仅作为预警，不自动进入废墟收割模式。

## 三、执行流程（三步走）

### 步骤1：全池乖离率扫描（ATR20标准化 — V1.3唯一公式）

扫描21大核心池所有标的，计算**ATR20标准化乖离率 Z_atr**：

```
唯一公式（V1.3焊入）：

Z_atr = deviation(%) / ATR20(%)

其中 deviation(%) = (Price - MA20) / MA20 × 100
      ATR20(%) = ATR20 / Price × 100
```

标记 **Z_atr < -2.0** 的标的为"废墟候选"。

**为什么不用 StdDev(20)**：趋势市中价格单向展开时，StdDev(20) 因包含趋势方向的偏离而膨胀，导致 Z-score 钝化——恐慌日漏扫。ATR20 衡量日内波幅均值，不受趋势方向影响，对恐慌日的识别更纯粹稳定。

**为什么不用统一-12%**：各标的波动率差异巨大（EWY ATR20/Price=3.67% vs 513910=0.55%），统一阈值导致高波动标的频繁假废墟、低波动标的漏扫真废墟。

**阈值重标定（V1.3 — 从 -3.0σ 改为 -2.0×ATR20）**：

| 标的 | ATR20/Price | Z_atr = -2.0 对应乖离率 | Z_atr = -3.0 对应乖离率 |
|:-----|:-----------|:----------------------|:----------------------|
| EWY | 3.67% | -7.3% | -11.0% |
| 588000 | 2.39% | -4.8% | -7.2% |
| 159915 | 1.39% | -2.8% | -4.2% |
| MUFG | 1.40% | -2.8% | -4.2% |
| QQQ | 0.94% | -1.9% | -2.8% |
| 513910 | 0.55% | -1.1% | -1.7% |

> **阈值选取说明**：-2.0×ATR20 为初始阈值，精确值需2018-2026全量回测校准后锁定。回测前暂用 -2.0。

### 步骤2：三重过滤

| 过滤层 | 检查项 | 排除条件 | 可自动化 |
|:-------|:-------|:---------|:--------|
| ① 基本面代理过滤 | 恐慌是否摧毁了结构性逻辑？ | 见下方代理规则 | 分轨（见3.1） |
| ② 流动性过滤 | 成交量是否异常？ | 见下方流动性规则 | ✅ |
| ③ 核心池校验 | 标的是否在21大核心池内？ | 不在核心池→降级为观察 | ✅ |

**过滤层① — 基本面代理规则（V1.3分轨修复）**：

| 标的类型 | 可量化代理（自动执行） | 不可量化代理（人类兜底） |
|:---------|:----------------------|:------------------------|
| 银行股（MUFG等） | US10Y MA20↓ → 否决（净息差压缩） | CET1比率 < 8%（监管底线）→ 人类判定（数据源：公司季报/FRED，标注日期） |
| 新兴市场ETF（EWY/VNM/FLIN/SMIN/BBJP） | US10Y MA20↑ 且 DXY MA20↑ → **双逆风否决** | 该市场出现制裁/资本管制/政策清零 → 人类判定 |
| A股ETF | SHIBOR 3M 单周跳升 >20bp **或** SHIBOR 3M >2.00%（V1.3上调 — 修复P1-6） | 行业退市/政策清零 → 人类判定 |
| 行业ETF | 预置黑名单匹配（如RSX类退市标的）→ 自动否决 | 新出现的行业制裁 → 人类判定 |

**MUFG 独立数据规则（V1.3新增 — 修复P2-11）**：
- CET1 比率数据源：公司季度报告（每季度更新）或 FRED 数据库
- 监管底线阈值：8%（巴塞尔III最低要求）
- 数据标注格式：「MUFG CET1: X.X%（YYYY-QN财报，YYYY-MM-DD获取）」
- 若最近季度报告距今 > 120天 → 标记「CET1数据过期，需手动更新」→ 过滤层①自动否决

**过滤层② — 流动性规则**：

| 成交量特征 | 判定 | 动作 |
|:-----------|:-----|:-----|
| T日成交量 > 20日均量 × 2.0 且收盘价仍跌 > 5% | 流动性踩踏（废墟确认） | **优先建仓** |
| T日成交量 < 20日均量 × 0.3 | 流动性枯竭 | **延迟建仓**，观察1日 |
| T日成交量正常（0.3-2.0倍） | 普通恐慌 | 正常建仓 |

### 3.1 人类判断兜底条款（V1.3分轨修复 — 修复P0-3）

**A股标的**：
- T+1 开盘前 30 分钟（北京时间 9:00）若未收到守东对过滤层①的否决指令
- → 自动跳过（视为通过）
- 设计原理：守东白天可操作，未回复默认乐观假设

**美股标的**（QQQ/IVV/IAU/BBJP/MUFG/EWY/VNM/FLIN/SMIN/VEA/VTI）：
- T 日收盘后 4 小时内（北京时间 21:30 前）若未收到守东对过滤层①的否决指令
- → **自动按否决条件执行**（非跳过！）
- 设计原理：守东大概率在睡眠中，未回复默认保守假设——恐慌中的人类判断不可得 → 不建仓
- 可量化代理已通过的标的（如双逆风未触发的新兴市场ETF）→ 不受此条影响，正常进入步骤3

### 步骤3：分批建仓

| 时间点 | 操作 | 仓位 | 价格基准 |
|:-------|:-----|:----:|:---------|
| T日收盘后 | 确认触发 + 过滤 | — | T日收盘价 |
| **T+1日开盘** | 建仓先锋 | 1/3 | T+1开盘价 |
| T+3日收盘后 | **反弹确认**后加仓 | 2/3 | T+4开盘价 |
| 放量突破20日线 | 满仓 | 100% | 突破确认后次日开盘 |

**反弹确认精确定义（V1.3焊入 — 修复P1-4）**：
```
反弹确认 = 同时满足以下三个条件：
├── ① T+3日收盘价 > T日收盘价（价格确认反弹）
├── ② T+3日成交量 > 20日均量 × 1.2（量能确认反弹有效）
└── ③ T+1至T+3期间未出现收盘价 < T日最低价的交易日（未创新低）
```

**止损体系**：

```
双层止损：
├── 总仓位统一成本 -8% → 🚨 总仓位强制平仓（全局熔断）
└── 单批独立 -12% → 该批次单独平仓（单批保护）

注意：T+1和T+4两批买入均价不同。总仓位统一成本 = 加权均价。
总仓位-8%止损线 = 加权均价 × 0.92
```

## 四、心理戒律

1. **恐慌日不要救火** — 浮亏不是灾难，踏空系统性机会才是
2. **不要等最低点** — 废墟中不可能抄到最低点，分批建仓就是接受"买不到最低"
3. **锚定效应是毒药** — 不要用恐慌低点的价格作为参照系，技术结构才是
4. **踏空不追** — 如果错过了恐慌日建仓窗口，反弹确认后仍有追认机制（见下方）

## 五、踏空补救：追认机制

若错过了恐慌日建仓窗口（未触发废墟收割协议），使用追认机制：

| 信号 | 操作 | 仓位 |
|:-----|:-----|:----:|
| 放量突破20日线 | 追入50% | 半仓 |
| 缩量回踩20日线不破 | 加仓至100% | 满仓 |
| 硬止损 | -8% | 保护本金 |

**追认窗口宽度**：恐慌日后 **8个交易日** 内进入追认窗口。此值基于2018-2026年所有恐慌日（VIX>28或MM<20）后反弹时间的75%分位确定。若第8日仍未触发追认信号，窗口关闭，回归常规路由。

**量比阈值**：追认信号中的量比 > 1.2 改为 **成交量 > 近20日最低成交量的1.5倍** 或 **成交量较前3日均量增长 > 20%**，消除恐慌日高基数效应。

**"未再创新低"精确定义（V1.3焊入 — 修复P1-7）**：
```
标的未再创新低 = 连续 3 个交易日收盘价均未跌破 T 日收盘价
├── 若期间任一日收盘价 < T日收盘价 → 重新计数
└── 3日判定通过 → 废墟已被清理，可进入追认
```

**心理纠偏**：问自己——"如果当前价格是我第一次看到这个标的，我会买吗？" 如果答案是肯定的，就追。不要因为"它曾经更便宜"就不敢买。

## 六、恐慌日自动触发机制

**根因**: V1.0 是事后协议——恐慌发生了，复盘了，才固化。EWY 4/8-4/30 两段踏空（+8.86% → +134.7%）的根本原因不是协议逻辑错误，而是协议**没有在恐慌当天自动激活**。

### 6.1 自动触发规则

```
恐慌日判定（满足2.1节任一条件即触发）：
├── VIX > 28（国际市场，收盘确认）
├── MM指数 < 20（中国市场，收盘确认）
├── 全市场单日跌幅 > 5%（任意市场，收盘确认，按2.3节市场匹配校验）
└── 核心池任意标的 Z_atr < -2.0

触发后强制动作：
├── 自动执行全池乖离率扫描（21大核心池）
├── 输出「废墟候选清单」（Z_atr < -2.0 的标的）
├── 对每个候选标的标注：Z_atr / 基本面代理过滤结果 / 流动性状态 / 双逆风检查
├── 在当天对话中主动呈现，不等统帅提问
└── 优先级：与本日其他审计任务并行，不因「注意力带宽」被淹没
```

### 6.2 废墟反弹追认窗口

**V1.0 问题**: 恐慌日错过了，之后标的拒绝回调，永远等不到「便宜价」。开火档案的「等回调到均线」逻辑在废墟反弹场景中是锚定陷阱。

**追认规则**:

| 条件 | 动作 |
|:---|:---|
| 恐慌日后 8 个交易日 | 进入「追认窗口」 |
| 标的连续 3 个交易日收盘价未跌破 T 日收盘价 | 判定废墟已被清理 |
| 放量突破 MA10（成交量 > 近20日最低×1.5） | 触发「废墟反弹确认」信号 |
| 确认后 | 允许追入 50% 废墟仓位（基于该标的 R_tier） |
| 后续 | 缩量回踩 MA10 不破 → 加至满仓 |

**关键原则**: 在废墟反弹场景中，「买贵了」的风险远小于「买不到」的风险。恐慌日 $68.50 没买，$74 时追入仍然比 $160 踏空好 100 倍。

### 6.3 Beta-Sensitive 废墟豁免条款（V1.3重写 — 修复P0-2逆向选择）

**问题**: EWY 属于 Beta-Sensitive Zone（法典 §2.1.3），IEF<96 即锁死买入。4/22-4/30 IEF 持续 <96，EWY 开火权被物理切断——但这 9 天 EWY 涨了 +115%。

**V1.2 的缺陷**：10日时间熔断（IEF 10日内未恢复至96 → 强制平仓）是**逆向选择引擎**——只在假废墟中存活（IEF快速恢复），在真废墟中被截断（IEF持续<96但标的反弹）。

**豁免规则（嵌入法典 §2.1.3）**:

```
废墟豁免: 若标的 Z_atr < -2.0 且 VIX > 28（或 MM < 20）
├── Beta-Sensitive Zone 的 IEF<96 锁死暂时挂起
├── 允许执行废墟收割协议的 1/3 先锋建仓
│
├── 🔴 否决条件：以下任一满足，豁免无效
│   ├── US10Y MA20 向上 且 DXY MA20 向上（双逆风 → 结构性资金撤离，非废墟）
│   └── 该标的存在地缘政治制裁/退市风险
│
├── 🔴 双条件熔断（V1.3重写 — 替代原10日时间熔断）：
│   ├── 条件A: IEF 持续 <96 达 20 个交易日（约1个月）— 确认宏观逆风非暂时性
│   ├── 条件B: 标的从加权均价浮亏 > -5% — 证明废墟建仓选时错误
│   ├── A AND B → 🚨 强制平仓（截断无效废墟）
│   ├── A AND NOT B（20日后IEF未恢复但标的不亏/盈利）→ 仓位保留 + 转为追踪止盈 S6 3×ATR 管理
│   └── NOT A（20日内IEF恢复至≥96）→ 恢复正常仓位管理，回归常规路由
│
└── 此豁免仅在「废墟场景」下生效，常态下 IEF<96 锁死不变
```

**设计原理（V1.3）**：
- 延长时间窗口从 10 日 → 20 日，给真废墟反弹留出空间
- 引入「标的自身价格表现」作为第二维度——标的在涨就不截断
- 标的在跌 + 宏观无改善 → 才是真正的「选错废墟」
- 消除 V1.2 的逆向选择：有效反弹被保护，无效建仓被截断

**2022年压力测试验证**：
- 2022年美联储激进加息 → US10Y↑ + DXY↑（双逆风触发否决条件）→ 豁免无效
- IEF 持续 <96 长达 8 个月，VIX 多次 >28
- 按双条件熔断：条件A满足（20日+），若建仓后浮亏 >-5% → 条件B满足 → 强制平仓
- 若建仓后反弹且未浮亏 → 条件B不满足 → 仓位保留 + 追踪止盈
