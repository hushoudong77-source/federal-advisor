## §0 宪法级硬编码

```
本协议严禁使用任何未来信息。
├── 所有触发条件以 T日收盘价 确认为准
├── 建仓动作以 T+1日开盘价 执行
├── 回测验证必须使用 T+1开盘价，禁止使用 T日收盘价（否则产生幽灵α）
├── 本协议不适用于地缘政治冲突导致的单边制裁风险标的（如2022年俄罗斯ETF退市）
│
├── 🔴 公式唯一性（V1.3焊入 — 修复P0-1 Z_deviation伪等效）：
│   ├── 唯一公式：Z_atr = (Price - MA20) / ATR20
│   │   ├── deviation = Price - MA20（价格乖离绝对额）
│   │   ├── ATR20 = 20日平均真实波幅（绝对额）
│   │   ├── 🔴 分母统一为 MA20（V1.4焊入 — 修复P0-新1分母漂移）：
│   │   │   ├── ATR20(%) = ATR20 / MA20 × 100（统一分母！不可用 Price）
│   │   │   └── 根因：Price < MA20 时，Price分母会使ATR20(%)膨胀，Z_atr绝对值被压缩→漏扫
│   │   └── 等价形式：Z_atr = deviation(%) / ATR20(%)，其中 deviation(%)=(Price-MA20)/MA20×100，ATR20(%)=ATR20/MA20×100
│   ├── ❌ 禁止使用 StdDev(20) 版本（Z-score）
│   ├── ❌ 禁止使用「或等效」等暗示两公式可互换的表述
│   ├── ❌ 禁止使用 Price 作为 ATR20(%) 的分母（分母漂移→恐慌日漏扫）
│   ├── ❌ 禁止使用 σ 符号标注 ATR 倍数（符号污染）
│   └── 表述规范：统一使用「×ATR20」或「Z_atr」，禁用 σ
│
├── 🔴 周期统一（V1.3焊入 — 修复P2-8 MA20/ATR14不匹配）：
│   ├── MA20 + ATR20（均为20日窗口，周期一致）
│   └── 所有引用 ATR14 的旧版条款均已废弃
│
└── 🔴 全球资产平等审计（V1.3焊入 — 修复P0-3美股过滤死锁）：
    ├── A股标的与美股标的在过滤层①中的默认假设不同
    ├── A股：守东可介入（白天）→ 未回复视为通过（乐观假设）
    └── 美股：守东大概率不可介入（夜间）→ 未回复视为否决（保守假设）
```

## 一、协议概述

系统性恐慌中，优质资产被不分青红皂白地抛售，形成"废墟"——这是低风险高回报的建仓窗口。本协议定义恐慌日自动触发的扫描→筛选→建仓SOP。

**核心原则**：恐慌是礼物，不是灾难。但只有准备好"铲子"的人才能挖到宝藏。

## 三、执行流程（三步走）

### 步骤1：全池乖离率扫描（ATR20标准化 — V1.3唯一公式）

扫描21大核心池所有标的，计算**ATR20标准化乖离率 Z_atr**：

```
唯一公式（V1.4焊入 — 修复分母漂移）：

Z_atr = (Price - MA20) / ATR20

等价形式：Z_atr = deviation(%) / ATR20(%)

其中 deviation(%) = (Price - MA20) / MA20 × 100
      ATR20(%) = ATR20 / MA20 × 100  ← 🔴 分母统一为 MA20！不可用 Price！
```

标记 **Z_atr < -2.0** 的标的为"废墟候选"。

**为什么不用 StdDev(20)**：趋势市中价格单向展开时，StdDev(20) 因包含趋势方向的偏离而膨胀，导致 Z-score 钝化——恐慌日漏扫。ATR20 衡量日内波幅均值，不受趋势方向影响，对恐慌日的识别更纯粹稳定。

**为什么不用统一-12%**：各标的波动率差异巨大（EWY ATR20/MA20=3.67% vs 513910=0.55%），统一阈值导致高波动标的频繁假废墟、低波动标的漏扫真废墟。

**🔴 分母漂移修复（V1.4焊入）**：
原 V1.3 公式 ATR20(%) = ATR20/Price×100，当 Price<MA20 时（恐慌日常态），分母 Price 被压缩 → ATR20(%) 膨胀 → Z_atr 绝对值被系统性压缩 → 阈值边界漏扫。
修复后：ATR20(%) = ATR20/MA20×100，分母恒定为 MA20，Price 的波动不再污染 ATR20(%) 的分母。
验证：Price=93, MA20=100, ATR20=3.5 → V1.3: Z=-7/3.76=-1.86（漏扫）。V1.4: Z=-7/3.5=-2.00（触发）。

**阈值重标定（V1.3 — 从 -3.0σ 改为 -2.0×ATR20）**：

| 标的 | ATR20/MA20 | Z_atr = -2.0 对应乖离率 | Z_atr = -3.0 对应乖离率 |
|:-----|:-----------|:----------------------|:----------------------|
| EWY | 3.67% | -7.3% | -11.0% |
| 588000 | 2.39% | -4.8% | -7.2% |
| 159915 | 1.39% | -2.8% | -4.2% |
| MUFG | 1.40% | -2.8% | -4.2% |
| QQQ | 0.94% | -1.9% | -2.8% |
| 513910 | 0.55% | -1.1% | -1.7% |

> 🔴 **阈值未标定警告（V1.4焊入）**：-2.0×ATR20 为初始阈值，**实盘部署前必须完成 2018-2026 全量回测校准，否则视为非法典状态。** 回测前暂用 -2.0。

### 3.1 人类判断兜底条款（V1.4延长美股窗口 — 修复P1-7时区死锁）

**A股标的**：
- T+1 开盘前 30 分钟（北京时间 9:00）若未收到守东对过滤层①的否决指令
- → 自动跳过（视为通过）
- 设计原理：守东白天可操作，未回复默认乐观假设

**美股标的**（QQQ/IVV/IAU/BBJP/MUFG/EWY/VNM/FLIN/SMIN/VEA/VTI）：
- **T+1 美股开盘前（北京时间 T+1 晚上 21:00 前）**若未收到守东对过滤层①的否决指令（V1.4延长：原4小时窗口→约17小时窗口）
- → **自动按否决条件执行**（非跳过！）
- 设计原理：守东大概率在 T 日夜间睡眠中，但 T+1 白天有充分时间查看。延长窗口至 T+1 晚 21:00 前，覆盖守东白天工作时间
- 可量化代理已通过的标的（如双逆风未触发的新兴市场ETF）→ 不受此条影响，正常进入步骤3

### 步骤3：分批建仓

| 时间点 | 操作 | 仓位 | 价格基准 |
|:-------|:-----|:----:|:---------|
| T日收盘后 | 确认触发 + 过滤 | — | T日收盘价 |
| **T+1日开盘** | 建仓先锋 | 1/3 | T+1开盘价 |
| T+3日收盘后 | **反弹确认**后加仓 | 2/3 | T+4开盘价 |
| 放量突破20日线 | 满仓 | 100% | 突破确认后次日开盘 |

**反弹确认精确定义（V1.4放宽 — 修复P1-4三条件过严）**：
```
反弹确认 = 同时满足以下三个条件：
├── ① T+3日收盘价 > T+1日收盘价（确认从建仓日反弹，替代原「> T日收盘价」——消除恐慌日高基数效应）
├── ② T+3日成交量 > (T+1至T+3期间最低成交量) × 1.5（消除恐慌日天量对20日均量的膨胀效应）
└── ③ T+3日收盘价 > T+2日收盘价（连续2日上涨确认，替代原「未创新低」——更简单更可触发）
```

**止损体系**：

```
双层止损 + 批次差异化保护（V1.4增强 — 修复P1-6加仓后保护失效）：

├── 总仓位统一成本 -8% → 🚨 总仓位强制平仓（全局熔断）
├── 第一批（T+1建仓 1/3）-12% → 该批次单独平仓（单批保护）
└── 第二批（T+4建仓 2/3）-10% → 该批次单独平仓（V1.4新增 — 比第一批更紧，因建仓时点更晚、信息更充分）

注意：T+1和T+4两批买入均价不同。总仓位统一成本 = 加权均价。
总仓位-8%止损线 = 加权均价 × 0.92

批次差异原理：T+4建仓时已观察3天反弹确认，信息优势更大 → 若仍下跌，选时错误的概率更高 → 止损更紧（-10%而非-12%）
```

## 四、心理戒律

1. **恐慌日不要救火** — 浮亏不是灾难，踏空系统性机会才是
2. **不要等最低点** — 废墟中不可能抄到最低点，分批建仓就是接受"买不到最低"
3. **锚定效应是毒药** — 不要用恐慌低点的价格作为参照系，技术结构才是
4. **踏空不追** — 如果错过了恐慌日建仓窗口，反弹确认后仍有追认机制（见下方）

## 五、踏空补救：追认机制

若错过了恐慌日建仓窗口（未触发废墟收割协议），使用追认机制：

| 信号 | 操作 | 仓位 |
|:-----|:-----|:----:|
| 放量突破20日线 | 追入50% | 半仓 |
| 缩量回踩20日线不破 | 加仓至100% | 满仓 |
| 硬止损 | -8% | 保护本金 |

**追认窗口宽度**：恐慌日后 **8个交易日** 内进入追认窗口。此值基于2018-2026年所有恐慌日（VIX>28或MM<20）后反弹时间的75%分位确定。若第8日仍未触发追认信号，窗口关闭，回归常规路由。

**量比阈值**：追认信号中的量比 > 1.2 改为 **成交量 > 近20日最低成交量的1.5倍** 或 **成交量较前3日均量增长 > 20%**，消除恐慌日高基数效应。

**"未再创新低"精确定义（V1.4修改 — 修复P0-新3追认死锁）**：
```
追认机制修改（V1.4 — 删除「未再创新低」前置条件）：
├── 原 V1.3 前置条件「连续 3 个交易日收盘价均未跌破 T 日收盘价」
│   └── 在典型恐慌路径中（T+1继续下跌再反弹），此条件在 T+6 之后才可能满足 → 追认窗口仅剩 2 日 → 名存实亡
├── V1.4 修改：
│   ├── 删除「未再创新低」作为前置条件
│   └── 唯一追认信号：放量突破 MA10（成交量 > 近20日最低 × 1.5 或 成交量较前3日均量增长 > 20%）
├── 追认窗口仍为恐慌日后 8 个交易日
└── 设计原理：废墟反弹的确认不是「不再创新低」，而是「买方重新掌控价格」
```

**心理纠偏**：问自己——"如果当前价格是我第一次看到这个标的，我会买吗？" 如果答案是肯定的，就追。不要因为"它曾经更便宜"就不敢买。

## 六、恐慌日自动触发机制

**根因**: V1.0 是事后协议——恐慌发生了，复盘了，才固化。EWY 4/8-4/30 两段踏空（+8.86% → +134.7%）的根本原因不是协议逻辑错误，而是协议**没有在恐慌当天自动激活**。

### 6.1 自动触发规则

```
恐慌日判定（满足2.1节任一条件即触发）：
├── VIX > 28（国际市场，收盘确认）
├── MM指数 < 20（中国市场，收盘确认）
├── 全市场单日跌幅 > 5%（任意市场，收盘确认，按2.3节市场匹配校验）
└── 核心池任意标的 Z_atr < -2.0

触发后强制动作：
├── 自动执行全池乖离率扫描（21大核心池）
├── 输出「废墟候选清单」（Z_atr < -2.0 的标的）
├── 对每个候选标的标注：Z_atr / 基本面代理过滤结果 / 流动性状态 / 双逆风检查
├── 在当天对话中主动呈现，不等统帅提问
└── 优先级：与本日其他审计任务并行，不因「注意力带宽」被淹没
```

**🔴 三轨道路由废墟模式分支（V1.4新增 — 修复P2-11接口缺失）**：

当废墟收割模式激活时（VIX>28 或 MM<<20），路由层增加「废墟模式」分支：

```
路由优先级（废墟模式）：
├── 废墟模式 > 进攻模式 > 反击模式 > 观望模式
├── 废墟候选标的（Z_atr < -2.0 且通过三重过滤）→ 优先进入废墟收割SOP
├── 废墟候选标的暂停常规进攻/反击判定（避免双轨并行导致仓位冲突）
├── 废墟模式退出条件：VIX < 20 且 MM > 40（恐慌解除）
└── 退出后：废墟仓位回归常规路由管理（止损/止盈/追踪）
```

**设计原理**：三轨道（进攻/反击/观望）是常态路由，废墟收割是第四轨道（恐慌轨道）。若标的在废墟日同时满足进攻条件（如恐慌暴跌后 MA200 仍向上，价格突破 H15），路由优先级冲突——废墟模式优先，因为恐慌中的废墟建仓比常态进攻具有更高的风险回报比。

### 6.2 废墟反弹追认窗口

**V1.0 问题**: 恐慌日错过了，之后标的拒绝回调，永远等不到「便宜价」。开火档案的「等回调到均线」逻辑在废墟反弹场景中是锚定陷阱。

**追认规则**:

| 条件 | 动作 |
|:---|:---|
| 恐慌日后 8 个交易日 | 进入「追认窗口」 |
| 放量突破 MA10（成交量 > 近20日最低×1.5 或 较前3日均量增长 > 20%） | 触发「废墟反弹确认」信号（V1.4：唯一追认信号，删除「未再创新低」前置条件） |
| 确认后 | 允许追入 50% 废墟仓位（基于该标的 R_tier） |
| 后续 | 缩量回踩 MA10 不破 → 加至满仓 |

**关键原则**: 在废墟反弹场景中，「买贵了」的风险远小于「买不到」的风险。恐慌日 $68.50 没买，$74 时追入仍然比 $160 踏空好 100 倍。

### 6.3 Beta-Sensitive 废墟豁免条款（V1.3重写 — 修复P0-2逆向选择）

**问题**: EWY 属于 Beta-Sensitive Zone（法典 §2.1.3），IEF<96 即锁死买入。4/22-4/30 IEF 持续 <96，EWY 开火权被物理切断——但这 9 天 EWY 涨了 +115%。

**V1.2 的缺陷**：10日时间熔断（IEF 10日内未恢复至96 → 强制平仓）是**逆向选择引擎**——只在假废墟中存活（IEF快速恢复），在真废墟中被截断（IEF持续<96但标的反弹）。

**豁免规则（嵌入法典 §2.1.3）**:

```
废墟豁免: 若标的 Z_atr < -2.0 且 VIX > 28（或 MM < 20）
├── Beta-Sensitive Zone 的 IEF<96 锁死暂时挂起
├── 允许执行废墟收割协议的 1/3 先锋建仓
│
├── 🔴 否决条件：以下任一满足，豁免无效
│   ├── US10Y MA20 向上 且 DXY MA20 向上（双逆风 → 结构性资金撤离，非废墟）
│   └── 该标的存在地缘政治制裁/退市风险
│
├── 🔴 Beta-Sensitive 长期逆风管理（V1.4重写 — 修复P0-新2双条件熔断互斥）：
│   ├── 删除 V1.3 双条件熔断条款（20日+浮亏-5%）。V1.3 的 -5% 阈值与双层止损体系（-8%/-12%）互斥
│   ├── Beta-Sensitive 废墟豁免的退出**完全由双层止损（-8%/-12%）和追踪止盈 S6 管理**
│   ├── IEF 恢复时间表不作为仓位退出的强制条件
│   │
│   ├── 🔴 预警升级（非强制平仓）：
│   │   ├── IEF 持续 <96 达 60 个交易日 → 标记「宏观逆风长期持仓」
│   │   ├── 标记后：禁止该标的新增废墟建仓（已建仓位不受影响）
│   │   └── 标记后：已有仓位仍由双层止损 + 追踪止盈 S6 管理
│   │
│   └── 设计原理（V1.4）：
│       ├── 废墟收割是左侧交易，建仓后二次探底 -5% 至 -10% 是常态
│       ├── V1.2 的 10 日无条件截断是明刀，V1.3 的 20 日+浮亏 -5% 是暗箭——同样致命
│       ├── 任何固定时间熔断都会制造逆向选择：只在假废墟中存活，在真废墟中被截断
│       ├── 双层止损（-8%总仓位/-12%单批）足以覆盖选错废墟的风险
│       └── 60 日预警升级仅限「禁止新增」，不截断已有仓位——让反弹自己证明自己
