## 一、协议概述

系统性恐慌中，优质资产被不分青红皂白地抛售，形成"废墟"——这是低风险高回报的建仓窗口。本协议定义恐慌日自动触发的扫描→筛选→建仓SOP。

**核心原则**：恐慌是礼物，不是灾难。但只有准备好"铲子"的人才能挖到宝藏。

## 三、执行流程（三步走）

### 步骤1：全池乖离率扫描（ATR20标准化 — V1.3唯一公式）

扫描21大核心池所有标的，计算**ATR20标准化乖离率 Z_atr**：

```
唯一公式（V1.4焊入 — 修复分母漂移）：

Z_atr = (Price - MA20) / ATR20

等价形式：Z_atr = deviation(%) / ATR20(%)

其中 deviation(%) = (Price - MA20) / MA20 × 100
      ATR20(%) = ATR20 / MA20 × 100  ← 🔴 分母统一为 MA20！不可用 Price！
```

标记 **Z_atr < -2.0** 的标的为"废墟候选"。

**🔴 Z_atr 扫描禁用逻辑（V1.7焊入 — 修复P0-1正文未同步禁用）**：
```
IF Z_atr阈值未标定（§0执行层禁令激活） THEN
├── 跳过 Z_atr 扫描
├── 仅输出提示：「条件④ Z_atr 扫描已禁用（待回测标定），当前仅条件①②③驱动」
└── 废墟候选清单仅包含条件①②③筛选结果
ELSE
└── 正常执行 Z_atr 扫描，标记 Z_atr < -2.0 标的为废墟候选
```

**为什么不用 StdDev(20)**：趋势市中价格单向展开时，StdDev(20) 因包含趋势方向的偏离而膨胀，导致 Z-score 钝化——恐慌日漏扫。ATR20 衡量日内波幅均值，不受趋势方向影响，对恐慌日的识别更纯粹稳定。

**为什么不用统一-12%**：各标的波动率差异巨大（EWY ATR20/MA20=3.67% vs 513910=0.55%），统一阈值导致高波动标的频繁假废墟、低波动标的漏扫真废墟。

**🔴 分母漂移修复（V1.4焊入）**：
原 V1.3 公式 ATR20(%) = ATR20/Price×100，当 Price<MA20 时（恐慌日常态），分母 Price 被压缩 → ATR20(%) 膨胀 → Z_atr 绝对值被系统性压缩 → 阈值边界漏扫。
修复后：ATR20(%) = ATR20/MA20×100，分母恒定为 MA20，Price 的波动不再污染 ATR20(%) 的分母。
验证：Price=93, MA20=100, ATR20=3.5 → V1.3: Z=-7/3.76=-1.86（漏扫）。V1.4: Z=-7/3.5=-2.00（触发）。

**阈值重标定（V1.3 — 从 -3.0σ 改为 -2.0×ATR20）**：

| 标的 | ATR20/MA20 | Z_atr = -2.0 对应乖离率 | Z_atr = -3.0 对应乖离率 |
|:-----|:-----------|:----------------------|:----------------------|
| EWY | 3.67% | -7.3% | -11.0% |
| 588000 | 2.39% | -4.8% | -7.2% |
| 159915 | 1.39% | -2.8% | -4.2% |
| MUFG | 1.40% | -2.8% | -4.2% |
| QQQ | 0.94% | -1.9% | -2.8% |
| 513910 | 0.55% | -1.1% | -1.7% |

> 🔴 **阈值未标定警告（V1.4焊入）**：-2.0×ATR20 为初始阈值，**实盘部署前必须完成 2018-2026 全量回测校准，否则视为非法典状态。** 回测前暂用 -2.0。

│   ├── 若触发 → 平仓第一批 1/3，重新计算剩余仓位加权均价
│   └── 跳过后续步骤2/3
│
├── 步骤2：检查总仓位是否触发 -8% 止损（含第一批浮亏）
│   ├── 若触发 → 平仓全部仓位，互斥锁解除
│   └── 跳过后续步骤3

│   └── 继续步骤4
│
└── 步骤4：重新计算新总仓位加权均价和新止损线
    ├── 总仓位加权均价 = (T+1买入价 × 1/3 + T+4买入价 × 2/3)
    ├── 总仓位 -8% 止损线 = 加权均价 × 0.92
    ├── 第一批 -12% 止损线维持不变（以T+1买入价计算）
    └── 第二批 -10% 止损线 = T+4买入价 × 0.90
```

**设计原理**：T+4是多动作并发日（加仓+互斥锁解除+可能的止损触发），若并行执行可能出现「止损+加仓」叠加，仓位管理和止损线计算崩溃。串行执行确保「先止损后加仓，已止损则不加仓」。

```
双层止损 + 批次差异化保护（V1.4增强 — 修复P1-6加仓后保护失效）：

├── 总仓位统一成本 -8% → 🚨 总仓位强制平仓（全局熔断）
├── 第一批（T+1建仓 1/3）-12% → 该批次单独平仓（单批保护）
└── 第二批（T+4建仓 2/3）-10% → 该批次单独平仓（V1.4新增 — 比第一批更紧，因建仓时点更晚、信息更充分）

注意：T+1和T+4两批买入均价不同。总仓位统一成本 = 加权均价。
总仓位-8%止损线 = 加权均价 × 0.92

批次差异原理：T+4建仓时已观察3天反弹确认，信息优势更大 → 若仍下跌，选时错误的概率更高 → 止损更紧（-10%而非-12%）

单批平仓后规则（V1.5新增 — 修复P1-6止损真空）：
├── 任一批次触发止损平仓后 → 立即重新计算剩余仓位的加权均价
├── 新总仓位止损线 = 新加权均价 × 0.92
└── 若仅剩第二批（2/3），其总仓位止损线 = 第二批买入价 × 0.92
```

## 四、心理戒律

## 五、踏空补救：追认机制

若错过了恐慌日建仓窗口（未触发废墟收割协议），使用追认机制：

| 信号 | 操作 | 仓位 |
|:-----|:-----|:----:|
| 放量突破20日线 | 追入50% | 半仓 |

| 硬止损 | -8% | 保护本金 |

**追认窗口宽度**：恐慌日后 **8个交易日** 内进入追认窗口。此值基于2018-2026年所有恐慌日（VIX>28或MM<20）后反弹时间的75%分位确定。若第8日仍未触发追认信号，窗口关闭，回归常规路由。

**🔴 统一追认日历（V1.7焊入 — 修复P1-5跨标的不一致；V1.8硬化 — 修复P1-3基准漂移）**：
```

├── 每只标的独立计算 panic 日基准（该标的首次触发恐慌条件①②③的交易日）
├── 全池共享最早 panic 日作为输出锚点，但不因后续 panic 日漂移
│   ├── 例：T日 A股 panic（MM<20），T+1日美股 panic（VIX>28）
│   │   ├── A股标的追认窗口基准 = T日（不因T+1美股panic漂移）
│   │   └── 美股标的追认窗口基准 = T+1日

## 六、恐慌日自动触发机制

**根因**: V1.0 是事后协议——恐慌发生了，复盘了，才固化。EWY 4/8-4/30 两段踏空（+8.86% → +134.7%）的根本原因不是协议逻辑错误，而是协议**没有在恐慌当天自动激活**。

│   │   │   └── 场景A：废墟退出后价格突破H15满足进攻条件 → 被锁死 → 踏空进攻窗口
│   │   │   └── 场景B：假废墟误触发→T+2退出→进攻窗口被锁至T+3 → 成本恶化
│   │   ├── V1.6修正：互斥锁 = 废墟建仓执行期间锁，退出即解除
│   │   │   ├── 互斥锁范围：T+1开盘（建仓1/3）至 T+4开盘（加仓2/3完成）期间
│   │   │   ├── 互斥锁解除条件（满足任一）：
│   │   │   │   ├── ① T+4开盘加仓完成 → 互斥锁自动解除
│   │   │   │   ├── ② 废墟模式退出（分层退出条件满足）→ 互斥锁立即解除
│   │   │   │   └── ③ 该标的触发总仓位-8%止损平仓 → 互斥锁立即解除
│   │   │   └── 解除后：标的立即回归常规进攻/反击判定，无需首席审计官手动解除
│   │   └── 设计原理：互斥锁防止的是建仓执行期间的并行冲突，非建仓完成后的压制
│
└── 退出后：废墟仓位回归常规路由管理（止损/止盈/追踪）
```

**设计原理**：三轨道（进攻/反击/观望）是常态路由，废墟收割是第四轨道（恐慌轨道）。若标的在废墟日同时满足进攻条件（如恐慌暴跌后 MA200 仍向上，价格突破 H15），路由优先级冲突——废墟模式优先，因为恐慌中的废墟建仓比常态进攻具有更高的风险回报比。

### 6.4 节假日 T+N 时间线裂缝熔断（V1.5新增 — 修复P2-12）

**问题**：T+3反弹确认、T+4开盘加仓、8日追认窗口均基于「交易日」假设。春节/国庆长假（7-9日休市）导致 T+1 与 T+3 间隔 10 个自然日，期间宏观环境可能剧变。

```
长假熔断规则：
├── 触发条件：T日与T+3日之间自然日间隔 > 5天 **且** 包含法定节假日（排除普通周末）
│   ├── 例：T日=周五，T+3=下周三，间隔5天（周六至周三）→ 不触发（普通周末）
│   └── 例：T日=1月25日（春节前最后交易日），T+3=2月10日（节后第2日），间隔16天且含春节假期 → 触发
│
├── 熔断动作：
│   ├── 反弹确认推迟至节后第2个交易日（市场消化假期信息后）
│   ├── 追认窗口（V1.6修正 — 修复P2-9跨假期基准漂移）：
│       ├── V1.5旧版：固定12自然日（≈8交易日×1.5倍），春节9天假期仅覆盖3交易日
│       └── V1.6修正：8交易日 + 按实际休市天数顺延
│           └── 例：春节休市7天 → 追认窗口 = 节前剩余交易日 + 节后8交易日
│   └── T+1已建仓的1/3仓位不受影响，止损/止盈正常执行
│
├── 节后第1个交易日（V1.6修正 — 修复P1-3信息消化日踏空）：
│   ├── V1.5旧版：「禁止任何废墟建仓/加仓操作」→ 节后首日必然跳空，禁止建仓=错过最佳窗口
│   ├── V1.6修正：「延迟建仓日」而非「禁止建仓日」
│   ├── 允许T+1（节后首日）按涨跌停执行条款延迟建仓（打开跌停后5分钟）
│   ├── 禁止T+3反弹确认（因跨假期间隔过长，信息失真）
│   └── 若节前T日已触发废墟并建仓1/3，节后首日该仓位不受影响
```

### 6.2 废墟反弹追认窗口

**V1.0 问题**: 恐慌日错过了，之后标的拒绝回调，永远等不到「便宜价」。开火档案的「等回调到均线」逻辑在废墟反弹场景中是锚定陷阱。

**追认规则**:

| 条件 | 动作 |
|:---|:---|
| 恐慌日后 8 个交易日 | 进入「追认窗口」 |
| 放量突破 MA10（成交量 > 近20日最低×1.5 或 较前3日均量增长 > 20%） | 触发「废墟反弹确认」信号（V1.4：唯一追认信号，删除「未再创新低」前置条件） |
| 确认后 | 允许追入 50% 废墟仓位（基于该标的 R_tier） |
| 后续 | 缩量回踩 MA10 不破 → 加至满仓 |

**关键原则**: 在废墟反弹场景中，「买贵了」的风险远小于「买不到」的风险。恐慌日 $68.50 没买，$74 时追入仍然比 $160 踏空好 100 倍。

### 6.3 Beta-Sensitive 废墟豁免条款（V1.3重写 — 修复P0-2逆向选择）

**问题**: EWY 属于 Beta-Sensitive Zone（法典 §2.1.3），IEF<96 即锁死买入。4/22-4/30 IEF 持续 <96，EWY 开火权被物理切断——但这 9 天 EWY 涨了 +115%。

**V1.2 的缺陷**：10日时间熔断（IEF 10日内未恢复至96 → 强制平仓）是**逆向选择引擎**——只在假废墟中存活（IEF快速恢复），在真废墟中被截断（IEF持续<96但标的反弹）。

**豁免规则（嵌入法典 §2.1.3）**:

```

├── 允许执行废墟收割协议的 1/3 先锋建仓
│
├── 🔴 否决条件：以下任一满足，豁免无效
│   ├── US10Y MA20 向上 且 DXY MA20 向上（双逆风 → 结构性资金撤离，非废墟）
│   └── 该标的存在地缘政治制裁/退市风险
│
├── 🔴 Beta-Sensitive 长期逆风管理（V1.4重写 — 修复P0-新2双条件熔断互斥）：
│   ├── 删除 V1.3 双条件熔断条款（20日+浮亏-5%）。V1.3 的 -5% 阈值与双层止损体系（-8%/-12%）互斥
│   ├── Beta-Sensitive 废墟豁免的退出**完全由双层止损（-8%/-12%）和追踪止盈 S6 管理**
│   ├── IEF 恢复时间表不作为仓位退出的强制条件
│   │
│   ├── 🔴 预警升级（非强制平仓）：
│   │   ├── IEF 持续 <96 达 60 个交易日 → 标记「宏观逆风长期持仓」

│   │   └── 标记后：已有仓位仍由双层止损 + 追踪止盈 S6 管理
│   │
│   └── 设计原理（V1.4）：
│       ├── 废墟收割是左侧交易，建仓后二次探底 -5% 至 -10% 是常态

│       ├── 双层止损（-8%总仓位/-12%单批）足以覆盖选错废墟的风险
