# V5.6 §0 固定层宪法

> 归属：双轨配置最终执行法典 V5.6 §0 | 签发：2026-05-11
> 定位：VEA（20%）+ VTI（10%）构成全局资产的固定底仓层，总权重 30%

---

## 0.1 宪法地位

固定层具有以下不可侵犯属性：

| 属性 | 内容 |
|:---|:---|
| **路由豁免** | 不进入第二段路由判断。永远不被分配到进攻/反击/闲置轨道 |
| **策略豁免** | 不适用 Spearhead/Counterpunch 的任何入场/离场规则 |
| **止损豁免** | 不设 ATR 止损、绝对底线止损、动态止盈——不设任何技术指标驱动的自动离场条件 |
| **宏观熔断豁免** | US10Y≥5.00%、VIX≥35、涨跌比<30% 等宏观闸对固定层无效 |
| **战时满载豁免** | S1/S2 满载态不改变固定层权重 |
| **唯一操作** | 仅执行年度再平衡（恢复至 VEA 20% / VTI 10% 目标权重） |
| **卖出禁令** | **任何情况下不得清仓固定层**（年度/偏离再平衡中的卖出超配部分不属于「清仓」，属于「权重修正」，被豁免于本禁令） |

## 0.2 再平衡触发条件

| 触发类型 | 条件 | 操作 |
|:---|:---|:---|
| **年度再平衡** | 每年 12 月首个 NYSE 交易日 | VEA 恢复至 20%，VTI 恢复至 10%。若该日 A 股休市，顺延至下一 A 股交易日执行美股交易指令 |
| **偏离触发** | 任一标的权重偏离目标 ±5pp（VEA<15% 或 >25%，VTI<5% 或 >15%） | 立即再平衡至目标权重 |
| **新增资金** | 全局总资产因外部注资增长 ≥20% | 恢复至目标权重：计算新总资产下的目标市值（VEA=新总资产×20%，VTI=新总资产×10%）。缺口优先用新增资金填补。新增资金不足时，按§0.4资金池竞争仲裁从现金层划拨（可动用至5%硬底）。仍不足时标记「现金不足-待注资」，暂停再平衡 |

**互斥条款**：年度再平衡日若偏离触发同时满足 → 仅执行年度再平衡一次，偏离触发顺延至下一交易日校验。避免同日双次再平衡产生重复交易。

## 0.3 再平衡执行规则

```
1. 计算当前 VEA/VTI 市值
2. 计算目标市值 = 全局总资产 × 目标权重（20%/10%）
3. 差额 = 目标市值 − 当前市值
4. 正差额 → 从现金账户划拨资金买入。若现金不足，暂停再平衡，标记「现金不足-待注资」，不卖出其他资产。**固定层再平衡为宪法义务，优先于§0.5现金主权率管理——再平衡可动用现金直至现金主权率降至 5% 为止，严禁击穿 5% 硬底。5% 硬底为终极防线，任何情况（含P0指令）不可突破。**
5. 负差额 → 卖出超配部分，资金回笼现金账户
6. 执行后固定层权重精确恢复至 20% + 10%
```

## 0.4 全局资产分层架构

```
全局资产
├── 固定层 30%（VEA 20% + VTI 10%）← 宪法管辖，永不离场
├── 竞争上岗池（进攻 + 反击，资金动态进出）← 双轨法典管辖
├── 豁免层（IAU + 518880）← 独立核算，不参与路由
└── 现金层（不在仓的所有资金，用户自行管理停放）
```

**固定层不计入竞争上岗池可用资金。豁免层独立核算，不计入竞争上岗池。**

**跨币种市值转换（全局适用）**：
```
对于美元计价标的（美股ETF）：
  CNY市值 = 持仓股数 × 当前市价(USD) × USDCNY（当日9:15央行中间价）

对于人民币计价标的（A股ETF）：
  CNY市值 = 持仓股数 × 当前市价(CNY)  （USDCNY=1）
```

```
现金层市值 = 全局总资产 − 固定层市值 − 已占用进攻仓位市值 − 已占用反击仓位市值 − 豁免层市值

其中：
  已占用市值 = Σ(持仓股数 × 当前市价 × 汇率因子)，非成本
    汇率因子 = USDCNY（美元标）/ 1（人民币标）
  豁免层市值 = IAU市值(CNY) + 518880市值
```

恒等式保证现金层永远非负（市值随市价波动，总资产同步波动）。

### 资金池竞争仲裁

当多个资金需求方同时申请资金时，按以下优先级排队：

```
优先级 P1：固定层再平衡（宪法义务，最高优先级）
   → 可动用现金至5%硬底

优先级 P2：反击止损回补（SRC-4/5宏观熔断触发后的资金释放，不占用现金）
   → 反向操作：SRC触发自动释放资金，不竞争现金

优先级 P3：进攻止损回补（同上，SRC触发自动释放资金）

优先级 P4：反击新开仓（需现金主权率>5%校验）
   → 同一优先级按路由步3排序：MA200走平标的优先于MA200向下

优先级 P5：进攻新开仓（需现金主权率>5%校验）

优先级 P6：豁免层买入（IAU/518880 P0指令，需现金主权率>8%）
   → 仅当现金主权率>8%且当日无P1-P5资金需求时执行
```

**同优先级竞争规则**：
- 资金不足时按路由优先级（§2.1步3）排队
- 同一优先级内按信号时间先进先出
- 资金不足以覆盖全部时，未分配标的标记「资金不足-待释放」，等待SRC触发释放资金后自动进入下一轮判定

## 0.5 现金主权率管理（§3.3）

### 0.5.1 定义

```
现金主权率 = 现金层市值 / 全局总资产

硬底线 = 5%
```

现金主权率衡量组合的流动性安全边际。低于5%时组合面临不可预期的流动性危机。

### 0.5.2 硬底线执行规则

```
现金主权率状态机（三态）：

状态 A：「正常」— 现金主权率 > 8%
  → 所有操作正常执行（固定层再平衡、进攻开仓、反击开仓、豁免层买入）

状态 B：「警戒」— 5% < 现金主权率 ≤ 8%
  → 固定层再平衡：正常执行（宪法义务，最高优先级）
  → 非固定层操作（进攻开仓、反击开仓、豁免层买入）：可执行
    但必须经过 §0.4 资金池竞争仲裁，且当日新增开仓资金总额
    不得超过「当前现金层 − 5%硬底」的一半（半速消耗）
  → 已有持仓的止损/止盈：正常执行（释放资金回笼现金层）

状态 C：「硬底触及」— 现金主权率 = 5%
  → 暂停一切非固定层操作（进攻开仓、反击开仓、豁免层买入）
  → 已有持仓的止损/止盈仍可执行
  → 固定层再平衡不可再动用现金（已触及 5% 硬底）
  → 从「硬底触及」恢复至「警戒」的条件：需通过 SRC 触发释放资金
    或外部注资，使现金主权率回到 >5%；恢复至「正常」需 >8%。

现金主权率计算公式：现金主权率 = 现金层市值 / 全局总资产
  其中现金层市值 = 全局总资产 − 固定层市值 − 已占用仓位市值 − 豁免层市值
  （详见 §0.4 恒等式）
```

**与 §0.4 资金池竞争仲裁的关系**：
- 状态 A（>8%）：P1-P6 按正常优先级执行，无额外约束
- 状态 B（5%-8%）：P1（固定层再平衡）正常执行；P2-P3（止损回补）正常执行；P4-P6（新开仓）需半速消耗
- 状态 C（=5%）：仅 P1 暂停（硬底已触及），P2-P3 正常执行，P4-P6 禁止

**P0 指令覆盖边界**（与 §1.3 联动）：
P0 不可覆盖现金主权率 5% 硬底线。任何 P0 指令若将导致现金主权率 < 5%，执行引擎自动拒绝并回告「硬底线冲突」。

### 1.4 汇率锚定规则

**全局总资产锚定货币**：人民币（CNY）

**美元资产市值转换公式**：
```
美元资产CNY市值 = 收盘价(USD) × 持仓股数 × USDCNY中间价（当日9:15央行公布）
```

**汇率更新频率**：
```
每日9:15一次，盘中不浮动
若当日央行中间价因节假日未发布 → 沿用最近交易日中间价
```

**跨币种计算规则**：
```
全局总资产(CNY) = Σ(人民币资产市值) + Σ(美元资产CNY市值)
其中美元资产CNY市值按当日9:15 USDCNY中间价统一折算

全局总资产的单标上限/资金池上限均以CNY计值
```

**汇率向下穿透规则**（适用于§3.1/§3.2所有公式）：
```
美元计价标的的仓位计算公式中，ATR(USD)和入场价(USD)必须乘以USDCNY转换为CNY：
  N₁(CNY)   = 总资产CNY × 1% / (3 × ATR(USD) × USDCNY)
  单标上限   = N₁ × 入场价(USD) × USDCNY ≤ 总资产 × 8%
  单批数量   = floor(单批金额CNY / (入场价(USD) × USDCNY))

人民币计价标的无需转换（USDCNY=1）。
详见§3.1.2和§3.2.2的公式定义。
```

## §4 宏观闸 (Macro Gates)

### 4.1 全局闸

| 闸 | 条件 | 动作 |
|:---|:---|:---|
| US10Y | ≥4.50% | 🟡预警，标注于指令备注栏 |
| US10Y | ≥5.00% | 🔴熔断，全池关闭（固定层豁免） |
| US10Y | 回落穿越<4.50% | 🟢绿色开火 |

### 4.1.1 重力加速协议（二阶熔断）

**核心逻辑**：US10Y 的变化率（二阶）独立于价格位阶（一阶）运行。即使 US10Y 仍在 5.00% 熔断线以下，单日跳升 > 8bps 意味着利率预期突变，必须触发全局防御。

| 条件 | 效力 | 复位条件 |
|:---|:---|:---|
| US10Y 单日跳升 > 8bps（当日收盘收益率 − 前日收盘收益率，非盘中极值） | 进攻开火权降级 50%（即新开仓 N 股数 × 50%）。反击不受影响 | 连续 2 个交易日单日跳升均 < 3bps |
| SHIBOR 3M 单日跳升 > 15bps | A股进攻开火权降级 50% | 连续 2 个交易日单日跳升均 < 5bps |

**跨闸互锁**：重力加速与宏观闸联立时，取更严格者。即若宏观闸已关闭某标的，重力加速不再额外降级；若宏观闸开放，重力加速在此基础上执行降级。

**P0 覆盖**：统帅 P0 可手动解除重力加速状态，但必须在指令中注明「已确认利率跳升为噪音」。

## §5 执行闭环 (Execution Loop)

### 5.1 每日执行流水线

```
交易日 15:00 A股收盘
  → 数据输入（OHLCV + 汇率 + 宏观锚点）
  → 路由判断（全池19标）
  → 若触发固定层偏离再平衡（§0.2）→ 立即执行再平衡
  → 再平衡完成后重新计算现金层
  → 路由结果按新现金层过滤（剔除现金主权率<5%对应的标的）
  → 策略分配（进攻/反击/闲置）
  → 指令生成
  → 人工执行（次日开盘后）
  → 闭环审计
  → 记忆更新
```

**时序约束**：
- 再平衡必须在路由判断之后执行，确保路由结果基于最新现金层
- 若再平衡触发，路由结果需重新计算一次
- 同一交易日仅允许一次再平衡+一次路由重算，防止死循环

### 5.2 闭环审计

每次执行后必须完成：

1. **指令对账**：输出指令 vs 实际执行，记录偏离
2. **持仓同步**：更新记忆中的持仓/成本/止损数据
3. **路由校验**：19标全量路由状态是否有变化
4. **宏观闸校验**：US10Y/VIX/涨跌比是否有闸门变化
5. **错误记录**：任何取数违规/逻辑偏差写入当日记忆

### 5.4 最终审计门（Final Clearance Gate）

> **定位**：§5 执行闭环的步骤3，位于指令生成之后、执行输出之前。策略计算出具体的买入/卖出/持有指令后，必须经过此门才能输出。

**执行原则**：三层审计，顺序执行。🔴层任一项不通过 → 指令熔断，返回策略层修正或放弃。🟡层不通过 → 指令可执行，但必须在备注栏标注警告。⚪层不通过 → 前置熔断，数据不新鲜则整条指令拒绝执行。

#### 🔴 第一层：硬性熔断（通不过=指令不执行）

| # | 审计项 | 规则 | 熔断条件 |
|:-:|:------|:----|:--------|
| ① | **1%风险法则** | N = (动态总资产 × 1%) / (买入价 − 动态止损位) | N 对应的本金暴露 > 1R → 熔断 |
| ② | **8%单标红线** | 该标的（含进攻第一发+反等价鞅加仓+反击持仓）跨策略合计 ≤ 动态总资产 8% | 合计 > 8% → 后续加仓指令熔断，已有持仓维持 |
| ③ | **三重止损防线** | 指令是否配套了不可撤销的止损单？（进攻=3×ATR追踪止损，反击=2×ATR+绝对底线-5%）| 止损单未挂载 → 熔断 |
| ④ | **轨道硬隔离** | 该标的当前是否被标记 ATTACK_LOCKED？ | 是 + 指令为反击买入 → 熔断 |
| ⑤ | **宏观全局闸二次确认** | US10Y ≥ 5.00%？VIX ≥ 35？ | 任一触发 → 全池熔断（固定层豁免） |

**① 1%风险法则详细计算公式**：
```
进攻：N₁ = floor(总资产CNY × 1% × 递减系数 / (3 × ATR(USD) × USDCNY))
反击：N₁ = floor(总资产CNY × 1% / (2 × ATR(USD) × USDCNY))
单次试错本金暴露 = N₁ × (买入价 − 止损位) × USDCNY ≤ 总资产 × 1%
```

**② 8%红线跨策略合并规则**：
```
单标总暴露% = [Σ(进攻持仓市值) + Σ(反击持仓市值)] / 动态总资产 × 100%
反击买入区间触发但进攻已持有时 → 反击买入指令熔断（ATTACK_LOCKED）
进攻已持有 + 反击也持有（历史遗留）→ 合并计算上限，不强制平仓反击
```

## 2.2 路由规则详解

**MA方向判定统一标准**（替代§1.1与§2.1中分散的表述）：
- `MA_t − MA_{t−20} > +0.3%` → 向上
- `MA_t − MA_{t−20} < -0.3%` → 向下
- `|MA_t − MA_{t−20}| ≤ 0.3%` → 走平
- 本判定适用于MA200和MA30的方向判断

### A7 容差

0.5%容差（×0.995）。低价标的额外保护：容差 = max(0.5%, 0.05元/入场价)。

# V5.6 §3.1 进攻策略 (Spearhead Protocol)

> 归属：双轨配置最终执行法典 V5.6 §3.1 | 签发：2026-05-11
> 核心哲学：纯趋势跟随。不预判，只跟随。唯一防线 = 3×ATR trailing stop。

## 3.1.2 仓位与建仓

**资金池**：独立子账户，全局总资产的 10%–15%。

**R 定义**（风险单位，全文档统一）：
```
R = 3 × ATR    ← 入场价与3×ATR止损价之间的最大亏损距离
```

**汇率转换规则**：
```
对于美元计价标的（QQQ/IVV/BBJP/MUFG/EWY/VNM/FLIN/SMIN）：
  所有含「全局总资产」和「入场价/ATR」的公式，均需乘以 USDCNY 统一单位
  汇率 = USDCNY（当日9:15央行中间价，§1.4）

对于人民币计价标的（A股ETF）：
  USDCNY = 1，维持原公式
```

**首发仓位计算**：
```
若 ATR ≤ 0 → 中止，数据异常
若 3×ATR ≥ 入场价 → 中止，波动率过大不适合进攻建仓

美元标的：N₁ = floor((全局总资产(CNY) × 1%) / (3 × ATR(USD) × USDCNY))
人民币标的：N₁ = floor((全局总资产 × 1%) / (3 × ATR))
注：美股ETF支持碎股交易，不追加整数倍取整
```

**单标上限截断**：
```
美元标的：
  若 N₁ × 入场价(USD) × USDCNY > 全局总资产 × 8%
    → N₁ = round(全局总资产 × 8% / (入场价(USD) × USDCNY), 2)

人民币标的：
  若 N₁ × 入场价 > 全局总资产 × 8%
    → N₁ = floor(全局总资产 × 8% / 入场价)
    → 再取整 floor(N₁ / 100) × 100（100股整数倍）。若取整后 N₁ = 0，标记「资金不足-跳过」，中止该标的建仓
```

**进攻资金池二次截断**：
```
进攻已占用总市值(CNY) = Σ(各进攻标的持仓股数 × 当前市价 × 汇率因子)
  汇率因子 = USDCNY（美元标）/ 1（人民币标）
若进攻已占用总市值 > 全局总资产 × 15% → 按持仓时间优先压缩：
  1. 最近建仓的标的触发减仓至该标单批N₁的50%
  2. 若仍超，继续压缩次新标的
  3. 截断后进攻总暴露 ≤ 全局总资产 × 15%

执行方式：按标的流动性分档（与§3.1.3跳空缺口TWAP分档一致）：
  >1亿美元日均成交额 → 1分钟TWAP
  1000万–1亿美元 → 5分钟TWAP
  <1000万美元 → 市价单立即执行
  A股ETF（含588000/513770/159545/159302等）统一归入>1亿美元档，不受美股小盘流动性分档约束
```

**加仓序列（反等价鞅 — 盈利加仓）**：

| 批次 | 触发条件 | 数量 |
|:---|:---|:---|
| 第一发 | 入场信号触发 | N₁ |
| 第二发 | 浮盈 ≥ 2×R（即股价−第一发入场价 ≥ 2×3×ATR） | N₁ × 50%（递减） |
| 第三发 | 股价相对第二发入场价再涨 ≥ 1×R（即股价≥第二发入场价+3×ATR） | N₁ × 25%（再递减） |

**单标上限 — 8% 硬顶**：

| 铁律 | 内容 |
|:---|:---|
| 一 | 总暴露（N₁+N₂+N₃）× 入场价 / 全局总资产 ≤ 8% |
| 二 | N₁ 占满 8% → 终生禁止加仓该标的 |
| 三 | N₁ + N₂ 达 8% → 永久取消第三发 |
| 四 | 严禁为凑三发主动压减 N₁ |

## 3.1.3 离场机制 — 唯一防线

**3×ATR Trailing Stop**：
```
买入即挂载：建仓以来最高收盘价回撤 3×ATR 追踪止损
  → 最高收盘价定义：建仓日至今每日收盘价的最大值，不含盘中最高价
  → R值锁定：ATR = 建仓日ATR(14)，全程锁定不变。每日追踪止损线 = 最高收盘价 − 3×建仓日ATR
触线 → 市价全清，无例外
未触线 → 死咬利润，不设上限
```

**跳空缺口执行条款**：若开盘价 ≤ 止损线 − 0.5×ATR（隔夜跳空直接击穿止损线），触发后按标的流动性分档执行：

| 日均成交额 | 执行方式 |
|:---|:---|
| >1亿美元（QQQ/IVV） | 1分钟TWAP，每30秒采样一次 |
| 1000万–1亿美元（BBJP/EWY/VNM/510300/510500/159915/513180/513910/588000/513770/159545/159302） | 5分钟TWAP，每60秒采样一次 |
| <1000万美元（FLIN/MUFG） | 市价单立即清仓（流动性枯竭时价格优先于时间） |

**废除的冗余防线**（全部移除）：
- ❌ MA30 跌破离场
- ❌ 时间止损
- ❌ MA200 转势离场
- ❌ 固定止损等1R

**不加。** 子账户隔离已定价尾部风险（10%–15%资金池），3×ATR双向滞后，纯跟随哲学。

## 3.1.5 与反击策略冲突解决

```
ATTACK_LOCKED：进攻持仓中

    - 反击策略对该标的保持 ATTACK_LOCKED（禁止建仓），防止一标双轨

ATTACK_UNLOCKED：进攻清仓后
  → 反击策略恢复对该标的的完整管辖权（SRC计数重置）
```

|:---|:---|:---|:---|

| **SRC-3** | 买入后该标的属地市场60个交易日未触发SRC-1/2/4/5的任何一项 | 市价全清 | 时间止损，防止资金无限锁定。60日按标的属地市场交易日计数（美股按NYSE日历，A股按上交所日历）。停牌日不计入，连续停牌>20交易日→标记『SRC-3待执行』，于复牌后首个交易日集合竞价阶段市价全清；或启动场内赎回通道（若为ETF） |
| **SRC-4** | 标的所属属地宏观闸触发（见§2.1步骤0） | 市价全清 | 宏观熔断清仓 |
| **SRC-5** | 全局熔断（US10Y≥5.00% 或 VIX≥35） | 市价全清 | 全局清仓（固定层豁免） |

**SRC统一兜底规则**：
- 所有SRC触发后天数计数重置为0
- 多个SRC同时触发 → 按编号从小到大执行（SRC-1优先于SRC-2）
- SRC-4/5执行后该标的进入60日冷却期（不重新进入买入区间判定）
  - 冷却期内，若触发该SRC的宏观闸条件连续3日解除 → 提前终止冷却期，下一交易日恢复买入区间判定
- SRC-1/2/3执行后无冷却期，下一交易日即可重新判定

**SRC-1卖出入场公式**：
```
卖出价 = 持仓均价 × (1 + sell_k × ATR / 持仓均价)
          = 持仓均价 + sell_k × ATR
```
sell_k逐标差异化参数见下表：

| 梯队 | sell_k | 适用标的 |
|:---|:---:|:---|

| T2 | 0.5 | BBJP、MUFG、510500 |
| T3 | 1.0 | 159915、588000、513180 |
| T3-A | 1.5 | EWY |
| T3-B | 2.0 | 513770、159302 |
| T4 | 1.0 | VNM、FLIN |
| 禁购 | 1.0（继承T4） | SMIN（已有持仓SRC-1止盈使用） |
