## §0 固定层宪法

> 定位：VEA（20%）+ VTI（10%）构成全局资产的固定底仓层，总权重 30%

### 0.1 宪法地位

固定层具有以下不可侵犯属性：

| 属性 | 内容 |
|:---|:---|
| **路由豁免** | 不进入第二段路由判断。永远不被分配到进攻/反击/闲置轨道。**空仓例外（V5.8.2r15）**：若持仓为零 → 临时进入路由判定，建仓后恢复豁免。详见路由§2.0 |
| **策略豁免** | 不适用 Spearhead/Counterpunch 的任何入场/离场规则 |
| **止损豁免** | 不设 ATR 止损、绝对底线止损、动态止盈——不设任何技术指标驱动的自动离场条件 |
| **宏观熔断豁免** | US10Y≥5.00% 宏观闸对固定层无效 |
| **战时满载豁免** | S1/S2 满载态不改变固定层权重 |
| **唯一操作** | 仅执行年度再平衡（恢复至 VEA 20% / VTI 10% 目标权重） |
| **卖出禁令** | **任何情况下不得清仓固定层**（年度/偏离再平衡中的卖出超配部分不属于「清仓」，属于「权重修正」，被豁免于本禁令） |

### 0.2 再平衡触发条件

| 触发类型 | 条件 | 操作 |
|:---|:---|:---|
| **年度再平衡** | 每年 12 月首个 NYSE 交易日 | VEA 恢复至 20%，VTI 恢复至 10%。若该日 A 股休市，顺延至下一 A 股交易日执行美股交易指令 |
| **偏离触发** | 任一标的权重偏离目标 ±5pp（VEA<15% 或 >25%，VTI<5% 或 >15%） | 立即再平衡至目标权重 |
| **新增资金** | 全局总资产因外部注资增长 ≥20%（比较基准：上次再平衡日的全局总资产。V5.8.2r11锚定） | 恢复至目标权重。缺口优先用新增资金填补。新增资金不足时，按§0.4资金池竞争仲裁从现金层划拨（可动用至5%硬底）。仍不足时标记「现金不足-待注资」，暂停再平衡 |

**互斥条款**：年度再平衡日若偏离触发同时满足 → 仅执行年度再平衡一次，偏离触发顺延至下一交易日校验。

### 0.3 再平衡执行规则

```
1. 计算当前 VEA/VTI 市值
2. 计算目标市值 = 全局总资产 × 目标权重（20%/10%）
3. 差额 = 目标市值 − 当前市值
4. 正差额 → 从现金账户划拨资金买入。若现金不足，暂停再平衡，标记「现金不足-待注资」，不卖出其他资产。
   固定层再平衡为宪法义务，优先于§0.5现金主权率管理——
   再平衡可动用现金直至现金主权率降至 5% 为止，严禁击穿 5% 硬底。
   5% 硬底为终极防线，任何情况（含P0指令）不可突破。
5. 负差额 → 卖出超配部分，资金回笼现金账户
6. 执行后固定层权重精确恢复至 20% + 10%
```

### 0.4 全局资产分层架构

```
全局资产
├── 固定层 30%（VEA 20% + VTI 10%）← 宪法管辖，永不离场
├── 竞争上岗池（进攻 + 反击，资金动态进出）← 双轨法典管辖
├── 豁免层（IAU + 518880）← 独立核算，不参与路由
└── 现金层（不在仓的所有资金，用户自行管理停放）
```

**固定层不计入竞争上岗池可用资金。豁免层独立核算，不计入竞争上岗池。**

**跨币种市值转换（全局适用）**：
```
美元标的 CNY市值 = 持仓股数 × 当前市价(USD) × USDCNY
人民币标的 CNY市值 = 持仓股数 × 当前市价(CNY)
```

```
现金层市值 = 全局总资产 − 固定层市值 − 已占用进攻仓位市值 − 已占用反击仓位市值 − 豁免层市值
```

### 资金池竞争仲裁

当多个资金需求方同时申请资金时，按以下优先级排队：

```
P1：固定层再平衡（宪法义务，最高优先级）→ 可动用现金至5%硬底
P4：反击新开仓（需现金主权率>5%）→ 同优先级按路由时间戳先到先得
P5：进攻新开仓（需现金主权率>5%）
P6：豁免层买入（IAU/518880 P0指令）→ 服从§0.5.2状态机：状态A全速/状态B半速/状态C禁止。不单独设置现金主权率门槛（V5.8.2r11修复：删除原>8%硬编码，消除与状态B的死锁）
```

**止损回补说明**：SRC触发后持仓清仓，资金自动回笼现金层，提升P4/P5/P6可用额度。止损回补为资金释放事件，非资金需求方，不参与排队竞争。原P2/P3编号已废弃。

**P6与状态机统一规则（V5.8.2r11修复）**：原P6「需现金主权率>8%」与§0.5.2状态B（5%<≤8%时允许半速执行）互斥——状态B说可以，P6说不行。修复：删除P6的>8%硬编码，豁免层买入统一服从§0.5.2三态裁决。状态A正常执行，状态B半速消耗，状态C禁止一切买入。

### 0.5 现金主权率管理

#### 0.5.1 定义

```
现金主权率 = 现金层市值 / 全局总资产
硬底线 = 5%
```

#### 0.5.2 硬底线执行规则 【V5.7修复③】

```
状态 A：「正常」— 现金主权率 > 8%
  → 所有操作正常执行

状态 B：「警戒」— 5% < 现金主权率 ≤ 8%
  → 固定层再平衡正常执行。非固定层操作可执行但半速消耗。已有持仓止损/止盈正常
  → 半速消耗定义：非固定层单笔开仓金额 = 正常计算值 × 50%。若正常计算值 × 50% < 最小交易单位（A股100股/美股0.01股），则标记「半速消耗-资金不足」，暂停该笔开仓

状态 C：「硬底触及」— 现金主权率 ≤ 5%  【V5.7修复：触发条件从=5%改为≤5%】
  → 暂停一切非固定层操作
  → 已有持仓的止损/止盈仍可执行
  → 固定层再平衡：
    - 现金主权率 < 5%（硬底击穿）：仅允许卖出操作（含固定层超配卖出、非固定层止盈/止损），禁止一切买入。优先通过卖出恢复至5%硬底。若所有持仓已清仓仍未恢复→标记「硬底击穿-待注资」
    - 现金主权率 = 5% 时：仅允许执行「卖出超配」（负差额），资金回笼现金层。
      禁止执行「买入缺口」（正差额），标记「硬底触及-买入暂停」。
      执行逻辑：正差额买入必然消耗现金→现金主权率数学上<5%→击穿硬底。
    - 5% < 现金主权率 ≤ 8%：固定层再平衡可动用现金，但动用后不得低于 5% 硬底。
      若正差额缺口 > (当前现金主权率 − 5%) × 总资产，则部分执行至 5% 边界，剩余缺口标记「现金不足-待注资」。
    - 5% 硬底本身为终极防线，任何情况（含 P0 指令）不可突破
  → 恢复至「警戒」需现金主权率回到 >5%；恢复至「正常」需 >8%
```

**P0 指令覆盖边界**：P0 不可覆盖现金主权率 5% 硬底线。

## §1 数据输入层 (Data Input)

> 功能：21 只标的每日收盘价、EMA、ATR、成交量等标准化数据包的接收与计算

### 1.1 自主计算层

系统基于 Tushare 日线数据自主计算以下技术指标：

| 指标 | 计算方法 | 数据源 |
|:---|:---|:---|
| 50EMA/150EMA/30EMA | 递归EMA公式 | Tushare pro.us_daily / pro.fund_daily / pro.index_daily |
| ATR(14) | Wilder平滑法 | Tushare |
| H20（20日最高价） | max(Close[-20:])，不含当日 | Tushare |
| 20日均量 | mean(Volume[-20:]) | Tushare |
| RSI(6) | Wilder方法 | Tushare |
| MACD Hist | 12-26-9 | Tushare |
| 乖离率 | (C−150EMA)/150EMA | Tushare |
| 800005/000922等宏观锚定指数 | 日线OHLCV | Tushare指数接口，每日更新 |

### 1.1.1 扫描前数据完整性强制校验（V5.8.2r6焊入）

**规则一：拉取即填表**
Tushare数据拉取成功后，必须在30秒内将OHLCV/EMA/ATR/H20/20日均量填入标的分析表格对应列。禁止数据已在内存但表格列为"—"。

**规则二：MA锚线自算义务**
各标的锚线方向（如MA20方向、MA60方向）必须基于拉取的OHLCV数据自行计算。禁止输出"⏳需P0"占位符。唯一例外：当日收盘价尚未被Tushare收录时标注"Tushare最新:YYYY-MM-DD"。

**规则三：表格输出前自检清单**
```
□ 所有EMA列均无"—"占位符
□ 所有MA锚线方向无"⏳需P0"占位符
□ 所有ATR列已填充数值
□ 所有H20/20日均量列已填充数值
□ 数据缺口标注格式统一（"EMA基值日期: YYYY-MM-DD (T-1)"）
□ Tushare最新日期已统一标注
```

**规则四：违规熔断**
表格输出中出现"—"/"⏳需P0"/"待算"占位符 → 立即中止输出，重新计算填表后重新输出。累计违规≥3次 → 当日剩余报告禁止输出，标记「数据完整性违规-暂停报告」。
